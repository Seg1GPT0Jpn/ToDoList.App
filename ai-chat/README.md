# MyAI チャット

スマホやPCのブラウザの中だけで動く、自分専用のAIチャットアプリ(PWA)です。

- **APIキー不要・無料**: AIモデルを端末にダウンロードし、端末のGPU(WebGPU)で動かします
- **プライバシー**: 会話はどこにも送信されず、端末内(localStorage)だけに保存されます
- **オフライン対応**: 一度モデルをダウンロードすれば、ネットがなくても使えます
- **AIのキャラクター設定**: 名前・性格・ルール(システムプロンプト)・創造性を自由に変更可能
- 複数の会話の管理、会話の書き出し(JSON)、生成の停止、思考過程の表示(Qwen3)

推論エンジンには [WebLLM](https://github.com/mlc-ai/web-llm) を使っています。

## 使い方

1. このフォルダを HTTPS で公開します(例: GitHub Pages を有効にして `https://<ユーザー名>.github.io/ToDoList.App/ai-chat/` を開く)
2. ☰ メニューを開き、モデルを選んで「読み込む」を押す(初回のみ数百MB〜数GBをダウンロード)
3. 話しかける
4. スマホではブラウザの「ホーム画面に追加」からアプリとしてインストールできます

### 対応環境

WebGPU が使えるブラウザが必要です。

- PC: Chrome / Edge の最新版
- Android: Chrome の最新版
- iPhone / iPad: iOS 26 以降の Safari

### モデルの選び方

| モデル | 目安のサイズ | 特徴 |
|---|---|---|
| Qwen3-1.7B | 約2GB | **おすすめ**。日本語が自然で、スマホでも動きやすい |
| Qwen2.5-1.5B-Instruct | 約1.6GB | 軽くて安定している |
| Qwen3-4B / Qwen2.5-3B | 約3〜4GB | より賢いが、ハイエンドの端末やPC向け |
| Qwen3-0.6B / Qwen2.5-0.5B | 約1GB未満 | 古いスマホ向け。精度は低め |

★印が付いているのが日本語におすすめのモデルです。読み込みに失敗する場合は、メモリ不足の可能性があるので小さいモデルを選んでください。

## 「独自のAI」にするには

ChatGPT のようなモデルを一から学習するには、数千億〜数兆語の文章データと、数億円規模のGPU計算が必要です。個人で現実的なのは次の3段階で、このアプリはその土台になっています。

1. **キャラクター設定(今すぐ可能)**: メニューの「AIのキャラクター設定」で名前・口調・専門分野・禁止事項などを書くだけで、振る舞いが大きく変わります。
2. **ファインチューニング(本格的な独自モデル)**: 公開されているモデル(Qwen など)に、自分で用意した会話例(数百〜数千件)を追加学習させます。
   - Google Colab の無料GPUと [Unsloth](https://github.com/unslothai/unsloth) などを使うと、LoRA という手法で数十分〜数時間で学習できます
   - 学習データは `{"messages": [{"role": "user", ...}, {"role": "assistant", ...}]}` の形式で用意します。このアプリの「会話を書き出し」で出力したJSONも素材にできます
3. **自作モデルをこのアプリに組み込む**: 学習したモデルを [MLC LLM](https://llm.mlc.ai/docs/compilation/convert_weights.html) で WebLLM 用に変換し、Hugging Face にアップロードします。その後 `app.js` の `CreateMLCEngine` に `appConfig` として自分のモデルのURLを追加すれば、このアプリで動かせます。
