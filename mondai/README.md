# プリント作成（問題プリント作成ソフト）

問題データ（zip）を読み込んで、問題をえらび、問題用紙・解答用紙・解答解説を印刷（PDF保存）するブラウザアプリです。インストールは不要です。

## つかいかた

1. `mondai/index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. **① データ**：もらった zip ファイルをそのままドロップ（3つまとめてOK）
3. **② 問題をえらぶ**：教科・科目・学年・単元・難易度・形式・キーワードでしぼりこみ
   - 1問ずつ「＋追加」、または「ランダムに追加」で 基礎◯問・標準◯問・応用◯問 のように自動で選ぶ
4. **③ 単語・用語テスト**：単語帳・用語カードから範囲と問題数を指定してテストを作る
   - 意味を書く／見出しを書く／4択／例文の空所補充
5. **④ プリント**：見本を見ながら設定して「印刷する／PDFで保存」
   - 1段・2段、選択肢の記号（ア・1・A）、選択肢の入れかえ、解答欄（問題の下／別紙の解答用紙）、解答・解説のつけ方、配点、文字の大きさ
   - 作ったプリントは名前をつけて保存しておける

## 読み込めるデータ

| データ | 中身 |
| --- | --- |
| かながわ教材（`kanagawa_question_data.zip`） | 中学・高校の単元プリント、授業・演習プリント、模試、共通テスト・二次対策（数式・図・表・長文つき） |
| つづりクエスト（`tsuzuri_questions.zip`） | 小中高の問題セット、後期中間の予想問題、単語帳、用語カード |
| 後期中間 予想問題（`export` の zip） | Scramble イディオムのデータ（単語・用語テストで使う） |

## データの扱い

- 問題データはこのリポジトリには**入れていません**（再配布不可・校内限定のデータがあるため）。
- 読み込んだデータは、そのブラウザの中（IndexedDB）にだけ保存され、どこにも送信されません。
- 別のパソコンやブラウザで使うときは、そこでもう一度 zip を読み込んでください。
- 数式の表示（KaTeX）と zip の展開（JSZip）にインターネット上の部品を使うので、初回はネットにつないで開いてください。
