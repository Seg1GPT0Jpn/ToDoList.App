# テスト方針と結果（TEST_STRATEGY）

| 種類 | 道具 | 場所 | 件数・結果（2026-10-31） |
| --- | --- | --- | --- |
| 単体テスト（ロジック） | Vitest | `tests/unit/*.test.js` | 111 件 成功 |
| データベース・認証・権限テスト | Vitest＋PGlite（実際の SQL を実行） | `tests/db/rls.test.js` | 48 件 成功 |
| 型検査 | TypeScript（`tsc --checkJs`） | `jsconfig.json` | エラーなし |
| E2E（統合・印刷・スマホ表示・回帰） | Playwright＋Chromium | `tests/e2e/run.mjs` | 28 件 成功 |
| Edge Function | `tsc --strict`（型のみ） | `supabase/functions/ai/` | 型検査のみ（実行は未確認） |

## 必須シナリオとの対応
| シナリオ | テスト |
| --- | --- |
| 問題を登録・編集・検索できる | E2E「問題を登録できる」「編集すると版が上がり…」「絞り込める」 |
| 問題を教材に追加できる | E2E「複製・類似検出・教材への追加…」「用紙を設定できる」 |
| 教材を保存・再編集できる | E2E「自動保存」「開き直して再編集できる」 |
| 問題用紙・解答用紙・解答解説を出力できる | E2E「出力：…」「印刷用 PDF を出力できる」 |
| 配点合計が満点と一致する | 単体 `exam.test.js`（多数の組み合わせ）、E2E「テスト制作：…配点合計＝満点」 |
| AI 問題生成・検証 | 単体（検証の部品：検算・類似）、型検査。実際の AI 呼び出しは未確認 |
| AI 利用不可でも既存機能が動作する | E2E「AI 未接続でも…」 |
| 他ユーザーの非公開データを閲覧できない | DB テスト「personal workspace / materials / questions」 |
| チームメンバーの権限が正しく適用される | DB テスト（閲覧者・編集者・レビュアー・管理者・オーナー） |
| 保存・復元が正常に動作する | E2E「バックアップを保存し、復元できる」「不正なバックアップは拒否」 |
| スマートフォン表示 | E2E「スマートフォン：…」（横はみ出しなし） |
| 既存機能の回帰 | E2E「移行」「内蔵問題」、単体 `builtin.test.js`（内蔵 3,840 問の検証） |
