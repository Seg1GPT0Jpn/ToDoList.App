# 画面設計（UI_UX_DESIGN）

## 構成
左のメニュー（スマホでは ☰ で開く）に 10 画面：ホーム／問題バンク／AIスタジオ／教材制作／テスト制作／解答・解説／ライブラリ／チーム／分析／設定・データ。URL は `#/画面名/引数?条件`。

## 方針
- 紙面（印刷物）は白・明朝体。画面は落ち着いた配色で、ライト・ダーク・端末の設定に合わせる、の 3 つから選べる（ダークモードでも紙は白）。
- 空の画面には次にすることを案内する（例：教材がない → 「新しい教材を作る」）。初回はホームに「はじめての方へ」とサンプル作成ボタン。
- 入力中のデータを守る：教材は自動保存（保存状態を見出しの下に表示）、未保存でページを離れると確認、元に戻す／やり直し、版の保存。
- エラーは日本語で具体的に表示し、操作履歴に記録する（設定・データ → 操作履歴・エラー記録）。
- 危ない操作（削除・置きかえ復元・公開）は確認してから行う。内蔵・取り込み問題の削除は非表示にするだけで元に戻せる。
- 見本は紙の幅に合わせて自動で縮小表示（印刷時は原寸）。
- キーボード：Ctrl+Z／Ctrl+Y（元に戻す・やり直し）、Ctrl+P（教材の印刷）、Esc（ダイアログ・メニューを閉じる）。ボタン・入力欄はすべてタブで移動できる。
- スマホ：1 列表示、メニューは引き出し式、横にはみ出さない（E2E で確認）。

## 主な画面
| 画面 | 中身 |
| --- | --- |
| ホーム | はじめての案内／作業中の教材・承認待ち・要修正・レビュー待ちの数／最近の教材／最近の問題／AI 履歴／最近の操作／ショートカット |
