# 開発全体計画（DEVELOPMENT_MASTER_PLAN）

## 目標
既存の「プリント作成」アプリを、問題バンク・教材制作・テスト制作・解答解説・AI・チーム・分析を備えた教材制作プラットフォームにする。既存の機能とデータは残す。

## 決めたこと（2026-10-31、ユーザーの選択）
- サーバー：**Supabase（無料枠）**。権限はデータベースの行単位セキュリティで強制。
- AI：**Claude（Anthropic）**。API キーは Supabase Edge Function の秘密情報にだけ置く。
- 進め方：優先度順に作り、区切りごとに公開。

## 順番を変えた点と理由
- Phase 3（AI）と Phase 4（テスト制作）は並行して作った。AI の検証に使う類似検出・検算は Phase 1 の部品なので先に用意した。
- TypeScript への全面移行はしない。ビルド工程を入れると GitHub Pages の公開方法を変える必要があり、既存の利用環境を壊すため。代わりに JSDoc 型注釈を `tsc --checkJs` で検査する（`docs/SYSTEM_ARCHITECTURE.md`）。
- Firebase ではなく Supabase を使う。Firebase では AI 用のサーバー処理（Cloud Functions）に有料プランが必要なため（ユーザーが選択）。
