# BGM を自分の曲にする

今の BGM は `tools/audio/compose.py` でプログラム合成したオリジナル曲です。
同じ名前のファイルを置きかえれば、アプリの中の曲がそのまま入れかわります（コードの変更は不要）。

## 曲の一覧（`rpg_game_app/assets/audio/`）

| ファイル | 流れる場所 |
| --- | --- |
| `bgm_home.mp3` | ホーム（ワールドマップ）・英語以外で専用曲のない画面 |
| `bgm_field_english.mp3` など6つ | 各教科のフィールド（english / science / social / japanese / math / information） |
| `bgm_battle.mp3` **または** `bgm_battle_piano/bass/drums/strings.mp3` | ふつうのバトル |
| `bgm_boss.mp3` **または** `bgm_boss_piano/bass/drums/strings.mp3` | ボス戦 |

- バトル・ボスは、**1つのファイル**（`bgm_battle.mp3` / `bgm_boss.mp3`）を置けば、それがそのまま流れます
- 4つのパート（ピアノ・ベース・打楽器・ストリングス）に分けて置くと、「正解を続けるほど楽器が増える」演出になります。
  4つとも**同じ長さ・同じテンポ**で書き出してください（同時に鳴らして重ねるため）

## 曲を作るときのコツ

- 形式：mp3（44.1kHz、128〜192kbps くらい）。1曲 1〜2分、ファイルは 1〜3MB 程度に
- くり返し再生されるので、**最後から最初へ自然につながる**ように作る（最後の小節を最初の小節につながるコードで終える）
- 音量をそろえる（どの曲も同じくらいの大きさに。大きすぎると効果音が聞こえにくい）
- mp3 は先頭に小さな無音が入ることがあります。ループのつなぎ目が気になるときは、書き出し時に先頭の無音をけずる

## 権利について（有料アプリで使うので大事）

- 音楽生成 AI を使う場合は、**そのサービスの利用規約で「商用利用できるか」**を必ず確認してください
  （無料プランは商用不可、有料プランなら可、というサービスが多いです）
- 既存の曲のメロディをまねたり、「〇〇（アーティスト名）風」で作ったものは避ける
- 作った曲の情報（使ったサービス・プラン・作った日）をメモしておくと、あとで安心です

## 入れかえ方

1. 作った曲を、上の表の名前にして `rpg_game_app/assets/audio/` に上書きで置く
2. `flutter run`（アプリを止めて起動しなおす。ホットリロードでは音は入れかわりません）
3. GitHub に上げるなら `git add rpg_game_app/assets/audio && git commit -m "BGM を入れかえ" && git push`

## Claude と一緒に作る場合

`tools/audio/compose.py` は、音符とコードを書くと曲を合成する仕組みです。
「明るくて少し切ない、テンポ120くらいの草原の曲」「サビでこういうメロディ（ドレミで）」のように伝えてもらえれば、
Claude がこのファイルを書きかえて曲を作りなおせます。聞いてみて「もっとゆっくり」「ここを明るく」と直していく、
という進め方ができます（できあがる音はシンプルな電子音です）。
