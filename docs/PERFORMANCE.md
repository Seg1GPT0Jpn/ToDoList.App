# 軽量化・高速化の記録（2026-10-30）

フル版（`rpg_game_app`）とつづりクエストLight（`tsuzuri_light`）の Web 版を計測し、効果を確かめながら直したこと。
機能・見た目・操作は変えていない（Light は白黒化と、冒険のマップ・単語チャレンジを外している。`LIGHT.md`）。

## 計測のしかた

- Chromium（ヘッドレス）・画面 412×860。CPU は「そのまま」と「4倍遅く（スマホ相当）」の2通り。
- 最初の画面：`flutter-first-frame` までの時間。
- 何もしていないとき：ホームを出して10秒間の CPU 時間（`Performance.getMetrics` の TaskDuration）と、1秒あたりの描きなおし回数（requestAnimationFrame の回数）。
- 通信量：同梱ファイルは brotli で圧縮した大きさ（本番の Firebase Hosting と同じ）。外部（gstatic など）は実際に受けとった大きさ。
- ヘッドレスでは GPU を使わず CPU で描くので、CPU 時間の絶対値は実機より大きい。前後の比べ方として見る。
- メモリ（JavaScript のヒープ）は計測ごとにぶれが大きい（±10MB 程度）。

## 見つけた問題

| 重大度 | 問題 | 対象 | 直したか |
| --- | --- | --- | --- |
| 最重大 | BGM が鳴っている間、audioplayers が再生位置を知らせるために**毎フレーム描きなおしを予約**していた。何もしていないホームでも毎秒約60回、画面全体を描いていた（CPU ほぼ100%） | フル版 | 直した |
| 大 | JS 版で公開していた。WebAssembly 版のほうが起動が速く、メモリが少ない | フル版 | 直した |
| 大 | オフライン・通信が遅いとき、クラウドの準備を最大8秒待ってからホームを出していた（8秒をすぎてつながっても、クラスルーム・対戦などは使えないままだった） | フル版 | 直した |
| 中 | フォントを読みこむ前に字を描くため、足りない字を中国語用の Noto などから十数回（約0.5〜0.75MB）取りに行っていた | 両方 | 直した |
| 中 | 飾りの動き（ホームの絵・足ぶみする主人公）の時計が別々のタイマーで動き、描きなおしが毎秒 15＋12 回に分かれていた | フル版 | 直した |
| 中 | `RpgServices` を作りなおすと（クラウドにつながったとき）、学習の記録・「NEW」・連続記録などの部品が新しく作られ、古いものと分かれてしまう | 両方 | 直した |
| 小 | 描画エンジンが英字フォント（Roboto、約73KB）と同梱ファイルの一覧を別に読んでいた | Light | 直した |
| 小 | フル版のアイコン画像が大きい（192px で 62KB、512px で 264KB） | フル版 | 直した（256色） |
| — | 冒険のマップ（Flame）は、止まっていても毎秒60回描く | フル版 | そのまま（下の「残っていること」） |

## したこと

| 変更 | ファイル |
| --- | --- |
| 音のプレイヤーの再生位置の追跡を止める（`positionUpdater = null`。このアプリは位置を使わない） | `rpg_game_app/lib/audio/player_backend.dart` |
| 飾りの時計を1つのタイマーにまとめ、描きなおしを同じフレームにそろえる | `rpg_game_app/lib/art/slow_clock.dart` |
| フォントを読み終えてから描く（フル版は本文・見出しを、クラウドの準備と同時に読む。最大8秒） | `rpg_game_app/lib/app/theme.dart`（`loadBodyFont`）・`rpg_game_app/lib/main.dart` |
| クラウドを待たずにホームを出し、つながったらログイン・クラスルーム・対戦・ランキングなどを差しこむ（`_CloudRoot`） | `rpg_game_app/lib/main.dart` |
| 作りなおしても同じ部品を使う（`_keep`）。回数の送り先はあとから差しこめる | `rpg_game_app/lib/app/services.dart`・`rpg_game_app/lib/app/usage_meter.dart` |
| フル版も WebAssembly 版で公開する（対応していないブラウザでは自動で JS 版） | `.github/workflows/deploy-web.yml` |
| フル版のアイコンを256色にする（見た目はほぼ同じ） | `rpg_game_app/web/icons/*`・`favicon.png` |
| Light：本文のフォントを Roboto の名前で登録し、google_fonts を使わない（`bundledSans`） | `tsuzuri_light/pubspec.yaml`・`tsuzuri_light/lib/main.dart`・`tsuzuri_light/assets/fonts/` |

## 残っていること・これからできること

- **冒険のマップ（Flame）は止まっていても毎秒60回描く**（CPU そのままで10秒あたり約4.6秒）。
  主人公が止まっている間だけ30回にすれば半分ほどになるが、風車・水などの動きのなめらかさが変わるので入れていない。
- Light で、Google ログインもクラスルームも使っていない人は Firebase（約0.25MB）を使わない。必要になるまで読まないこともできるが、
  ログインを押したときに読みこむと、ブラウザがログインのポップアップを止めることがあるので入れていない。
- 本文のフォント（0.73MB）は、すでに約4000字に絞ってある。さらに絞っても0.05MBほどしか減らない。
- 描画エンジン（1.18MB）は Flutter の Web 版に必要。2回目からはブラウザに残る。
- 実機（スマホ）での電池の減り方は計測していない。
