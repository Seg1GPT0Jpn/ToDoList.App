## 1. 現状調査（§0）

| 層 | 場所 | 中身 |

### 指示書との差（今回つくるもの）

1. **分類が浅い**：教科→科目→分野→単元→小単元の体系がデータとして存在しない（§2〜§4）
2. **問題に属性が足りない**：単元の所属、思考レベル、難しさの種類（知識・計算・読解・思考・初見・記述・時間）、出典の種類、対象学年、想定時間、関連問題、前提知識（§5・§37・§43・§44・§46）
3. **出題形式が4択と入力式だけ**（§38）
4. **ワンパン問題**：敵の強さが固定表、プレイヤーの攻撃はレベルだけで伸びる → レベル25ならどの教科のエリア1も1撃（§7・§8）
5. **敵39種**、役割が見た目に固定（§9・§10）
6. **背景オブジェクトの種類が少ない**、紙の質感がどこも同じ（§11・§12）
7. **6つの国の物語が薄い**（国民・守護者・忘却された理由・学ぶ理由）、NPC の役割が「地形ごとのあいさつ」中心（§13〜§15）
8. **単語帳がゲームと別物**（§16〜§18）
9. **総合演習（大問・配点・部分点・時間配分）がない**、弱点分析が単元単位まで、前提知識をたどる学習ルートがない（§45・§47・§48）

## 2. 壊してはいけないもの（互換性の約束）

- **ID は変えない**：問題 ID・問題セット ID・ステージ ID・ワールド ID・カード ID・装備 ID。学習記録・クリア状況・亡霊・宝箱はすべて ID で保存されている
- **セーブデータ**：`RpgProgress` の既存キーは読み続ける。新しい項目は「無ければ初期値」で追加し、移行が必要なときは読み込み時のマイグレーションで行う
- **著作権ガード**：RPG・課金コンテンツには `origin: original` だけ。LEAP・STEP の中身は同梱しない（ロック解除した端末の中でだけ使う）。ガチャ・ランダム課金は入れない
- **既存の遊び**：冒険・戦闘・カード・ボス連戦・宿・宝箱・泉・亡霊・復習の塔・海・空・共通テスト遺跡・試験ワールド・対戦・暗記カード・単語帳・実績・図鑑・装備・物語・設定・プロモコード・Google ログイン同期・Web 版
- **テスト**：コア 689件・アプリ 438件が通り続けること。`flutter analyze` で警告ゼロ

## 3. 設計方針

- **分類は細かく・マップは遊びやすく**：学習体系（カリキュラムの木）とゲームのマップ（ルート・エリア）は別のデータにし、エリアは「どの単元・小単元を出すか」を指すだけにする
- **コンテンツとロジックを分ける**：体系・問題・敵の種族・NPC・クエスト・物語はデータ（JSON または Dart の定数表）。敵を1体足すのに画面のコードを書き換えなくてよい形にする
- **段階的な移行**：新しい属性はすべて「省略可」。既存の問題はツールで体系に割り当てる（ファイル → 単元の対応表＋タグ）。古い形式の問題もそのまま読める
- **難しさは HP インフレにしない**：敵の HP を「必要な正解数」として決め、プレイヤーの強さは「教科の習熟度」で決まる部分を大きくする

### 技術的に難しい点と代わりの方法（§32）

- **記述・論述・証明の自動採点**：端末内だけでは正確な採点ができない。最初は「模範解答＋採点基準（チェックリスト）で自己採点」し、部分点を記録する。将来 AI 採点をつなげる口（採点インターフェース）を用意しておく
- **実際の過去問**：著作権の確認ができないため同梱しない。出典の種類は `officialStyle`（本番の形式にそろえた自作）・`original` を中心にし、`officialPastExam` は将来、利用条件を確認できたものだけを入れられる形にしておく
- **音声問題**：既存の読み上げ（flutter_tts）を使う。録音した音声ファイルは扱わない

## 6. フェーズ2の結果：難易度と成長（ワンパン対策）

| 項目 | 決め方 |
| --- | --- |
| 冒険Lv | これまでどおり全体の経験値。HP・守り（受けるダメージ）を決める |
| 習熟Lv | 科目（数学Ⅰ・化学・日本史…）ごとの経験値。その科目のエリアで得た経験値と、練習で正解した問題の科目の経験値がたまる |
| 戦闘Lv | 習熟Lv×0.6＋冒険Lv×0.4 |
| 与えるダメージ | 敵の推奨レベルでの攻撃力 ×（1＋0.05×（戦闘Lv−推奨Lv））。上限1.5倍・下限0.55倍 |
| 装備の攻撃 | 冒険Lvの攻撃力に対する割合に変換して掛ける |

- 敵の HP は一切ふやしていない。どのエリアも推奨レベルでは4問以上の正解が必要で、冒険Lv50・習熟Lv50でもすばやい正解1回では倒せない（最低3問）ことをテストで保証
- 学びのボーナス：思考レベル4以上の問題に正解するとダメージ +10%〜+50%・経験値 +3〜+15、苦手な単元（正答率70%未満）の問題に正解するとダメージ ×1.2・経験値 +3
- 既存のセーブデータは、クリア済みエリアの経験値をその科目の習熟として移行（`masteryVersion`）
- 練習のバトル（海・空・復習の塔・単元の練習）は、これまでどおり敵の HP がレベルに合わせて決まる

## 7. フェーズ3の結果：出題形式

| 形式 | JSON の書き方 | 採点 | 部分点 |
| --- | --- | --- | --- |
| 4択・入力式 | これまでどおり（`choices`・`answerIndex`・`accepted`） | 一致 | なし |
| 正誤 `trueFalse` | `truth: true/false`（判定する文は `sentence`） | 一致 | なし |
| 複数選択 `multiSelect` | `multiSelect: {options, correct}` | すべて一致 | （正しい選択−余分な選択）÷正解数 |
| 並べ替え `order` | `order: {items, joiner}`（items は正しい順） | 順序が一致 | となり合う順が正しい割合 |
| 数値入力 `numeric` | `numeric: {value, tolerance, unit}` | 許容誤差内（分数・指数・全角・単位つき可） | なし |
| 穴埋め `cloze` | `cloze: {text: "… [1] … [2]", blanks: [[…],[…]]}` | 全部の空らん | 正しい空らんの割合 |
| 段階問題 `multiStep` | `subQuestions: [4択, …]`（誘導） | 全部の小問 | 正しい小問の割合 |
| 記述 `written` | `written: {kind, modelAnswer, rubric:[{point,score}], passScore}` | 自己採点で合格点以上 | 得点÷満点 |

- 戦闘では、部分点が5割以上ならまちがいでも小さなダメージを与え、受けるダメージは半分
- 記述は模範解答と採点基準を見ている間、時間が止まる（自己採点の時間は数えない）。将来、自動採点をつなげられる形（Grader）
- 制限時間は形式で変わる（入力・並べ替え×2、複数選択×1.5、穴埋め×（空らん数＋1）、段階問題×小問数、記述×6）
- 4択しか出せない画面（宝箱・扉・泉・対戦・宿の授業・共通テスト遺跡の小テスト）には、4択以外の問題を出さない
- 見本：各教科の「追加問題」に新しい形式のセット（合計50問、最難関レベルの証明問題をふくむ）

- 単語の森（ホーム → 単語の森）：単語が魔物になって5体ずつ現れる。同じ単語を英→日・日→英・スペル入力・発音（読み上げ）の4つの形で出題し、正解すると攻撃。1語あたり約3問で倒せる
- 覚えぐあいは二択ではなく、形式ごとの正答・直近の結果・復習の箱から★0〜3で表す。忘れかけ（直近ミス・正答率60%未満・復習日到来）の単語は「忘却の塔（単語）」でまとめて再戦
- 単語コレクション：★2以上の単語が入る。出会っていない単語は「？？？」
- 単語の答えが学習記録に残るようにした（これまで定期テストの海の単語バトルの答えは記録されていなかった）。科目の習熟（英語）にも入る
- 使う単語は同梱の自作リストだけ。LEAP・EEVI は RPG・単語の森には使わない（従来どおり海・空の学習モードだけ）

## 12. フェーズ8の結果：問題の追加

- 6教科に新しい問題セットを12個（各教科 `*_v4_01` と `*_v4_02`）、合わせて354問を追加した。問題数は 9,870 問 → 10,224 問
- `*_v4_01`：問題が10問未満だった単元（英語の類義語・英作文・精読・実用文・入試、集合・命題・ユークリッドの互除法・空間図形、芳香族・有機の基礎・剛体、古代アメリカ・アフリカ・東南アジア、戦後日本経済、随筆、コミュニケーション、システムの信頼性）と、難関・東大レベルの問題（思考レベル6〜7、記述・証明・誘導・並べ替え・数値入力）

## 13. フェーズ9の結果：学習ルート・総合演習・成長の見える化

学習ステータス → 「成長と学習ルート」「総合演習」から開く。

- 成長の4つのものさし（`GrowthReport`）：初見正答率（初めての問題に1回目で正解）／応用問題（思考レベル4以上）の正答率／初見問題（初見度の高い問題）の正答率／定着率（3日以上あけて答えたときの正答率）。教科ごとにも見られる
- 学習の段階のはしご（`PhaseLadder`）：フェーズ1 基礎 〜 フェーズ7 東大。その段階の問題を10問以上・正答率70%以上で到達し、下から順にのぼる
- 学習ルート（`LearningRoute`）：正答率60%未満の単元から、学習体系の前提を最大4段さかのぼり、前提ほど前に並べる。いちばん前にある弱点を「根本の原因」として出し、そこから練習できる（例：数学Ⅱ 微分の応用 → 数学Ⅱ 微分 → 数学Ⅰ 2次関数のグラフ → 数学Ⅰ 式の計算）
- 複合弱点（`CompositeWeakness`）：2つの単元を組み合わせる問題（`combines`）でのつまずき。組み合わせる単元そのものが弱点なら「土台の弱点」、どちらも単独ではできていれば「組み合わせの弱点」と区別してすすめる
- 総合演習（`ExamPaper`・`ExamResult`）：第1部 基礎（3点×6問）・第2部 標準（5点×6問）・第3部 応用・発展（12点×2問）の3部構成、100点に換算。制限時間は問題の目安時間の合計。4択以外の形式もまじり、複数選択・並べかえ・段階の問題・記述は部分点。分野がかたよらないように選ぶ。終わると部ごと・分野ごと・思考の種類ごと・形式ごとの得点、複合弱点、問題の見直し（正解と解説）を出し、学習ルートにつなぐ。答えは学習記録に残る
- 学習記録に、問題の性質（思考レベル・初見・段階）と「間をあけて答えた回数・正解数」を足した。古い記録はそのまま読める（足した項目は0＝不明として扱う）
