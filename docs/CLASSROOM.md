# クラスルーム（設計メモ）

友だちと6ケタのコードで集まり、単語の小テスト・定期テストの「範囲と日付」をいっしょに準備する。

## 方針
- 共有するのは **単語帳の名前・番号の範囲・日付・ニックネームだけ**。単語の中身は共有しない（市販の単語帳を配らないため）。
  メンバーは自分の端末にある同じ名前の単語帳から出題する（名前は空白・大文字小文字を無視して照合）。
- 小テストは1週間前、定期テストは2週間前から、毎日の分を自動で出す（まだの単語 ÷ 前日までの日数 ＋ 範囲の復習）。前日と当日は範囲の全部を苦手順に「最終チェック」。
- 共闘ボス：範囲ごとに1体。体力 = 範囲の単語数 × 人数。メンバーの正解の **合計** で削る。だれが何問かはサーバーに置かない（自分の分は端末にだけ）。
- 未成年向けの安全：自由に文章を送る機能はない。ニックネームとクラス名は20字まで。学校名・クラス名は入れないよう案内。作った人はメンバーを外せる。報告ボタンあり。

## データ（Firestore）
- `classrooms/{6ケタ}`：`name`・`ownerId`・`ownerName`・`members`（ID→ニックネーム）・`tasks`（範囲の配列）・`closed`・`createdAt`・`expiresAt`（180日）
- `classrooms/{6ケタ}/boss/{範囲ID}`：`dealt`（正解の合計）

## ルール（firestore.rules）
- 読む：ログインしていてコードを知っている人（一覧は出せない）
- 作る：自分だけがメンバー・自分がオーナー・期限は181日以内
- 作った人：名前・範囲・閉じる・期限・メンバーを外す（自分は外せない）
- メンバー：自分の分だけ（入る＝閉じていない・期限内・40人まで／抜ける／ニックネーム）。作った人は抜けられない
- ボス：メンバーだけ読み書き。1回に足せるのは100まで、減らせない
- テスト：`rpg_game_app/test_rules`（`npm install && npm test`。Java が必要）36項目

## コード
- コア（描画なし）：`rpg_game/lib/src/classroom/classroom.dart`（範囲・クラス・今日の分・ボス）
- アプリ：`rpg_game_app/lib/classroom/`（置き場所の窓口・端末の記録・画面・お知らせ）、`lib/cloud/firestore_classroom_backend.dart`
- 入口：ホームの「冒険の手帳」の「クラスルーム」、単語帳ホームのボタン、招待リンク `?class=123456`（Web）

## 公開の手順
ルールを変えたので、PC で `firebase deploy --only firestore:rules --project tsuzuri-quest-v2` が必要（Web の自動公開ではルールは変わらない）。
