# 神奈川県検定（神奈川県知識向上委員会）

| ファイル | 内容 |
|---|---|
| `01_問題冊子.pdf` | 問題冊子（大問6題・全32問・100点） |
| `02_解答用紙.pdf` | マークシート型の解答用紙 |
| `03_解答と解説.pdf` | 正解・解説・記述の採点基準・認定基準・写真素材一覧・出典 |
| `questions.py` | 問題データ（ここを直して作り直す） |
| `figures.py` | 地図・グラフ・模式図を描く部品 |
| `data/kanagawa_map.json` | 県内33市町村の境界（国土地理院「地球地図日本」をもとに作成） |

## 写真の入れ方

1. `03_解答と解説.pdf` の「写真素材一覧」にあるぱくたそのページから写真をダウンロードする
2. `images/p01.jpg` 〜 `images/p14.jpg` の名前で保存する
3. `python3 build.py` を実行する（または `01_問題冊子.html` をブラウザで開いて印刷する）

## 作り直し

`python3 build.py` で HTML と PDF をすべて作り直します（PDF 変換には Node.js 版 Playwright を使用）。
