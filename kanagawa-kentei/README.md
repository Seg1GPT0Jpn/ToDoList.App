# 神奈川県検定

| ファイル | 内容 |
|---|---|
| `01_問題冊子.pdf` | 問題冊子（全41問・100点） |
| `02_解答用紙.pdf` | 解答用紙 |
| `03_解答と解説.pdf` | 正解・解説・認定基準・写真素材一覧 |
| `questions.py` | 問題データ（ここを直して作り直す） |

## 写真の入れ方

1. `03_解答と解説.pdf` の「写真素材一覧」にあるぱくたそのページから写真をダウンロードする
2. `images/p01.jpg` 〜 `images/p10.jpg` の名前で保存する
3. `python3 build.py` を実行する（または `01_問題冊子.html` をブラウザで開いて印刷する）

## 作り直し

`python3 build.py` で HTML と PDF をすべて作り直します。
