# 神奈川県検定（神奈川県知識向上委員会）

| ファイル | 内容 | 配布先 |
|---|---|---|
| `01_問題冊子.pdf` | 問題冊子（問1〜問8・200点満点。配点は非表示） | 受験者 |
| `02_解答用紙.pdf` | マークシート型の解答用紙（配点は非表示） | 受験者 |
| `03_解答と解説_受験者用.pdf` | 正答・解説・認定基準（得点率）・写真の出典 | 受験者（試験後） |
| `04_認定証.pdf` | ゴールド・シルバー・ブロンズ・参加賞の認定証 | 合格者・参加者 |
| `05_採点基準_採点者用.pdf` | 正答・配点・記述の採点基準・出題のねらい・認定基準（点数） | 採点者のみ |

## 作り直し

- `python3 fetch_images.py` … 写真を Wikimedia Commons から取得（作者・ライセンスは `images/credits.json`）
- `python3 gsi_maps.py` … 国土地理院の地図を作成
- `python3 build.py` … 01〜03・05 を HTML と PDF で出力
- `python3 certificates.py` … 04 の認定証を出力

問題は `questions.py`、図は `figures.py`、組版の部品は `layout.py` にあります。
