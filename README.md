# つづりクエスト for elementary and junior high school

小学1年生〜中学3年生の5教科（英語・算数数学・国語・理科・社会）を、ノートの世界を旅する
クイズ RPG で学ぶアプリです。高校生向けの「つづりクエスト」をもとに作りました。

- 5つの国 × 学年の道（小1〜中3）・約4,300問（すべて自作）
- 定期テストの海・高校入試の空・単語の森・対戦モード・復習の塔
- Flutter + Flame（Web と Android）

開発のしかたは [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) にあります。
