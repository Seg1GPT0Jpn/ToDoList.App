# 定期テスト

`tests/<テスト名>/<番号>_<教科>.md` に1教科1ファイルで書く。PDF にするには：

```bash
python3 textbooks/tools/build_tests.py 小5_2学期期末
```

出力は `books/テスト/<テスト名>_<番号>_<教科>.pdf`。1ページ目から問題、「## 解答と解説」から後ろは新しいページ（先生用）。

## 書き方（全教科共通）

- 対象：神奈川県の公立小学校5年生（教科書は東京書籍）。11月下旬の **2学期期末テスト**。**将来、湘南高校（神奈川県公立トップ校）に入る子を想定**したレベル：学校の単元テストで満点を取る子が、さらに考えないと解けない問題を混ぜる（基本4：標準4：思考・発展2）。基本でも「なぜそうなるか」を問い、思考問題は中学受験の標準〜やや難レベル・神奈川県公立入試の思考力問題のつながり（資料を読み比べて説明する・条件を整理する・理由を記述する）を意識する。ただし範囲外の知識は使わせない（範囲内の知識を組み合わせて解く）。目標：その子たちで平均65〜75点。
- 時間 45分・100点満点。配点の合計がちょうど100点になること（必ず足し算して確かめる）。
- A4 で問題は2〜3ページ（解答欄をふくめて）。問題用紙に直接書きこむ形式。
- 冒頭は必ず次の形（教科名と範囲だけ変える）：

```html
<div class="t-head">
<div class="t-title">小学5年　2学期 期末テスト　算数</div>
<div class="t-row"><div class="t-info">時間 45分<br>100点満点</div><div class="t-name">名前</div><div class="t-score"><br>／100</div></div>
</div>
<p class="t-range">出題範囲：〇〇・〇〇・〇〇</p>
```

- 大問：`#### <span class="no">1</span> 指示文。 <span class="haiten">各3点（計12点）</span>`
- 小問は (1)(2)… 。2列に並べたいときは `<div class="cols2" markdown="1"> … </div>`（中の各行は改行で区切る）。
- 解答欄：短い答え `<span class="ans-box"></span>`、長め `<span class="ans-box w2"></span>`／`w3`。
  文で答える欄 `<div class="kaku"></div>`（2行分は `<div class="kaku tall"></div>`）。算数の式の欄 `<div class="shiki"></div>`。
- 読む文章・資料は `<div class="honbun" markdown="1"> … </div>`。表は Markdown の表。図はインライン SVG（`<figure><svg …>…</svg></figure>`、白黒）。
- `<div … markdown="1">` の前後には空行を入れる。
- 最後に：

```markdown
## 解答と解説

<div class="kaito" markdown="1">

#### <span class="no">1</span>
(1) 答え　…ひとこと解説（つまずきやすい点・採点の目安：部分点の出し方）
…
</div>
```

- 正確さが最優先。答えと問題・図・資料の数値が必ず一致するよう、書いたあと全問を自分で解き直して確かめる。

## 湘南高校の定期テスト（予想問題）の形式にそろえる（2026-11 追加・最優先）

**注意：作るのは「予想問題」ではなく実際の定期試験。** 「予想問題」「難化版」「本番より難しい」などの言葉、問題の種類を示すラベル（中学入試・湘南型・実験改・架空のデータ など）は書かない。形式（用紙・書体・レイアウト・表紙・注意書き・解答用紙・解答解説）だけをまねる。

**いちばん大事：`tests/見本/` に教科ごとの見本ファイル（1_国語.md・2_算数.md・3_理科.md・4_社会.md・5_英語.md）がある。
自分の教科の見本のマークアップ（クラス名・構造・見出しの書き方・表紙・解答用紙）をそのまま写して使うこと。**
見本の PDF は `python3 tools/build_tests.py 見本` で `books/テスト/見本_*.pdf` にできる。用紙・書体は教科ごとに自動で切りかわる
（算数 A3縦・明朝・2段組／国語 A4横・縦書き／英語 A4・Times／理科 A4・ゴシック／社会 B5・ゴシック）。
HTML のブロック（div・table）の中で Markdown を使うときは `markdown="1"` をつけ、入れ子の div は1行で閉じるか、純粋な HTML で書く。

ユーザーから届いた湘南高校1年の定期テスト予想問題（国語・数学Ⅰ・英語コミュニケーションⅠ・生物基礎・地理総合）の形式をまねる。
**上の「冒頭は必ず次の形」「大問の書き方」は、この節の形式で置きかえる**（解答欄の部品 ans-box・kaku・shiki、配点合計100点、「## 解答と解説」から先生用、は同じ）。
使える部品（tools/test.css）：

| 部品 | 書き方 |
|---|---|
| 上の帯（タイトル行） | `<div class="t-band"><b>小学5年　算数　2学期期末テスト <span class="tag">予想問題</span></b><span>令和8年　月　日（　）　校時 実施</span></div>` |
| 黒いラベル／白ぬきラベル | `<span class="tag">中学入試</span>` ／ `<span class="tag w">プリント改</span>` |
| 注意の枠 | `<div class="chu" markdown="1">★注意★ …</div>` |
| 四角の大問番号 | `<span class="bn">1</span>` |
| 黒の「問1」 | `<span class="mon">問1</span>` |
| 四角の空欄記号 | `<span class="kuuran">ア</span>` |
| 2段組 | `<div class="two-col" markdown="1"> … </div>` |
| 解説の見出し帯 | `<div class="band">1　分数のたし算</div>`（薄い帯は `band light`） |
| 大問の見出し（理社英） | `<div class="t-sec">Ⅰ　流れる水のはたらき【16点】 <span class="tag w">実験</span></div>` |
| 表紙（1ページまるごと） | `<div class="t-cover" markdown="1"> … </div>` |
| 解答用紙（新しいページ） | `<div class="sheet" markdown="1"><div class="sheet-title">記述式解答用紙</div> …表… </div>` |
| 原稿用紙のマス | `<div class="genko" data-cols="20" data-rows="4"></div>`（20字×4行＝80字、行末に字数の目印） |
| 縦書き（国語、A4横） | `<section class="tate" markdown="1"> … </section>`（中は縦書き。2けたの数字は `<span class="tcy">12</span>`） |
| 選択肢を横に並べる | `<div class="choices"><span>ア　…</span><span>イ　…</span></div>` |

配点は丸数字で（各③）、（①）のように書いてよい（数学の形式）。ラベル（tag）は、中学入試／難関私立／湘南型（湘南高校の入試や授業でよく出る型）／思考力／架空のデータ など、問題の性格を示すのに使う。

### 教科ごとの形式

- **国語（「現代の国語」予想問題の形式）**：**縦書き・A4横**。1ページ目は表紙（`<section class="tate">` の中に `t-cover` を使わず、タイトル「五学年　国語　二学期期末試験」＋〔予想問題〕ラベル、「受験上の注意」の＊箇条（設問の指示に従う／「本文中の語を用いて」は語句を変えない／字数指定は句読点も一字／漢字の誤りは減点 など）、配点表（大問Ⅰ〜Ⅵと配点・計）、「五年（　）組（　）番 氏名（　　）」）。続けて【Ⅰ】次の各問いに答えなさい。（12点）→ 問1 …（各一点）の形で、漢字・語彙 → 文法・敬語 → 説明文（本文は枠囲み）→ 記述。本文の段落は ①②…。記述の解答欄は原稿用紙のマス（genko）。**解答と解説は横書き**（`</section>` の後ろ）で、冒頭に「このテストのねらい」の枠、【Ⅰ】漢字・語彙（12点）のように大問ごとの表（問・答え・解説）。
- **算数（「数学Ⅰ」予想問題の形式）**：最初に上の帯。★注意★の枠（「□1〜□6は答えのみ、□7・□8は記述問題で答えに至る過程も書く」「○の中の数字は配点」「中学入試 は中学入試で頻出の型、湘南型 は…を示す」）。本文は **2段組**、大問は `<span class="bn">1</span> 次の計算をせよ。（各③）`、小問 (1)(2)…、問題ごとに tag。問題用紙とは別に **解答用紙**（sheet：大問ごとの欄の表、記述問題は大きな枠）を付ける。解答は「算数　予想問題　解答・詳しい解説」のタイトル → 大問ごとに band 見出し → (1) **答え**（太字）→【解き方】→【よくある誤答】→【類題で確認】（1〜2問、答えつき）。
- **英語（「English Communication I」予想問題の形式）**：1ページ目は表紙（t-cover：2026 / English / Second Semester Final Examination (45mins.) / For 5th-Grade students / 予想問題（範囲））。2ページ目から：英語の注意文（※ Write your answers on the ANSWER SHEET. 小5向けなので、その下に小さく日本語訳）→〈Listening Section〉Ⅰ〜Ⅱ（音声の代わりに先生が原稿を読む。原稿は解答ページに）→〈Vocabulary Section〉Ⅲ〜Ⅴ →〈Reading & Writing Section〉Ⅵ〜Ⅷ。各大問は「Ⅰ. Question 1」のような見出し＋英語の指示文（下に日本語）＋右に配点 (2×5)。答えは記号・単語を ANSWER SHEET（sheet、4線は不要、記入欄の表）に書く形式。解答は「Ⅰ. 解答：…」＋【訳】＋【解説】、リスニング原稿。
- **理科（「生物基礎」予想問題の形式）**：最初に上の帯（「5年 理科 2学期期末試験 [予想問題]（100点）」と右に「2026年 月 日（ ）」）。範囲の枠（chu：「範囲：教科書 P.○〜○（流れる水のはたらき・もののとけ方・人のたんじょう）／ノート・プリント」、※ ラベルの意味、※ 字数指定は句読点も1字、計算は式も書く）。大問は t-sec で「Ⅰ　もののとけ方と水の温度【20点】 <span class="tag w">実験</span>」、リード文 → 図（SVG）・表（表1 … <span class="tag">架空のデータ</span> など、実際の値に近いもの）→ (1)…【2点】のように小問ごとに配点。解答は (1) 答え・〔例〕記述例・よくある誤答・採点基準。
- **社会（「地理総合」予想問題の形式）**：1ページ目は表紙（t-cover：「令和8年度 2学期期末試験 5年生 社会 予想問題（教科書の出題形式をもとに作成・本番より難しめ）」、―諸注意―（マークは濃く／問題は全部で○問／【記述】【論述】は記述式解答用紙に／論述は句点まで書く など））。本文は【大問1】食料生産を支える人々に関する以下の問い（問1〜問8）に答えよ。（計25点）＜知識・技能＞＜思考・判断・表現＞、●で始まるリード文、図・表、`<span class="mon">問1</span>` 〜（1点）、選択肢は①〜④や表の組み合わせ（①〜⑥）。問の通し番号は全体で問1〜問25くらい。最後に **マーク式解答用紙（練習用）**（sheet：問番号と①〜⑥の表）と **記述式解答用紙**（sheet：【論述】は genko の原稿用紙・字数の目印つき、【記述】は枠）。解答は「解答一覧」の表（問1 ②…）→ 大問ごとに band → 問ごとの解説。
