# 定期テスト

`tests/<テスト名>/<番号>_<教科>.md` に1教科1ファイルで書く。PDF にするには：

```bash
python3 textbooks/tools/build_tests.py 小5_2学期期末
```

出力は `books/テスト/<テスト名>_<番号>_<教科>.pdf`。1ページ目から問題、「## 解答と解説」から後ろは新しいページ（先生用）。

## 書き方（全教科共通）

- 対象：神奈川県の公立小学校5年生（教科書は東京書籍）。11月下旬の **2学期期末テスト**。**将来、湘南高校（神奈川県公立トップ校）に入る子を想定**したレベル：学校の単元テストで満点を取る子が、さらに考えないと解けない問題を混ぜる（基本4：標準4：思考・発展2）。基本でも「なぜそうなるか」を問い、思考問題は中学受験の標準〜やや難レベル・神奈川県公立入試の思考力問題のつながり（資料を読み比べて説明する・条件を整理する・理由を記述する）を意識する。ただし範囲外の知識は使わせない（範囲内の知識を組み合わせて解く）。目標：その子たちで平均65〜75点。
- 時間 45分・100点満点。配点の合計がちょうど100点になること（必ず足し算して確かめる）。
- A4 で問題は2〜3ページ（解答欄をふくめて）。問題用紙に直接書きこむ形式。
- 冒頭は必ず次の形（教科名と範囲だけ変える）：

```html
<div class="t-head">
<div class="t-title">小学5年　2学期 期末テスト　算数</div>
<div class="t-row"><div class="t-info">時間 45分<br>100点満点</div><div class="t-name">名前</div><div class="t-score"><br>／100</div></div>
</div>
<p class="t-range">出題範囲：〇〇・〇〇・〇〇</p>
```

- 大問：`#### <span class="no">1</span> 指示文。 <span class="haiten">各3点（計12点）</span>`
- 小問は (1)(2)… 。2列に並べたいときは `<div class="cols2" markdown="1"> … </div>`（中の各行は改行で区切る）。
- 解答欄：短い答え `<span class="ans-box"></span>`、長め `<span class="ans-box w2"></span>`／`w3`。
  文で答える欄 `<div class="kaku"></div>`（2行分は `<div class="kaku tall"></div>`）。算数の式の欄 `<div class="shiki"></div>`。
- 読む文章・資料は `<div class="honbun" markdown="1"> … </div>`。表は Markdown の表。図はインライン SVG（`<figure><svg …>…</svg></figure>`、白黒）。
- `<div … markdown="1">` の前後には空行を入れる。
- 最後に：

```markdown
## 解答と解説

<div class="kaito" markdown="1">

#### <span class="no">1</span>
(1) 答え　…ひとこと解説（つまずきやすい点・採点の目安：部分点の出し方）
…
</div>
```

- 正確さが最優先。答えと問題・図・資料の数値が必ず一致するよう、書いたあと全問を自分で解き直して確かめる。
