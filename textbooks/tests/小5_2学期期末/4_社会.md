<div class="band">大問1　米づくりのさかんな地域（18点）</div>

<span class="mon">問1</span> **④**（山形県・最上川）　庄内平野は山形県の日本海側。最上川は山形県内を流れ、酒田市で日本海に注ぐ。信濃川は新潟県。
<span class="mon">問2</span> **②**（正・正・誤）　cの「やませ」は、夏に東北地方の太平洋側にふく冷たくしめった風で、冷害の原因になる。庄内平野で米づくりを助けるのは、夏に南東からふく**かわいた風**（稲の葉をかわかし、病気を防ぐ）。
<span class="mon">問3</span> 【記述・解答例】**大型の機械が使いやすくなり、作業が早く楽にできる（作業時間が短くなる）。**
採点基準（4点）：「機械が使いやすい（入りやすい）」2点＋「作業が早く・楽に・時間が短く」2点。「水の管理がしやすくなる」も2点として加えてよい（最大4点）。「便利になる」だけは1点。
<span class="mon">問4</span> **③**　カントリーエレベーターは、もみをかんそう・保管し、出荷に合わせて送り出す施設。
<span class="mon">問5</span> **②**　品種改良。「つや姫」「はえぬき」は山形県で生まれた品種。
<span class="mon">問6</span> **③**　秋田県・山形県・宮城県の3つ。新潟県は中部地方（北陸）なので数えない。
<span class="mon">問7</span> **③**　合計は 59＋54＋46＋36＋34＝229（万t）。59÷229＝約0.26 → 約4分の1。誤答の理由：「1位だから半分くらい」と思いこむと①を選ぶ。

<div class="band">大問2　水産業のさかんな地域（20点）</div>

<span class="mon">問8</span> **④**（a遠洋漁業・b沿岸漁業）　沖合漁業は「日本近くの海で、中型の船で数日がかりで行う漁業」。
<span class="mon">問9</span> **②**（c養殖業・d栽培漁業）　**最後までいけすで育てる＝養殖業、とちゅうで海や川に放流する＝栽培漁業**。取りちがえが最も多い。
<span class="mon">問10</span> **③**（正・誤・正）　a：遠洋は約340万t→約220万t（ほかの3つはふえている）。b：2000年は遠洋約90万t、沿岸約160万tで、沿岸の方が多い→誤。c：沖合は1990年の約610万tが最大で、2000年には約260万tに。
<span class="mon">問11</span> 【論述・解答例】**世界の国々が200海里の水域で外国の漁を制限し、燃料の石油も値上がりしたから。**（37字）
採点基準（4点）：「200海里（自国の近くの海）で外国の漁を制限した」4点、「燃料（石油）が値上がりした」4点のどちらかがあれば4点。「外国の海でとれなくなった」程度は2点。40字をこえたもの・句点のないものは1点減点。
<span class="mon">問12</span> **②**　約610万t→約200万t。610÷200＝約3 → 約3分の1。
<span class="mon">問13</span> 【記述・解答例】**育てた稚魚や稚貝を放流して数をふやすので、とりすぎて魚などがへるのを防げるから。**
採点基準（3点）：「放流して数をふやす」2点＋「へるのを防ぐ（とりつくさない）」1点。
<span class="mon">問14</span> **③**　資料3の4種類の合計は、1980年・1990年ごろの約1090万tが最も多く、2020年は約420万tと大きくへっている。①②④は正しい（水産物の輸入が多いことは資料5の魚介類の自給率54%からもわかる）。

<div class="band">大問5　自動車工業（14点）</div>

<span class="mon">問28</span> **④**　プレス（鉄板を打ちぬき・曲げる）→ようせつ（部品をつなぐ）→ようそう（色をぬる）→組み立て（エンジン・シートなどを取りつける）→検査。
<span class="mon">問29</span> **②**　関連工場。さらに小さな部品をつくる関連工場から部品が届くしくみも覚える。
<span class="mon">問30</span> **③**　ジャストインタイム（方式）。
<span class="mon">問31</span> 【記述・解答例】**部品を工場にたくさん置いておかなくてよいので、倉庫などの場所がいらず、むだが少ない。**
採点基準（3点）：「部品を多く置かなくてよい（在庫が少ない）」2点＋「場所・費用・むだが少ない」1点。
<span class="mon">問32</span> 【論述・解答例】**組み立て工場は必要な分の部品しか置いていないので、一つの部品が届かないとすぐ部品が足りなくなり、自動車を完成できないから。**（58字）
採点基準（4点）：①「必要な分しか部品を置いていない（在庫が少ない）」2点　②「その部品がないと自動車が完成しない（ラインが止まる）」2点。

<div class="band">大問6　資料を組み合わせて考える（12点）</div>

<span class="mon">問33</span> 【論述・解答例】**自給率が99%の米を食べる量は半分以下にへり、自給率が53%の肉類を食べる量は約4倍にふえたので、輸入にたよる割合が高い食料を多く食べるようになったから。**（74字）
採点基準（6点）：①米を食べる量がへったこと＋米の自給率が高いこと（資料9と資料5を結びつける）3点　②肉類を食べる量がふえたこと＋肉類の自給率が低いこと 3点。片方の資料だけ（「米を食べなくなったから」など）は各1点。「食生活が洋風になったから」だけは2点。80字をこえたもの・句点のないものは1点減点。
ポイント：神奈川県公立入試の社会でよく出る「2つの資料を組み合わせて理由を説明する」形式。**量の変化（資料9）**と**自給率の高さ（資料5）**の両方を書いているかを見る。
