# 小6国語 詩歌1「詩・短歌・俳句の基礎」

<p class="lead">ねらい：詩の種類と表現技法、短歌の句切れ、俳句の季語・切れ字がわかり、作品の情景と作者の感動を読み取って、鑑賞文が書けるようになる。　中3の「和歌・俳句」と入試の詩歌問題の土台！</p>

## 読み方のポイント

<div class="point" markdown="1">

**POINT 1　詩の種類は「言葉」×「形」で決まる**

| 分け方 | 種類 | 意味 |
|---|---|---|
| 使っている言葉（用語） | **口語詩** | 今の話し言葉（現代の言葉）で書かれた詩 |
| | **文語詩** | 昔の書き言葉（「〜けり」「〜なり」など）で書かれた詩 |
| 形（形式） | **定型詩** | 音の数（七五調・五七調など）に**きまりがある**詩 |
| | **自由詩** | 音の数に**きまりがない**詩 |
| | **散文詩** | 行分けせず、ふつうの文章のように書かれた詩 |

組み合わせて「**口語自由詩**」「**文語定型詩**」のように言います。今の教科書の詩はほとんどが**口語自由詩**です。

<div class="ex" markdown="1">

まだあげ初めし前髪の　（七音・五音）
林檎のもとに見えしとき　（七音・五音）　　　島崎藤村「初恋」より　→　**文語定型詩**（七五調）

</div>

- 詩のまとまりを「**連**（れん）」、1行1行を「**行**」といいます。連と連の間は1行あいています。

</div>

<div class="point" markdown="1">

**POINT 2　表現技法の一覧**<span class="deru">入試</span>

| 技法 | しくみ | 例（オリジナル） |
|---|---|---|
| **直喩**（ちょくゆ） | 「**ような・みたいな・ごとし**」を使ってたとえる | 雪の**ように**白い手 |
| **隠喩**（いんゆ） | 「ような」を使わずにたとえる | 君は　ぼくらの**太陽だ** |
| **擬人法**（ぎじんほう） | 人でないものを**人のように**書く | 風が　そっと**ささやく** |
| **反復**（はんぷく） | 同じ言葉や行をくり返す | 走れ　走れ　走れ |
| **対句**（ついく） | 形のにた言葉を**対（ペア）にして**ならべる | 山は青く　川は清い |
| **倒置**（とうち） | ふつうの語順を**逆にする** | 行こう　まだ見ぬ海へ |
| **体言止め** | 行や文の終わりを**名詞（体言）**で止める | 夕焼けの空に光る**一番星** |
| **省略** | 言葉をあえて書かず、余韻を残す | もう一度だけ……。 |
| **呼びかけ** | 人やものに呼びかける | 春の風**よ** |
| **擬声語・擬態語** | 音や様子を、それらしく表す | **ざあざあ**（音）　**ふわふわ**（様子） |

**効果の書き方**（記述でそのまま使える）
- 比喩 →「〜の様子を**生き生きと（目にうかぶように）**表している」
- 反復 →「くり返すことで、〜という思いを**強調**している」
- 倒置・体言止め →「〜を**強く印象づけ**、**余韻**を残している」

</div>

<div class="point" markdown="1">

**POINT 3　詩を読む手順**

1. **題名**を見る（いちばん短い「主題のヒント」）。
2. **連の数**を数え、各連で「何が見えるか（情景）」をつかむ。
3. **くり返し**・**表現技法**に印をつける（作者が強めたいところ）。
4. 最後の連に注目して、**作者の感動の中心（主題）**を一文でまとめる。

</div>

<div class="point" markdown="1">

**POINT 4　短歌は五七五七七（三十一音）**

| 句 | 初句 | 二句 | 三句 | 四句 | 結句 |
|---|---|---|---|---|---|
| 音数 | 五 | 七 | 五 | 七 | 七 |
| まとまり | **上の句**（かみのく） | 上の句 | 上の句 | **下の句**（しものく） | 下の句 |

- 全部で**31音**なので「**三十一文字**（みそひともじ）」ともいう。
- 音の数え方：**小さい「ゃ・ゅ・ょ」は前の字といっしょに1音**（きゃ＝1音）。**「っ」「ん」「ー」はそれぞれ1音**。
　例　がっこう＝が・っ・こ・う（4音）　きゃべつ＝きゃ・べ・つ（3音）
- 音が多いものを**字余り**、少ないものを**字足らず**という。

</div>

<div class="point" markdown="1">

**POINT 5　句切れ：意味の切れ目をさがす**<span class="deru">入試</span>

**句切れ**＝一首の中で、意味や調子が大きく切れるところ。**「。」がつけられる所**をさがします。

| 見つけるサイン | 例 |
|---|---|
| 言い切りの形（終止形・命令形）、「〜なり」「〜けり」「〜ぬ」 | 銀杏ちる**なり** |
| 「〜や」「〜かな」「〜よ」「〜ぞ」などの言葉 | 哀しからず**や** |
| 名詞で止まって、次から新しい内容になる | |

<div class="ex" markdown="1">

白鳥は　哀しからずや**。**／空の青　海のあをにも　染まずただよふ　　若山牧水　→　**二句切れ**
金色の　ちひさき鳥の　かたちして　銀杏ちるなり**。**／夕日の岡に　　与謝野晶子　→　**四句切れ**
瓶にさす　藤の花ぶさ　みじかければ　たたみの上に　とどかざりけり　　正岡子規　→　**句切れなし**

</div>

- 句切れは**初句切れ・二句切れ・三句切れ・四句切れ・句切れなし**の5種類。
- 句切れがある所は、作者の**感動が強い**所。晶子の歌は「夕日の岡に銀杏ちるなり」の**倒置**にもなっている。

</div>

<div class="point" markdown="1">

**POINT 6　俳句は五七五（十七音）・季語・切れ字**

| きまり | 内容 |
|---|---|
| 音数 | **五・七・五の十七音**。世界でいちばん短い詩 |
| **季語** | 季節を表す言葉を**1つ**入れる。季節は**昔のこよみ（旧暦）**で決まる |
| **切れ字** | 「**や**」「**かな**」「**けり**」が代表。**感動の中心**を示し、そこで意味が切れる |

**まちがえやすい季語**（今の感覚とずれるもの）

| 季節 | 季語 |
|---|---|
| 春 | 菜の花・蛙（かわず）・雪解け・春の海・雀の子・梅・つばめ |
| 夏 | **五月雨**（さみだれ＝梅雨の雨）・若葉・蟬・ほたる・**夕立** |
| 秋 | **七夕**・**天の川**・**朝顔**・名月・柿・とんぼ・すすき |
| 冬 | **小春**（冬の初めのあたたかい日）・枯野・雪・大根・こたつ |

- 七夕（旧暦の7月7日）や朝顔は**秋**。昔のこよみでは、7・8・9月が秋だったからです。
- 季語のない**無季俳句**や、五七五にとらわれない**自由律俳句**（尾崎放哉「咳をしても一人」など）もある。

<div class="ex" markdown="1">

古池**や**　蛙飛びこむ　水の音　　　　松尾芭蕉　（季語：蛙・春／切れ字：や／初句切れ）
柿くへば　鐘が鳴るなり**。**　法隆寺　　正岡子規　（季語：柿・秋／二句切れ）
春の海　終日（ひねもす）のたり　のたり**かな**　与謝蕪村　（季語：春の海・春／切れ字：かな／句切れなし）

</div>

</div>

<div class="memo" markdown="1">

**本質**　短歌も俳句も、言葉が少ない分、**読む人が情景を想像して完成させる**詩です。切れ字や句切れは、写真で言えば「ピントを合わせる場所」。そこに作者の「おっ！」という感動があります。季語は、たった一語で季節の空気（気温・光・におい）まで伝える「圧縮ファイル」だと考えましょう。

</div>

<div class="point" markdown="1">

**POINT 7　鑑賞文は「情景→技法→感動→自分の感想」の4つで書く**

| 順番 | 書くこと | 書き出しの例 |
|---|---|---|
| ① 情景 | 季語・季節、何が見え、何が聞こえるか | この句の季語は「〜」で、季節は〜である。 |
| ② 技法 | 切れ字・句切れ・比喩などと、その**効果** | 「〜」という切れ字によって、〜が強められている。 |
| ③ 感動 | 作者が何に心を動かされたか | 作者は、〜に感動したのだろう。 |
| ④ 感想 | 自分がどう感じたか（理由つき） | 私は、〜という点にひかれた。 |

<div class="ex" markdown="1">

**模範鑑賞文**（柿くへば鐘が鳴るなり法隆寺　正岡子規）
この句の季語は「柿」で、季節は秋である。作者が柿を食べていると、法隆寺の鐘の音が聞こえてきたという情景が目にうかぶ。「鳴るなり」で意味が切れる二句切れの句で、最後を「法隆寺」という名詞で止める体言止めによって、古い寺の重々しさと秋ののどかな空気が余韻として残る。私は、柿の味と鐘の音という、味覚と聴覚が一つになった表現に、旅のゆったりとした楽しさがよく表れていると感じた。

</div>

</div>

<div class="memo" markdown="1">

**先生のひとこと**　鑑賞文でいちばん多い減点は「きれいだと思いました」で終わること。「**どの言葉から**」「**なぜ**」そう感じたのかを必ず書きましょう。料理の感想で「おいしい」だけでなく「だしの香りがきいていておいしい」と言える人は、鑑賞文も上手です。

</div>

#### <span class="no">9</span> Kさんは、次の俳句について鑑賞文を書きました。あとの問いに答えなさい。

<div class="ex" markdown="1">

菜の花や月は東に日は西に　　与謝蕪村

**Kさんの鑑賞文**
この句の季語は「〔　①　〕」で、季節は〔　②　〕である。「や」という〔　③　〕によって、一面に広がる菜の花畑への感動が強められている。東の空には月がのぼり、西の空には日がしずもうとしている。「月は東に」「日は西に」と、形のにた言葉を〔　④　〕にしてならべることで、〔　⑤　〕が目にうかぶ。

</div>

(1) ①〜④に入る言葉を答えなさい。（③は漢字をふくむ3字、④は漢字2字）
(2) 〔　⑤　〕に入る言葉として最も適するものを、次の1〜4の中から一つ選び、その番号を答えなさい。
　1．朝早く、小さな庭に咲いた一輪の菜の花
　2．夕暮れどき、空と大地いっぱいに広がる雄大な景色
　3．真夜中の、星だけが光るまっ暗な畑
　4．雨にぬれて、しずかにうつむく菜の花

**解説**　(2) 月が東からのぼり、日が西にしずむのは**夕方**。菜の花畑の広さと空の広さが合わさった、大きな景色である。
