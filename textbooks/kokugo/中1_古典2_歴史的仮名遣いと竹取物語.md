# 中1国語 古典2「古典入門（歴史的仮名遣い・竹取物語）」

<p class="lead">ねらい：歴史的仮名遣いをすらすら現代仮名遣いで読み、重要古語と主語の補い方を使って『竹取物語』の内容をつかめるようになる。</p>

## 古典のポイント

<div class="point" markdown="1">

**POINT 1　古文と歴史的仮名遣いとは**

- **古文**：昔（主に平安時代〜江戸時代）の日本語で書かれた文章。今の日本語の「ご先祖さま」なので、似ているところも多い。
- **歴史的仮名遣い**：古文の書き表し方。昔の発音に合わせた書き方が、発音が変わったあとも残ったもの。
- **現代仮名遣い**：今の書き表し方。テストで「現代仮名遣いに直しなさい」と言われたら、**すべてひらがなで**、今の読み方どおりに書く。

<div class="ex" markdown="1">

いふ（言ふ）→ いう　　　をかし → おかし　　　けふ（今日）→ きょう

</div>

</div>

<div class="memo" markdown="1">

**本質**　なぜ「いふ」と書いて「いう」と読むの？　昔は本当に「イフ（ifu）」に近い音で言っていたのです。ところが、言葉の**とちゅうのハ行の音は、だんだん弱くなってワ行の音に変わりました**（平安時代ごろから）。発音は変わったのに、書き方は昔のまま残った――これが歴史的仮名遣いの正体です。だから読み方の「きまり」があるのです。

</div>

<div class="point" markdown="1">

**POINT 2　歴史的仮名遣いの読み方のきまり（一覧）**<span class="deru">入試</span>

| きまり | 歴史的仮名遣い → 現代仮名遣い | 例 |
|---|---|---|
| ① 語頭以外の**は・ひ・ふ・へ・ほ** | → **わ・い・う・え・お** | かは→かわ　おもふ→おもう　まへ→まえ　かほ→かお　にほひ→におい |
| ② **ゐ・ゑ・を** | → **い・え・お** | ゐなか→いなか　こゑ→こえ　をかし→おかし |
| ③ **ぢ・づ** | → **じ・ず** | はぢ→はじ　よろづ→よろず　みづ→みず |
| ④ **くわ・ぐわ** | → **か・が** | くわし（菓子）→かし　ぐわんじつ→がんじつ |
| ⑤ **au**（〜あう・〜かう など） | → **ô**（おう・こう など） | やう→よう　かうべ→こうべ　まうす→もうす |
| ⑥ **iu**（〜いう・〜きう・〜しう など） | → **yû**（ゆう・きゅう・しゅう など） | うつくしう→うつくしゅう　きうり→きゅうり |
| ⑦ **eu**（〜えう・〜けう・〜てう など） | → **yô**（よう・きょう・ちょう など） | けふ→けう→きょう　てふ→てう→ちょう |
| ⑧ 助動詞・助詞などの**む** | → **ん** | なむ→なん　行かむ→ゆかん |

**2段階で直すもの**に注意。①で「ふ→う」にしてから、⑤〜⑦の母音のきまりを使う。
　あふぎ（扇）→ あうぎ → **おうぎ**　　たふとし → たうとし → **とうとし**　　けふ → けう → **きょう**

</div>

<div class="memo" markdown="1">

**注意**　①は「語頭（言葉の最初）以外」だけ。**はな（花）・ひと（人）・ふね（船）**のように言葉の頭にあるハ行はそのまま。また、2つの言葉が合わさった語（**あさひ**＝朝＋日）の「ひ」も、もとは「日」の頭なので「い」にしない。

</div>

<div class="memo" markdown="1">

**先生のひとこと**　⑤〜⑦は「ローマ字にして考える」が最強です。「やう」＝ y**au** → y**ô**「よう」。「てう」＝ t**eu** → t**yô**「ちょう」。ちょうちょうは昔「てふてふ」と書きました。ちょっとかわいいですね。

</div>

<div class="point" markdown="1">

**POINT 4　冒頭「今は昔」を読む**<span class="deru">入試</span>

<div class="ex" markdown="1">

今は昔、竹取の翁といふ者ありけり。野山にまじりて竹を取りつつ、よろづのことに使ひけり。名をば、さぬきの造となむいひける。その竹の中に、もと光る竹なむ一筋ありける。あやしがりて寄りて見るに、筒の中光りたり。それを見れば、三寸ばかりなる人、いとうつくしうてゐたり。

</div>

**読み（現代仮名遣いで読む部分）**
いふ→**いう**　使ひ→**つかい**　いひける→**いいける**　なむ→**なん**　うつくしう→**うつくしゅう**　ゐたり→**いたり**
（翁＝おきな、造＝みやつこ、筒＝つつ、三寸＝さんずん）

**現代語訳**
今ではもう昔のことだが、竹取の翁という者がいた。野や山に分け入って竹を取っては、いろいろなことに使っていた。名前を、さぬきの造といった。（ある日、）その竹の中に、根もとが光る竹が一本あった。（翁が）不思議に思って近寄って見ると、筒の中が光っている。その中を見ると、三寸（約9センチメートル）ほどの人が、とてもかわいらしい様子で座っていた。

| 原文 | 意味 | ここがポイント |
|---|---|---|
| 今は昔 | 今ではもう昔のことだが | 昔話の決まった書き出し |
| ありけり | いた | 「けり」＝**〜た**（過去） |
| 〜つつ | 〜しては（くり返し） | |
| よろづ | いろいろ・たくさん | |
| もと | 根もと | |
| あやしがりて | 不思議に思って | 「あやし」＝不思議だ |
| 光りたり | 光っている | 「たり」＝**〜ている** |
| ばかり | 〜ほど・〜くらい | |
| いと | とても | |
| うつくしう | かわいらしく | 今の「美しい」とはちがう！ |

</div>

<div class="point" markdown="1">

**POINT 5　「かぐや姫の昇天」を読む**

<div class="ex" markdown="1">

天人、「遅し。」と心もとながりたまふ。かぐや姫、「もの知らぬこと、なのたまひそ。」とて、いみじく静かに、おほやけに御文奉りたまふ。あわてぬさまなり。
（中略）
ふと天の羽衣うち着せたてまつりつれば、翁を、いとほし、かなしとおぼしつることも失せぬ。この衣着つる人は、もの思ひなくなりにければ、車に乗りて、百人ばかり天人具して、昇りぬ。

</div>

**読み**　たまふ→**たまう**　のたまひそ→**のたまいそ**　おほやけ→**おおやけ**　いとほし→**いとおし**　思ひ→**おもい**

**現代語訳**
天人は、「遅い。」とじれったがりなさる。かぐや姫は、「ものの道理がわからないことを、おっしゃらないでください。」と言って、とても静かに、帝にお手紙をさしあげなさる。あわてない様子である。
（中略）
（天人が）さっと天の羽衣を（かぐや姫に）お着せ申し上げたので、（かぐや姫が）翁を気の毒だ、いとしいと思っていらっしゃった気持ちも消えてしまった。この衣を着た人は、思い悩むことがなくなってしまうので、（かぐや姫は）車に乗って、百人ほどの天人を連れて、（天に）昇ってしまった。

| 原文 | 意味 |
|---|---|
| 心もとながる | じれったく思う |
| 〜たまふ | 〜なさる（**身分の高い人の動作につく**敬語） |
| な〜そ | **〜しないでください**（やわらかい禁止） |
| いみじく | とても・たいそう |
| おほやけ | 朝廷・帝 |
| 奉る | さしあげる |
| 〜ぬ（あわてぬ） | 〜ない（打ち消し） |
| 〜ぬ（失せぬ・昇りぬ） | 〜てしまった（完了） |
| いとほし | 気の毒だ |
| かなし | いとしい・かわいい |
| 具す | 連れる・連れて行く |

</div>

<div class="memo" markdown="1">

**本質**　天の羽衣を着ると「もの思ひ」（人間らしい悩みや悲しみ）がなくなる。つまり、かぐや姫は**人間の心を失って**月へ帰ったのです。直前まで翁との別れを悲しみ、帝に手紙を書いていた姫が、一瞬で別人のようになる――この**人間の世界と月の世界の対比**が、『竹取物語』のいちばんの読みどころです。

</div>

**POINT 6　重要古語の一覧**<span class="deru">入試</span>

**A　今も使うが、意味がちがう言葉（古今異義語）**

| 古語 | 古文での意味 | 今の意味 |
|---|---|---|
| **うつくし** | **かわいらしい** | 美しい |
| **あやし** | **不思議だ**／身分が低い | 疑わしい |
| **ありがたし** | **めったにない** | 感謝したい |
| **おどろく** | **はっと気づく**／目を覚ます | びっくりする |
| **ののしる** | **大声で騒ぐ**・評判になる | 悪口を言う |
| **かなし** | **いとしい**・かわいい／悲しい | 悲しい |
| **やがて** | **そのまま**／すぐに | そのうちに |
| **年ごろ** | **長年** | 年齢・適齢期 |

| 古語 | 意味 | 古語 | 意味 |
|---|---|---|---|
| **いと** | とても | **をかし** | 趣がある・おもしろい |
| **いみじ** | たいそう（よい・ひどい） | **あはれ** | しみじみと心を動かされる |
| **ゆかし** | 見たい・知りたい | **めでたし** | すばらしい |

| **よろづ** | いろいろ・たくさん | **やうやう** | しだいに・だんだん |

<div class="point" markdown="1">

**POINT 7　古文の主語・助詞の補い方**

古文では「**が・は・を**」や**主語がよく省略**される。読むときは自分で補う。

<div class="ex" markdown="1">

翁　竹　取る　→　翁**が**竹**を**取る
あやしがりて寄りて見るに　→　**（翁が）**不思議に思って近寄って見ると

</div>

**主語を見つける手がかり**

| 手がかり | 考え方 |
|---|---|
| ① 直前に出てきた人物 | 新しい人物が出てこなければ、**同じ人が主語**のことが多い |
| ② 「〜て」「〜で」でつながる | 前と後ろで**主語は同じ**ことが多い |
| ③ 「〜ば」「〜に」「〜を」「〜ど」でつながる | **主語が変わる**ことが多い（「見るに、筒の中光りたり」→ 見たのは翁、光ったのは筒の中） |
| ④ 敬語（**たまふ**・のたまふ など） | 身分の高い人（帝・かぐや姫・天人）が主語 |
| ⑤ 「 」とて・「 」と言ふ | 会話の直前・直後の人物が話し手 |

</div>

<div class="memo" markdown="1">

**発展**　**係り結び**（中2でくわしく学習）。文の中に「**ぞ・なむ・や・か**」があると文末が**連体形**、「**こそ**」があると**已然形**に変わる。冒頭の「さぬきの造と**なむ**いひ**ける**」「竹**なむ**一筋あり**ける**」も、ふつうなら「けり」で終わるところが「ける」になっている。これは強調のしるしです。

</div>

<div class="memo" markdown="1">

**先生のひとこと**　古文は「外国語」ではなく「昔の日本語」。①歴史的仮名遣いを直して声に出す、②知らない古語を表で確認、③主語を（　）で書きこむ――この3ステップで、ほとんどの文章が読めます。

</div>

### 入試にチャレンジ

#### <span class="no">9</span> 次の文章を読んで、あとの問いに答えなさい。（＊は注）
