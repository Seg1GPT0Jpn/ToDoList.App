# 中2国語 語句7「熟語の構成・同音異義語」

<p class="lead">ねらい：二字熟語の構成を「訓読みで文にする」方法で見分け、三字・四字熟語の組み立てと、まぎらわしい同音異義語・同訓異字を使い分けられるようになる。神奈川入試の問一・問三で毎年ねらわれる！</p>

## 語句のポイント

<div class="point" markdown="1">

**POINT 1　熟語は「漢字どうしの関係」でできている**

漢字は1字1字が意味を持つ「部品」です。熟語の構成とは、**2つの部品がどうつながっているか**ということ。これは中1で学んだ**文節どうしの関係（主語・述語、修飾・被修飾など）と同じ考え方**です。

| 構成 | 見分け方 | 例 |
|---|---|---|
| ① **似た意味**の字を重ねる | 2字とも同じような意味 | 森林・温暖・絵画・身体・増加・豊富 |
| ② **反対・対**の意味の字を重ねる | 2字が反対／ペア | 明暗・売買・高低・往来・前後・損得 |
| ③ **上の字が下の字を修飾** | 「〜な〇」「〜に〇する」 | 青空・深海・黒板・急増・楽勝・再会 |
| ④ **下の字が上の字の目的・対象** | 「〇を〜する」「〇に〜する」（**下から上へ返る**） | 読書・登山・帰国・乗車・着席・握手 |
| ⑤ **主語・述語**の関係 | 「〇が〜する」（**上から下へそのまま**） | 日没・地震・雷鳴・国立・県営・人造 |
| ⑥ **打ち消しの字が上につく** | 不・無・非・未 ＋ 〜 | 不安・無理・非常・未知 |
| ⑦ **接尾語が下につく** | 〜的・〜性・〜化・〜然 | 美的・酸性・変化・平然 |
| ⑧ **同じ字を重ねる** | 々（くり返し記号） | 人々・堂々・刻々 |
| ⑨ **長い語を省略** | もとの語を思い出す | 国連（国際連合）・入試（入学試験）・特急（特別急行） |

</div>

<div class="point" markdown="1">

**POINT 2　見分け方の手順　――　訓読みして「文」にしてみる** <span class="deru">入試</span>

1. 1字ずつ**訓読み**（意味がわかる読み）にする。　例：登山 → 登る＋山
2. 2字をつないで**短い文**を作る。
　・上から下へ「〇が〜する」と読める → **⑤ 主語・述語**　　日没＝日**が**没する
　・下から上へ「〇を（に）〜する」と読める → **④ 目的・対象**　　登山＝山**に**登る
　・上が下をくわしくしている → **③ 修飾**　　深海＝深い海、急増＝急に増える
3. 文にならないときは、2字の意味をくらべる → 似ている **①**、反対 **②**。

<div class="ex" markdown="1">

まぎらわしい組：**③ と ④**　「**再会**」＝再び会う（上が修飾）③　／　「**帰国**」＝国に帰る（下から返る）④
　　　　　　　　**④ と ⑤**　「**県営**」＝県が営む（主語）⑤　／　「**営業**」＝業を営む（目的）④

</div>

</div>

<div class="memo" markdown="1">

**本質**　④の「下から上へ返って読む」熟語は、**漢文の返り点（レ点）と同じしくみ**です。「読書」は漢文で書けば「読ㇾ書（書を読む）」。中国語は「動詞→目的語」の順、日本語は「目的語→動詞」の順だから、ひっくり返るのです。中2の漢文入門でもう一度出会います。

</div>

<div class="point" markdown="1">

**POINT 3　三字熟語の構成**

| 構成 | 例 |
|---|---|
| **一字＋二字**（上の一字が下の二字にかかる） | **不**自由・**無**関心・**非**常識・**未**完成・**新**記録・**大**自然・**初**対面 |
| **二字＋一字**（下に一字がつく） | 積極**的**・安全**性**・自動**化**・日本**式**・人生**観**・責任**感**・想像**力** |
| **一字＋一字＋一字**（三つが対等） | 松竹梅・衣食住・上中下・市町村・心技体 |

**打ち消しの接頭語の使い分け** <span class="deru">入試</span>

| 字 | 意味 | 例 |
|---|---|---|
| **不** | 〜でない・〜しない | 不自由・不可能・不公平・不完全・不注意・不親切 |
| **無** | 〜がない | 無関心・無責任・無意識・無意味・無計画・無表情 |
| **非** | 〜ではない（あてはまらない） | 非常識・非公開・非公式・非科学的・非常口 |
| **未** | **まだ**〜していない（いずれそうなる） | 未完成・未解決・未成年・未経験・未発表・未知数 |

**接尾語**：〜**的**（〜のような・〜に関する：科学的）、〜**性**（性質：安全性）、〜**化**（〜になる：温暖化）、〜**然**（〜のようす：学者然）

</div>

<div class="point" markdown="1">

**POINT 4　四字熟語の構成**

| 構成 | 例 |
|---|---|
| **四字が対等**に並ぶ | 春夏秋冬・喜怒哀楽・東西南北・花鳥風月・起承転結 |
| **似た意味**の二字熟語を重ねる | 公明＝正大、完全＝無欠、自由＝自在、絶体＝絶命 |
| **反対・対**の意味の二字熟語を重ねる | 半信⇔半疑、一長⇔一短、質疑⇔応答、大同⇔小異 |
| **主語・述語**の関係 | 意気が投合（する）、本末が転倒（する）、大器は晩成（する） |
| **上の二字が下の二字を修飾** | 単刀→直入、高層→建築、人工→衛星 |

- 四字熟語は**二字＋二字**に分けて、二字熟語と同じように関係を考えるのがコツ。
- 書きまちがい注意：**絶体**絶命（×絶対）、**異口**同音（×異句）、**危機**一髪（×危機一発）、**五里**霧中（×五里夢中）、**単刀**直入（×短刀）

</div>

<div class="point" markdown="1">

|---|---|---|

| かんしん | **関心**：興味／**感心**：心を動かされる／**歓心**：喜ぶ心／**寒心**：おそれ心配する | 関心を持つ　歓心を買う　寒心にたえない |
| たいしょう | **対象**：目標・相手／**対照**：くらべる・違いがはっきり／**対称**：つりあう | 中学生が対象　対照的な性格　左右対称 |
| いどう | **移動**：位置が移る／**異動**：職や地位が変わる／**異同**：ちがい | 席を移動　人事異動　両者の異同 |

| しゅうしゅう | **収集**：集める／**収拾**：混乱をおさめる | 切手を収集　事態を収拾 |
| せいさん | **精算**：細かく計算する／**清算**：貸し借りや関係を整理する | 運賃を精算　借金を清算 |
| かてい | **過程**：途中の道すじ／**課程**：学習の範囲／**仮定**：仮に決める | 成長の過程　義務教育の課程 |
| かいほう | **開放**：開け放つ／**解放**：自由にする／**快方**：病気がよくなる／**介抱**：世話をする | 校庭を開放　人質を解放　快方に向かう |

</div>

<div class="point" markdown="1">

**POINT 6　同訓異字（上級編）　――　熟語にして意味を確かめる** <span class="deru">入試</span>

| 訓 | 使い分け（熟語のヒント） |
|---|---|
| はかる | **計る**（時間・計算：時間を計る）／**測る**（長さ・深さ・温度：距離を測る）／**量る**（重さ・量：体重を量る）／**図る**（くわだてる：解決を図る）／**諮る**（意見を聞く：会議に諮る） |
| おさめる | **治める**（統治：国を治める）／**収める**（収納・収穫：成功を収める）／**納める**（納入：税を納める）／**修める**（修得：学問を修める） |
| つとめる | **努める**（努力：解決に努める）／**務める**（任務：司会を務める）／**勤める**（勤務：会社に勤める） |
| あらわす | **表す**（表現：気持ちを表す）／**現す**（出現：姿を現す）／**著す**（著作：本を著す） |
| おかす | **犯す**（犯罪：罪を犯す）／**侵す**（侵入：権利を侵す）／**冒す**（冒険：危険を冒す） |
| かたい | **固い**（固定：決意が固い）／**堅い**（堅実：手堅い・口が堅い）／**硬い**（硬直：硬い石・表情が硬い） |
| こえる | **越える**（場所・時を越す：山を越える）／**超える**（基準を上回る：定員を超える） |
| たつ | **断つ**（断絶：連絡を断つ）／**絶つ**（絶える：命を絶つ・消息を絶つ）／**裁つ**（裁断：布を裁つ） |

</div>

<div class="memo" markdown="1">

**先生のひとこと**　同訓異字は「**熟語にする**」が最強の武器。「布を〇つ」→「裁断」の「裁」。「定員を〇える」→「超過」の「超」。漢字を見て迷ったら、その字を使った熟語を1つ思い浮かべて、意味がぴったり合うか確かめよう。熟語の構成も同じで、**訓読みで文にする**――「漢字を言葉にもどす」のが、この単元すべての合言葉です。

</div>

## 解答・解説

<div class="kaito" markdown="1">

#### <span class="no">1</span>
(1) ア　(2) イ　(3) エ　(4) オ　(5) ウ　(6) エ　(7) イ　(8) オ　(9) ア　(10) ウ
**解説**　(3) 顔を洗う、(6) 火を消す＝下から返る。(4)(8) 市が営む・国が営む＝主語・述語。(5) 晩い秋、(10) 激しく動く＝修飾。(9)「加」も「入」も「くわわる・はいる」で似た意味。

#### <span class="no">2</span>
(1) 非常識　(2) 未完成　(3) 無関心　(4) 不可能　(5) 未成年　(6) 無責任　(7) 非公開　(8) 不公平
**解説**　「未」は「**まだ**〜ない」。完成も成年も、いずれそうなるもの。

#### <span class="no">3</span>
(1) 積極的　(2) 安全性　(3) 機械化　(4) 人生観
**解説**　「的」＝〜のようなさま、「性」＝性質、「化」＝〜になる、「観」＝見方。意味の手がかりで選ぶ。

#### <span class="no">4</span>
