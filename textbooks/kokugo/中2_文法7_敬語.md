# 中2国語 文法7「敬語」

<p class="lead">ねらい：「だれの動作か」「だれを高めるか」から、尊敬語・謙譲語・丁寧語を正しく選び、手紙・電話・面接で使えるようになる。誤用の見ぬき方は入試の定番！</p>

## 文法のポイント

<div class="point" markdown="1">

**POINT 1　敬語とは「人間関係を言葉で表すしくみ」**

敬語は、話し手が**相手や話題の人をどう位置づけているか**を、言葉の形で表すしくみです。「えらい人に使う言葉」と覚えるより、**だれを高め、だれを低めるか**の矢印で考えましょう。

| 種類 | はたらき | 使う相手の動作 | 例 |
|---|---|---|---|
| **尊敬語** | 相手や話題の人の**動作・持ち物を高める** | **目上の人**の動作 | 先生が**いらっしゃる**。お客様が**お帰りになる**。 |
| **謙譲語** | **自分や身内**の動作をへりくだり、**動作の向かう先**を高める | **自分・身内**の動作 | 私が先生のお宅に**うかがう**。 |
| **丁寧語** | 聞き手に対して、ていねいに言う | だれの動作でも | 雨が降り**ます**。これは本**です**。**ございます**。 |
| **美化語** | ものごとを上品に言う（だれも高めない） | ― | **お**茶、**お**花、**ご**飯、**お**菓子 |

</div>

<div class="point" markdown="1">

**POINT 2　まず「主語」を見つける　――　敬語の問題はこれで9割とける** <span class="deru">入試</span>

1. ――線の動作をしているのは**だれか**（主語）を見つける。
2. 主語が**目上・相手・お客様**　→　**尊敬語**
3. 主語が**自分・自分の家族・自分の学校や会社の人**　→　**謙譲語**

<div class="ex" markdown="1">

**先生が**　私の作文を　**ご覧になる**。　（主語＝先生　→　尊敬語）
**私が**　先生の作文を　**拝見する**。　（主語＝私　→　謙譲語）

</div>

</div>

<div class="memo" markdown="1">

**先生のひとこと**　敬語はシーソーです。**尊敬語は相手の席を上げる**、**謙譲語は自分の席を下げて、相手を相対的に上げる**。だから「相手の席を下げる（相手に謙譲語）」「自分の席を上げる（自分に尊敬語）」はどちらもアウト。迷ったら「その動作、だれがしてる？」と聞く。これだけで入試の敬語問題はほぼ取れます。

</div>

<div class="point" markdown="1">

**POINT 3　特別な形の敬語動詞（一覧表）　――　まるごと覚える！** <span class="deru">入試</span>

| ふつうの言い方 | 尊敬語（相手の動作） | 謙譲語（自分の動作） |
|---|---|---|
| いる | いらっしゃる・おいでになる | おる |
| 行く | いらっしゃる・おいでになる | 参る・うかがう |
| 来る | いらっしゃる・おいでになる・見える・お見えになる・お越しになる | 参る |
| 言う | おっしゃる | 申す・申し上げる |
| する | なさる | いたす |
| 食べる・飲む | 召し上がる | いただく |
| 見る | ご覧になる | 拝見する |
| 聞く | お聞きになる | うかがう・承る・拝聴する |
| 知る・思う | ご存じだ（知る）・お思いになる | 存じる・存じ上げる |
| 会う | お会いになる | お目にかかる |
| くれる・与える | くださる | ― |
| あげる・与える | ― | 差し上げる |
| もらう | （お受け取りになる） | いただく・頂戴する |
| 見せる | お見せになる | お目にかける・ご覧に入れる |
| 着る | 召す・お召しになる | ― |
| 寝る | お休みになる | ― |
| 借りる | お借りになる | 拝借する |

- 「**いらっしゃる**」は「いる・行く・来る」の3つをかねる。「**うかがう**」は「行く（訪ねる）」と「聞く」の2つをかねる。
- 「**いただく**」は「食べる・飲む」と「もらう」の謙譲語。**相手に「いただいてください」は誤り**（→「召し上がってください」）。

</div>

<div class="point" markdown="1">

**POINT 4　特別な形がない動詞は「型」にあてはめる**

| 種類 | 型 | 例（書く・待つ・説明する） |
|---|---|---|
| 尊敬語 | **お（ご）〜になる** | **お**書き**になる**　**お**待ち**になる**　**ご**説明**になる** |
| 尊敬語 | **〜れる・られる**（助動詞） | 書か**れる**　待た**れる**　説明さ**れる** |
| 尊敬語（相手へのお願い） | **お（ご）〜ください** | **お**待ち**ください**　**ご**説明**ください** |
| 謙譲語 | **お（ご）〜する（いたす・申し上げる）** | **お**書き**する**　**お**待ち**する**　**ご**説明**いたします** |

- 「お」は和語（訓読みの語）、「ご」は漢語（音読みの語）につくことが多い。例：お知らせ／ご連絡
- 「〜れる・られる」は**受け身・可能・自発**と同じ形。「先生が話さ**れる**」の「れる」は**尊敬**。主語が目上の人で、高める意味なら尊敬。
- 「〜れる・られる」の尊敬は、「お〜になる」より**敬意がやや軽い**。

<div class="ex" markdown="1">

型の見分け：**「になる」で終わる → 尊敬、「する・いたす」で終わる → 謙譲。**
「お持ち**になる**」＝先生が持つ（尊敬）　　「お持ち**する**」＝私が持つ（謙譲）

</div>

</div>

<div class="point" markdown="1">

**POINT 5　身内と「外」の人　――　ウチ・ソトで考える** <span class="deru">入試</span>

- **外の人に向かって話すときは、自分の家族・自分の学校や会社の人は「ウチ」。高めない。**
　× 母が「よろしく」と**おっしゃって**いました。
　○ 母が「よろしく」と**申して**おりました。
- 会社や学校では、**外の人に自分の上司のことを話すときも敬語をつけない**（名字だけで呼ぶ）。
　○（取引先の人に）「部長の田中は、ただいま席を外して**おります**。」
- 相手側のものは高め、自分側のものはへりくだる。

| | 相手側（高める） | 自分側（へりくだる） |
|---|---|---|
| 会社 | 御社（話す）・貴社（書く） | 弊社・小社 |
| 学校 | 御校（話す）・貴校（書く） | 本校・当校 |
| 家族 | お父様・お母様・ご家族 | 父・母・家の者 |
| 品物 | お品・ご厚意 | 粗品・寸志 |
| 意見 | ご意見・ご高見 | 私見・愚見 |

</div>

<div class="point" markdown="1">

**POINT 6　よくある誤用　――　入試はここをねらう！** <span class="deru">入試</span>

| 誤用の型 | 誤り | 正しい形 |
|---|---|---|
| ① **相手の動作に謙譲語** | 先生が**申された**とおりです。 | 先生が**おっしゃった**とおりです。 |
| | 受付で**うかがって**ください。 | 受付で**お聞きになって**ください。 |
| | どうぞ**いただいて**ください。 | どうぞ**召し上がって**ください。 |
| | 会員証を**ご利用して**ください。 | 会員証を**ご利用ください**（**ご利用になって**ください）。 |
| ② **自分の動作に尊敬語** | 私が**いらっしゃいます**。 | 私が**参ります**。 |
| ③ **身内を高める** | 父が**召し上がって**います。 | 父が**いただいて**います（**食べて**います）。 |
| ④ **二重敬語**（同じ種類の敬語を重ねる） | 先生が**おっしゃられた**。 | 先生が**おっしゃった**。 |
| | 社長が**お帰りになられた**。 | 社長が**お帰りになった**。 |
| | 作品を**ご覧になられる**。 | 作品を**ご覧になる**。 |

- 二重敬語は「おっしゃる（尊敬）＋られる（尊敬）」のように**尊敬が2つ**重なっている。ていねいにしたつもりで、かえって不自然。
- 「お召し上がりになる」「お伺いする」などは二重敬語の形だが、慣習として定着しているので許されている（覚えなくてよい）。

</div>

<div class="point" markdown="1">

**POINT 7　場面別の敬語（手紙・電話・面接）**

**手紙**　頭語と結語はセット。**拝啓**（つつしんで申し上げます）―**敬具**、**前略**（前文を省略します）―**草々**
　前文（時候のあいさつ・相手の安否）→ 主文（用件）→ 末文（結びのあいさつ）→ 後付け（日付・署名・あて名）
**電話**　「〇〇と**申します**。△△様は**いらっしゃいます**か。」「少々**お待ちください**。」
　家族あての電話：「父はただいま出かけて**おります**。戻りましたら、**お電話いたします**（させます）。」
**面接**　「〇〇中学校から**参りました**、〇〇と**申します**。」「**御校**を志望した理由は〜です。」

</div>

<div class="memo" markdown="1">

**発展**　謙譲語には2つのタイプがある（文化審議会「敬語の指針」2007年の5分類）

| | はたらき | 例 |
|---|---|---|
| **謙譲語Ⅰ** | 自分の動作の**向かう先の人**を高める（向かう先が必要） | うかがう・申し上げる・差し上げる・お目にかかる・拝見する・お〜する |
| **謙譲語Ⅱ（丁重語）** | 自分の動作を、**聞き手**に対してていねいに述べる（向かう先がなくてよい） | 参る・申す・いたす・おる・存じる |

「明日から旅行に**参ります**」は、旅行先を高めているわけではなく、**話している相手**にていねいに言っている（丁重語）。「旅行先に**うかがいます**」は向かう先がないので不自然。中学校の教科書では、まとめて「謙譲語」として学びます。5分類＝尊敬語・謙譲語Ⅰ・謙譲語Ⅱ（丁重語）・丁寧語・美化語。

</div>

## 練習問題

### 基本

#### <span class="no">1</span> 次の――線の敬語の種類を、あとのア〜エから1つずつ選びなさい。

<div class="cols2" markdown="1">

(1) 校長先生が**いらっしゃる**。
(2) 私は駅で先生を**お待ちする**。
(3) 今日は天気が**よいです**。
(4) 台所で**お湯**をわかす。
(5) 先生が手紙を**お書きになる**。
(6) 明日、私がお宅に**うかがいます**。
(7) 市長が会場で**話される**。
(8) あちらが受付で**ございます**。

</div>

ア　尊敬語　　イ　謙譲語　　ウ　丁寧語　　エ　美化語

<div class="cols2" markdown="1">

### 標準

#### <span class="no">5</span> 次の――線を、正しい敬語に直しなさい。（直す必要のないものは○を書く）

(1) 先生、どうぞ温かいうちに**いただいて**ください。
(2) 校長先生が、明日の行事について**申されました**。
(3) お客様、受付で**うかがって**ください。
(4) 母は、先生によろしくと**おっしゃって**いました。
(5) 私が駅までお客様を**ご案内いたします**。
(6) 先生は、もうお昼ご飯を**お食べになりましたか**。
(7) 部長が「明日は休む」と**おっしゃられた**。
(8) こちらのパンフレットを**ご利用して**ください。

#### <span class="no">6</span> 次の場面に合うように、（　）の言葉を正しい敬語に直しなさい。

(1) 家にかかってきた電話で：「父は今、出かけて（いる）。」
(2) 職員室で：「失礼します。二年一組の山田と（言う）。佐藤先生は（いる）か。」
(3) 先生へ：「この前お借りした本を、明日お返し（する）。」
(4) 店員がお客様へ：「どちらの品に（する）か。」
(5) 面接で：「私は、〇〇中学校から（来た）。」

#### <span class="no">7</span> 「れる・られる」の意味を見分けなさい。――線の意味を、あとのア〜エから1つずつ選びなさい。

<div class="cols2" markdown="1">

(2) 弟が母にしから**れる**。
(3) このきのこは食べ**られる**。
(4) 秋の気配が感じ**られる**。
(5) 社長が新聞を読ま**れる**。
(6) 私はピーマンが食べ**られる**ようになった。

</div>

#### <span class="no">8</span> 次の手紙の一部を読んで、あとの問いに答えなさい。

<div class="ex" markdown="1">

　寒さに向かいますので、どうぞご自愛ください。　　**B**

(2) ①〜④の敬語のうち、使い方が正しいものを**すべて**選び、番号で答えなさい。
(3) (2)で正しくないとしたものを、それぞれ正しい形に直しなさい。

### 入試にチャレンジ

#### <span class="no">9</span> 次の各問いに答えなさい。

(1) 次の文の――線部の敬語の使い方が適切でないものを、1〜4の中から一つ選び、その番号を答えなさい。
　1．先生が**おっしゃった**ことを、ノートに書きとめる。
　2．お客様が**お見えになった**ので、応接室にご案内した。
　3．私の祖父は、毎朝新聞を**ご覧になる**。
　4．先生のお宅で、おいしいお菓子を**いただいた**。
(2) 次の文の――線部「**参ります**」と同じ種類の敬語を使っているものを、1〜4の中から一つ選び、その番号を答えなさい。
　明日、私が資料を持って**参ります**。
　1．先生が笑顔で**いらっしゃる**。　　2．校長先生が会議に**出席される**。
　3．私が会場の受付を**いたします**。　　4．どうぞ、こちらで**お休みください**。
(3) 次の文の――線部を適切な敬語に改めたものとして最も適するものを、1〜4の中から一つ選び、その番号を答えなさい。
　（生徒が来校した保護者に）「お母様、こちらの書類を**見て**ください。」
　1．拝見して　　2．ご覧になられて　　3．ご覧になって　　4．お見せして

#### <span class="no">10</span> 中学生のKさんは、職場体験先のパン屋の店長に、お礼の電話をかけた。次の会話を読んで、あとの問いに答えなさい。

<div class="ex" markdown="1">

店員　　「はい、ベーカリーみなとです。」
Kさん　「①**私は、みなと中学校二年のKです**。先週の職場体験で、お世話になりました。店長の森さんは②**おられますか**。」
店員　　「店長は、ただいま配達に出ておりまして……。」
Kさん　「そうですか。では、③**お礼を言いたい**ので、また後でお電話いたします。」
店員　　「④**店長が帰ってきたら、Kさんから電話があったと伝えておきます**ね。」

</div>

(1) ――線①を、「申す」を使って、電話の名乗り方として適切な言い方に直しなさい。
(2) ――線②は、敬語の使い方として好ましくないとされることがある。尊敬語の特別な形を使って書き直しなさい。
(3) ――線③を、謙譲語を使って書き直しなさい。（「お礼を」に続けて）
(4) ――線④について、店員の立場から見て、店長に**尊敬語を使っていない**のはなぜか。その理由として最も適するものを、次の1〜4の中から一つ選び、その番号を答えなさい。
　1．店長は年下なので、敬語を使う必要がないから。
　2．店の外の人であるKさんに対して、自分の店の人を高めないのが正しい使い方だから。
　3．店長が今その場にいないので、敬語を使っても伝わらないから。
　4．電話では、尊敬語を使わずに丁寧語だけで話すのが決まりだから。

#### <span class="no">11</span> Kさんは、高校の面接の練習をしている。次のKさんの発言を、敬語を正しく使って書き直しなさい。直すところは3か所ある。

**解説**　「お（ご）」の後ろは**連用形**（読み・持ち・待ち）か漢語（案内・出席）。

#### <span class="no">4</span>
(1) 私（自分）・謙譲語　(2) 先輩・尊敬語　(3) 私（自分）・謙譲語　(4) 社長・尊敬語　(5) 私（自分）・謙譲語
**解説**　(2)「くださる」は「くれる」の尊敬語。(5)「ご覧に入れる」は「見せる」の謙譲語。「ご覧になる（尊敬）」とまちがえない。

#### <span class="no">5</span>
(1) 召し上がって　(2) おっしゃいました（話されました）　(3) お聞きになって（お尋ねになって）　(4) 申して
(5) ○　(6) 召し上がりましたか　(7) おっしゃった　(8) ご利用ください（ご利用になって）
**解説**　(1)(2)(3)(8) は相手の動作に謙譲語を使った誤り。(4) 外の人（先生）に向けて身内（母）を高めている。(6)「お食べになる」は「食べる」に特別な形（召し上がる）があるので使わない。(7) 二重敬語。

#### <span class="no">6</span>
(1) おります　(2) 申します・いらっしゃいます（おいでになります）
(3) します（いたします）　(4) なさいます　(5) 参りました
**解説**　(3)「お返し**する**」で謙譲の型ができている。「お返しいたします」でもよい。(4) お客様の動作なので尊敬語「なさる」。

#### <span class="no">7</span>
(1) エ　(2) ア　(3) イ　(4) ウ　(5) エ　(6) イ
**解説**　見分け方：「〜ことができる」に言いかえられれば**可能**、「自然と〜」なら**自発**（感じる・思い出す・案じるなど心の動き）、「〜に〜される」の形なら**受け身**、目上の人の動作なら**尊敬**。

#### <span class="no">8</span>
(1) 2
(2) ①・③
(3) ② 申して　④ いらっしゃって（おいでになって・お越しになって・お越し）
**解説**　(1)「前略」は前文（時候のあいさつ）を省くときに使うので、時候のあいさつがあるこの手紙には合わない。「拝啓―敬具」がセット。(2) ① 先生の動作に尊敬の「れる」で正しい。② 身内（母）に尊敬語は×。③「存じる」は自分の「思う」の謙譲語で正しい。④ 先生の動作に謙譲語「参る」は×。

#### <span class="no">9</span>
(1) 3　(2) 3　(3) 3
**解説**　(1) 3 は身内（祖父）の動作に尊敬語を使っている。「見る」「読む」などでよい。2「お見えになる」は慣用として認められている。(2)「参ります」も「いたします」も**自分の動作**をへりくだる謙譲語。1・2・4 はすべて相手の動作で尊敬語。(3) 保護者（相手）の動作なので尊敬語「ご覧になる」。2 は二重敬語、1・4 は謙譲語。

#### <span class="no">10</span>
(1) （私は、）みなと中学校二年のKと申します。
(2) いらっしゃいますか
(3) （お礼を）申し上げたい
(4) 2
**解説**　(2)「おる」は謙譲語（丁重語）なので、相手側の人に「おられる」を使うのは好ましくないとされる。(3)「言う」の謙譲語は「申す・申し上げる」。お礼を**向ける先**（店長）を高めるので「申し上げる」が最適。(4) ウチ（店の人）とソト（客や外の人）の関係。

#### <span class="no">11</span>
（例）「〇〇中学校から**参りました**、Kと**申します**。御校の説明会で、先生方が**おっしゃった**『自分で問いを立てる学び』に心を引かれました。」
**解説**　「来ました」→「参りました」、「言います」→「申します」（どちらも自分の動作なので謙譲語）。「おっしゃられた」は二重敬語なので「おっしゃった」。面接は話し言葉なので「御校」でよい（書くときは「貴校」）。
