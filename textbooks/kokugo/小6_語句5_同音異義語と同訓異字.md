# 小6国語 語句5「同音異義語・同訓異字」

<p class="lead">ねらい：読みが同じで意味がちがう漢字・熟語を、「熟語の意味」「漢字1字の意味」から考えて使い分けられるようになる。漢字の書き取りで点を落とさない力をつけよう。</p>

## 語句のポイント

<div class="point" markdown="1">

**POINT 1　「同音異義語」と「同訓異字」**

| 種類 | どんなものか | 例 |
|---|---|---|
| **同音異義語** | 音読みが同じで、意味がちがう**熟語** | いがい → **意外**・**以外** |
| **同訓異字** | 訓読みが同じで、意味がちがう**漢字** | あう → **会う**・**合う**・**遭う** |

- 日本語は音の種類が少ないので、同じ読みの言葉がとても多い。**ひらがなで読むと同じでも、漢字にすると意味がはっきり分かれる**。
- だから入試の書き取りでは、「読みを知っているか」ではなく「**意味がわかっているか**」が問われている。

</div>

<div class="memo" markdown="1">

**本質**　漢字は「**1字1字が意味をもつ文字**」（表意文字）です。熟語の意味は、ほぼ「漢字1字の意味のたし算」でできています。だから迷ったら、**1字ずつ訓読みや意味にもどして考える**。たとえば「**以外**」は「**以**（〜より）＋**外**（そと）」＝それより外側のもの。「**意外**」は「**意**（思い）＋**外**（そと）」＝思っていたことの外。これで、もうまちがえません。

</div>

<div class="point" markdown="1">

**POINT 2　見分け方の3ステップ**

1. 文の中で、その言葉が**どんな意味で使われているか**を、ほかの言葉に言いかえてみる。
2. 候補の熟語を、**漢字1字ずつの意味**に分けてみる。
3. **いっしょに使われやすい言葉（セット）**で確かめる。

<div class="ex" markdown="1">

そのニュースに強い〔かんしん〕をもつ。　→「興味」と言いかえられる →「**関**（かかわる）＋心」→ **関心**
弟の努力に〔かんしん〕する。　→「りっぱだと心を動かされる」→「**感**（感じる）＋心」→ **感心**

</div>

</div>

<div class="point" markdown="1">

**POINT 3　よく出る同音異義語①**<span class="deru">入試</span>

| 読み | 熟語と意味 | 例文 |
|---|---|---|
| いがい | **意外**（思いのほか）／**以外**（それをのぞいたほか） | 意外な結果。／水以外は飲まない。 |
| かんしん | **関心**（興味）／**感心**（りっぱだと心を動かす） | 環境に関心をもつ。／努力に感心する。 |
| ほしょう | **保証**（まちがいないと請け合う）／**保障**（地位や権利などを守る）／**補償**（損害をつぐなう） | 品質を保証する。／社会保障。／事故の補償金。 |
| たいしょう | **対象**（目標・相手）／**対照**（くらべ合わせる・ちがいがきわだつ）／**対称**（つり合っている） | 小学生が対象。／対照的な性格。／左右対称の図形。 |
| いし | **意志**（やりとげようとする心）／**意思**（考え・思い） | 意志が強い。／意思を表示する。 |
| かいほう | **開放**（開けはなす）／**解放**（ときはなして自由にする）／**快方**（病気がよくなる）／**介抱**（看病する） | 校庭を開放する。／人質の解放。／快方に向かう。 |
| たいせい | **体制**（社会や組織のしくみ）／**態勢**（物事への身がまえ・準備）／**体勢**（体のかまえ） | 新しい体制。／受け入れ態勢。／体勢をくずす。 |
| ついきゅう | **追求**（目的のものを追い求める）／**追究**（どこまでも明らかにする）／**追及**（責任などを問いつめる） | 利益の追求。／真理の追究。／責任を追及する。 |

| かてい | **過程**（途中の道すじ）／**課程**（学校で学ぶ内容）／**仮定**（仮に決める）／**家庭** | へいこう | **平行**（どこまでも交わらない）／**並行**（並んで進む・同時に行う）／**閉口**（困りはてる） |

<div class="memo" markdown="1">

**先生のひとこと**　ペアで覚えるときは「**仲間の言葉**」を1つセットに。**保健**室・**保険**証、**鑑賞**＝美術館・**観賞**＝金魚や草花、**競走**＝かけっこ・**競争**＝なんでも勝負。ゲームの装備セットのように、**場面とセット**で覚えると、テストで思い出しやすくなります。

</div>

**POINT 5　同訓異字の使い分け表**<span class="deru">入試</span>

| 訓 | 漢字と使い分け（〔　〕は意味を確かめる熟語） |
|---|---|
| **あう** | **会う**：人と顔を合わせる〔会見〕／**合う**：一致する・ぴったりする〔合致〕／**遭う**：よくないことに出あう〔遭難〕 |
| **はかる** | **計る**：時間・数〔計算・時計〕／**測る**：長さ・高さ・深さ・広さ〔測量〕／**量る**：重さ・かさ〔重量〕／**図る**：くわだてる・工夫する〔意図〕 |
| **おさめる** | **収める**：中に入れる・成果を得る〔収納・収穫〕／**納める**：お金や品物をわたす・終える〔納税〕／**治める**：国や乱れをしずめる〔政治〕／**修める**：学問や行いを身につける〔修学〕 |
| **あつい** | **暑い**：気温が高い〔暑中〕／**熱い**：物の温度が高い・気持ちがはげしい〔熱湯〕／**厚い**：はばがある・心がこもっている〔厚紙・厚意〕 |
| **あける** | **開ける**：とじていたものを開く〔開門〕／**明ける**：夜や期間が終わる〔夜明け〕／**空ける**：中をからにする〔空席〕 |
| **かえる** | **変える**：前とちがうようにする〔変化〕／**代える**：役目をほかのものにさせる〔代理〕／**替える**：新しいものととりかえる〔両替〕／**換える**：交換する〔交換〕 |
| **うつす** | **写す**：文字や形をそのまま書きとる・写真にとる〔写真〕／**映す**：光や画面に姿を出す〔映画〕／**移す**：場所を動かす〔移動〕 |
| **つとめる** | **努める**：努力する〔努力〕／**勤める**：会社などで働く〔勤務〕／**務める**：役目を受けもつ〔任務〕 |
| **のぼる** | **上る**：上のほうへ行く・数量に達する〔上昇〕／**登る**：自分の足で高いところへ行く〔登山〕／**昇る**：日や地位が高くあがる〔昇進〕 |
| **とる** | **取る**：手に持つ（いちばん広く使う）／**採る**：選んで集める〔採用・採集〕／**捕る**：つかまえる〔捕獲〕／**撮る**：写真や映像をとる〔撮影〕 |
| **あらわす** | **表す**：気持ちや考えを外に出す〔表現〕／**現す**：かくれていた姿を出す〔出現〕／**著す**：本を書いて出す〔著者〕 |
| **たつ** | **立つ**／**建つ**：建物ができる〔建築〕／**断つ**：切りはなす・やめる〔断水〕／**絶つ**：つながりを終わらせる〔絶交〕／**裁つ**：布を切る〔裁断〕 |
| **その他** | **早い**（時刻）・**速い**（スピード）／**易しい**（かんたん）・**優しい**（思いやり）／**冷める**（温度）・**覚める**（目）／**備える**（準備）・**供える**（神仏にささげる）／**伸びる**（長さ・力）・**延びる**（時間・日程） |

</div>

<div class="memo" markdown="1">

**本質**　同訓異字は「**その漢字を使った熟語**」に言いかえられるかで確かめます。「税金をおさめる」→「納税」と言えるから**納**。「国をおさめる」→「政治」の**治**。「成功をおさめる」→「成功を収穫する」…とは言わないけれど、「**手に入れる**」なので**収**（収入・収益の収）。**熟語がいちばんの味方**です。

</div>

<div class="memo" markdown="1">

**注意**　「体重を**量る**」「体温を**測る**（計る）」のように、ものによっては2つの書き方がみとめられているものもあります。入試では、上の表の**代表的な使い方**で書けば大丈夫です。

</div>

## 解答・解説

<div class="kaito" markdown="1">

#### <span class="no">1</span>
(1) 意外　(2) 以外　(3) 関心　(4) 感心　(5) 容易　(6) 保健
**解説**　(1) 思っていたことの外＝意外。(2) 日曜日をのぞいたほか＝以外。(5)「たやすい」の意味なので**容易**。(6) 健康を保つ部屋なので**保健**室。

#### <span class="no">2</span>
(1) 会　(2) 合　(3) 遭　(4) 開　(5) 明　(6) 空
(7) 暑　(8) 熱　(9) 厚
**解説**　(3) 遭難の「遭」。(5)「夜明け」の「明」。(6)「空席」の「空」。(7) 気温は「暑い」、(8) 物の温度は「熱い」。

#### <span class="no">3</span>
(1) 計　(2) 測　(3) 量　(4) 図
(5) 納　(6) 治　(7) 収　(8) 修
**解説**　(4) 意図の「図」。(7)「勝利を手に入れる」なので「収める」。

#### <span class="no">4</span>
(1) ア　(2) イ　(3) ウ　(4) ア　(5) イ　(6) ウ
**解説**　「**保証**＝品物や人がたしかだと請け合う」「**保障**＝安全や権利を守る」「**補償**＝**補**ってつぐなう」。(5)「対照的」はちがいがきわだつこと。

#### <span class="no">5</span>
(1) 務　(2) 勤　(3) 努　(4) 表　(5) 現
(6) 写　(7) 映
**解説**　(1)「任務」→役目を受けもつ。(2)「勤務」。(3)「努力」。(5)「出現」の現。(7) 水面に姿が出るのは「映る・映す」（「映像」の映）。

#### <span class="no">6</span>
(1) 制 → 勢　(2) 過 → 課　(3) 観 → 鑑
(4) 並 → 平　(5) 究 → 及　(6) 志 → 思
**解説**　(1) 体のかまえは「体**勢**」。「体制」は社会や組織のしくみ。(2) 学ぶ内容は「課程」。(3) 絵画（芸術）を味わうのは「鑑賞」。(4) 交わらないのは「平行」。(5) 責任を問いつめるのは「追及」。(6) 考えを表すのは「意思」。

#### <span class="no">7</span>
(1) 製作　(2) 制作　(3) 昇　(4) 登
(5) 供　(6) 備
**解説**　(1) 木の箱は「物」なので製作、(2) 壁画は芸術作品なので制作。(3) 日がのぼるのは「昇る」。(5)「お供え」の供、(6)「準備」の備。

#### <span class="no">8</span>
(1) 2　(2) 3　(3) 2　(4) 4
**解説**　(1) よくないことに出あうのは「遭う」。2 の台風も「遭う」。1 は会う、3・4 は合う。(2)「機会」＝チャンス。1 は機械、2 は器械、4 は奇怪。(4) 1 は「指示」、2 は「過程」、3 は思いやりなので「厚意」が正しい。

#### <span class="no">9</span>
(1) ① 測　② 意外　③ 検討　④ 映　⑤ 修　⑥ 務

#### <span class="no">10</span>
