# 小6国語 語句4「慣用句・ことわざ・故事成語」

<p class="lead">ねらい：慣用句・ことわざ・故事成語のちがいを知り、意味・由来・正しい使い方を覚えて、文章の中で使いこなせるようになる。　中3の「慣用句・四字熟語」の土台になる単元です。</p>

## 語句のポイント

<div class="point" markdown="1">

**POINT 1　3つのちがいをはっきりさせよう**

| 種類 | どんな言葉か | 例 |
|---|---|---|
| **慣用句** | 2つ以上の言葉が結びついて、**元の言葉とはちがう特別な意味**になったもの | 顔が広い（＝知り合いが多い） |
| **ことわざ** | 昔から言い伝えられてきた、**生活の知恵や教え（教訓）**をふくむ短い言葉 | 急がば回れ |
| **故事成語** | **中国の古い出来事やお話（故事）**からできた言葉 | 矛盾・蛇足 |

- 慣用句は「**文の部品**」。「顔が広い人」「腹を立てる」のように、文の中に入れて使う。
- ことわざは「**それだけで1つの教え**」。「〜というように」「〜とはこのことだ」と引用して使うことが多い。

</div>

<div class="memo" markdown="1">

**本質**　慣用句は「**セットで1つの単語**」のようなもの。だから**部品を取りかえられません**。「顔が広い」を「顔が大きい」と言ったら、ただの顔のサイズの話になってしまいます。「足を洗う（悪い仲間から抜ける）」を「足をすすぐ」にしてもダメ。**形ごと覚える**のがコツです。

</div>

<div class="point" markdown="1">

**POINT 2　体の部分を使った慣用句**<span class="deru">入試</span>

| 部分 | 慣用句と意味 |
|---|---|
| **頭** | 頭が下がる（感心してうやまう）／頭をかかえる（困りはてる）／頭を冷やす（落ち着く） |
| **顔** | 顔が広い（知り合いが多い）／顔に泥をぬる（はじをかかせる）／顔から火が出る（とてもはずかしい） |
| **目** | 目が高い（よいものを見分ける力がある）／目を丸くする（おどろく）／目に余る（見ていられないほどひどい） |
| **耳** | 耳が痛い（弱点をつかれて聞くのがつらい）／耳をうたがう（聞きまちがいかと思うほどおどろく）／耳にたこができる（同じことを何度も聞かされてうんざり） |
| **鼻** | 鼻が高い（ほこらしい）／鼻にかける（自慢する）／鼻であしらう（相手をばかにして冷たくあつかう） |
| **口** | 口がかたい（秘密を守る）／口をすべらす（うっかり言ってしまう）／口をとがらす（不満そうな顔をする） |
| **歯・舌** | 歯が立たない（かなわない）／歯に衣着せぬ（思ったことをはっきり言う）／舌を巻く（とても感心する） |
| **首** | 首を長くする（今か今かと待つ）／首をかしげる（ふしぎに思う） |
| **肩** | 肩を持つ（味方をする）／肩を落とす（がっかりする）／肩の荷が下りる（責任から解放されてほっとする） |
| **胸** | 胸をなでおろす（安心する）／胸がおどる（わくわくする）／胸を借りる（強い相手に練習の相手をしてもらう） |
| **腹** | 腹を割る（本心をうちあける）／腹をくくる（覚悟を決める）／腹が黒い（心の中で悪いことを考えている） |
| **手** | 手を焼く（あつかいに困る）／手に汗をにぎる（はらはらする）／手も足も出ない（どうしようもない） |
| **足** | 足が出る（予算をこえる）／足を洗う（悪い仲間や仕事をやめる）／足が棒になる（歩きすぎて足がつかれる） |
| **腕・腰** | 腕が鳴る（力を見せたくてうずうずする）／腕をみがく（技術を高める）／腰が低い（えらぶらず、ていねい） |

</div>

<div class="memo" markdown="1">

**先生のひとこと**　物語文の読解では、「**肩を落とした**」「**胸をなでおろした**」「**唇をかんだ**」のような体の動きの言葉が、そのまま**気持ちのヒント**になります。慣用句を覚えることは、読解の点数にも直結しますよ。

</div>

<div class="point" markdown="1">

**POINT 4　意味の似たことわざ・反対の意味のことわざ**<span class="deru">入試</span>

**① 意味の似たことわざ**

| 意味 | ことわざ |
|---|---|
| 名人でも失敗することがある | 猿も木から落ちる ＝ 弘法にも筆の誤り ＝ かっぱの川流れ |
| 価値がわからない人には役に立たない | 猫に小判 ＝ 豚に真珠 |
| 手ごたえがない・ききめがない | のれんに腕押し ＝ ぬかにくぎ ＝ 豆腐にかすがい |
| 悪いことに悪いことが重なる | 泣きっ面に蜂 ＝ 弱り目にたたり目 |
| 欲ばると両方とも失う | 二兎を追う者は一兎をも得ず ＝ あぶはち取らず |
| 比べものにならないほどちがう | 月とすっぽん ＝ ちょうちんにつりがね |
| 小さなことも積み重ねると大きくなる | ちりも積もれば山となる ＝ 雨垂れ石をうがつ |
| 用心の上にも用心する | 石橋をたたいて渡る ＝ 念には念を入れよ |
| 急ぐときほど安全・確実な方法をとれ | 急がば回れ ＝ 急いては事を仕損じる |

**② 反対の意味のことわざ**

| こちらは… | ⇔ | こちらは… |
|---|---|---|
| 好きこそものの上手なれ（好きなことは上達する） | ⇔ | 下手の横好き（好きでも上手とはかぎらない） |
| 三人寄れば文殊の知恵（集まるとよい知恵が出る） | ⇔ | 船頭多くして船山に上る（指図する人が多いとまとまらない） |
| 蛙の子は蛙（子は親に似る） | ⇔ | とんびが鷹を生む（平凡な親からすぐれた子が生まれる） |
| 渡る世間に鬼はなし（世の中にはやさしい人もいる） | ⇔ | 人を見たら泥棒と思え（人をかんたんに信じるな） |
| 善は急げ（よいことはすぐにやれ） | ⇔ | 急がば回れ／石橋をたたいて渡る |
| 立つ鳥跡を濁さず（去るときはきれいに） | ⇔ | 後は野となれ山となれ（あとはどうなってもかまわない） |
| 果報は寝て待て（あせらず待てば幸運が来る） | ⇔ | まかぬ種は生えぬ（何もしなければ結果は出ない） |

</div>

<div class="point" markdown="1">

**POINT 5　故事成語は「お話」ごと覚える**<span class="deru">入試</span>

| 故事成語 | もとになったお話（故事） | 意味 |
|---|---|---|
| **矛盾** | 楚の国の商人が「どんな盾も突き通す矛」と「どんな矛も防ぐ盾」を売っていた。ある人に「その矛でその盾を突いたらどうなるのか」と聞かれ、答えられなかった。（『韓非子』） | 話のつじつまが合わないこと |
| **蛇足** | 蛇の絵を早くかいた者が酒を飲める、という競争で、一番にかき終えた男が調子に乗って足までかいた。「蛇に足はない」と言われ、酒を取られた。（『戦国策』） | よけいなつけ足し |
| **五十歩百歩** | 戦場で五十歩にげた兵士が、百歩にげた兵士を「おくびょうだ」と笑った。孟子が「にげたことは同じだ」と王に説いた。（『孟子』） | 少しのちがいはあっても、本質は同じ |
| **漁夫の利** | しぎ（鳥）とはまぐりが、くちばしと貝がらでかみ合って争っているうちに、通りかかった漁師が両方ともつかまえた。（『戦国策』） | 二者が争っているすきに、第三者が利益を横取りすること |
| **推敲** | 唐の詩人・賈島が、詩の一句を「僧は推す月下の門」にするか「僧は敲く」にするかで迷い、えらい詩人の韓愈に「敲くがよい」と教わった。 | 文章や詩を何度も練り直すこと |
| **杞憂** | 杞の国の人が「天が落ちてきたらどうしよう」と、ねむれないほど心配した。（『列子』） | しなくてよい心配、取りこし苦労 |
| **四面楚歌** | 楚の項羽が漢の軍に囲まれたとき、四方から楚の歌が聞こえてきた。項羽は「楚の人々まで敵になったのか」となげいた。（『史記』） | まわりが敵ばかりで、助けがないこと |
| **背水の陣** | 漢の韓信が、わざと川を背にして陣をしき、にげ場をなくして兵士を必死に戦わせ、勝った。（『史記』） | 後がない覚悟で物事に取り組むこと |
| **塞翁が馬** | 国境のとりでに住む老人の馬がにげたが、名馬を連れて帰ってきた。その馬から息子が落ちて足をけがしたが、そのおかげで戦争に行かずにすんだ。（『淮南子』） | 人生の幸・不幸は予測できない |
| **守株** | 切り株にうさぎがぶつかって死んだのを見た農夫が、畑仕事をやめて毎日切り株を見張ったが、二度とうさぎは来なかった。（『韓非子』） | 古いやり方にこだわって進歩しないこと（「株を守る」とも） |

</div>

<div class="memo" markdown="1">

**本質**　故事成語は、**お話のどこが「意味」になったか**を考えると忘れません。「蛇足」は**足**がよけいだった話、「漁夫の利」は**漁師**が得をした話、「五十歩百歩」は**にげたことに変わりはない**話。言葉の中に、お話のカギになる部分がそのまま入っています。

</div>

<div class="point" markdown="1">

**POINT 6　まちがえやすい使い方**<span class="deru">入試</span>

| 言葉 | ○ 本来の意味 | × よくある誤り |
|---|---|---|
| **気が置けない** | 遠慮しなくてよい、気楽につき合える | 油断できない、気がゆるせない |
| **情けは人のためならず** | 人に親切にすると、めぐりめぐって**自分によいことが返ってくる** | 情けをかけると、その人のためにならない |
| **役不足** | 本人の力にくらべて、**役目が軽すぎる** | 役目にくらべて力が足りない（それは「**力不足**」） |
| **流れに棹さす** | 流れに乗って勢いをつける | 流れにさからう |
| **姑息** | その場しのぎ、一時の間に合わせ | ひきょう |
| **煮詰まる** | 議論が進み、結論が出そうになる | 行きづまる |
| **汚名** | 汚名を**返上**する（悪い評判を消す） | 汚名を挽回する（「**名誉**を挽回する」とまざった形） |
| **雪辱** | 雪辱を**果たす**（前の負けの仕返しをする） | 雪辱を晴らす（「**屈辱**を晴らす」とまざった形） |
| **的** | 的を**射る**（要点をうまくとらえる） | 的を得る |

</div>

<div class="memo" markdown="1">

**注意**　「気が置けない」の「気を置く」は「**気をつかう・遠慮する**」という意味。それが「ない」のだから、「遠慮しなくていい＝仲がいい」となります。**言葉を分解して考える**と、誤りにだまされません。

</div>
