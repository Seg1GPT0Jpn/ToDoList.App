# 中2国語 古典5「漢文入門（返り点・書き下し文・故事成語）」

<p class="lead">ねらい：返り点のきまりで読む順番がわかり、訓読文を書き下し文に直せるようになる。矛盾・推敲・蛇足・漁夫の利・五十歩百歩などの故事成語を、原文といっしょに覚える。</p>

## 漢文のポイント

<div class="point" markdown="1">

**POINT 1　そもそも漢文とは？　――中国語を日本語の順に読むくふう**

**漢文**は、昔の中国の文章（古典中国語）です。日本人は1000年以上前から、これを**日本語として読む**くふうをしてきました。これを**訓読**といいます。

いちばんの問題は**語順**です。中国語は英語と同じで「**動詞 → 目的語**」の順。日本語は「**目的語 → 動詞**」の順です。

| | 語順 | 例 |
|---|---|---|
| 中国語（漢文） | 読む ＋ 書を | 読書 |
| 日本語 | 書を ＋ 読む | 書を読む |

熟語の「読書」「登山」「帰国」は、まさにこの中国語の語順がそのまま残ったもの。だから、下の字から上の字へ**返って**読む必要があります。その目印が**返り点**です。

| 呼び名 | どんなもの | 例 |
|---|---|---|
| **白文** | 漢字だけの、もとの文 | 学而時習之 |
| **訓読文** | 白文に返り点・送り仮名・句読点をつけたもの | 学<sup>ビテ</sup>而時<sup>ニ</sup>習<sub style="font-weight:700">レ</sub>之<sup>ヲ</sup> |
| **書き下し文** | 訓読文を、漢字かな交じりの日本語の文に書き直したもの | 学びて時に之を習ふ。 |

</div>

<div class="memo" markdown="1">

**注意**　漢文は本来**縦書き**で、送り仮名は漢字の**右下**、返り点は漢字の**左下**につけます。このテキストは横書きなので、**送り仮名を右上の小さいカタカナ**（学<sup>ビテ</sup>）、**返り点を右下の小さい記号**（習<sub style="font-weight:700">レ</sub>）で表します。

**POINT 2　返り点のきまり　――「飛ばして、あとで返る」**

大原則：**返り点のついていない字は、上から順に読む。返り点のついた字は、いったん飛ばして、あとで返って読む。**

| 返り点 | きまり | 例（読む順） |
|---|---|---|
| **レ点** | **すぐ下の1字**を読んでから、レ点の字に返る（1字だけ返る） | 読<sub style="font-weight:700">レ</sub>書　→　書①　読②　「書を読む」 |
| **一・二点** | **2字以上**はなれて返る。**一点の字まで読んだら二点の字へ**（三点があれば次に三へ） | 登<sub style="font-weight:700">二</sub>高山<sub style="font-weight:700">一</sub>　→　高①山②　登③　「高山に登る」 |
| **上・下点**（上・中・下） | **一二点をはさんで**、さらに返る。上点の字まで読んだら下点の字へ | 有<sub style="font-weight:700">下</sub>読<sub style="font-weight:700">二</sub>書<sub style="font-weight:700">一</sub>者<sub style="font-weight:700">上</sub>　→　書①読②者③有④　「書を読む者有り」 |

**読む順番の手順**（これで必ず解ける）

1. いちばん上の字から見ていく。**返り点のない字・一点の字・上点の字**は、出てきたら読む。
2. **レ点・二点・三点・下点の字**は、飛ばして先へ進む（あとで返る）。
3. 字を読んだら「**レ点で待っている字はないか？**（すぐ上の字）」「**一を読んだら二へ、二を読んだら三へ**」「**上を読んだら下へ**」と確かめて返る。
4. 返って読み終えたら、**まだ読んでいない、いちばん上の字**から続ける。

<div class="ex" markdown="1">

**レ点が続く**　欲<sub style="font-weight:700">レ</sub>見<sub style="font-weight:700">レ</sub>之　→　之①　見②　欲③　「之を見んと欲す」（下から順にどんどん返る）
**レ点＋一二点**　不<sub style="font-weight:700">レ</sub>入<sub style="font-weight:700">二</sub>虎穴<sub style="font-weight:700">一</sub>　→　虎①穴②　入③　不④　「虎穴に入らず」

</div>

</div>

<div class="memo" markdown="1">

**発展**　**一レ点**（一点とレ点が1つの字についたもの）は「**まずレ点、次に一点**」の順にはたらきます。
楚人有<sub style="font-weight:700">下</sub>鬻<sub style="font-weight:700">二</sub>盾与<sub style="font-weight:700">一レ</sub>矛者<sub style="font-weight:700">上</sub>（矛盾）
→　楚①人②　盾③　矛④　与⑤（レ点で返る）　鬻⑥（一から二へ）　者⑦　有⑧（上から下へ）
書き下し文：**楚人に盾と矛とを鬻ぐ者有り。**

</div>

<div class="point" markdown="1">

**POINT 3　送り仮名と書き下し文のきまり**

**送り仮名**：日本語の活用語尾や助詞を、**歴史的仮名遣いのカタカナ**で漢字の右下に小さく書いたもの。

**書き下し文のきまり**

| きまり | 例 |
|---|---|
| ① 送り仮名は**ひらがな**に直す（歴史的仮名遣いのまま） | 習<sup>フ</sup>　→　習ふ |
| ② 日本語の**助詞・助動詞**にあたる漢字は**ひらがな**にする | 不　→　ず　　也　→　なり　　与（と）　→　と　　之（の）　→　の |
| ③ **置き字**は書かない | 而・於　→　書かない |
| ④ それ以外の漢字は**漢字のまま**残す（代名詞の「之（これ）」も漢字のまま） | 之<sup>ヲ</sup>　→　之を |

<div class="ex" markdown="1">

吾<sup>ガ</sup>盾之堅<sup>キコト</sup>　→　吾が盾**の**堅きこと　（この「之」は助詞「の」なので**ひらがな**）
学<sup>ビテ</sup>而時<sup>ニ</sup>習<sub style="font-weight:700">レ</sub>之<sup>ヲ</sup>　→　学びて時に**之**を習ふ　（この「之」は「これ」という代名詞なので**漢字**）

</div>

</div>

<div class="point" markdown="1">

**POINT 4　置き字　――「書いてあるのに読まない字」**

中国語ではちゃんと意味があるのに、日本語では**送り仮名などで意味を表すので、読まない字**を**置き字**といいます。

| 置き字 | 主なはたらき | 日本語では | 例 |
|---|---|---|---|
| **而** | 前後をつなぐ（順接・逆接） | 前の字の送り仮名「て・して・ども」で表す | 学<sup>ビテ</sup>而　→　学びて |
| **於・于・乎** | 場所・対象・比較（〜に・〜より） | 下の字の送り仮名「に・を・より」で表す | 施<sub style="font-weight:700">二</sub>於人<sup>ニ</sup><sub style="font-weight:700">一</sub>　→　人に施す |
| **矣・焉** | 文末で強めたり、言い切ったりする | 読まない | 謂<sub style="font-weight:700">レ</sub>過<sup>チト</sup>矣　→　過ちと謂ふ |

</div>

<div class="memo" markdown="1">

**注意**　「乎」は、文末で「**〜か・〜や**」（疑問・反語）と読むときは**置き字ではない**（書き下し文ではひらがな）。「不亦説乎（亦説ばしからずや）」の「乎」は「や」と読む。

</div>

**POINT 5　故事成語　――昔の中国のエピソードから生まれた言葉**　<span class="deru">入試</span>

| 故事成語 | 意味 | もとの話（出典） |
|---|---|---|
| **矛盾** | つじつまが合わないこと | 「どんな盾も突き通す矛」と「どんな矛も通さない盾」を売る商人（韓非子） |
| **推敲** | 文章を何度も練り直すこと | 詩人が「推す」か「敲く」かで迷い続けた（唐の詩人・賈島の話） |
| **蛇足** | よけいなつけ足し | 蛇の絵の早がき競争で、足までかいて負けた（戦国策） |
| **漁夫の利** | 二者が争っているすきに、第三者が利益を得ること | しぎとはまぐりが争っているうちに、漁師が両方つかまえた（戦国策） |
| **五十歩百歩** | 少しの違いはあっても、本質は同じこと | 戦場で五十歩逃げた兵が、百歩逃げた兵を笑った（孟子） |
| **温故知新** | 昔のことを学び、新しい知識や考えを得ること | 論語「温故而知新」 |
| **杞憂** | しなくてよい心配、とりこし苦労 | 杞の国の人が、天が落ちてこないかと心配した（列子） |
| **守株** | 古い習慣にこだわり、進歩がないこと | 切り株にぶつかったうさぎを待ち続けた農夫（韓非子） |
| **四面楚歌** | まわりが敵ばかりで、助けがないこと | 項羽が、四方から故郷の楚の歌を聞いた（史記） |
| **背水の陣** | 失敗したら後がない覚悟で取り組むこと | 川を背にして陣をしき、兵を必死に戦わせた（史記） |

**POINT 6　故事成語の原文と書き下し文**

**① 矛盾**（韓非子）

<div class="ex" markdown="1">

楚人有<sub style="font-weight:700">下</sub>鬻<sub style="font-weight:700">二</sub>盾与<sub style="font-weight:700">一レ</sub>矛者<sub style="font-weight:700">上</sub>。誉<sub style="font-weight:700">レ</sub>之曰、「吾盾之堅、莫<sub style="font-weight:700">二</sub>能陥<sub style="font-weight:700">一</sub>也。」又誉<sub style="font-weight:700">二</sub>其矛<sub style="font-weight:700">一</sub>曰、「吾矛之利、於<sub style="font-weight:700">レ</sub>物無<sub style="font-weight:700">レ</sub>不<sub style="font-weight:700">レ</sub>陥也。」或曰、「以<sub style="font-weight:700">二</sub>子之矛<sub style="font-weight:700">一</sub>、陥<sub style="font-weight:700">二</sub>子之盾<sub style="font-weight:700">一</sub>、何如。」其人弗<sub style="font-weight:700">レ</sub>能<sub style="font-weight:700">レ</sub>応也。

</div>

**書き下し文**　楚人に盾と矛とを鬻ぐ者有り。之を誉めて曰はく、「吾が盾の堅きこと、能く陥すもの莫きなり。」と。又其の矛を誉めて曰はく、「吾が矛の利なること、物に於いて陥さざる無きなり。」と。或ひと曰はく、「子の矛を以て、子の盾を陥さば何如。」と。其の人応ふること能はざるなり。
**現代語訳**　楚の国の人で、盾と矛を売る者がいた。盾をほめて「わたしの盾のかたいことといったら、突き通せるものはない。」と言った。またその矛をほめて「わたしの矛の鋭いことといったら、どんなものでも突き通さないものはない。」と言った。ある人が「あなたの矛で、あなたの盾を突いたらどうなるのか。」と言った。その人は答えることができなかった。

**② 蛇足**（戦国策・一部）　蛇の絵を早くかき上げた人が、得意になって足までかいていると、あとからかき上げた人が酒を取り上げて言った。

<div class="ex" markdown="1">

蛇固無<sub style="font-weight:700">レ</sub>足。子安能為<sub style="font-weight:700">二</sub>之足<sub style="font-weight:700">一</sub>。　→　蛇固より足無し。子安くんぞ能く之が足を為らん。
（現代語訳：蛇にはもともと足がない。あなたはどうして蛇の足などかけようか、かけはしない。）

</div>

**③ 漁夫の利**（戦国策・一部）　しぎがはまぐりの身をつつき、はまぐりは殻を閉じてしぎのくちばしをはさんだ。

<div class="ex" markdown="1">

両者不<sub style="font-weight:700">レ</sub>肯<sub style="font-weight:700">二</sub>相舍<sub style="font-weight:700">一</sub>。漁者得而并禽<sub style="font-weight:700">レ</sub>之。　→　両者相舍つるを肯ぜず。漁者得て之を并せ禽ふ。
（現代語訳：両者はたがいにはなそうとしない。そこへ漁師がやって来て、両方ともつかまえてしまった。）

</div>

**④ 推敲**　唐の詩人・賈島は、ろばに乗りながら「僧は推す月下の門」という句を作ったが、「推す」を「敲く」にしようかと迷い、手で押すまねやたたくまねをくり返した。大文学者の韓愈の行列にぶつかってしまい、わけを話すと、韓愈は「敲くがよい」と答えた。

</div>

<div class="memo" markdown="1">

**本質**　返り点は「暗号」ではなく、**中国語の語順を日本語の語順に並べかえる記号**です。「不」（〜ず）が上にあるのは、英語の not が動詞の前にくるのと同じ。だから「不<sub style="font-weight:700">レ</sub>知」は「知ら**ず**」と、**否定が最後**にきます。

</div>

<div class="memo" markdown="1">

**発展**（高校でくわしく）**再読文字**　1つの字を**2回読む**字。「未」は、まず返り点を無視して「**未だ**」と読み、返ってきてもう一度「**ず**」と読む。
未<sub style="font-weight:700">レ</sub>知<sup>ラ</sup>　→　未だ知らず（まだ知らない）

</div>

<div class="memo" markdown="1">

**先生のひとこと**　返り点は「**ちょっと待ってね**」の札です。レ点は「1人だけ先に行って」、一二点は「一番が通ったら二番どうぞ」、上下点は「一二グループが全部済んでから」。札のない子は、どんどん先に進んでＯＫ。

</div>

#### <span class="no">3</span>
(1) 書を読む。　(2) 山に登る。　(3) 知らず。　(4) 故郷に帰る。
(5) 学びて時に之を習ふ。
(6) 己の欲せざる所は、人に施すこと勿かれ。
**解説**　(3) 「不」は助動詞「ず」なのでひらがな。(5) 「而」は置き字、「習ふ」は歴史的仮名遣いのまま。(6) 読む順は　己→欲→不→所／人→施→勿（於は置き字）。「勿」は「なかれ」と読み、漢字のまま書くのがふつう。（意味：自分がされたくないことは、人にしてはいけない）

(2) 青は之を藍より取りて藍より青し。
(3) 学びて思はざれば則ち罔し。
