# 中3国語 語句8「慣用句・四字熟語・ことわざ（入試対策）」

<p class="lead">ねらい：入試によく出る慣用句・四字熟語・ことわざを「意味・使い方・誤用」の3点セットで覚え、漢字のまちがいや意味の誤解をしなくなる。敬語の誤用もあわせて、語彙の問題で1点も落とさない力をつける。</p>

## 語句のポイント

<div class="point" markdown="1">

**POINT 1　入試では「3つの角度」から出る**<span class="deru">入試</span>

| 出され方 | 問題の例 | 対策 |
|---|---|---|
| **① 意味** | 「――線の意味として最も適するものを選びなさい」 | 言葉の**成り立ち**から意味を考える（下の「本質」） |
| **② 使い方** | 「使い方が**正しいもの**（**適切でないもの**）を選びなさい」 | **よくある誤用**とセットで覚える |
| **③ 形・漢字** | 「漢字のまちがいを直しなさい」「（　）に入る語を答えなさい」 | 漢字の**意味**を考えて書く（一発→一**髪**） |

**4つの種類のおさらい**
- **慣用句**：2語以上が結びついて特別な意味になったもの（**文の部品**）。例：口火を切る
- **ことわざ**：生活の知恵・教訓をふくむ言い伝え（**それだけで1つの教え**）。例：急がば回れ
- **故事成語**：中国の古い出来事からできた言葉。例：他山の石・矛盾
- **四字熟語**：漢字4字で特別な意味を表す言葉。故事成語でもあるものが多い。例：呉越同舟・朝三暮四

</div>

**POINT 3　意味を誤解しやすい言葉**<span class="deru">入試</span>

文化庁の「国語に関する世論調査」でも、本来の意味とちがう意味で使う人が多いとされた言葉です。

| 言葉 | ○ 本来の意味 | × よくある誤解 |
|---|---|---|

| **敷居が高い** | 不義理や失礼をしていて、相手の家に行きにくい | 高級・上品すぎて入りにくい |
| **破天荒** | だれもしなかったことを**初めて**行うこと | 豪快で大胆なこと |
| **憮然** | 失望して、ぼんやりしている様子 | 腹を立てている様子 |
| **失笑** | こらえきれずに、思わず吹き出して笑うこと | 笑いも出ないほどあきれること |

| **煮詰まる** | 議論が十分に進み、結論が出る段階になる | 行きづまって結論が出せない |
| **他山の石** | 他人のよくない言動も、自分をみがく助けになる | 目上の人のよい行いを手本にする |
| **世間ずれ** | 世の中でもまれて、ずる賢くなっていること | 世間の考えからずれていること |
| **潮時** | 物事をするのにちょうどよい時期 | 物事の終わり・引き際 |
| **雨模様** | 雨が降りそうな空の様子 | 小雨が降ったりやんだりしている様子 |

<div class="memo" markdown="1">

**本質**　誤解しやすい言葉は、**言葉の部品に分解する**と本来の意味が見えてきます。

- 「役**不足**」…足りないのは**役**のほう。だから「その人に対して役が小さすぎる」。
- 「流れに**棹さす**」…船頭が棹を川底について、**流れに乗って船を進める**動作。
- 「気が**置けない**」…「気を置く」＝気をつかう・遠慮する。それが「置けない」から、遠慮がいらない。
- 「**破天荒**」…「天荒」は、だれも開いたことのない荒れ地。それを「破る」＝初めて切り開く。

丸暗記より、**なぜその意味になるのか**を一度考えておくと、本番で迷いません。

</div>

| ○ 正しい形 | × 誤った形 | まざった相手 |
|---|---|---|
| 汚名を**返上**する／名誉を**挽回**する | 汚名を挽回する | 返上＋挽回 |
| 的を**射る**／当を**得る** | 的を得る | 射る＋得る |
| 雪辱を**果たす**／屈辱を**晴らす** | 雪辱を晴らす | 果たす＋晴らす |

| 取りつく**島**もない | 取りつく暇もない | 島（たよるもの）を「暇」と聞きまちがい |
| 押しも押され**もせぬ** | 押しも押されぬ | 「押すに押されぬ」 |
| **上を下へ**の大騒ぎ | 上へ下への大騒ぎ | 「上へ下へ」と聞きまちがい（本来は上の物を下にするほどの混乱） |
| **足を**すくわれる | 足元をすくわれる | 「足元を見られる」 |

<div class="memo" markdown="1">

**先生のひとこと**　「**霧と夢**」はセットで覚えましょう。五里**霧**中は「霧の中で迷子」＝方針が立たない。無我**夢**中は「夢中で我を忘れる」＝熱中する。迷子になったら霧、熱中したら夢。これで二度とまちがえません。

**読みにも注意**　一期一会（いち**ご**いち**え**）・老若男女（ろう**にゃく**なん**にょ**）・言語道断（**ごん**ご**どう**だん）・一朝一夕（いっちょういっ**せき**）・有象無象（**う**ぞう**む**ぞう）

</div>

**POINT 7　ことわざ：意味・漢字の誤りに注意**<span class="deru">入試</span>

| ことわざ | 意味 | 注意 |
|---|---|---|
| **濡れ手で粟** | 苦労せずに多くの利益を得る | ×濡れ手で**泡**（粟は穀物。濡れた手でつかむとたくさんつく） |
| **待てば海路の日和あり** | あせらず待てば、よい機会がくる | ×待てば**甘露**の日和あり |
| **袖振り合うも他生の縁** | ちょっとした出会いも前世からの縁 | ×**多少**の縁（「他生」は前世のこと） |
| **枯れ木も山のにぎわい** | つまらないものでも、ないよりはまし | **自分のことをへりくだって**使う。他人に使うと失礼 |
| **犬も歩けば棒に当たる** | ①出しゃばると災難にあう ②思わぬ幸運にあう | もとは①の意味。今は②でも使う |
| **転ばぬ先の杖** | 失敗しないよう、前もって用心する | 「備えあれば憂いなし」と似た意味 |
| **生き馬の目を抜く** | すばしこく、油断のならないこと | 「抜け目がない」と似た意味 |
| **青は藍より出でて藍より青し** | 弟子が師よりすぐれること（出藍の誉れ） | 故事成語（『荀子』） |

**似た意味の組み合わせ**　五十歩百歩 ≒ 大同小異／十人十色 ≒ 千差万別／馬の耳に念仏 ≒ 馬耳東風／一石二鳥 ≒ 一挙両得
**反対の意味の組み合わせ**　異口同音（みな同じ） ⇔ 十人十色（みなちがう）／大器晩成 ⇔ 栴檀は双葉より芳し（すぐれた人は幼いころからすぐれている）

</div>

<div class="point" markdown="1">

**POINT 8　敬語・語彙の総合：誤用のパターン**<span class="deru">入試</span>

| 誤用のパターン | × 誤り | ○ 正しい |
|---|---|---|
| **相手の動作に謙譲語** | 先生が**申された**とおりです。 | 先生が**おっしゃった**とおりです。 |
| | 受付で**うかがって**ください。 | 受付で**おたずねください**（お聞きください）。 |
| | どうぞこの資料を**拝見して**ください。 | どうぞこの資料を**ご覧ください**。 |
| | 温かいうちに**いただいて**ください。 | 温かいうちに**召し上がって**ください。 |
| **身内に尊敬語**（外の人に話すとき） | 父が**いらっしゃいます**。 | 父が**おります**。 |
| | 母が**おっしゃっていました**。 | 母が**申しておりました**。 |
| **二重敬語** | 先生が**おっしゃられた**。 | 先生が**おっしゃった**。 |
| | 社長が**ご覧になられる**。 | 社長が**ご覧になる**。 |
| **「お（ご）〜する」を相手に** | 窓口を**ご利用して**ください。 | 窓口を**ご利用ください**。 |

**手順**　① その動作は**だれの動作か**を見る　② 相手（目上）の動作 → 尊敬語、自分（身内）の動作 → 謙譲語　③ 敬語が**二重**になっていないか確かめる。

</div>

<div class="memo" markdown="1">

**発展**　慣用句・四字熟語は、作文でも武器になります。ただし「**使い慣れていない言葉は使わない**」のが鉄則。条件作文で「役不足」「確信犯」を誤った意味で使うと、それだけで減点です。自信のある言葉を、**一つの作文に一つか二つ**。それが一番効果的です。

</div>

## 練習問題

### 基本

#### <span class="no">1</span> 次の（　）に体の一部や物を表す漢字一字（または二字）を入れて、慣用句を完成させなさい。

<div class="cols2" markdown="1">

(1) 友人の見事な作文に（　）を巻いた。
(2) 楽しい雰囲気に（　）を差す発言。
(3) 何度説明されても（　）に落ちない。
(4) 先輩たちも彼の判断には一（　）置く。
(5) 遅れないよう、前もって（　）を刺す。
(6) 祖父が（　）塩にかけて育てた盆栽。
(7) 会議の口（　）を切ったのは私だった。
(8) 次の代表として彼に白（　）の矢が立った。

</div>

#### <span class="no">2</span> 次の四字熟語には、漢字の誤りが一字ずつある。誤っている漢字をぬき出し、正しい漢字に直しなさい。

<div class="cols2" markdown="1">

(1) 異句同音
(2) 危機一発
(3) 五里夢中
(4) 絶対絶命
(5) 自我自賛
(6) 短刀直入
(7) 責任転化
(8) 意心伝心

</div>

#### <span class="no">3</span> 次の四字熟語の意味を、あとのア〜カから1つずつ選びなさい。

<div class="cols2" markdown="1">

(1) 我田引水
(2) 付和雷同
(3) 本末転倒
(4) 針小棒大
(5) 臨機応変
(6) 大器晩成

</div>

ア　小さなことを大げさに言う　　イ　その場に応じて適切に対応する
ウ　自分に都合のよいようにする　　エ　大人物は時間をかけて大成する
オ　他人の意見にすぐ従う　　カ　大事なこととつまらないことを取りちがえる

### 標準

#### <span class="no">4</span> ――線の言葉の使い方が正しいものには○、誤っているものには×を書きなさい。

(1) 「主役なんて、私には**役不足**です」と、彼女は謙遜して断った。
(2) 彼とは小学校からの**気が置けない**友人なので、何でも相談できる。

#### <span class="no">1</span>
(1) 舌　(2) 水　(3) 腑　(4) 目　(5) 釘　(6) 手　(7) 火　(8) 羽
**解説**　(3)「腑」は内臓のこと。腹の中に落ちて納まらない＝納得できない。(8) 神が選んだ家の屋根に白い羽の矢が立つ、という言い伝えから。

#### <span class="no">2</span>
(1) 句→口　(2) 発→髪　(3) 夢→霧　(4) 対→体　(5) 我→画　(6) 短→単　(7) 化→嫁　(8) 意→以
**解説**　漢字の意味から考える。(2) 髪の毛一本のすきま。(3) 霧の中で方向がわからない。(7) 責任をほかに「嫁がせる」＝おしつける。

#### <span class="no">3</span>
(1) ウ　(2) オ　(3) カ　(4) ア　(5) イ　(6) エ
**解説**　(1) 自分の田にだけ水を引く。(2)「雷同」は雷が鳴ると万物がそれに応じて響くこと。

#### <span class="no">4</span>
(1) ×　(2) ○　(3) ×　(4) ○　(5) ×　(6) ○　(7) ○　(8) ○
**解説**　(1) 謙遜するなら「**力不足**」。(3)「敷居が高い」は、不義理をして行きにくいときに使う。高級で入りにくい意味は誤用。(5)「流れに棹さす」は流れに乗る意味。逆らう意味で使っているので誤り。(6) こらえきれず吹き出して笑う、で正しい。(7) その場しのぎ、で正しい。

#### <span class="no">5</span>
(1) 汚名を返上（または「名誉を挽回」）　(2) 的を射て　(3) 怒り心頭に発した　(4) 取りつく島もない　(5) 雪辱を果たす　(6) 押しも押されもせぬ

#### <span class="no">6</span>
(1) 粟　(2) 海路　(3) 他生　(4) 大同小異　(5) 千差万別　(6) 十人十色
**解説**　(3)「他生」は前世や来世のこと。「多少」と書くのは誤り。(6) 異口同音は「みな同じことを言う」、十人十色は「人それぞれちがう」。

#### <span class="no">7</span>
(1) 2　(2) 3　(3) 3　(4) 2
**解説**　(1) 1 は最近広まった誤解の意味。「檄」は昔の中国で、人々に呼びかけるために出した文書のこと。(2)「天荒」を破る＝初めて切り開く。1・2 は誤解の意味。(3) 1 がよくある誤解。(4) 1 がよくある誤解。

#### <span class="no">8</span>
(1) 2　(2) 4
(3) ご覧ください（ご覧になってください）
(4) おたずねください（お聞きください）
(5) おっしゃいました
**解説**　(1) 1「申す」は謙譲語、4「いただく」は謙譲語で、どちらも相手の動作に使っている。3 は身内の母に尊敬語 →「申しておりました」。(2) 4「ご〜する」は謙譲の形 →「ご利用ください」。1 は先生の動作に尊敬語、2・3 は自分の動作に謙譲語で、どれも適切。(5)「おっしゃる」＋「られる」の**二重敬語**。

#### <span class="no">9</span>
(1) 番号：③　直し方：力不足
(2) 1
**解説**　(1) 自分の力が足りないと心配しているので「力不足」。「役不足」だと「主役でも自分には軽すぎる」という、えらそうな意味になってしまう。④ は先輩たちがMさんの演技を認めていた、で正しい。(2) 方針が立たず迷っている状態なので「五里霧中」。
