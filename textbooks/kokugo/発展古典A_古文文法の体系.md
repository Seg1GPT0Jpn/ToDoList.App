### POINT 1　古文の動詞は9種類　――「6つの活用形」は口語とほぼ同じ

古文の活用形は「未然形・連用形・終止形・連体形・**已然形**・命令形」の6つ。口語の「仮定形」の位置に**已然形**（いぜんけい）がある。

| 活用の種類 | 例（語幹） | 未然形 | 連用形 | 終止形 | 連体形 | 已然形 | 命令形 |
|---|---|---|---|---|---|---|---|
| **四段** | 書く（書） | か | き | く | く | け | け |
| **ラ行変格（ラ変）** | あり（あ） | ら | り | **り** | る | れ | れ |
| **ナ行変格（ナ変）** | 死ぬ（死） | な | に | ぬ | ぬる | ぬれ | ね |
| **上一段** | 見る（○） | み | み | みる | みる | みれ | みよ |
| **上二段** | 起く（起） | き | き | く | くる | くれ | きよ |
| **下一段** | 蹴る（○） | け | け | ける | ける | けれ | けよ |
| **下二段** | 受く（受） | け | け | く | くる | くれ | けよ |
| **カ行変格（カ変）** | 来（○） | こ | き | く | くる | くれ | こ・こよ |
| **サ行変格（サ変）** | す（○） | せ | し | す | する | すれ | せよ |

**「〜二段」**は、イ段とウ段（上二段）、エ段とウ段（下二段）の**2つの段**を使うから。**「〜一段」**は1つの段だけを使う。


### POINT 2　活用の種類の見分け方　――「暗記組」を先に、残りは「ず」をつける　<span class="deru">入試</span>

**手順1　数の少ない「暗記組」を先に確かめる**

| 種類 | 所属する主な語（これだけ覚える） |
|---|---|
| **上一段** | **着る・似る・煮る・干る・見る・射る・鋳る・居る・率る**（「き・に・ひ・み・い・ゐ」＋る）、用ゐる・試みる など |
| **下一段** | **蹴る**（1語だけ） |
| **カ変** | **来**（く） |
| **サ変** | **す・おはす**、「〜す・〜ず」の複合語（念ず・具す・旅す など） |
| **ナ変** | **死ぬ・往ぬ（去ぬ）**（2語だけ） |
| **ラ変** | **あり・をり・侍り・いまそかり**（4語） |

**手順2　残りは「ず」をつけて、直前の音で決める**

| 「ず」の直前の音 | 活用の種類 | 例 |
|---|---|---|
| **ア段** | 四段 | 書か・ず　思は・ず |
| **イ段** | 上二段 | 起き・ず　落ち・ず　老い・ず |
| **エ段** | 下二段 | 受け・ず　求め・ず　植ゑ・ず |

※上一段（見ず）もイ段になるので、**手順1を先に**やるのがコツ。


### POINT 3　口語文法との対応　――9種類が5種類に「整理」された

| 古文 | → | 口語 | 例 |
|---|---|---|---|
| 四段・ラ変・ナ変・下一段 | → | **五段** | 書く→書く　あり→ある　死ぬ→死ぬ　蹴る→蹴る |
| 上一段・上二段 | → | **上一段** | 見る→見る　起く→起きる |
| 下二段 | → | **下一段** | 受く→受ける　求む→求める |
| カ変・サ変 | → | **カ変・サ変** | 来→来る　す→する |

- 終止形が**連体形と同じ形**になったのが口語の大きな変化（起く→**起くる**→起きる）。
- 口語の**仮定形**（書け・ば）は、古文の**已然形**から生まれた。ただし意味がちがう。

| 形 | 意味 | 訳 | 例 |
|---|---|---|---|
| **未然形＋ば** | **仮定**条件（まだそうなっていない） | もし〜ならば | 雨降ら**ば**（もし雨が降るならば） |
| **已然形＋ば** | **確定**条件（すでにそうなっている） | 〜ので・〜と | 雨降れ**ば**（雨が降るので／降ると） |

形容詞・形容動詞も「なる」をつけて見分ける。

| 種類 | 見分け方 | 未然形 | 連用形 | 終止形 | 連体形 | 已然形 | 命令形 |
|---|---|---|---|---|---|---|---|
| 形容詞**ク活用**（なし） | 「なる」で「なく」 | （く）・から | く・かり | し | き・かる | けれ | かれ |
| 形容詞**シク活用**（をかし） | 「なる」で「をかしく」 | （しく）・しから | しく・しかり | し | しき・しかる | しけれ | しかれ |
| 形容動詞**ナリ活用**（静かなり） | 終止形が「〜なり」 | なら | なり・**に** | なり | なる | なれ | なれ |
| 形容動詞**タリ活用**（堂々たり） | 終止形が「〜たり」（漢語につく） | たら | たり・と | たり | たる | たれ | たれ |


<div class="memo" markdown="1">

**本質**　中2の文法5で「古文の『起く』が長い時間をかけて『起きる』（上一段）に変わった」と学びました。理由は、終止形と連体形の**区別がなくなった**から。鎌倉・室町時代ごろから、文を連体形で終える言い方（係り結びがないのに「〜ける。」で終わる形）がふえ、連体形「起くる」が終止形の役目を引きついで、やがて「起きる」になりました。**係り結びが消えていった**のも、この変化と同じ流れです。

</div>

### POINT 4　主な助動詞の一覧（接続・意味・活用の型）　<span class="deru">入試</span>

口語と同じく、**接続（どの活用形につくか）**が意味を決める最大の手がかり。

| 接続 | 助動詞 | 主な意味（訳） | 活用の型 |
|---|---|---|---|
| **未然形** | る・らる | 受身（〜れる）・尊敬（お〜になる）・自発（自然と〜れる）・可能（〜できる） | 下二段型 |
| | す・さす・しむ | 使役（〜させる）・尊敬（お〜になる） | 下二段型 |
| | **ず** | 打消（〜ない） | 特殊型 |
| | **む（ん）** | 推量・意志・適当（勧誘）・仮定・婉曲 | 四段型 |
| | じ | 打消推量（〜ないだろう）・打消意志（〜まい） | 無変化型 |
| | まし | 反実仮想（もし〜ならば…だろうに）・ためらい | 特殊型 |
| | まほし | 希望（〜たい） | 形容詞シク型 |
| **連用形** | **き** | 過去（〜た）＝**自分が直接経験した**過去 | 特殊型 |
| | **けり** | 過去（〜た・〜たそうだ）＝**伝え聞いた**過去／詠嘆（〜たなあ） | ラ変型 |
| | **つ・ぬ** | 完了（〜た・〜てしまった）・強意（きっと〜） | つ：下二段型　ぬ：ナ変型 |
| | **たり** | 完了（〜た）・存続（〜ている） | ラ変型 |
| | **けむ（けん）** | 過去推量（〜ただろう）・過去の原因推量（どうして〜たのだろう） | 四段型 |
| | たし | 希望（〜たい） | 形容詞ク型 |
| **終止形**（ラ変型には連体形） | **べし** | 推量・意志・可能・当然・命令・適当 | 形容詞ク型 |
| | **らむ（らん）** | 現在推量（今ごろ〜ているだろう）・現在の原因推量（どうして〜のだろう） | 四段型 |
| | まじ | 打消推量・打消意志・不可能・打消当然・禁止 | 形容詞シク型 |
| | めり | 推定（〜ようだ）・婉曲 | ラ変型 |
| | **なり** | **伝聞**（〜そうだ）・**推定**（〜ようだ、とくに音・声から） | ラ変型 |
| **連体形・体言** | **なり** | **断定**（〜である）・存在（〜にある） | 形容動詞型 |
| | たり | 断定（〜である） | 形容動詞型 |
| | ごとし | 比況（〜のようだ） | 形容詞ク型 |
| **特殊** | **り** | 完了・存続（〜た・〜ている）。**サ変の未然形・四段の已然形**につく（「サ・未・四・已」で「さみしい」と覚える） | ラ変型 |

### POINT 5　よく出る助動詞の活用表

| 助動詞 | 未然形 | 連用形 | 終止形 | 連体形 | 已然形 | 命令形 |
|---|---|---|---|---|---|---|
| き | （せ） | ○ | き | **し** | **しか** | ○ |
| けり | （けら） | ○ | けり | ける | けれ | ○ |
| つ | て | て | つ | つる | つれ | てよ |
| ぬ | な | **に** | **ぬ** | ぬる | ぬれ | ね |
| たり（完了） | たら | たり | たり | たる | たれ | たれ |
| り | ら | り | り | **る** | **れ** | れ |
| ず | （ず）・ざら | ず・ざり | ず | **ぬ**・ざる | **ね**・ざれ | ざれ |
| む | ○ | ○ | む | む | め | ○ |
| べし | べく・べから | べく・べかり | べし | べき・べかる | べけれ | ○ |
| なり（断定） | なら | なり・**に** | なり | なる | なれ | なれ |

○はその活用形がないもの、（　）は使い方が限られるもの。太字は**識別でねらわれる形**。「ぬ」「に」「る」「れ」「ね」が、ちがう助動詞の表に何度も出てくることを確かめよう。

**POINT 6　意味の決め方　――「主語」と「位置」で決まる**

**① き と けり**　「き」は**自分の体験**（聞き**し**＝私が聞いた）。「けり」は物語の地の文では**伝え聞いた過去**（竹取の翁といふ者あり**けり**＝いたそうだ）、和歌や会話では**詠嘆**（〜だったのだなあ）が多い。
**② つ・ぬ**　ふつうは完了。下に推量（む・べし・らむ）がくると**強意**：「**てむ・なむ・つべし・ぬべし**」＝きっと〜だろう、〜してしまおう。
**③ む・べし**　主語の人称で決める。

| 主語 | む | べし |
|---|---|---|
| 一人称（私） | **意志**（〜しよう） | 意志 |
| 二人称（あなた） | **適当・勧誘**（〜するのがよい） | 適当・命令 |
| 三人称（彼・物） | **推量**（〜だろう） | 推量・当然 |
| 文中の**連体形**（下に体言・助詞） | **仮定・婉曲**（〜としたら・〜ような） | 可能・当然 など文脈で |

**④ らむ と けむ**　時間で分ける。今のことを推量 → **らむ**、過去のことを推量 → **けむ**。目の前の事実に「どうして」をつけて理由を推量するのが**原因推量**（ひさかたの光のどけき春の日にしづ心なく花の散る**らむ**＝どうして花は散っているのだろう）。
**⑤ まし**　「**〜せば…まし**」「〜ましかば…まし」の形で**反実仮想**＝事実に反することを仮定する（世の中にたえて桜のなかり**せば**春の心はのどけから**まし**＝もし桜がなかったなら、春の心はのどかだろうに）。

</div>

### POINT 7　識別の手順　――「直前の形（接続）」→「下に続く語」→「意味」　<span class="deru">入試</span>

**① 「なり」の識別**

| 種類 | 見分け方 | 例 |
|---|---|---|
| **断定**の助動詞 | **体言・連体形**につく。「〜である」 | 女もしてみむとて、する**なり**。 |
| **伝聞・推定**の助動詞 | **終止形**（ラ変型は連体形）につく。音・声・うわさの文脈。「あ（ん）なり」「な（ん）なり」の形も | 男もす**なる**日記 |
| **形容動詞**の活用語尾 | 「いと（とても）」をつけられ、状態を表す | あはれ**なり**　静か**なり** |
| 動詞「**なる**」 | 「〜に・〜く・〜と」のあとで「〜になる」 | 人に**なり**ぬ |

四段動詞は終止形と連体形が同じ形なので、そのときは**文脈（音か、断定か）**で決める。

**② 「ぬ」「ね」の識別**

| 種類 | 接続 | 「ぬ」の形 | 「ね」の形 |
|---|---|---|---|
| **打消「ず」** | 未然形 | 連体形（下に体言・係り結びの結び） | 已然形（下に「ど・ども・ば」、こその結び） |
| **完了「ぬ」** | 連用形 | 終止形（文末で言い切る） | 命令形 |

下二段・上二段などは**未然形と連用形が同じ形**（見え・ず／見え・ぬ）。そのときは「ぬ」**自身の活用形**（下に何が続くか）で決める。

**③ 「に」の識別**

| 種類 | 見分け方 | 例 |
|---|---|---|
| **完了「ぬ」**の連用形 | **連用形**につき、下に「**き・けり・たり・けむ**」 | 帰り**に**けり |
| **断定「なり」**の連用形 | 体言・連体形につき、下に「**あり・侍り・おはす**」（間に「も・ぞ」などが入る）。「〜で（ある）」 | もとの水**に**あらず |
| **格助詞** | 体言・連体形につき「〜に」（場所・時・対象） | 野山**に**まじりて |
| **接続助詞** | 連体形につき「〜と・〜ので・〜のに」 | 寄りて見る**に** |
| 形容動詞の活用語尾 | 「〜なり」の連用形。「いと」がつく | ほのか**に**　あはれ**に** |

**④ 「る・れ」の識別**　――直前の音を見る

| 直前の音 | 正体 | 例 |
|---|---|---|
| **ア段**（四段・ナ変・ラ変の未然形） | 受身・尊敬・自発・可能の「**る**」（連用形・未然形は「れ」） | 思は**る**　おどろか**れ** |
| **エ段**（サ変の未然形・四段の已然形） | 完了・存続の「**り**」の連体形「る」・已然形「れ」 | 春立て**る**　住め**る**かた |

**⑤ 「なむ」の識別**

| 直前 | 正体 | 訳 |
|---|---|---|
| **未然形** | 願望の**終助詞** | 〜してほしい |
| **連用形** | 完了（強意）「ぬ」の未然形＋推量「む」 | きっと〜だろう・〜してしまおう |
| 体言・連体形など | **係助詞**（結びは連体形）。取り去っても文が成り立つ | 強調（訳さない） |
| 「死・往（去）」＋なむ | ナ変動詞の未然形活用語尾＋「む」 | 死のう・死ぬだろう |


<div class="memo" markdown="1">

**注意**　過去「き」は、カ変・サ変には特別なつき方をする。カ変：**こし・こしか**（未然形）／**きし・きしか**（連用形）、サ変：**せし・せしか**（未然形）。「ながめ**せ**しまに」の「せ」はサ変「す」の未然形で、「し」が過去「き」の連体形。また、ラ変型の連体形＋「なり・めり」は「ある**なり**→あん**なり**→あ**なり**」のように撥音便になり、「ん」が書かれないことが多い（さべき**な**めり＝さるべき**なる**めり）。

</div>

### POINT 8　古文の敬語　――3種類と「敬意の方向」　<span class="deru">入試</span>

| 種類 | だれへの敬意か | 主な語（もとの語 → 訳） |
|---|---|---|
| **尊敬語** | **動作をする人**（主語） | おはす・おはします（あり・行く・来→いらっしゃる）、のたまふ・のたまはす（言ふ→おっしゃる）、おぼす・おぼしめす（思ふ→お思いになる）、ご覧ず（見る→ご覧になる）、仰す（言ふ→おっしゃる）、大殿籠る（寝→おやすみになる）、**たまふ**（四段：与ふ→お与えになる／補助：お〜になる） |
| **謙譲語** | **動作を受ける人**（客体） | 申す・聞こゆ（言ふ→申し上げる）、**奉る**・参らす（与ふ→さしあげる）、**参る**・まうづ（行く・来→参上する）、まかる・まかづ（退出する）、承る（聞く→うかがう）、さぶらふ・侍り（仕ふ→お仕えする・おそばに控える） |
| **丁寧語** | **聞き手・読み手** | **侍り**・**候ふ**（あり・をり→あります・ございます／補助：〜です・〜ます） |

**だれから**：地の文 → **作者（語り手）**から。会話文 → **話し手**から。手紙 → **書き手**から。
**だれへ**：尊敬語 → **主語**へ。謙譲語 → **動作の受け手**へ。丁寧語 → **聞き手（会話）・読者（地の文）**へ。

<div class="ex" markdown="1">

おほやけに御文**奉り**　**たまふ**。（竹取物語「かぐや姫の昇天」・地の文）
**奉り**：謙譲語（さしあげる）→ 受け手＝**帝**（おほやけ）へ。作者から。
**たまふ**：尊敬語（補助動詞）→ 主語＝**かぐや姫**へ。作者から。
→ 1つの動作で**2人を同時に高めている**＝**二方面への敬語**（訳：帝にお手紙をさしあげなさる）

</div>


### POINT 9　二方面への敬語・最高敬語・まぎらわしい敬語

- **二方面への敬語**：**謙譲語＋尊敬語**の順に重なる（奉りたまふ・聞こえたまふ・参りたまふ）。前が「受け手」、後ろが「主語」を高める。
- **最高敬語（二重敬語）**：「**せたまふ・させたまふ・しめたまふ**」「おぼしめす」「のたまはす」など、尊敬語を重ねた形。**地の文**では天皇・中宮など、**最も身分の高い人**にだけ使う。会話文では、ほかの人にも使うことがある。
- 「す・さす」の識別：**だれかに〜させる**相手がいれば**使役**、いなければ、下に「たまふ」が続く形は**尊敬**。
- **たまふ**の識別：**四段**（たまは・たまひ・たまふ・たまふ・たまへ・たまへ）は**尊敬**。**下二段**（たまへ・たまへ・○・たまふる・たまふれ・○）は**謙譲**（〜ております。会話文で「思ふ・見る・聞く・知る」につく）。
- **奉る・参る**には**尊敬語**の用法もある（奉る＝お召しになる・召し上がる、参る＝召し上がる）。「受け手」がいない文では尊敬語を疑う。

**敬語で主語を決める（中1 古典2 POINT 7 の続き）**：主語が書かれていなくても、「たまふ」があれば身分の高い人、「侍り」が会話にあれば聞き手に気をつかう話し手……と、**敬語が主語の名札になる**。

**先生のひとこと**　敬語の問題は「**矢印を2本引く**」だけ。①矢印の**出発点**は、地の文なら作者、会話なら話し手。②矢印の**行き先**は、尊敬語なら主語、謙譲語なら受け手、丁寧語なら聞き手。口語の敬語（中2 文法7）で「まず主語を見つける」と習ったのと、考え方はまったく同じです。

#### <span class="no">11</span>
（解答例）
**問題**　次の――線の語の説明として最も適するものを、あとのア〜ウから一つずつ選びなさい。
① 古人も多く旅に死せ**る**あり。（おくのほそ道）
② 風の音にぞおどろか**れ**ぬる（古今和歌集）
③ 人に笑は**る**。（作例）
ア　完了・存続の助動詞「り」　　イ　自発の助動詞「る」　　ウ　受身の助動詞「る」
**答え**　① ア　② イ　③ ウ
**解説**　手がかりは「直前の形（接続）」と「意味」。①「死せ」はエ段（サ変の未然形）なので「り」。②③はア段（四段の未然形）なので「る」。そのうえで意味を考え、②は心の動き「おどろく（はっと気づく）」に「自然と」が入るので自発、③は「人に」があり「〜される」なので受身。
**作るときのコツ**　同じ「る」でも、直前の音（ア段かエ段か）で正体が変わるものを並べると、よい識別問題になる。「なり」なら「すなる（伝聞）／するなり（断定）」のように、**直前の活用形だけがちがう**組を選ぶとよい。
