# 中1理科 地学1「火山と火成岩」

<p class="lead">マグマのねばりけ、火山噴出物、鉱物、火山岩と深成岩、火山の災害と恵み｜神奈川県公立高校入試では「ねばりけ・形・噴火・色の関係」と「斑状組織・等粒状組織のでき方の理由」がよく出る。すべてを「マグマのねばりけ」と「冷え方」の2つで説明できるようにしよう。</p>

## 要点まとめ

### 1　火山とマグマ

- 地下の岩石が高温でとけたものを**マグマ**という。マグマは地下深くでできて上昇し、地下数 km のところに**マグマだまり**をつくる。
- マグマには水蒸気などの**気体**がとけこんでいる。マグマが上昇して圧力が下がると、とけていた気体が**あわ**になって体積がふくらみ、そのいきおいで地表にふき出す。これが**噴火**。
- マグマが地表に流れ出たものを**溶岩**という（地下にあるうちはマグマ、地表に出たら溶岩）。

<div class="memo" markdown="1">

**先生のひとこと**　噴火は、よくふった炭酸飲料のふたを開けるのと同じ。中の液体（マグマ）にとけていた気体が、圧力が下がって一気にあわになり、液体ごとふき出す。液体がドロドロ（ねばりけが強い）だと、あわがぬけにくく、たまりにたまって**ドカン**と爆発する。サラサラだと、あわはすぐぬけて**おだやか**に流れ出る。

</div>

**POINT　ねばりけで全部決まる**

| マグマのねばりけ | **強い** | 中くらい | **弱い** |
|---|---|---|---|
| 火山の形 | 盛り上がったドーム状 | 円すい形 | 傾斜がゆるやか |
| 噴火のようす | **激しく爆発的** | 爆発と溶岩流をくり返す | **おだやか**（溶岩が流れ出る） |
| 溶岩・火山灰の色 | **白っぽい** | 灰色 | **黒っぽい** |
| マグマの温度 | 低い（約 900℃） | 中間 | 高い（約 1200℃） |
| 無色鉱物と有色鉱物 | 無色鉱物が**多い** | 中間 | 有色鉱物が**多い** |
| できる火山岩 | 流紋岩 | 安山岩 | 玄武岩 |

</div>

- **なぜ形が決まる？**　ねばりけが強い溶岩は流れにくいので、火口のまわりに**盛り上がる**。弱い溶岩は流れやすいので、**うすく広く**広がる。
- 成層火山は、溶岩と火山灰などが**交互に積み重なって**できた円すい形の火山（富士山など）。日本の火山に多い。

<div class="memo" markdown="1">

**発展　ねばりけのもとは二酸化ケイ素（SiO₂）**　マグマにふくまれる**二酸化ケイ素**（ガラスや水晶の成分）が多いほど、ねばりけが強くなる。二酸化ケイ素の割合は、玄武岩質のマグマで約 50％、流紋岩質のマグマで約 70％以上。二酸化ケイ素はセキエイなどの白っぽい（無色の）鉱物になるので、「ねばりけが強い＝白っぽい」がつながる。また、温度が低いほどねばりけは強くなる（はちみつを冷やすと固くなるのと同じ）。

</div>

### 3　火山噴出物<span class="deru">入試</span>

噴火によってふき出されたものをまとめて**火山噴出物**という。

| 火山噴出物 | 特徴 |
|---|---|
| **火山ガス** | 主成分は**水蒸気**。ほかに二酸化炭素・二酸化硫黄（SO₂）・硫化水素（H₂S）など。有毒な成分をふくむ |
| **溶岩** | マグマが地表に流れ出たもの、またそれが冷え固まったもの |
| **火山弾** | ふき飛ばされたマグマが空中で冷え固まったもの。紡錘形（ラグビーボール形）など特有の形 |
| **軽石** | マグマが急に冷えるときに気体がぬけてできた**穴がたくさんある**石。白っぽく軽い（水にうくものもある） |
| **火山れき** | 直径 2〜64 mm の粒 |
| **火山灰** | 直径 **2 mm 以下**の細かい粒。風に運ばれて遠くまで積もる |

- **火砕流**：高温の火山ガスと火山灰・岩石などが一体となって、山の斜面を高速で流れ下る現象。非常に危険（雲仙普賢岳 1991年）。
- 火山灰は、上空の**偏西風**（西から東へふく風）に運ばれ、火山の**東側**に多く積もる。

**観察　火山灰の粒を調べる（わんがけ）**
① 火山灰を蒸発皿に少量とり、水を加えて**指でおし洗い**する。
② にごった水を捨て、新しい水を加える。①②を**水がにごらなくなるまで**くり返す。（細かい粒を流して、鉱物の粒だけを残すため）
③ 残った粒を乾かし、**双眼実体顕微鏡**やルーペで観察する。
→ 鉱物の粒が見られる。粒は角ばっている（流れる水に運ばれていないので、角がけずられていない）。

<div class="memo" markdown="1">

**注意**　火山灰の粒は「角ばっている」、川原の石や地層の砂の粒は「丸みを帯びている」。地層の単元でも、この区別がそのまま出題される。

</div>

### 4　鉱物<span class="deru">入試</span>

マグマが冷えてできた**結晶**の粒を**鉱物**という。火山灰や火成岩は鉱物の集まり。

| 区別 | 鉱物 | 色 | 形・特徴 |
|---|---|---|---|
| **無色鉱物** | **セキエイ** | 無色・白色 | 不規則な形。割れ口がふぞろい |
| | **チョウ石** | 白色・うすいもも色 | 柱状・短冊状。決まった方向に割れやすい |
| **有色鉱物** | **クロウンモ** | 黒色・褐色 | 板状・六角形。うすくはがれる |
| | **カクセン石** | 暗緑色・黒色 | 長い柱状 |
| | **キ石** | 緑色・暗褐色 | 短い柱状 |
| | **カンラン石** | 黄緑色・褐色 | 丸みのある粒状 |
| | 磁鉄鉱 | 黒色 | 磁石につく |

- 有色鉱物には鉄やマグネシウムがふくまれ、黒っぽく重い。白っぽい岩石は**無色鉱物**が多く、黒っぽい岩石は**有色鉱物**が多い。
- **チョウ石**はほとんどすべての火成岩にふくまれる。**セキエイ**は白っぽい岩石（流紋岩・花こう岩）に多い。**カンラン石**は黒っぽい岩石（玄武岩・斑れい岩）に見られる。

|---|---|---|
| でき方 | マグマが地表や地表付近で**急に**冷えて固まった | マグマが地下深くで**ゆっくり**冷えて固まった |

<div class="point" markdown="1">

**POINT　なぜ粒の大きさがちがうのか（記述の定番）**

- 結晶は、ゆっくり冷えるほど**大きく成長する時間**がある。
- **深成岩**：地下深くで長い時間をかけて冷えるので、どの鉱物も大きく成長 → **等粒状組織**。
- **火山岩**：地下にあるうちに（マグマだまりで）ゆっくり成長していた鉱物が**斑晶**になり、残りのマグマが地表付近で**急に冷えた**ため、結晶が大きく成長できずに**石基**になった → **斑状組織**。
- 冷え方が「ゆっくり → 急に」の2段階なので、火山岩には大きな粒と小さな粒の両方がある。

</div>

**モデル実験　ミョウバンの結晶**
- 70℃くらいの湯にミョウバンをとかした濃い水溶液を、2つのペトリ皿に入れる。
- A：湯につけたまま**ゆっくり**冷やす → 大きな結晶が並ぶ（等粒状組織に似る）。
- B：しばらく湯につけてから**氷水に移して急に**冷やす → 大きな結晶のまわりに小さな結晶がたくさんできる（斑状組織に似る）。

<div class="memo" markdown="1">

**先生のひとこと**　かき氷のシロップを冷凍庫でゆっくり凍らせると大きな氷の結晶ができ、液体窒素で一瞬で凍らせると細かい結晶になる。「ゆっくり＝大きい、急に＝小さい」は、結晶ならどれでも同じ。「火山岩＝急に冷えた＝斑状（まだら）」「深成岩＝深いところでゆっくり＝等粒状」のセットで覚えよう。

</div>

### 7　日本の火山 ― 災害と恵み

- 日本には**活火山が 111**ある（気象庁、2017年以降）。日本列島は、プレートが沈みこむところに沿って火山が帯のように並んでいる。
- 気象庁は、主な活火山について**噴火警戒レベル**（1〜5）を発表している。各自治体は、溶岩流・火砕流・火山灰などの危険な範囲を示した**ハザードマップ**をつくっている。

| 災害 | 恵み |
|---|---|
| 溶岩流・火砕流・噴石による被害 | **温泉**（箱根など） |
| 火山灰による農作物・交通・健康への被害 | **地熱発電**（地下の熱で発電。CO₂ をほとんど出さない） |
| 火山ガスによる被害 | 美しい景観・観光地（国立公園） |
| 火山泥流（火山灰などが雨で流れる） | わき水（富士山のまわりなど）、鉱産資源 |

**入試直前チェック（できたら□にチェック）**

□ ねばりけが**強い**：ドーム状・爆発的・白っぽい（昭和新山）。**弱い**：傾斜がゆるやか・おだやか・黒っぽい（マウナロア）。円すい形の成層火山は富士山。
