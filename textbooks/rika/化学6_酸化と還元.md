## 要点まとめ

### 1　物質どうしが結びつく化学変化（化合）

- 2種類以上の物質が結びついて、**別の1種類の物質**ができる化学変化を**化合**という（できた物質は**化合物**）。分解のちょうど逆。
　　分解：AB → A ＋ B　　　化合：A ＋ B → AB
- できた物質は、もとの物質とは**性質がまったくちがう**。これが「化学変化で新しい物質ができた」証拠になる。

- 鉄粉と硫黄の粉末をよく混ぜて試験管に入れ、混合物の**上部を加熱**する。
- 赤くなり始めたら**加熱をやめても、反応は最後まで続く**。反応で出る**熱**で、となりの部分が次々に反応するから（**発熱反応**→ 5）。
- 黒い**硫化鉄**ができる。
　**鉄 ＋ 硫黄 → 硫化鉄　Fe ＋ S → FeS**

| | 加熱前（鉄と硫黄の混合物） | 加熱後（硫化鉄） |
|---|---|---|
| 色 | 灰色と黄色が混ざっている | **黒っぽい**色 |
| 磁石 | **引きつけられる**（鉄の性質） | **引きつけられない** |
| うすい塩酸を加える | **水素**が発生（においはない） | **硫化水素**が発生（**卵がくさったようなにおい**、有毒） |

- においは、手で**あおぐようにして**かぐ。硫化水素は有毒なので、換気をし、少しだけ発生させる。
- **銅と硫黄**：銅線を硫黄の蒸気の中に入れると激しく反応し、黒い**硫化銅**ができる（Cu ＋ S → CuS）。

<div class="memo" markdown="1">

**本質**　混合物は「鉄と硫黄がとなりにいるだけ」なので、磁石につくし塩酸と反応して水素も出る（鉄の性質がそのまま残る）。化合すると、鉄原子と硫黄原子が**結びついた別の物質**になるので、鉄の性質はなくなる。「混ざる」と「結びつく」は、まったくちがう。

</div>

### 3　酸化と燃焼<span class="deru">入試</span>

- 物質が**酸素と結びつく**化学変化を**酸化**、できた物質を**酸化物**という。
- 熱や光を出しながら**激しく**酸化することを**燃焼**という。鉄がさびる・銅の表面が黒ずむのは、**おだやかな酸化**。

| 物質（色） | 加熱したときのようす | 化学反応式 | 酸化物（色） |
|---|---|---|---|
| 銅（赤色） | 光は出さず、表面から黒くなる | 2Cu ＋ O₂ → 2CuO | 酸化銅（**黒色**） |
| マグネシウム（銀色） | **強い光**を出して激しく燃える | 2Mg ＋ O₂ → 2MgO | 酸化マグネシウム（**白色**） |
| 鉄（スチールウール） | 火花を出して燃える | 鉄 ＋ 酸素 → 酸化鉄 | 酸化鉄（**黒色**） |
| 炭素 | 燃える | C ＋ O₂ → CO₂ | 二酸化炭素（気体） |
| 水素 | 音を立てて燃える | 2H₂ ＋ O₂ → 2H₂O | 水 |

- **有機物**（ろう・木・紙・エタノールなど、炭素をふくむ物質）が燃えると、**二酸化炭素と水**ができる。有機物に炭素 C と水素 H がふくまれているから。（例：メタン CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O）

**先生のひとこと**　「燃やしたら重くなる」はふしぎに感じるよね。木や紙を燃やすと軽くなるのは、できた**二酸化炭素と水（水蒸気）が空気中に出ていく**から。スチールウールは、空気中の**酸素がくっついて**、できた酸化鉄が皿の上に残るので重くなる。どちらも「何が出ていき、何が残るか」で考えればスッキリする（くわしくは化学7）。

**発展**　**製鉄**も還元。鉄鉱石（酸化鉄）をコークス（炭素）といっしょに溶鉱炉で熱し、酸素をうばって鉄を取り出す（例：Fe₂O₃ ＋ 3CO → 2Fe ＋ 3CO₂）。

### 5　化学変化と熱（発熱反応・吸熱反応）<span class="deru">入試</span>

<div class="cols2" markdown="1">

- **発熱反応**：熱を**出す**化学変化。まわりの温度が**上がる**。
　例：**化学かいろ**（鉄粉が空気中の酸素で**酸化**される）、燃焼、鉄と硫黄の反応、酸化カルシウム（生石灰）と水の反応（加熱式弁当）。
- **吸熱反応**：熱を**吸収する**化学変化。まわりの温度が**下がる**。
　例：**炭酸水素ナトリウムとクエン酸**に水を加える、**塩化アンモニウムと水酸化バリウム**を混ぜる（アンモニアが発生）、熱分解（加熱し続けないと進まない）。

- 化学かいろは、袋を開けて**空気（酸素）にふれると**温かくなる。中の**活性炭**は空気中の酸素を集めやすくし、**食塩水**は鉄の酸化を速めるはたらきをする。
- 冷却パック（たたくと冷える）は、吸熱の変化を利用している。

<div class="memo" markdown="1">

**本質**　物質は「**化学エネルギー**」というエネルギーをたくわえている。反応後の物質の化学エネルギーが反応前より**小さい**と、その差が熱として出てくる（発熱）。逆に**大きい**と、まわりから熱をうばう（吸熱）。ボールが坂を下るときにエネルギーを出し、坂を上るにはエネルギーが要るのと同じイメージだ。私たちが食べ物から得るエネルギーも、体の中で栄養分がゆっくり**酸化**されて出てくる化学エネルギーだ。

</div>

<div class="point" markdown="1">

**入試直前チェック（できたら□にチェック）**

□ 鉄と硫黄：加熱をやめても反応が続く（**発熱反応**）。硫化鉄は**磁石につかない**、塩酸で**硫化水素（くさった卵のにおい）**。混合物は磁石につき、塩酸で**水素**。
□ 酸化＝酸素と結びつく。燃焼＝熱や光を出す激しい酸化。銅 → 酸化銅（**黒**）、マグネシウム → 酸化マグネシウム（**白**）。
□ スチールウールを燃やすと**重くなる**（酸素が結びつく）。酸化鉄は電流が流れにくく、塩酸で気体が出ない。
□ 還元＝酸化物から酸素をうばう。**2CuO ＋ C → 2Cu ＋ CO₂**。酸化と還元は**同時**に起こる。
□ 還元の実験：**ガラス管を出してから火を消す**（逆流防止）→ **ピンチコックを閉じる**（銅の再酸化防止）。
□ 発熱反応（化学かいろ）と吸熱反応（炭酸水素ナトリウム＋クエン酸）の例が言える。
