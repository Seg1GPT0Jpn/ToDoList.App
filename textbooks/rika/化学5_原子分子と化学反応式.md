## 要点まとめ

### 1　化学変化と分解

- もとの物質とは**性質のちがう別の物質ができる**変化を**化学変化**（化学反応）という。
　（比べよう）**状態変化**：氷 → 水 → 水蒸気のように、すがたが変わるだけで**物質そのものは変わらない**。
- 1種類の物質が、2種類以上の別の物質に分かれる化学変化を**分解**という。
　・加熱による分解 ＝ **熱分解**　　・電流による分解 ＝ **電気分解**

<div class="memo" markdown="1">

**本質**　化学変化は、レゴブロックの作品をバラバラにして**別の作品に組みかえる**イメージ。ブロック（＝あとで習う**原子**）は1個も増えも減りもしない。この「**原子の組みかえ**」が、化学5〜7をつらぬく一番大事な考え方だ。

</div>

### 3　酸化銀の熱分解

- **黒色**の酸化銀を加熱すると、気体が出て、**白色**の固体が残る。
- 気体に**火のついた線香**を入れると**激しく燃える** → **酸素**。
- 白色の固体は、①みがくと**金属光沢**が出る　②**電気を通す**　③たたくと**うすく広がる（のびる）** → 金属の**銀**。

<div class="point" markdown="1">

**POINT 2　酸化銀の熱分解**

酸化銀 → 銀 ＋ 酸素　　**2Ag₂O → 4Ag ＋ O₂**
（銀原子：左 2×2＝4、右 4　　酸素原子：左 1×2＝2、右 2　で左右がそろう）

</div>

- 純粋な水は電流がほとんど流れないので、**水酸化ナトリウム**を少しとかして**電流を流れやすくする**（水酸化ナトリウム自体は変化しない）。
- **陰極（−極）**：**水素**が発生。マッチの火を近づけると**ポンと音を立てて燃える**。
- **陽極（＋極）**：**酸素**が発生。火のついた線香を入れると**激しく燃える**。
- 体積の比　**水素：酸素 ＝ 2：1**
- 化学反応式　**2H₂O → 2H₂ ＋ O₂**

<div class="memo" markdown="1">

**先生のひとこと**　「陰極は水素」は「**いん・す**（陰・水）」と覚えよう。水素が2倍出るのは、水の分子 H₂O に水素原子が2個あるから。気体は、同じ温度・圧力なら**分子の数が多いほど体積が大きい**ので、2H₂ と O₂（分子の数 2：1）の体積も 2：1 になる。
**発展**　水の電気分解の逆向きの反応（2H₂ ＋ O₂ → 2H₂O）から電気を取り出すのが**燃料電池**。燃料電池自動車は、走っても水しか出さない。

</div>

### 5　原子と元素記号

- 物質をつくっている、それ以上分けることのできない小さな粒子を**原子**という。大きさは約1億分の1 cm。19世紀のはじめ（1803年ごろ）に、イギリスの**ドルトン**が原子の考え（原子説）を発表した。

<div class="point" markdown="1">

**POINT 3　原子の性質（3つ）**<span class="deru">入試</span>

① 化学変化で、それ以上**分けることができない**。
② 化学変化で、新しくできたり、**なくなったり、ほかの種類の原子に変わったりしない**。
③ 種類によって、**質量や大きさが決まっている**。

</div>

- 原子の種類を**元素**といい、約120種類が知られている。元素はアルファベット1文字か2文字の**元素記号**で表す（1文字目は**大文字**、2文字目は**小文字**：Cu ○、CU ×、cu ×）。

| | 元素 | 記号 | | 元素 | 記号 | | 元素 | 記号 |
|---|---|---|---|---|---|---|---|---|
| 非金属 | 水素 | **H** | 金属 | ナトリウム | **Na** | 金属 | 鉄 | **Fe** |
| | 炭素 | **C** | | マグネシウム | **Mg** | | 銅 | **Cu** |
| | 窒素 | **N** | | アルミニウム | **Al** | | 亜鉛 | **Zn** |
| | 酸素 | **O** | | カリウム | **K** | | 銀 | **Ag** |
| | 硫黄 | **S** | | カルシウム | **Ca** | | 金 | **Au** |
| | 塩素 | **Cl** | | バリウム | **Ba** | | 鉛 | **Pb** |

- Na・K・Fe・Cu・Ag・Au はラテン語などの名前から来た記号。**Ag（銀）と Au（金）の取りちがえに注意**。

<div class="memo" markdown="1">

**発展**　**周期表**：元素を原子の質量の小さい順に並べると、似た性質の元素が周期的にあらわれる（1869年、ロシアの**メンデレーエフ**が発表）。たての列（族）の元素は性質が似ている。たとえば一番右の列（He・Ne・Ar）はほかの物質とほとんど反応しない気体、一番左の列の Na・K は水と激しく反応する金属。

| 族 → | 1 | 2 | 13 | 14 | 15 | 16 | 17 | 18 |
|---|---|---|---|---|---|---|---|---|
| 第1周期 | H | | | | | | | He |
| 第2周期 | Li | Be | B | **C** | **N** | **O** | F | Ne |
| 第3周期 | **Na** | **Mg** | **Al** | Si | P | **S** | **Cl** | Ar |
| 第4周期 | **K** | **Ca** | （この間に Fe・Cu・Zn などが入る） | | | | | |

**発展**　原子の中心には＋の電気をもつ**原子核**（陽子と中性子でできている）があり、そのまわりを−の電気をもつ**電子**が回っている。原子は「それ以上分けられない」というのは**化学変化では**という意味（中3の「イオン」で学ぶ）。

</div>

### 6　分子と化学式

- いくつかの原子が結びついてできた、**その物質の性質を示す最小の粒子**を**分子**という。
- 物質を元素記号と数字で表したものを**化学式**という。原子の数は元素記号の**右下に小さく**書く（1は書かない）。

### 7　単体と化合物（物質の分類）<span class="deru">入試</span>

- 化合物は、分解すると**2種類以上の物質に分けられる**。水 → 水素＋酸素、酸化銀 → 銀＋酸素。単体はそれ以上分解できない。
- 「酸素」には、単体の**酸素（O₂）**と、元素（原子の種類）としての**酸素（O）**の2つの意味がある。「水には酸素がふくまれる」の酸素は**元素**のほう（水の中に O₂ の気体が入っているわけではない）。

### 8　化学反応式のつくり方<span class="deru">入試</span>

化学変化を化学式で表した式を**化学反応式**という。矢印の左に**反応前の物質**、右に**反応後の物質**を書く。

<div class="point" markdown="1">

**POINT 4　化学反応式をつくる4つの手順（例：水素が燃えて水ができる）**

① ことばの式を書く　　　　　水素 ＋ 酸素 → 水
② 化学式にする　　　　　　　H₂ ＋ O₂ → H₂O
③ 酸素原子をそろえる　　　　左は O が2個、右は1個 → 右の H₂O を2個に：H₂ ＋ O₂ → **2**H₂O
④ 水素原子をそろえる　　　　右は H が 2×2＝4個 → 左の H₂ を2個に：**2H₂ ＋ O₂ → 2H₂O**
⑤ 最後に、**左右で原子の種類と数が同じか**を必ず確かめる（H：4＝4、O：2＝2）。

**ルール**　数をそろえるときは、化学式の前の**係数**（大きい数字）だけを変える。化学式の中の小さい数字を変えると、別の物質になってしまう（H₂O を H₂O₂ にしたら過酸化水素！）。係数の1は書かない。

</div>

- **係数の意味**：2H₂O は「水の分子が**2個**」。ふくまれる原子は H が 2×2＝**4個**、O が **2個**。3CO₂ なら O 原子は 2×3＝**6個**。
- **コツ**：①化合物の中で一番原子の多いものから合わせる　②**単体（O₂・Cu・Mg など）は最後**に合わせる（ほかに影響しないので）。

| 化学変化 | 化学反応式 | 化学変化 | 化学反応式 |
|---|---|---|---|
| 炭酸水素ナトリウムの熱分解 | 2NaHCO₃ → Na₂CO₃ ＋ CO₂ ＋ H₂O | 水素の燃焼 | 2H₂ ＋ O₂ → 2H₂O |
| 酸化銀の熱分解 | 2Ag₂O → 4Ag ＋ O₂ | マグネシウムの燃焼 | 2Mg ＋ O₂ → 2MgO |
| 水の電気分解 | 2H₂O → 2H₂ ＋ O₂ | 炭素の燃焼 | C ＋ O₂ → CO₂ |

<div class="memo" markdown="1">

**先生のひとこと**　メタンの燃焼で練習しよう。CH₄ ＋ O₂ → CO₂ ＋ H₂O。C は1個ずつでOK。H は左4個なので右を 2H₂O に。すると右の O は 2＋2＝4個なので、最後に単体の O₂ を2個にして **CH₄ ＋ 2O₂ → CO₂ ＋ 2H₂O** の完成。「原子の数あわせパズル」だと思って、左右の原子を必ず指で数えよう。

</div>

<div class="point" markdown="1">

**入試直前チェック（できたら□にチェック）**

□ 炭酸水素ナトリウムの熱分解 → **炭酸ナトリウム・二酸化炭素・水**。水は**塩化コバルト紙（青→赤）**、CO₂ は**石灰水（白くにごる）**。
□ 試験管の口を**下げる**理由（水が加熱部に流れて割れる）、火を消す**前に**ガラス管を出す理由（石灰水の逆流）を書ける。
□ 炭酸ナトリウムは炭酸水素ナトリウムより水に**よくとけ**、フェノールフタレイン液で**濃い赤**。
□ 酸化銀（**黒**）→ 銀（**白**）＋ 酸素。銀は金属光沢・電気を通す・のびる。
□ 水の電気分解：**陰極に水素、陽極に酸素、体積は 2：1**。水酸化ナトリウムは電流を流しやすくするため。
□ 原子の性質3つ。**単体（元素1種類）と化合物（2種類以上）**、分子をつくる・つくらないを分類できる。
□ 化学反応式は**係数だけ**で数をそろえ、最後に原子の数を確かめる。

</div>
