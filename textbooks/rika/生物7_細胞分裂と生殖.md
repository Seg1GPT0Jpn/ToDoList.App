## 要点まとめ

### 1　生物はどうやって成長するのか<span class="deru">入試</span>

- 多細胞生物の体が大きくなるのは、①**細胞分裂で細胞の数がふえ**、②**ふえた細胞の1つ1つが大きくなる**から。
- 1つの細胞が2つに分かれることを**細胞分裂**という。体をつくる細胞がふえる分裂を**体細胞分裂**という。
- 植物の根では、**先端に近い部分**（成長点）で細胞分裂がさかん。先端付近の細胞は**小さく**、根もとに近いほど細胞は**大きい**。

ソラマメなどの根に、等間隔（例：2 mm）に印をつけて2日間育てる。
**結果**：**先端に近い d と e の間だけが大きくのびた**。ほかの間隔はほとんど変わらない。

<div class="point" markdown="1">

**POINT 2　体細胞分裂の順序**

① 分裂前：核が見える（中で染色体が**複製**され、2倍になっている）
② 核の形が見えなくなり、**ひものような染色体**が見えるようになる
③ 染色体が細胞の**中央に並ぶ**
④ 染色体が**2つに分かれ**、細胞の**両端**に移動する
⑤ 両端に**2つの核**ができ、中央に**しきり**ができる（動物の細胞は、まん中が**くびれて**分かれる）
⑥ **2つの細胞**ができる → それぞれが大きくなる

</div>

- **染色体**：核の中にある、**遺伝子**をふくむもの。酢酸オルセイン液などでよく染まる。
- 体細胞分裂では、分裂の前に染色体が**複製**され（同じものが2本くっついた状態）、それが**半分ずつ**分かれる。だから、分裂後の2つの細胞は、もとの細胞と**同じ数・同じ内容の染色体**をもつ。<span class="deru">入試</span>
- 顕微鏡で見ると、**分裂していない細胞（分裂前）がいちばん多い**。分裂前の時期が一番長いから。

<div class="memo" markdown="1">

**本質**　体細胞分裂は「**設計図のコピーを配る**」作業。染色体は体の設計図（遺伝子）。分裂の前に設計図を丸ごとコピーして、2つの細胞に1セットずつ配るので、何回分裂しても全部の細胞が同じ設計図をもつ。②〜⑤で染色体が太く短くまとまるのは、長い設計図を「束ねて」運びやすくするためだ。

</div>

<div class="memo" markdown="1">

**発展**　観察した細胞の数の割合から、それぞれの時期にかかる時間がわかる。400個の細胞のうち、③（中央に並ぶ）が12個なら、分裂の1周期が20時間のとき、③にかかる時間は 20 × 12/400 ＝ **0.6時間（36分）**。「たくさん見られる時期ほど、長くかかる」と考える。

</div>

### 3　生殖 ― 無性生殖<span class="deru">入試</span>

- 生物が自分と同じ種類の新しい個体（子）をつくることを**生殖**という。
- **無性生殖**：雌雄の親を必要とせず、**体細胞分裂**によって子をつくる生殖。

| 無性生殖の種類 | 内容 | 例 |
|---|---|---|
| **分裂** | 体が2つに分かれる | ゾウリムシ・アメーバ |
| **出芽** | 体の一部がふくらみ、分かれる | 酵母菌・ヒドラ |
| **栄養生殖** | 植物の体の一部（根・茎・葉）から新しい個体ができる | ジャガイモ（いも）・サツマイモ・オランダイチゴ（ほふく茎）・ヤマノイモ（むかご）・さし木 |

<div class="point" markdown="1">

**POINT 3　無性生殖の子は親とまったく同じ**

無性生殖の子は、親の体細胞分裂でできるので、**親とまったく同じ遺伝子（染色体）**を受けつぐ。そのため、子の形質（形や性質）は**親と同じ**になる。このような、同じ遺伝子をもつ個体の集団を**クローン**という。
**利点**：短い時間で、たくさんふやせる。おいしい品種などの性質をそのまま残せる（さし木・つぎ木、ジャガイモのいも）。
**欠点**：全部が同じ性質なので、病気や環境の変化に弱い性質なら、**全部が一度に被害を受ける**おそれがある。

</div>

### 4　生殖 ― 有性生殖<span class="deru">入試</span>

- **有性生殖**：雌雄の親がかかわり、**生殖細胞**が**受精**して子をつくる生殖。
- 生殖細胞：動物では**卵**（卵巣でつくる）と**精子**（精巣でつくる）。植物では**卵細胞**（胚珠の中）と**精細胞**（花粉の中）。
- **受精**：生殖細胞の**核どうしが合体**すること。受精してできた細胞を**受精卵**という。

**動物の有性生殖（カエル）**：卵と精子が受精 → **受精卵** → 体細胞分裂をくり返して**胚**になる → おたまじゃくし → カエル。
受精卵が細胞分裂を始めてから、自分で食物をとり始めるまでの時期の個体を**胚**という。受精卵から体のつくりが完成していく過程を**発生**という。

**植物の有性生殖（被子植物）**<span class="deru">入試</span>
① 花粉がめしべの**柱頭**につく（**受粉**）。
② 花粉から**花粉管**がのび、**胚珠**に向かう。
③ 花粉管の中を**精細胞**が運ばれる。
④ 精細胞の核と、胚珠の中の**卵細胞**の核が合体する（**受精**）。
⑤ 受精卵は分裂をくり返して**胚**（将来、植物の体になる部分）になる。
⑥ **胚珠全体が種子**に、**子房が果実**になる。

- **花粉管の観察**：スライドガラスに**砂糖水（ショ糖水溶液）**を落とし、ホウセンカやインパチエンスの花粉をまいて、数分〜数十分ごとに顕微鏡で見る。砂糖水は、**柱頭に近い条件**にするため。花粉管がのびていくようすが見える。
- 精子は泳いで卵に向かうが、植物の精細胞は泳げないので、**花粉管を通って**卵細胞まで運ばれる。

<div class="point" markdown="1">

**POINT 4　減数分裂**

生殖細胞（卵・精子・卵細胞・精細胞）がつくられるときの特別な細胞分裂を**減数分裂**という。生殖細胞の染色体の数は、体細胞の**半分**になる。
受精すると、受精卵の染色体の数は**もとの体細胞と同じ**にもどる。（半分 ＋ 半分 ＝ 1つ分）
子は、**両親から半分ずつ**染色体（遺伝子）を受けつぐ。

</div>

| 生物 | 体細胞の染色体数 | 生殖細胞の染色体数 |
|---|---|---|
| ヒト | **46本** | **23本** |
| タマネギ | 16本 | 8本 |
| エンドウ | 14本 | 7本 |
| イヌ | 78本 | 39本 |

- 染色体の数は生物の種類によって決まっていて、**体の大きさや複雑さとは関係ない**（イヌはヒトより多い）。

<div class="memo" markdown="1">

**本質**　もし減数分裂がなく、生殖細胞が体細胞と同じ46本だったら、受精卵は92本、その子は184本…と**世代ごとに2倍**にふえてしまう。減数分裂は、**世代をこえて染色体の数を一定に保つ**しくみ。また、子は両親の遺伝子を組み合わせて受けつぐので、**親と少しずつちがう、さまざまな形質の子**が生まれる。環境が変わっても、どれかが生き残れる可能性が高い ― これが有性生殖の利点で、進化（生物8）にもつながる。

</div>

| | 無性生殖 | 有性生殖 |
|---|---|---|
| 親 | 1つの親（雌雄なし） | 雌雄の親（生殖細胞） |
| 細胞分裂 | 体細胞分裂だけ | 減数分裂 → 受精 → 体細胞分裂 |
| 子の形質 | **親とまったく同じ** | 親と**同じとは限らない**（さまざま） |
| 利点 | 速くたくさんふやせる・形質を保てる | 環境の変化に強い集団になる |

<div class="memo" markdown="1">

**先生のひとこと**　無性生殖は「**コピー機**」、有性生殖は「**2つのデッキからカードを半分ずつ出して新しいデッキを組む**」イメージ。コピーは速くて確実だけど全部同じ。デッキを組み直すと手間はかかるが、いろいろなデッキができて、どんな相手（環境）にもだれかが勝てる。

</div>

<div class="point" markdown="1">

**入試直前チェック（できたら□にチェック）**

□ 成長 ＝ 細胞分裂で**数がふえる** ＋ 1つ1つが**大きくなる**。根は**先端付近**がよくのびる。
□ 塩酸 → **細胞を離れやすく**。染色液（酢酸オルセイン・酢酸カーミン）→ **核・染色体を染める**。おしつぶす → **重なりをなくす**。
□ 分裂の順：核 → 染色体が見える → **中央に並ぶ** → **両端へ** → しきり → 2つの細胞。
□ 体細胞分裂では染色体の数は**変わらない**。減数分裂では**半分**。受精でもとにもどる。
□ 無性生殖（分裂・出芽・栄養生殖）の子は親と**同じ遺伝子（クローン）**。
□ 受粉 → **花粉管**がのびる → **精細胞**と**卵細胞**が受精 → 胚珠が**種子**、子房が**果実**。

</div>
