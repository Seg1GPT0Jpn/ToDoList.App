## 要点まとめ

### 1　地層の材料はどこから来るか

岩石が地層になるまでには、次の4つのステップがある。

| <span style="white-space:nowrap">ステップ</span> | 何が起こるか | 例 |
|---|---|---|
| <span style="white-space:nowrap">① **風化**</span> | 地表の岩石が、気温の変化（温まる・冷える）や水・植物の根のはたらきで、もろくなってくずれる | 岩のすき間の水がこおってふくらみ、岩をわる |
| <span style="white-space:nowrap">② **侵食**</span> | 流れる水や風が、岩石をけずる | 川の上流のV字谷 |
| <span style="white-space:nowrap">③ **運搬**</span> | けずられた土砂を、流れる水が運ぶ | 運ばれる途中で角がとれて**丸く**なる |
| <span style="white-space:nowrap">④ **堆積**</span> | 流れがゆるやかになったところで、土砂が積もる | 河口・海底・湖の底、扇状地・三角州 |

- 堆積をくり返して、何層にも重なったものが**地層**。地層はふつう、**下の層ほど古い**（上へ上へと積もるから）。
- 流れる水で運ばれた粒は、ぶつかり合って**角がとれ、丸みをおびている**。火山灰の粒は流されていないので**角ばっている**。<span class="deru">入試</span>

- 1つの層の中では、**下ほど粒が大きい**ことが多い。洪水などで一度に運ばれた土砂は、重い（大きい）粒から先にしずむから。
- 地層を下から上へ見て、**粒がだんだん小さくなる**（れき→砂→泥）→ その場所が**河口から遠く（深く）なった**＝土地がしずんだか、海面が上がった。
　**粒がだんだん大きくなる**（泥→砂→れき）→ その場所が**浅く（河口に近く）なった**。

**先生のひとこと**　コップに水と砂と泥を入れてよくふってから置いておくと、まず砂が底にしずみ、泥は水をにごらせたまま、ゆっくりと上にたまる。これが「下ほど粒が大きい」の正体。重い荷物を持った人ほど早くしゃがみこむ、と覚えよう。

### 3　堆積岩<span class="deru">入試</span>

堆積したものが、長い年月の間に上の地層の重みでおし固められてできた岩石を**堆積岩**という。

| <span style="white-space:nowrap">堆積岩</span> | もとになったもの | 見分けるポイント |
|---|---|---|
| <span style="white-space:nowrap">**れき岩**</span> | れき（2 mm 以上） | 粒が大きく、**丸みをおびている** |
| <span style="white-space:nowrap">**砂岩**</span> | 砂 | 粒が丸みをおびている |
| <span style="white-space:nowrap">**泥岩**</span> | 泥 | 粒がとても小さい |
| <span style="white-space:nowrap">**石灰岩**</span> | 貝殻・サンゴなど生物の死がい（炭酸カルシウム） | うすい塩酸をかけると**二酸化炭素**が発生する。くぎで傷がつく |
| <span style="white-space:nowrap">**チャート**</span> | ケイ酸質の殻をもつ小さな生物（放散虫など）の死がい | **とてもかたい**（くぎで傷がつかない。鉄のハンマーでたたくと火花が出る）。塩酸をかけても**気体は出ない** |
| <span style="white-space:nowrap">**凝灰岩**</span> | **火山灰**・火山れきなど火山の噴出物 | 粒が**角ばっている**。近くで火山が噴火した証拠 |

- れき岩・砂岩・泥岩は**粒の大きさ**で区別する。
- 火成岩（マグマが冷え固まった岩石）とのちがい：堆積岩の粒は丸みをおびていて、**化石**をふくむことがある。火成岩の粒（鉱物）は角ばっていて、化石はふくまない。

<div class="memo" markdown="1">

**本質**　石灰岩とチャートは、どちらも「生物の死がい」が原料。それなのに塩酸への反応がちがうのは、成分がちがうから。石灰岩は**炭酸カルシウム**（貝殻・卵の殻・チョークと同じ）なので、塩酸と反応して二酸化炭素を出す。チャートは**二酸化ケイ素**（ガラスや石英と同じ）なので、塩酸と反応せず、ガラスのようにかたい。「何でできているか」がわかれば、性質は覚えなくても説明できる。

</div>

### 4　化石と地質年代<span class="deru">入試</span>

<div class="point" markdown="1">

**示相化石と示準化石**

| | 示相化石 | 示準化石 |
|---|---|---|
| <span style="white-space:nowrap">わかること</span> | 地層ができた当時の**環境**（相＝ようす） | 地層ができた**時代**（準＝基準） |
| 条件 | 限られた環境でしか生きられない生物 | **短い期間**に、**広い範囲**で、**たくさん**栄えた生物 |
| 例 | **サンゴ**：あたたかくて浅い海　**アサリ・ハマグリ**：浅い海　**シジミ**：河口や湖（海水と淡水がまじる所）　**ブナ**：やや寒い気候の陸地 | **古生代**：サンヨウチュウ・フズリナ　**中生代**：アンモナイト・恐竜　**新生代**：ビカリア・ナウマンゾウ・マンモス |

</div>

| 地質年代 | およその期間 | 主なできごと |
|---|---|---|
| 古生代 | 約5.4億年前 〜 約2.5億年前 | 魚類・両生類が現れ、植物が陸上に進出 |
| 中生代 | 約2.5億年前 〜 約6600万年前 | 恐竜・アンモナイトが栄える。鳥類が現れる |
| 新生代 | 約6600万年前 〜 現在 | ほ乳類が栄える。人類が現れる |

<div class="memo" markdown="1">

**発展**　地球の歴史（約46億年）を1年のカレンダーにすると、1日は約1260万年。古生代の始まりは**11月中旬**、恐竜が絶滅したのは**12月26日ごろ**（6600万 ÷ 1260万 ＝ 約5日前）、わたしたち人類（ホモ・サピエンス）が現れたのは**大みそかの午後11時半ごろ**。地層は、この長い時間を記録した「地球の日記帳」なんだ。

</div>

<div class="point" markdown="1">

**POINT　地層のかたむきの求め方**

① 各地点で、鍵層（火山灰層）の上面の**標高**を出す：**標高 ＝ 地点の標高 − 地表からの深さ**
② 標高を比べる。標高が同じ方向にはかたむいていない。標高が低い方向へ**低くなるようにかたむいている**。
③ 地層が平行に重なり、曲がったりずれたりしていないとき、かたむきの割合はどこでも同じ。これを使って、別の地点の深さも予想できる。

</div>


- この例でDが「Bの南、Cの東」にあり標高55mなら、火山灰層の上面は東西方向で10m低い35m → 深さ 55 − 35 ＝ **20 m** と予想できる。
- 柱状図が「深さ」で並んでいるときは、**そのまま比べてはいけない**。必ず標高に直してから比べる。

**地層から歴史を読む3つのルール**
① 下の地層ほど古い（**地層累重の法則**）。
② 地層を切っている断層は、切られている地層より**新しい**。
③ 不整合面があれば、その間に**隆起→侵食→沈降**があった。
海の生物の化石があれば、その地層は**海の底**でできた。山の上で見つかれば、その後**大きく隆起**した。

**入試直前チェック（できたら□にチェック）**

□ 風化 → 侵食 → 運搬 → 堆積。流水で運ばれた粒は**丸い**、火山灰の粒は**角ばる**。
□ れき（**2mm以上**）は岸の近く、泥は沖の深いところにたまる。上へ粒が小さくなる → **深くなった**。
□ 塩酸で二酸化炭素 → **石灰岩**。とてもかたく塩酸に反応しない → **チャート**。火山灰 → **凝灰岩**。
□ 示相化石 ＝ **環境**（サンゴ：あたたかく浅い海、シジミ：河口・湖）、示準化石 ＝ **時代**。
□ 古生代：サンヨウチュウ・フズリナ、中生代：アンモナイト・恐竜、新生代：ビカリア・ナウマンゾウ。
□ かたむきは「**地点の標高 − 深さ**」で鍵層の標高を出して比べる。
□ 引く力 → 正断層、おす力 → 逆断層・しゅう曲。不整合 ＝ 隆起・侵食・沈降の証拠。
