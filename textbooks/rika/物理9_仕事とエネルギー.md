## 要点まとめ

### 1　理科の「仕事」<span class="deru">入試</span>

- 物体に力を加えて、その**力の向きに**物体を動かしたとき、力は物体に**仕事**をしたという。

<div class="point" markdown="1">

**仕事の求め方**

**仕事〔J〕 ＝ 力の大きさ〔N〕 × 力の向きに動いた距離〔m〕**
単位は **J（ジュール）**。1 N の力で 1 m 動かしたときの仕事が 1 J。
（質量 100 g の物体にはたらく重力 ＝ 約 1 N。1 kg なら 10 N として計算することが多い）

</div>

| 場面 | 仕事 | 理由 |
|---|---|---|
| 重力 20 N の物体を 1.5 m 持ち上げる | 20 × 1.5 ＝ **30 J** | 重力に逆らう力 20 N で 1.5 m 動かした |
| 摩擦力 8 N の床で、物体を一定の速さで 3 m 引く | 8 × 3 ＝ **24 J** | 一定の速さ → 引く力 ＝ 摩擦力 |
| 重い荷物を持ったまま**じっと立つ** | **0 J** | 動いていない（距離 0） |
| 荷物を持って**水平に歩く** | **0 J**（持ち上げる力の仕事） | 力（上向き）と動く向き（横）が垂直 |
| 宇宙で慣性で進み続ける探査機 | **0 J** | 力がはたらいていない |

<div class="memo" markdown="1">

**本質**　日常の「仕事」とは意味がちがう。理科の仕事は「**どれだけ力で物を動かしたか**」の量で、**力 × 距離**のかけ算。どちらかが 0 なら仕事も 0。重い荷物を持って立ち続けるとつかれるが、物は動いていないので理科の仕事は 0 J。

</div>

- **仕事の原理**：道具を使うと**力は小さくできる**が、その分**動かす距離が長く**なり、**仕事の大きさは変わらない**。
- 動滑車そのものに重さがあるときは、それも持ち上げるので、引く力 ＝（物体＋動滑車）÷ 2。
- 実際には摩擦があるので、道具を使うと仕事は少し**大きく**なる（小さくはならない）。

</div>

<div class="memo" markdown="1">

**先生のひとこと**　仕事の原理は「力と距離のトレードオフ」。ゲームで言えば、攻撃力を半分にすると攻撃回数が2倍になって、与えるダメージの合計は同じ、というイメージ。計算問題は「**道具を使わずに真上に持ち上げたときの仕事**」を先に出して、それを距離や力でわるのが最速。

</div>

### 3　仕事率<span class="deru">入試</span>

- 1秒あたりにする仕事を**仕事率**という。「仕事の速さ」「パワー」のこと。

<div class="point" markdown="1">

**仕事率〔W〕 ＝ 仕事〔J〕 ÷ かかった時間〔s〕**

単位は **W（ワット）**。1 W ＝ 1秒あたり 1 J。電力の W と同じ単位（1 W の電気器具は1秒に 1 J の電気エネルギーを使う）。

</div>

- 例：30 J の仕事を 2 秒でする → **15 W**。同じ 30 J を動滑車で 4 秒かけてする → **7.5 W**。仕事は同じでも、時間が長いと仕事率は小さい。
- **発展**：一定の速さで動かすとき、仕事率 ＝ 力 × 速さ。60 N の物体を 0.25 m/s で持ち上げ続けると 60 × 0.25 ＝ 15 W。

### 4　エネルギー ― 位置エネルギーと運動エネルギー<span class="deru">入試</span>

- ほかの物体に**仕事をする能力**を**エネルギー**という。単位は仕事と同じ **J**。　「30 J のエネルギーをもつ」＝「最大で 30 J の仕事ができる」。
- **位置エネルギー**：高い所にある物体がもつエネルギー。**高さが高いほど**、**質量が大きいほど**大きい（どちらにも**比例**）。高さは**基準面**（ふつうは床）から測る。
- **運動エネルギー**：動いている物体がもつエネルギー。**質量が大きいほど**（比例）、**速さが大きいほど**大きい（**速さの2乗に比例**：速さ2倍 → 4倍、3倍 → 9倍）。

- **ふりこ**：Aではなした球は、反対側の**Aと同じ高さ（C）**まで上がる。いちばん低いBで**最も速い**。
- 途中に**くぎ**を打ってひもが引っかかっても、球は**はなした位置と同じ高さ**まで上がる（ふれ方は変わる）。
- **ジェットコースター**：スタート地点より**高い所へは行けない**。同じ高さの地点では、**速さも同じ**。低い所ほど速い。
- 斜面の**傾きや形がちがっても**、同じ高さから下りれば、下に着いたときの**速さは同じ**（傾きで変わるのは、着くまでの時間）。
- 実際には摩擦や空気の抵抗があるので、力学的エネルギーは少しずつ減り、ふりこはやがて止まる。減った分は**熱や音のエネルギー**に変わっている。

<div class="memo" markdown="1">

**本質**　エネルギーは「お金」に例えるとわかりやすい。位置エネルギーは「貯金」、運動エネルギーは「手持ちのお金」。坂を下ると貯金をおろして手持ちが増え（速くなる）、坂を上ると手持ちを貯金にもどす（遅くなる）。合計（力学的エネルギー）は変わらない。摩擦は「手数料」で、少しずつ熱として出ていく。

</div>

### 6　エネルギーの移り変わりと保存<span class="deru">入試</span>

| エネルギー | 例 |
|---|---|
| 電気エネルギー | 電流がもつ。家電製品を動かす |
| 熱エネルギー | 物の温度を上げる |
| 光エネルギー | 太陽光、照明の光 |
| 音エネルギー | 空気をふるわせる |
| 化学エネルギー | 物質の中にたくわえられている（燃料、食べ物、電池） |
| 弾性エネルギー | 変形したばね・ゴムがもつ |
| 核エネルギー | 原子核がもつ（原子力発電） |

| 器具・現象 | エネルギーの移り変わり |
|---|---|
| **発電機**（手回し発電機・火力発電のタービン） | 運動 → **電気** |
| **モーター** | 電気 → **運動** |
| **光電池（太陽電池）** | 光 → **電気** |
| **乾電池・燃料電池** | 化学 → **電気** |
| LED・電灯 | 電気 → **光**（＋熱） |
| 電熱線・電気ストーブ | 電気 → **熱** |
| スピーカー | 電気 → **音** |
| 光合成（植物） | 光 → **化学** |
| 火力発電 | 化学 → 熱 → 運動 → 電気 |

- **エネルギー保存の法則**：エネルギーは移り変わっても、その**総量は変わらない**。
- ただし、変換のとき一部は目的外の**熱**などになる。目的のエネルギーに変わった割合を**変換効率**という。

<div class="point" markdown="1">

**変換効率〔%〕 ＝ 目的のエネルギー〔J〕 ÷ もとのエネルギー〔J〕 × 100**

例：100 J の電気エネルギーで、光エネルギーが 20 J 得られた → 変換効率 **20 %**。残り 80 J は主に熱になって出ていった（なくなったわけではない）。
LED が省エネなのは、白熱電球より**熱にむだになる分が少なく、変換効率が高い**から。

</div>

<div class="memo" markdown="1">

**発展**　熱になったエネルギーは、まわりに広がってしまい、もとの電気や運動にもどすのがむずかしい。だから「総量は変わらないのに、使えるエネルギーは減っていく」。省エネが大切なのはこのため。

</div>

### 7　熱の伝わり方

| 伝わり方 | しくみ | 例 |
|---|---|---|
| **伝導**（熱伝導） | 物体の中や、ふれ合った物体の間を、**高温の部分から低温の部分へ**熱が伝わる。金属は伝えやすい | なべの取っ手が熱くなる、保冷剤で冷やす |
| **対流** | 温められた液体・気体が**移動して**熱を運ぶ。温まると密度が小さくなって**上へ**、冷えると**下へ** | ふろの湯の上だけ熱い、エアコンの風で部屋全体が暖まる |
| **放射**（熱放射） | 熱が**光（赤外線など）**として空間を伝わる。**空気がなくても**伝わる。黒い物ほど吸収しやすい | 太陽で地面が暖まる、たき火やストーブの前で顔が熱い |

- 熱は、温度が**高い物から低い物へ**移動し、両方が同じ温度になると止まる。
- 暖房の風は**下向き**、冷房の風は**上向き**にすると、対流で部屋全体の温度がそろいやすい。
- 魔法びん：二重のかべの間を**真空**にして伝導・対流を防ぎ、かべを**鏡のように**して放射を防ぐ。

<div class="point" markdown="1">

**入試直前チェック（できたら□にチェック）**

□ 仕事〔J〕＝ 力〔N〕× 力の向きに動いた距離〔m〕。動かない・力と垂直に動く → 0 J。
□ 仕事の原理：動滑車は**力 1/2・距離 2倍**。斜面は力 ＝ 重力 × 高さ ÷ 長さ。仕事は変わらない。
□ 仕事率〔W〕＝ 仕事〔J〕÷ 時間〔s〕。
□ 位置E は**高さ・質量に比例**。運動E は**質量に比例、速さの2乗に比例**。
□ 力学的E ＝ 位置E ＋ 運動E は一定（摩擦なし）。ふりこは**同じ高さ**まで上がる。最下点で**最も速い**。
□ 変換効率 ＝ 目的のE ÷ もとのE × 100。残りは主に**熱**。エネルギーの総量は保存される。
□ 熱の伝わり方は**伝導・対流・放射**。放射は真空でも伝わる。

</div>
