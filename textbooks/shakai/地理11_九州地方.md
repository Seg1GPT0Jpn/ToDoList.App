# 中2地理 地理11「九州地方」

<p class="lead">対象：中学2年 地理（小5から挑戦OK）｜中心テーマは「自然環境」。火山とシラス台地・カルデラ／温暖な気候と台風／促成栽培と畜産／北九州工業地域の変化（IC・自動車）／公害の克服と環境モデル都市／沖縄の自然・歴史・観光と基地</p>

## 要点まとめ

### 0　九州地方の見取り図（8つの県）

- 九州地方＝**九州島の7県＋沖縄県**。南西諸島は九州の南から台湾の近くまで、弓のように連なる。
- アジア（韓国・中国）に近く、昔から**大陸との交流の玄関口**。地方の中心は **福岡市**（地方中枢都市・政令指定都市）。

| 県 | 県庁所在地 | 主な産物・キーワード |
|---|---|---|
| **福岡県** | 福岡市 | 北九州市（**八幡製鉄所**→北九州工業地域）、**自動車**、いちご、博多港 |
| **佐賀県** | 佐賀市 | **有明海ののり養殖**、筑紫平野の米・麦（二毛作）、有田焼などの陶磁器 |
| **長崎県** | 長崎市 | 島がとても多い、**造船**、雲仙岳（普賢岳）、びわ、出島（江戸時代の貿易） |
| **熊本県** | 熊本市 | **阿蘇山のカルデラ**、**トマト**・**い草**（たたみ表）、IC（半導体）工場、**水俣病** |
| **大分県** | 大分市 | **温泉**（別府・湯布院）、**地熱発電**、かぼす、大分の製鉄所・石油化学 |
| **宮崎県** | 宮崎市 | **宮崎平野の促成栽培**（ピーマン・きゅうり）、肉用若鶏・豚・肉牛 |
| **鹿児島県** | 鹿児島市 | **シラス台地**、**桜島**、豚・肉牛・肉用若鶏、さつまいも、茶、屋久島（世界自然遺産） |
| **沖縄県** | **那覇市** | さとうきび・パイナップル・きく、**観光**、**さんご礁**、**アメリカ軍基地** |

### 1　火山がつくった大地 ― カルデラとシラス台地

- 九州は **火山の多い地方**。北から **雲仙岳**（長崎）、**阿蘇山**（熊本）、**九重山**（大分）、**霧島山**、**桜島**（鹿児島）。
- **阿蘇山**：大噴火のあとに地面が落ちこんでできた巨大なくぼ地＝**カルデラ**。世界最大級で、中に**町や村・田畑・鉄道**まである。<span class="deru">入試</span>
- **シラス台地**：九州南部（鹿児島県〜宮崎県南部）に広がる、火山の噴出物（**シラス**）が厚く積もった台地。
- **雲仙岳（普賢岳）**は1990年代はじめの噴火で**火砕流**が発生し、大きな被害が出た。**桜島**は今も噴火をくり返し、鹿児島市に火山灰が降る。

<div class="memo" markdown="1">
**本質**　シラス台地は「スポンジの上の畑」。雨がすぐ地下にしみこむので**水田に向かない**。だから昔は**さつまいも**など乾燥に強い作物が中心だった。第二次世界大戦後、**ダムや用水路**で水を引けるようになり、**野菜・茶**の栽培や、えさを使う**畜産**が大きくのびた。「自然の弱点 → 人の工夫 → 今の産業」という流れで説明できるようにしよう。
</div>

### 2　温暖な気候と台風

- 沖合を暖流の **黒潮（日本海流）** と **対馬海流** が流れ、冬でも**温暖**。
- **梅雨**や**台風**の影響で**夏に雨がとても多い**。とくに南九州は年降水量が多い。九州は台風の通り道で、**集中豪雨**による水害・土砂災害も多い。
- 南西諸島（沖縄など）は **亜熱帯** に近い気候（南西諸島の気候）。1年中暖かく、冬でも平均気温が15℃を下回らない。

**POINT 2　沖縄の伝統的な家のくふう**<span class="deru">入試</span>

- **台風**に備えて：家のまわりを**石垣**やフクギの防風林で囲む、**屋根を低く**する、かわらを**しっくい**で固める。
- **水不足**に備えて：川が短く、雨水がすぐ海に流れてしまう → 屋根の上に**貯水タンク**。
- 最近はコンクリートづくりの家が多い（台風に強い）。

### 3　九州の農業 ― 北は稲作、南は畑作と畜産

| 地域 | 自然条件 | 農業 |
|---|---|---|
| **筑紫平野**（福岡・佐賀） | 九州最大の平野。**筑後川**が流れる | **稲作**。冬は温暖なので裏作に**麦**をつくる**二毛作**。水路（**クリーク**） |
| **有明海** | 遠浅で干満の差が大きい | **のりの養殖**（佐賀県は全国上位）。**干拓**で農地を広げた |
| **宮崎平野** | **冬も温暖で日照時間が長い** | ビニールハウスで**ピーマン・きゅうり**の**促成栽培** |
| **シラス台地**（鹿児島・宮崎） | 水もちが悪い | **さつまいも**・**茶**、**畜産**（豚・肉牛・肉用若鶏） |
| **熊本平野・八代平野** | 温暖 | **トマト**（熊本県は全国有数）、**い草**（たたみ表、ほぼ熊本県産） |
| **沖縄** | 亜熱帯、台風が多い | **さとうきび**・**パイナップル**、電照ぎく、マンゴー |

<div class="point" markdown="1">
**POINT 3　促成栽培（そくせいさいばい）＝「時期を早める」作戦**<span class="deru">入試</span>

1. **なぜできる？** 宮崎平野は**黒潮**の影響で冬も暖かく、晴れの日が多い → ビニールハウスの暖房費が少なくてすむ。
2. **なぜもうかる？** ほかの産地（関東など）の野菜が出回らない**冬〜春**に出荷できる → **値段が高い時期**に売れる。
3. **どうやって運ぶ？** 保冷トラック（**高速道路**）やフェリーで東京・大阪などの大都市へ。
4. **課題**：重油の値上がりで暖房費が増える。→ 省エネ設備・ブランド化。

</div>

<div class="point" markdown="1">
**POINT 4　南九州の畜産**<span class="deru">入試</span>

- **鹿児島県・宮崎県**は、**豚・肉牛・肉用若鶏（ブロイラー）**の飼育頭数・羽数が、いずれも**全国の上位**（北海道とならぶ）。
- **黒豚**・**宮崎牛**など**ブランド化**して、ほかの産地と差をつける。
- 課題：**輸入肉**との競争、**家畜の伝染病**（口蹄疫・鳥インフルエンザ）への対策、えさの多くが輸入飼料。

</div>

<div class="memo" markdown="1">
**先生のひとこと**　促成栽培は、ゲームの「**早期予約特典**」みたいなもの。みんなが持っていない時期に手に入るから価値が高い。逆に、時期をおくらせるのが**抑制栽培**（中部地方の高原野菜など）。セットで覚えよう。
</div>

### 4　工業 ― 北九州工業地域の変化とIC・自動車

<div class="point" markdown="1">
**POINT 5　鉄の町から「新しい工業」へ**<span class="deru">入試</span>

| 時期 | できごと | 理由・背景 |
|---|---|---|
| **1901年** | 官営の **八幡製鉄所** が操業開始（今の北九州市） | 近くの**筑豊炭田**の**石炭**、**中国から鉄鉱石**を輸入しやすい |
| 〜1950年代 | **北九州工業地帯**として鉄鋼業で発展 | 四大工業地帯の一つとよばれた |
| 1960年代〜 | 地位が低下 →「**北九州工業地域**」に | **エネルギー革命**（石炭→石油）で炭鉱が閉山。工業の中心が太平洋ベルトの東側へ |
| 1970年代〜 | **IC（集積回路）工場**が九州各地に進出 | IC は**小さく軽く高価** → **航空機**や**高速道路**で運んでも採算がとれる。空港・高速道路の近くに工場 |
| 1990年代〜 | **自動車工場**の進出（福岡県・大分県など） | 広い土地と労働力、**アジアに近い港**。部品工場も集まる |

</div>

- 九州は IC 工場が多く「**シリコンアイランド**」とよばれる。2024年には熊本県で、海外の大手企業による大規模な**半導体工場**が動き出した。
- 自動車工場が多く、九州を「**カーアイランド**」とよぶこともある。

<div class="memo" markdown="1">
**本質**　工場の場所は「**何を運ぶか**」で決まる。鉄鋼は原料（鉄鉱石・石炭）が**重くてかさばる**ので**港の近く**。IC は製品が**小さくて高い**ので、**空港や高速道路の近く**なら内陸でもOK。この考え方はほかの地方でも使える。
</div>

### 5　公害の克服と環境モデル都市

| 都市 | どんな公害？ | どうなった？ |
|---|---|---|
| **水俣市**（熊本県） | 化学工場の排水にふくまれた**有機水銀（メチル水銀）**が魚介類に取りこまれ、それを食べた人々に**水俣病**が発生（**四大公害病**の一つ） | 汚れた海の底をうめ立てて整備。ごみの細かい分別など、環境を大切にするまちづくり |
| **北九州市**（福岡県） | 工場のけむりによる**大気汚染**、**洞海湾**の水質汚濁（「死の海」とよばれた） | **市民（女性たち）の運動**→ 市・企業が対策 → 空と海がきれいに。**エコタウン**でリサイクル産業 |

- 北九州市と水俣市は、国から **環境モデル都市** に選ばれた（2008年）。<span class="deru">入試</span>
- 北九州市は、公害を克服した技術を、アジアなどの**海外の都市に伝える**国際協力も行っている。

<div class="memo" markdown="1">
**本質**　「公害を出した町」が「環境の先進地」に変わった。失敗の経験とそれを解決した技術が、**持続可能な社会**をつくる力になる、というのが九州で学ぶ大きなメッセージ。
</div>

### 7　沖縄 ― 自然・歴史・観光と基地

| テーマ | ポイント |
|---|---|
| **自然** | 亜熱帯の気候、**さんご礁**の海、マングローブ。土地の開発で**赤土**が海に流れ、さんご礁が傷つく問題 |
| **歴史** | 15世紀に**琉球王国**が成立（首都は**首里**）。日本・中国・東南アジアを結ぶ**中継貿易**で栄えた → 1879年に**沖縄県**に → 太平洋戦争末期に**沖縄戦** → 戦後**アメリカの統治下** → **1972年に日本に復帰** |
| **文化** | 首里城跡などが世界文化遺産。エイサー・三線（さんしん）など独自の文化 |
| **産業** | **観光業**などの**第三次産業**の割合がとても高い（観光客の多くは航空機で来る）。農業はさとうきび・パイナップル・きく・マンゴー |
| **基地** | 日本にあるアメリカ軍専用施設の面積の**約7割**が沖縄県に集中。騒音・事故・土地利用の制約などの課題 |

<div class="memo" markdown="1">
**先生のひとこと**　沖縄の問題は「さんご礁の**環境保全**」と「観光の**開発**」、そして「**基地**」が重なっている。入試の記述では「〜という利点がある一方で、〜という課題がある」と**両面**を書くのがコツ。
</div>
