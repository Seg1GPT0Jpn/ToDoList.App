<div class="point" markdown="1">
**やませと冷害**<span class="deru">入試</span>

- **やませ**：初夏〜夏に、**北東**から東北地方の**太平洋側**にふく、**冷たく湿った風**（寒流の**親潮**の上を通ってくるので冷たい）。
- やませがふき続くと、霧やくもりの日が多くなり、**日照不足と低温**で稲が育たない ＝ **冷害**。
- 対策：**寒さに強い品種**への**品種改良**、田の水を深くはって稲を寒さから守る、など。

</div>

### 3　東北の農業と漁業 ── 日本の米どころ

<div class="point" markdown="1">
**稲作**＝東北地方は日本の**穀倉地帯**（全国の米の約4分の1を生産）<span class="deru">入試</span>

- 雪どけ水が豊富。夏は昼が長く、日本海側は夏に晴れて気温が上がる。**庄内平野・秋田平野・仙台平野**などが米どころ。
- **銘柄米**：「**あきたこまち**」（秋田）、「**はえぬき**」「つや姫」（山形）、「**ひとめぼれ**」（宮城）など。冷害に強く、おいしい品種を開発してきた。
- 米が余るようになり、国は1970年ごろから米の生産量をへらす**減反政策**（**生産調整**）を進め、**転作**（米以外の作物に切りかえる）がすすんだ。国が生産量を割り当てるしくみは**2018年に廃止**。

</div>

<div class="cols2" markdown="1">

**果樹栽培**<span class="deru">入試</span>
- **青森県**の**津軽平野**：**りんご**（全国の半分以上）。すずしい気候が合う。
- **山形県**の**山形盆地**：**さくらんぼ**（全国の半分以上）・西洋なし。
- **福島県**の**福島盆地**：**もも**。
- 盆地の**扇状地**（水はけがよい）を利用（中部地方の甲府盆地と同じ）。

**三陸の漁業**<span class="deru">入試</span>
- 三陸沖は、寒流の**親潮**（千島海流）と暖流の**黒潮**（日本海流）がぶつかる**潮目**（潮境）→ プランクトンが多く、魚が集まる**好漁場**。
- **リアス海岸**の湾内は波がおだやか → **かき・わかめ・こんぶ**の**養殖**。陸奥湾は**ほたて**。
- 八戸・気仙沼・石巻などの漁港。

</div>

### 4　伝統行事と伝統工芸 ── 冬の暮らしと願い

<div class="point" markdown="1">
**東北の夏祭りと伝統的工芸品**<span class="deru">入試</span>

| 夏祭り（東北四大祭り） | 県 | 伝統的工芸品 | 県 |
|---|---|---|---|
| **ねぶた祭**（大きな灯ろう） | 青森 | **津軽塗**（漆器） | 青森 |
| **竿燈まつり**（ちょうちんを稲穂に見立てる） | 秋田 | **南部鉄器**（鉄びん） | 岩手 |
| **七夕まつり** | 宮城（仙台） | **宮城伝統こけし** | 宮城 |
| **花笠まつり** | 山形 | **大館曲げわっぱ**（すぎの木） | 秋田 |
| | | **天童将棋駒** | 山形 |
| | | **会津塗**（漆器） | 福島 |

- 祭りには、**豊作**や無病息災を願う意味がこめられている。今は多くの**観光客**を集める。
- 伝統工芸は、冬に**雪で農作業ができない**間の**副業**として、地元の**木・漆・鉄**などを使って発達した（北陸と同じ考え方）。
- 課題：**後継者不足**。→ 現代の生活に合うデザインや、海外への輸出（南部鉄器のカラフルな急須など）にも取り組んでいる。

</div>

- **工業**：**東北新幹線・東北自動車道**の整備で、**高速道路のインターチェンジ付近**に**工業団地**ができ、**電子部品**・**自動車**関連の工場が進出した。
- **課題**：若い人が都市へ出て、農村や山間部で**過疎化・高齢化**が進む。

### 5　東日本大震災と復興

<div class="point" markdown="1">
**東日本大震災（2011年3月11日）**<span class="deru">入試</span>

- 三陸沖を震源とする、**マグニチュード9.0**の巨大地震（東北地方太平洋沖地震）。
- **大津波**が太平洋沿岸をおそった。特に**リアス海岸**の湾の奥では、波が集まって**高く**なり、大きな被害が出た。
- **福島第一原子力発電所の事故**が起こり、多くの人が長い間ふるさとをはなれて避難した。
- **復興**：住宅の**高台移転**、**防潮堤**の建設、土地のかさ上げ、**三陸沿岸道路**（復興道路）の整備、震災の記憶を伝える**震災遺構**・伝承施設。
- 学んだこと：**ハザードマップ**の確認、「自分の命は自分で守る」**早めの避難**、地域での**防災訓練**。

</div>

### 9　観光と自然保護・寒さに負けない暮らし

- **観光**：**さっぽろ雪まつり**、スキー場（外国人観光客にも人気）、流氷観光、ラベンダー畑。アジアなどから多くの観光客。
- **自然保護**：**知床**では、自然を守りながら観光する **エコツーリズム**。ガイドつきのツアー、**高架木道**（ヒグマや植物を守りつつ歩ける）、マイカー規制など。<span class="deru">入試</span>
- **寒さ・雪への工夫**：**二重窓**・断熱材、灯油タンク、道路の雪をとかす**ロードヒーティング**、雪が積もりにくい**縦型の信号機**、矢羽根（道路のはしを示す標識）。

<div class="memo" markdown="1">
**本質**　東北・北海道は「**寒さ**」がキーワード。寒さは**冷害**というマイナスを生むけれど、**品種改良**や**酪農**（寒くても牧草は育つ）、**流氷・雪の観光**のように、**自然条件に合わせた工夫**でプラスに変えてきた。入試の記述では「**自然条件 → だから → 産業・くふう**」の順で書こう。
</div>
