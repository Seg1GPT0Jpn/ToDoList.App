# 中3歴史 歴史16「戦後の日本の改革と冷戦」

<p class="lead">対象：中学3年 歴史（小5から挑戦OK）｜GHQの占領と民主化・日本国憲法・国際連合・冷戦と朝鮮戦争・サンフランシスコ平和条約と日米安全保障条約・日ソ共同宣言と国連加盟</p>

## 要点まとめ

<div class="memo" markdown="1">
**先生のひとこと**　この単元は「**負けた日本が、つくり直されて、独立するまで**」の物語。**①民主化（日本の中をつくり直す）②冷戦（世界が2チームに分かれる）③独立回復（日本は西側チームへ）**の3つがからみ合うのが入試のツボ。
</div>

### 1　敗戦と占領 ── 「なぜ」「何を」「どうした」

| 流れ | できごと |
|---|---|
| **なぜ** | **1945年8月14日**、**ポツダム宣言**（米・英・中が出した降伏の条件）を受け入れ、**8月15日**に天皇がラジオで降伏を伝えた。 |
| **何が** | 連合国軍（中心はアメリカ）が日本を**占領**。**GHQ（連合国軍最高司令官総司令部）** の最高司令官は **マッカーサー**。<span class="deru">入試</span> |
| **どうなった** | GHQ が指令を出し、**日本の政府がそれを実行する**「**間接統治**」の方法で、**非軍事化**と**民主化**を進めた。 |

- **領土**：日本の領土は北海道・本州・四国・九州と周辺の島々に限られた。**沖縄・奄美群島・小笠原諸島**はアメリカが直接統治した（間接統治ではない！）。
- **非軍事化**：軍隊を解散。戦争指導者を **極東国際軍事裁判（東京裁判）** で裁き、戦争に協力した人々を公職から追放。
- くらし：海外からの**引き揚げ**、食料不足で**闇市**・農村への**買い出し**、物価が急に上がる**インフレーション**。

<div class="memo" markdown="1">
**本質**　GHQ の目的は「**日本が二度と戦争をしない国にする**」こと。改革は**「何が戦争を支えていた？」→「それをどう変えた？」**のセットで覚えよう。
</div>

### 3　日本国憲法の制定

- GHQ の案をもとに政府が改正案をつくり、帝国議会で審議・修正。
- **1946年11月3日 公布**（今の「文化の日」）→ **1947年5月3日 施行**（今の「憲法記念日」）<span class="deru">入試</span>

<div class="point" markdown="1">
**POINT　大日本帝国憲法と日本国憲法のちがい**<span class="deru">入試</span>

| | 大日本帝国憲法（1889年発布） | 日本国憲法（1946年公布） |
|---|---|---|
| 主権 | **天皇**主権 | **国民**主権 |
| 天皇 | 国の元首。軍隊を指揮する | 日本国と日本国民統合の**象徴** |
| 人権 | **法律の範囲内**で認める | 永久の権利として保障（**基本的人権の尊重**） |
| 戦争・軍隊 | 天皇が陸海軍を統帥。国民に兵役の義務 | 戦争を放棄し、戦力をもたない（**平和主義**） |
| 議会 | 貴族院と衆議院 | 衆議院と**参議院**。国会は「国権の最高機関」 |
| 決めた人 | 天皇が定めて国民にあたえた（欽定憲法） | 国民が定めた（民定憲法） |

- 日本国憲法の三つの基本原理：**国民主権・基本的人権の尊重・平和主義**

</div>

### 4　国際連合 ── 「二度と世界大戦を起こさない」ために

- **1945年10月**、**国際連合（国連）** 発足。原加盟国51か国、本部は**ニューヨーク**。
- 中心は**安全保障理事会**。**常任理事国**は**アメリカ・イギリス・フランス・ソ連（今はロシア）・中国**の5か国で、1か国でも反対すると決められない **拒否権** をもつ。<span class="deru">入試</span>

| | 国際連盟（1920年） | 国際連合（1945年） |
|---|---|---|
| 本部 | ジュネーブ（スイス） | **ニューヨーク**（アメリカ） |
| 大国の参加 | アメリカは**不参加**、ソ連は途中から | 米ソなど大国が最初から参加 |
| 制裁 | 経済制裁が中心 | **軍事的な制裁**もできる |
| 決め方 | 総会は全会一致 | 総会は多数決。安保理の常任理事国に**拒否権** |

<div class="memo" markdown="1">
**本質**　国連は「連盟の失敗（大国不在・全会一致・制裁が弱い）」の反省からできた。そのかわり大国に**拒否権**をあたえた。……この拒否権が**冷戦**で大問題になる。
</div>

### 5　冷戦 ── 世界が2つのチームに分かれる

**冷戦（冷たい戦争）**：アメリカとソ連が、直接の戦争（熱い戦争）はしないまま、世界中できびしく対立した状態。<span class="deru">入試</span>

| | **西側（資本主義）陣営** | **東側（社会主義・共産主義）陣営** |
|---|---|---|
| 中心 | **アメリカ** | **ソ連** |
| 経済のしくみ | 会社や土地を個人がもち、自由に競争する | 国が工場や土地をもち、経済を計画する |
| 軍事同盟 | **北大西洋条約機構（NATO）**（1949年） | **ワルシャワ条約機構**（1955年） |

- **ドイツ**：1949年に**西ドイツ**と**東ドイツ**に分かれた。のちに**ベルリンの壁**（1961年）。
- **中国**：内戦で共産党が勝ち、**1949年**に**中華人民共和国**が成立（主席 **毛沢東**）。国民党は**台湾**へ。
- **朝鮮**：北緯38度線を境に、南をアメリカ、北をソ連が占領 → **1948年**、南に**大韓民国（韓国）**、北に**朝鮮民主主義人民共和国（北朝鮮）**。

<div class="point" markdown="1">
**POINT　朝鮮戦争（1950〜1953年）と日本**<span class="deru">入試</span>

- **なぜ**：南北統一をめざし、**1950年**に北朝鮮が韓国に攻めこんだ。
- **何が**：韓国側をアメリカ中心の**国連軍**、北朝鮮側を**中国の義勇軍**が支援。1953年に**休戦**（今も南北に分かれたまま）。
- **日本への影響①（経済）**：アメリカ軍が日本で大量の物資を買い入れた → **特需景気**（朝鮮特需）。日本の経済が**復興**するきっかけに。
- **日本への影響②（軍事）**：日本にいたアメリカ軍が朝鮮へ出動 → GHQ の指令で **警察予備隊**（1950年）→ 保安隊（1952年）→ **自衛隊**（1954年）。

</div>

<div class="memo" markdown="1">
**本質**　冷戦で、アメリカの日本への方針は「**弱くしておく**」から「**西側の強い仲間にする**」へ変わった（**占領政策の転換**）。経済復興・警察予備隊・**早期の独立**は、すべてこの流れ。
</div>

### 6　独立の回復と国際社会への復帰

- **1951年 サンフランシスコ平和条約**（首相 **吉田茂**）：アメリカなど48か国と調印。**ソ連などは調印せず**、中国は会議に招かれなかった。**1952年4月に発効**し、日本は**独立を回復**。<span class="deru">入試</span>
- **同じ日に日米安全保障条約**：独立後も**アメリカ軍が日本にとどまる**ことを認めた。沖縄・小笠原はアメリカの統治が続いた（奄美群島は1953年に復帰）。
- **1954年 第五福竜丸事件**：アメリカの水爆実験で日本の漁船が被ばく → **原水爆禁止運動**が広がる。
- **1955年 55年体制**：自由民主党（自民党）が政権をとり、野党第一党は社会党。この体制が**38年間**続く。
- **1956年 日ソ共同宣言**（首相 **鳩山一郎**）：ソ連と**国交回復** → 同じ年に**国際連合加盟**。<span class="deru">入試</span>
- **1960年 日米安全保障条約の改定**（首相 岸信介）：はげしい反対運動（**安保闘争**）。

<div class="point" markdown="1">
**POINT　なぜ国連加盟は1956年まで待たされたのか？**<span class="deru">入試</span>

- 国連に入るには**安全保障理事会の賛成**が必要。
- サンフランシスコ平和条約に調印しなかった**ソ連**は、常任理事国として**拒否権**を使い、日本の加盟に反対していた。
- **1956年の日ソ共同宣言**でソ連と国交が回復 → ソ連が反対しなくなり、**同じ年の12月に加盟**。
- **北方領土**：日ソ共同宣言では、平和条約を結んだあとに**歯舞群島・色丹島**を引きわたすとされたが、平和条約は今も結ばれていない。

</div>

- 冷戦のなかで、アジア・アフリカでは植民地からの独立が進んだ。**1955年**に**アジア・アフリカ会議**（インドネシアのバンドン）、**1960年**はアフリカで17か国が独立した「**アフリカの年**」。

### 入試直前チェック

- GHQ（最高司令官 **マッカーサー**）の**間接統治**。目的は **非軍事化と民主化**。
- **財閥解体**（経済）・**農地改革**（自作農を増やす）・**選挙法改正**（満20歳以上の男女）・**教育基本法**（義務教育9年）。
- 日本国憲法：**1946年11月3日公布、1947年5月3日施行**。国民主権・基本的人権の尊重・平和主義。
- 国際連合（1945年）：本部ニューヨーク。常任理事国5か国に**拒否権**。
- 冷戦：**アメリカ（西側・NATO）** vs **ソ連（東側・ワルシャワ条約機構）**。**朝鮮戦争**（1950年）→ **特需景気**・**警察予備隊**。
- **サンフランシスコ平和条約**（1951年調印・1952年発効、**吉田茂**）＋**日米安全保障条約**。**日ソ共同宣言**（1956年、**鳩山一郎**）→ 同年に**国連加盟**。
