# 中1歴史 歴史4「平安時代」

<p class="lead">対象：中学1年 歴史（小5から挑戦OK）｜桓武天皇の改革・摂関政治と藤原氏・国風文化・地方の乱れと武士の成長・院政・平氏の政権と日宋貿易</p>

## 要点まとめ

### 0　平安時代の流れを1分でつかむ

平安時代は **794年〜1185年ごろ** の約400年。主役が **天皇 → 藤原氏（貴族）→ 上皇 → 武士（平氏）** と入れかわっていく時代。「**だれが政治の実権をにぎったか**」で4つに区切ると、流れがスッキリ見える。

| 年 | できごと | 政治の主役 |
|---|---|---|
| **794** | **桓武天皇**が都を **平安京**（京都）に移す <span class="deru">入試</span> | 天皇（律令の立て直し） |
| 797 | **坂上田村麻呂**が **征夷大将軍** になる（東北の蝦夷を攻める） | |
| 805・806 | **最澄**（天台宗）・**空海**（真言宗）が唐から帰国 | |
| 858 | **藤原良房**が幼い天皇の政治を代行（のち正式に **摂政**） | 藤原氏（**摂関政治**） |
| 887 | **藤原基経**が **関白** になる | |
| **894** | **菅原道真**の意見で **遣唐使を停止** <span class="deru">入試</span> | |
| 935 | **平将門の乱**（関東）が起こる（939〜941年は **藤原純友の乱**） | |

</div>

### 1　桓武天皇の政治 ― 律令政治の立て直し

**なぜ？** 奈良時代の終わり、平城京では **仏教勢力（寺院・僧）が政治に口を出す** ようになり、貴族の争いも続いた。また、**公地公民** のしくみ（班田収授法）もくずれ始めていた。

**何をした？**（**桓武天皇**、在位781〜806年）

- **784年 長岡京** → **794年 平安京** へ都を移す。奈良の大寺院を新しい都に移さず、仏教勢力と距離をとった。
- **国司の不正をきびしく取りしまる**（地方の政治を立て直す）。
- 東北地方で朝廷に従わない人々（**蝦夷**）を従わせるため、**坂上田村麻呂** を **征夷大将軍** に任命。802年に **胆沢城**（岩手県）を築き、蝦夷の指導者 **アテルイ** を降伏させた。
- 農民の負担を軽くするため、一部の地域をのぞいて **一般の農民からの兵士の徴集をやめた**。

**どうなった？** 天皇中心の政治がいったん立て直され、新しい仏教も生まれた。

|---|---|---|---|
| **最澄** | **天台宗** | **比叡山延暦寺**（滋賀県・京都府の境） | 山の中で修行・学問 |
| **空海** | **真言宗** | **高野山金剛峯寺**（和歌山県） | きびしい修行と祈りで願いをかなえる（密教） |

- 2人とも **遣唐使** といっしょに唐に渡って学んだ。
- 奈良の仏教が「都の中で国家を守る」ものだったのに対し、**山奥の寺** で修行し、天皇や貴族のために **祈とう**（病気や災いをはらう祈り）を行った。

</div>

**史料を読もう**　藤原道長が、娘の威子を天皇のきさきにしたお祝いの席でよんだとされる歌（藤原実資の日記『小右記』に記録）

<div class="ex" markdown="1">

（現代語訳）この世の中は、まるで自分のための世の中だと思う。夜空の満月に欠けたところがないように、わたしの思いどおりにならないことは何もないのだから。
</div>

- 「満月」＝道長の権力が **完全なもの** になったことのたとえ。摂関政治の全盛を示す史料として入試によく出る。<span class="deru">入試</span>

**藤原氏の財力の源 ― 荘園**
奈良時代の **墾田永年私財法**（743年）以来、貴族や寺社は私有地（**荘園**）を広げた。平安時代には、地方で土地を開発した有力者が、**国司の税の取り立てをのがれるため**、土地を藤原氏などの有力な貴族や寺社に **寄進**（名目上さし出すこと）した。

**本質**　摂関政治は「**血のつながり**」と「**荘園の財力**」の2本柱。天皇の祖父という立場で政治を動かし、全国の荘園から入る富でぜいたくな暮らしを支えた。だから荘園が整理されたり（→院政）、天皇との血のつながりが切れたりすると、藤原氏の力は一気に弱まる。

### 3　東アジアの変化と遣唐使の停止

- **なぜ？** 9世紀、**唐** は国内の反乱で **おとろえ**、航海も **危険** だった。そこで **894年**、**菅原道真** の提案で **遣唐使が停止** された。道真はのちに藤原氏に退けられ、**大宰府**（福岡県）に追われた（現在は「学問の神様」として天満宮にまつられる）。
- **どうなった？** **907年 唐がほろびる**。中国は **宋**（960年〜）が統一。朝鮮半島では **高麗**（918年〜）が **新羅** をほろぼした。
- 正式な国交はなくなったが、**宋の商人** は日本にやってきて、民間の貿易は続いた。

### 4　国風文化 ― 日本らしい文化が花開く <span class="deru">入試</span>

**なぜ？** 遣唐使の停止の前から、唐の文化を **日本の風土や生活、日本人の感情に合うように** 工夫する動きが進んでいた。停止をきっかけに、その動きがいっそう強まった。摂関政治のころの **貴族** が担い手。

<div class="point" markdown="1">
**POINT 3　国風文化のまとめ**

| 分野 | 内容 |
|---|---|
| **かな文字** | 漢字をくずした **ひらがな**、漢字の一部をとった **カタカナ**。日本語の発音どおりに書ける → **女性** による文学が発達 |
| 和歌 | **『古今和歌集』**（**紀貫之** らが編集。天皇の命令でつくった最初の和歌集＝勅撰和歌集） |

| 住まい | **寝殿造**（中央の寝殿を中心に、庭・池をもつ貴族のやしき） |
| 絵画 | **大和絵**（日本の風景や人物をえがく。絵巻物にも） |

- 紫式部も清少納言も、天皇のきさきに仕えた女性。紫式部は道長の娘・**彰子** に、清少納言は **定子** に仕えた。

</div>

**史料を読もう**　清少納言『枕草子』の書き出し

<div class="ex" markdown="1">
春はあけぼの。やうやう白くなりゆく山ぎは、少しあかりて、紫だちたる雲の細くたなびきたる。
（現代語訳）春は明け方がいちばんいい。だんだん白くなっていく山のあたりの空が少し明るくなって、むらさきがかった雲が細く横に長く広がっているのがすてきだ。
</div>

- 漢字ではなく **かな** で、日本の **季節の美しさ** を自由に書いている → 国風文化らしさ。

**浄土信仰（浄土教）**
**なぜ広まった？** 地方の乱れや災害・疫病が続き、人々の不安が高まった。さらに、釈迦の教えがおとろえる **末法** の世が **1052年** に始まると信じられた。

- **何を信じた？** **阿弥陀仏**（阿弥陀如来）にすがり **念仏**（南無阿弥陀仏）をとなえれば、死後に **極楽浄土** に生まれ変われる。
- 10世紀、**空也** が都の市で念仏を広めた（「市聖」）。**源信** が『往生要集』で極楽へ行く方法を説いた。
- **どうなった？** 貴族たちは極楽浄土をこの世に再現しようと **阿弥陀堂** を建てた。

| 建物 | だれが | どこに | ポイント |
|---|---|---|---|
| **平等院鳳凰堂** | **藤原頼通**（1053年） | 京都府宇治市 | 10円硬貨の表のデザイン |
| **中尊寺金色堂** | **奥州藤原氏**（藤原清衡、1124年） | 岩手県 **平泉** | 金ぱくでおおわれた阿弥陀堂。浄土信仰が **地方** にも広がった証拠 |

<div class="memo" markdown="1">
**先生のひとこと**　国風文化は「**かな・寝殿造・大和絵・浄土信仰**」の4点セット。入試では、ほかの時代の文化とまぜて「平安時代の文化として正しいものを選べ」と出る。**『源氏物語』＝紫式部、『枕草子』＝清少納言**の組み合わせは絶対に逆にしないこと。
</div>

### 5　地方の乱れと武士の成長

**なぜ武士が生まれた？** 都の貴族が政治の実権を争っている間に、地方では **国司** が税を取り立てて私腹をこやし、治安が悪化した。そこで、地方の **豪族** や有力な農民が、自分の土地を守るために **武装** した。これが **武士** の始まり。

- 武士は一族や家来（**郎党**）を率いて **武士団** をつくった。
- やがて、**天皇の子孫** を棟梁（かしら）とする大きな武士団が生まれた。**源氏**（清和天皇の子孫）と **平氏**（桓武天皇の子孫）が二大勢力。
- 朝廷や貴族は、武士を **都の警備** や **反乱のしずめ** に使うようになった。

| 年 | 反乱・戦い | 場所 | 内容・結果 |
|---|---|---|---|
| 935〜940 | **平将門の乱** | **関東**（下総＝千葉県・茨城県あたり） | 将門が関東の国府を次々におそい「新皇」を名のる → 地方の武士に討たれる |
| 939〜941 | **藤原純友の乱** | **瀬戸内海** | 元国司の純友が海賊を率いて反乱 → 討たれる |
| 1051〜1062 | **前九年合戦** | **東北** | **源頼義・義家** の父子が東北の豪族をしずめる |
| 1083〜1087 | **後三年合戦** | **東北** | **源義家** が活躍 → 東国で源氏の名声が高まる。その後、東北では **奥州藤原氏**（平泉）が栄える |

- 2つの反乱（将門・純友）をしずめたのも **武士** だった → 朝廷は **武士の力なしでは地方をおさめられない** ことがはっきりした。<span class="deru">入試</span>

<div class="memo" markdown="1">
**神奈川とのつながり**　前九年合戦で活躍した **源頼義** は、1063年に **鎌倉の由比郷**（今の鎌倉市材木座のあたり）に **八幡宮をまつった**。これがのちに源頼朝が今の場所に移した **鶴岡八幡宮** のはじまり。また、相模国（神奈川県）には **三浦氏・大庭氏** などの武士団が育ち、源氏と結びついていった。鎌倉が「源氏ゆかりの地」になったのはこのころからなんだ。
</div>

### 6　院政 ― 天皇をやめたあとも政治を動かす

**なぜ？** 11世紀後半、藤原氏を母方の親せきにもたない **後三条天皇** が即位し、**荘園の整理**（1069年）を行うなど、天皇自ら政治を立て直そうとした。その子の **白河天皇** は、位をゆずって **上皇** になったあとも政治を続けた（**1086年**）。

- **院政**：**上皇**（位をゆずった天皇。住まいを「院」という）が中心となって行う政治。
- **どうなった？** 藤原氏（摂関家）の力はおとろえた。上皇には **荘園の寄進が集中** し、上皇は **武士**（北面の武士）を警備に用いた → 武士が **中央の政治** に近づく。
- 大寺院も荘園をもち、**僧兵** を使って朝廷に強い要求をした。白河上皇でさえ思いどおりにならないと言ったのが「**賀茂川の水、双六のさい（さいころ）、山法師（延暦寺の僧兵）**」。

### 7　保元・平治の乱と平氏の政権

<div class="point" markdown="1">
**POINT 4　武士が政治の主役になるまで**<span class="deru">入試</span>

| 年 | できごと | ポイント |
|---|---|---|
| **1156** | **保元の乱** | 天皇と上皇の対立、藤原氏の内部争いを、**源氏・平氏の武士の力** で解決 |
| **1159** | **平治の乱** | **平清盛** が **源義朝**（頼朝の父）をたおす。頼朝は伊豆に流される |
| **1167** | 平清盛が **太政大臣** になる | **武士として初めて** 朝廷の最高の位に |
| 1180 | 清盛の孫が **安徳天皇** として即位 | 清盛は娘・徳子を天皇のきさきにし、**外戚** となった（藤原氏と同じやり方！） |

</div>

**平清盛の政治と日宋貿易**

- 一族を朝廷の高い位につけ、**多くの荘園と知行国** を手に入れた。「平氏にあらずんば人にあらず」（平氏一門でなければ人ではない）と言われるほど栄えた。
- **日宋貿易**：**兵庫の港（大輪田泊）** を修築し、**瀬戸内海の航路** を整えて **宋** と貿易。航海の守り神として **厳島神社**（広島県）をあつく信仰した。<span class="deru">入試</span>
- 輸入品：**宋銭**（銅銭）・絹織物・陶磁器・書物　／　輸出品：金・硫黄・刀剣など
- **宋銭** が大量に入ってきて、日本でも貨幣（お金）が使われるようになっていった。

**どうなった？** 平氏が朝廷の政治をひとりじめし、藤原氏と同じく天皇の外戚となったため、**貴族・寺社・地方の武士の反感** を買った。1180年、源頼朝らが兵をあげる（→ 歴史5へ）。

<div class="memo" markdown="1">
**本質**　平清盛は「武士なのに **貴族のやり方**（外戚・高い位・荘園）で権力をにぎった」人物。新しい点は **日宋貿易で経済を動かした** こと。この「武士が貴族のまねをした」ことが反感を呼び、次の源頼朝は **都から離れた鎌倉で、武士のための政治** を始めることになる。
</div>
