# 中3公民 公民5「国会と内閣」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜中心テーマは「法律をつくる国会」と「それを実行する内閣」の関係。国会の地位／二院制と衆議院の優越の理由／国会の種類／法律ができるまで／内閣と議院内閣制／内閣不信任と解散／行政のしごとと行政改革・公務員</p>

## 要点まとめ

### 1　国会の地位 ―「国権の最高機関」で「唯一の立法機関」

<div class="point" markdown="1">
**POINT 1　憲法第41条**<span class="deru">入試</span>

「国会は、**国権の最高機関**であつて、国の**唯一の立法機関**である。」

| ことば | 意味 | なぜ？ |
|---|---|---|
| **国権の最高機関** | 国の政治の中心となる、最も重要な機関 | 主権者である**国民が選挙で直接選んだ代表者**でつくられているから |
| **唯一の立法機関** | **法律をつくれるのは国会だけ** | 国民の代表が話し合って決めたきまりだけが、国民をしばる「法律」になれるから |

</div>

- 憲法第43条①「両議院は、**全国民を代表する選挙された議員**でこれを組織する。」→ 国会議員は、自分の選挙区だけでなく**国民全体の代表**。
- 内閣が定める**政令**や、地方公共団体の**条例**もきまりだが、法律の範囲内で定めるもので、法律そのものではない。

<div class="memo" markdown="1">
**本質**　「最高機関」といっても、国会が内閣や裁判所に命令できるという意味ではない。日本は**三権分立**（公民6）なので、裁判所は国会がつくった法律を「憲法違反」と判断することもできる。「国民にいちばん近い機関だから、政治の中心」と理解しよう。
</div>

### 2　二院制と衆議院の優越

- 憲法第42条「国会は、**衆議院及び参議院**の両議院でこれを構成する。」＝**二院制（両院制）**。

<div class="cols2" markdown="1">

**二院制にしている理由**<span class="deru">入試</span>
- 2つの議院で話し合うことで、**慎重に審議**できる（1つの院の決定の行きすぎや、まちがいをおさえる）。
- 選ばれ方や任期がちがう議員がいるので、**国民のいろいろな意見**を反映できる。

**衆議院の優越がある理由**<span class="deru">入試</span>
- 衆議院は参議院より**任期が短く**（4年と6年）、**解散もある**。
- そのため選挙の回数が多く、**その時々の国民の意見（民意）をより強く反映している**と考えられるから。

</div>

| | 衆議院 | 参議院 |
|---|---|---|
| 議員定数・任期 | 465人・4年（**解散あり**） | 248人・6年（3年ごとに半数改選。**解散なし**） |
| 被選挙権 | 満25歳以上 | 満30歳以上 |

<div class="point" markdown="1">
**POINT 2　衆議院の優越**（衆議院と参議院の議決がちがうとき）<span class="deru">入試</span>

| 議決するもの | 衆議院の優越の内容 |
|---|---|
| **法律案の議決**（第59条） | 参議院が衆議院とちがう議決をした（または60日以内に議決しない）→ 衆議院が**出席議員の3分の2以上**の多数で**再可決**すれば法律になる |
| **予算の議決**（第60条） | 予算は**衆議院が先に審議**する（**予算の先議権**）。**両院協議会**でも意見が一致しない（または参議院が30日以内に議決しない）→ **衆議院の議決が国会の議決**になる |
| **条約の承認**（第61条） | 予算と同じ（両院協議会で不一致、または参議院が30日以内に議決しない → 衆議院の議決が国会の議決）。先議権はない |
| **内閣総理大臣の指名**（第67条） | 両院協議会で不一致（または参議院が10日以内に指名しない）→ **衆議院の議決が国会の議決** |
| **内閣不信任の決議**（第69条） | **衆議院だけ**ができる |

- **両院協議会**：衆議院と参議院の議決がちがうとき、両院の代表が意見を調整する会。予算・条約・総理大臣の指名では必ず開かれる。
- **憲法改正の発議**には衆議院の優越は**ない**（**各議院の総議員の3分の2以上**の賛成が必要。第96条）。

</div>

<div class="memo" markdown="1">
**先生のひとこと**　法律案だけは「**再可決（3分の2）**」、予算・条約・総理指名は「**衆議院の議決がそのまま国会の議決**」。法律案は国民の生活をしばるから、衆議院もハードルの高い3分の2が必要なんだ。日数は「**法60・予30・条30・指名10**」と覚えよう。
</div>

### 3　国会の種類

| 種類 | 召集されるとき | 会期・おもな仕事 |
|---|---|---|
| **常会**（通常国会） | **毎年1回、1月中**に召集 | 会期**150日**。おもに次の年度の**予算**を審議する |
| **臨時会**（臨時国会） | **内閣**が必要と認めたとき、または**いずれかの議院の総議員の4分の1以上**の要求があったとき | 補正予算や急ぎの議題 |
| **特別会**（特別国会） | **衆議院の解散による総選挙の日から30日以内** | **内閣総理大臣の指名**を最初に行う |
| **参議院の緊急集会** | **衆議院の解散中**に、緊急の必要があるとき（内閣が求める） | とった措置は、次の国会で**衆議院の同意**が必要 |

### 4　国会のしごと

<div class="cols2" markdown="1">

- **法律の制定**（立法）
- **予算の議決**
- **条約の承認**（条約を結ぶのは内閣）
- **内閣総理大臣の指名**
- **憲法改正の発議**

- **弾劾裁判所**の設置（ふさわしくない裁判官をやめさせるか判断する。両議院の議員で組織）
- **国政調査権**（証人をよんで質問する**証人喚問**などで、政治の実態を調べる。第62条）
- **内閣不信任の決議**（衆議院のみ）

</div>

- **委員会**：議員が少人数のグループに分かれて、法律案を**専門的にくわしく審査**するところ（予算委員会・外務委員会など）。必要に応じて、学者や関係者から意見を聞く**公聴会**を開く（予算の審議では必ず開く）。
- 法律案は**内閣**も**国会議員**も提出できる。成立する法律は、**内閣が提出したもの（内閣提出法案）が多い**。
- 公布＝成立した法律を国民に広く知らせること。

<div class="memo" markdown="1">
**先生のひとこと**　学校でいえば、**委員会**は「文化祭実行委員会」、**本会議**は「全校集会」。細かいことは委員会でじっくり話し合い、最後に全員の場で決める。だから国会は「**委員会中心**」で動いているんだ。
</div>

### 6　内閣と議院内閣制

- 憲法第65条「**行政権は、内閣に属する。**」 **行政**＝国会が決めた法律や予算にもとづいて、実際に政治を行うこと。
- 内閣は、**内閣総理大臣（首相）**と**国務大臣**で組織される。

| 項目 | 内容（日本国憲法） |
|---|---|
| **内閣総理大臣** | **国会議員**の中から**国会の議決で指名**し（第67条）、**天皇が任命**する（第6条） |
| **国務大臣** | 内閣総理大臣が任命・罷免する。**過半数は国会議員**でなければならない（第68条） |
| **文民** | 内閣総理大臣と国務大臣は**文民**（軍人でない人）でなければならない（第66条②） |
| **閣議** | 内閣の方針を決める会議。内閣総理大臣が開き、**全員一致**で決めるのが原則 |

<div class="point" markdown="1">
**POINT 3　議院内閣制**<span class="deru">入試</span>

- **内閣が、国会の信任にもとづいて成立し、国会に対して連帯して責任を負う**しくみ（第66条③「内閣は、行政権の行使について、国会に対し連帯して責任を負ふ。」）。
- なぜ？ → 国民が直接選んだのは国会議員だけ。**国民の代表である国会の信頼**があって、はじめて内閣は政治を行える（国民 → 国会 → 内閣という**信任の流れ**）。
- だから、国会で多数をしめる政党（**与党**）の党首が、ふつう内閣総理大臣になる。

| | **議院内閣制**（日本・イギリス） | **大統領制**（アメリカ） |
|---|---|---|
| 行政のトップの選び方 | **国会**が首相を指名 | **国民**が大統領を選ぶ（議会とは別の選挙） |
| 議会との関係 | 内閣は議会に責任を負う。不信任・解散がある | 大統領と議会は独立。大統領は議会を解散できない |

</div>

- 第70条：**衆議院議員総選挙の後に初めて国会が召集されたとき**（特別会）も、内閣は**総辞職**する。→ 新しい国会で、改めて総理大臣を指名し直す。
- 解散 → 総選挙は、「**内閣と衆議院の意見が対立したとき、どちらが正しいかを国民に判断してもらう**」しくみ。内閣不信任の可決がなくても、内閣は天皇の国事行為（第7条）への助言と承認によって解散を決めることができ、実際の解散はこの形が多い。

<div class="memo" markdown="1">
**本質**　国会（衆議院）は「内閣はダメだ！」と**不信任**をつきつけ、内閣は「では国民に聞いてみよう」と**解散**で対抗する。最後に決めるのは**選挙での国民の声**。どちらかが一方的に強くならない、つり合いのしくみなんだ。
</div>

### 8　内閣のしごと（第73条など）

<div class="cols2" markdown="1">

- **法律を執行**する（実行する）
- **予算を作成**して国会に提出する
- 外交関係を処理し、**条約を結ぶ**
- **政令**を定める
- 天皇の国事行為に**助言と承認**を与える

- **最高裁判所長官を指名**し、その他の裁判官を**任命**する
- **臨時会の召集**を決める
- 恩赦（刑を軽くすること）を決める
- 衆議院の解散を決める

</div>

### 9　行政のしごとと行政改革・公務員

- 内閣の下に、**1府12省庁**などの行政機関がある（2001年の**中央省庁再編**で整理された）。例：**内閣府**・総務省・法務省・外務省・**財務省**・文部科学省・**厚生労働省**・農林水産省・経済産業省・国土交通省・環境省・防衛省、国家公安委員会。そのほか復興庁・**デジタル庁**、内閣府の下のこども家庭庁などもある。
- **公務員**：国や地方公共団体で働く人。憲法第15条②「すべて公務員は、**全体の奉仕者**であつて、一部の奉仕者ではない。」
- **行政権の拡大**：社会が複雑になり、行政の仕事がふえた（「小さな政府」から「大きな政府」へ）。その結果、**許認可権**（営業などを許可する権限）をもつ役所の力が強くなりすぎた、**縦割り行政**のむだ、などの問題が出てきた。

| **行政改革**（行政の仕事をむだなく、効率的にする） | 例 |
|---|---|
| **規制緩和**：役所の許認可などのきまりを減らし、民間の自由な活動をうながす | 電力の小売自由化、コンビニでの一部の医薬品の販売 |
| **民営化**：国の事業を民間の会社にする | 国鉄 → **JR**（1987年）、日本郵政公社 → 日本郵政グループ（2007年） |
| **組織の整理** | 中央省庁再編（2001年）、独立行政法人の設立 |

<div class="memo" markdown="1">
**先生のひとこと**　規制緩和のメリットは、新しい会社が参入して**競争が起き、サービスがよくなる・値段が下がる**こと。でも、規制には安全を守る役割もあるから「全部なくせばよい」わけではない。入試の記述では「**効率**」と「**安全・公正**」の両方の視点を書けると強いよ。

**入試直前チェック**

- □ 国会は「国権の最高機関」で「唯一の立法機関」（第41条）。その理由を言える。

(1) **1**　内閣不信任が可決されたら「**10日以内**」に解散か総辞職。30日は特別会の召集（総選挙の日から30日以内）や、予算・条約で参議院が議決しない期間。
(2) （例）**2つの議院で審議することで慎重に話し合うことができ、また国民のいろいろな意見を反映できるから。**
(3) **2**　緊急集会は衆議院がいないときの臨時の措置なので、衆議院の同意が必要（第54条）。
