# 中2地理 地理14「中部地方」

<p class="lead">対象：中学2年 地理（小5から挑戦OK）｜東海・中央高地・北陸の3地域のちがい・日本アルプス・中京工業地帯と東海工業地域・扇状地の果樹と高原野菜・北陸の稲作と地場産業</p>

## 要点まとめ

### 1　中部地方のすがた ＝ 「3つの顔」をもつ地方

- 本州の**まん中**にある、**9県**の地方。日本海と太平洋の**両方**に面している。
- まん中に**3000m級の山々（日本アルプス）**がそびえるので、**気候も産業も**、山をはさんで大きくちがう。→ **3つの地域**に分けて考える。<span class="deru">入試</span>

| 地域 | ふくまれる県 | 気候 | ひとことで言うと |
|---|---|---|---|
| **東海** | **静岡県・愛知県**・岐阜県南部 | 太平洋側（夏に雨、冬は晴れて温暖） | **工業**の東海（自動車・楽器・オートバイ） |
| **中央高地** | **山梨県・長野県**・岐阜県北部 | 中央高地（内陸）の気候 | **果樹と高原野菜**の中央高地 |
| **北陸** | **新潟県・富山県・石川県・福井県** | 日本海側（冬に雪が多い） | **米と地場産業**の北陸 |

### 2　自然 ── 「日本の屋根」日本アルプス

<div class="cols2" markdown="1">

| 山地・山脈 | ポイント |
|---|---|
| **飛騨山脈**（北アルプス） | 富山・長野・岐阜の県境 |
| **木曽山脈**（中央アルプス） | 長野県の中 |
| **赤石山脈**（南アルプス） | 長野・山梨・静岡の県境 |
| **富士山** | 日本最高峰（3776m）。世界文化遺産 |

- 3つの山脈をまとめて **日本アルプス**（「**日本の屋根**」）。北から **飛騨・木曽・赤石**（「ひ・き・あ」）。<span class="deru">入試</span>
- 日本アルプスの東には、本州を横切る大きなみぞ **フォッサマグナ** がある。

| 川・平野・盆地 | ポイント |
|---|---|
| **信濃川** | **日本最長**の川。長野県では千曲川 |
| **越後平野** | 信濃川の下流。日本有数の米どころ |
| **濃尾平野** | **木曽川・長良川・揖斐川**（木曽三川）の下流 |
| **甲府盆地・長野盆地** | 扇状地が広がる。果樹 |

<div class="point" markdown="1">
**扇状地＝果樹**の理由<span class="deru">入試</span>

- **扇状地**：川が山地から平地に出るところに、**つぶの大きい砂や小石**が積もってできた扇形の土地。
- **扇央**は水はけがよく水を得にくい → 水田には向かないが、**果樹**には向いている（昔は**桑畑**＝かいこのえさ）。
- **甲府盆地**（山梨）：**ぶどう・もも**。昼と夜の気温差が大きく、雨が少ない → **あまい果物**が育つ。観光農園・ワインも。
- **長野盆地**など：**りんご**（すずしい気候）。

</div>

<div class="point" markdown="1">
**高原野菜と抑制栽培**<span class="deru">入試</span>

- **八ヶ岳のふもと（野辺山原）**など標高1000m以上の高原は、**夏でもすずしい**。
- そこで**レタス・キャベツ・はくさい**などを育て、ほかの産地では暑くて作りにくい**夏に出荷**する ＝ **抑制栽培**（出荷時期を**おくらせる**）。
- ほかの産地のものが少ない時期 → **高い値段**で売れる。保冷トラックで高速道路を使い東京などへ。

</div>


- **工業の移り変わり**（諏訪盆地・岡谷市など）：<span class="deru">入試</span>
　明治〜昭和初め：**製糸業**（かいこのまゆから生糸）→ 第二次世界大戦後：きれいな空気と水を生かした**精密機械**（時計・カメラ）→ 現在：**電子部品**・プリンターなど。高速道路沿いに工場が進出。
- **観光**：上高地・軽井沢（避暑地）、スキー場、温泉。白川郷・五箇山の**合掌造り**（大雪に耐える急な屋根）。

### 5　北陸 ── 雪どけ水の米どころと、冬に生まれた地場産業

<div class="point" markdown="1">
**北陸の稲作**<span class="deru">入試</span>

- **越後平野**（新潟）・**富山平野**・**金沢平野**・**福井平野**など。春の**豊富な雪どけ水**が田をうるおす。
- 冬は雪で田畑が使えない → 1年に1回、米だけを作る**水田単作地帯**。
- 新潟県は米の収穫量が全国1位。「**コシヒカリ**」などの**銘柄米（ブランド米）**。
- 越後平野はかつて水はけの悪い低湿地 → **排水路**などを整え、**乾田**（かわいた田）にかえて米どころに。

</div>

<div class="point" markdown="1">
**地場産業と伝統産業 ── 「冬の副業」から始まった**<span class="deru">入試</span>

| 種類 | 産物（県・市） |
|---|---|
| **地場産業**（地元の資源や技術を生かし、地域と結びついて発達した産業） | **めがねフレーム**（福井県**鯖江市**）、**洋食器**（新潟県**燕市**）、金物（新潟県三条市）、売薬（富山） |
| **伝統産業・伝統的工芸品** | **輪島塗**（石川県輪島市）、**加賀友禅**・**九谷焼**（石川）、**越前和紙**（福井）、**高岡銅器**（富山）、小千谷ちぢみ（新潟） |

- なぜ北陸でさかん？ → 冬は**雪で農作業ができない** → 家の中でできる**副業**として発達した。

</div>

- **富山県**：黒部川など急流の川 → **水力発電**（黒部ダム）→ 電気をたくさん使う**アルミニウム**工業。
- **富山県**の砺波平野：**チューリップの球根**（水田の裏作として）。
- **福井県**の若狭湾沿い：**原子力発電所**が多い（電気は近畿地方へ）。

<div class="memo" markdown="1">
**先生のひとこと**　北陸は「**冬にできないことを、冬にできることへ変えた**」地域。雪で外に出られない → 家で漆をぬる、金属をみがく。雪どけ水 → 米。急な川 → 電気 → アルミ。**自然→産業**のつながりで覚えると、記述問題でそのまま使えるよ。
</div>
