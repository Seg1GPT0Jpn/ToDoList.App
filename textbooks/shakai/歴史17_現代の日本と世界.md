# 中3歴史 歴史17「高度経済成長と現代の日本・世界」

<p class="lead">対象：中学3年 歴史（小5から挑戦OK）｜高度経済成長と公害・石油危機・沖縄返還と近隣諸国との国交・冷戦の終結・バブル経済・グローバル化と現代の課題・<b>歴史分野の総まとめ</b></p>

## 要点まとめ

<div class="memo" markdown="1">
**先生のひとこと**　いよいよ歴史の最終回。戦後の日本は「**急成長（高度経済成長）→ ブレーキ（石油危機）→ 大きくふくらんで破裂（バブル）→ 長い不況とグローバル化**」という、ジェットコースターのような道を進んだ。後半では**歴史全体を1枚の地図のように見わたす**「総まとめ」もやるよ。

### 2　公害 ── 成長の「かげ」

- 企業が利益を優先し、工場の廃水やけむりの対策をおこたった → 各地で**公害**。とくに**四大公害病**は裁判になり、いずれも**住民（患者）側が勝訴**した。<span class="deru">入試</span>

| 公害病 | 場所 | 原因 |
|---|---|---|
| **水俣病** | **熊本県・鹿児島県**（八代海沿岸） | 工場廃水の中の**有機水銀**（メチル水銀） |
| **新潟水俣病** | **新潟県**（**阿賀野川**流域） | 工場廃水の中の**有機水銀** |
| **イタイイタイ病** | **富山県**（**神通川**流域） | 鉱山から流れ出た**カドミウム** |
| **四日市ぜんそく** | **三重県**（四日市市） | 石油化学コンビナートのけむりの**亜硫酸ガス**（大気汚染） |

- 対策：**1967年 公害対策基本法** → **1971年 環境庁**（今の環境省）→ 1993年 環境基本法。

<div class="memo" markdown="1">
**本質**　「水・川」の公害病は、川の名前とセットで覚える（阿賀野川・神通川）。四日市ぜんそくだけが**空気（大気汚染）**。「**水・水・水・空気**」と覚えておくと、選択問題で一発で見分けられる。
</div>

### 3　石油危機（オイル・ショック）と安定成長

- **なぜ**：**1973年**、**第四次中東戦争**をきっかけに、アラブの産油国が石油の値段を大はばに引き上げ、輸出を制限した。
- **何が**：石油を輸入にたよる日本は大打撃。物価が急上昇し、トイレットペーパーの買いだめさわぎも起きた。**1974年**、戦後はじめて**マイナス成長** → **高度経済成長が終わった**。<span class="deru">入試</span>
- **どうなった**：省エネルギーの技術開発、**自動車・電気機械（家電・半導体）** などの輸出がのびて**安定成長**へ。輸出が多すぎて、アメリカなどとの間で**貿易摩擦**が起きた。（1979年に第二次石油危機）

### 4　日本の外交と沖縄返還

| 年 | 条約など | 相手・首相 | ポイント |
|---|---|---|---|
| **1965年** | **日韓基本条約** | 韓国（佐藤栄作） | 韓国を朝鮮半島の**唯一の合法的な政府**と認めて国交正常化 |
| **1972年** | **沖縄返還** | アメリカ（佐藤栄作） | 沖縄が日本に復帰。ただし**アメリカ軍基地は多く残った**（今も日本の米軍専用施設の面積の約7割が沖縄に）<span class="deru">入試</span> |
| **1972年** | **日中共同声明** | 中国（**田中角栄**） | 中華人民共和国と**国交正常化** |
| **1978年** | **日中平和友好条約** | 中国（福田赳夫） | 両国の関係をさらに深める |

- **非核三原則**：核兵器を「**持たず、つくらず、持ちこませず**」。沖縄返還のころに国の方針になった（佐藤栄作はのちにノーベル平和賞）。
- そのほか：小笠原諸島の返還（1968年）。朝鮮民主主義人民共和国（北朝鮮）とは、今も国交がない（2002年に初の日朝首脳会談、拉致問題）。
- 世界では**ベトナム戦争**（1965年ごろアメリカが本格介入〜1975年）。反戦運動が世界に広がった。

### 5　冷戦の終結とその後の世界

| 年 | できごと |
|---|---|
| 1985年 | ソ連で**ゴルバチョフ**が指導者になり、改革を進める |
| **1989年** | 東ヨーロッパで民主化が進み、**ベルリンの壁が崩壊**。米ソ首脳が**マルタ会談**で**冷戦の終結**を宣言 <span class="deru">入試</span> |
| **1990年** | **東西ドイツが統一** |
| 1991年 | **湾岸戦争**（イラクのクウェート侵攻に多国籍軍が攻撃）。**ソ連が解体**（ロシアなどの国々に分かれる） |
| 1992年 | **PKO協力法** → 自衛隊がカンボジアで国連の**平和維持活動（PKO）**に参加 |
| 1993年 | **ヨーロッパ連合（EU）** 発足 |
| 2001年 | アメリカで**同時多発テロ** → アフガニスタン攻撃、2003年にイラク戦争 |

<div class="memo" markdown="1">
**本質**　冷戦が終わっても世界は平和にならなかった。米ソのにらみ合いでおさえられていた**民族・宗教の対立**が表に出て、**地域紛争**や**テロ**が増えた。だから冷戦後は「国どうしの戦争」より「**地域紛争・難民・テロ**」が大きな課題になったんだ。
</div>

### 6　バブル経済と平成の日本

- **1980年代後半**：円高のなかで金利が下がり、あまったお金が**株式と土地**に流れこんで、値段が実際の価値以上にふくらんだ ＝ **バブル経済**。
- **1991年ごろ** バブルが崩壊 → 銀行や企業の経営が悪化し、長い不況（**平成不況**）へ。
- **1993年**、非自民の連立内閣（細川護熙）が成立し、**55年体制が終わった**。
- **1995年** 阪神・淡路大震災、**2008年** 世界金融危機、**2011年** 東日本大震災（福島第一原子力発電所の事故）。

### 7　グローバル化と現代の課題

- **グローバル化**：人・もの・お金・情報が国境をこえて地球規模で行き来する。インターネットの普及（**情報化**）がそれを加速。
- 課題：**少子高齢化**と人口減少／**地球温暖化**（1997年 **京都議定書**、2015年 **パリ協定**）／2015年に国連で **SDGs（持続可能な開発目標）**／地域紛争と難民／**核兵器**の問題。

- 高度経済成長：**1955年ごろ〜1973年**。1964年 **東京オリンピック**・新幹線、1968年 **GNP 第2位**。三種の神器 → 3C。
