# 中2地理 地理12「中国・四国地方」

<p class="lead">対象：中学2年 地理（小5から挑戦OK）｜中心テーマは「交通・人口」。山陰・瀬戸内・南四国の気候のちがいとその理由／瀬戸内工業地域と石油化学コンビナート／本州四国連絡橋と交通の変化（ストロー現象）／過疎と町おこし／高知平野の促成栽培・愛媛のみかん</p>

## 要点まとめ

### 0　中国・四国地方の見取り図（9つの県）

- **中国地方**（5県）と**四国地方**（4県）。間に**瀬戸内海**があり、小さな島がたくさん浮かぶ。
- 地域を北から3つに分けて考える：**山陰**（中国山地より北、日本海側）／**瀬戸内**（瀬戸内海の沿岸）／**南四国**（四国山地より南、太平洋側）。
- 地方の中心は **広島市**（地方中枢都市・政令指定都市）。**岡山市**も政令指定都市。

| 県 | 県庁所在地 | 主な産物・キーワード |
|---|---|---|
| **鳥取県** | 鳥取市 | **鳥取砂丘**、日本なし（二十世紀なし）、らっきょう、境港（水あげ量が多い） |
| **島根県** | **松江市** | **宍道湖のしじみ**、**石見銀山**（世界文化遺産）、出雲大社、過疎が早くから進んだ |
| **岡山県** | 岡山市 | **水島地区（倉敷市）の石油化学コンビナート**・製鉄、もも・ぶどう（マスカット）、学生服・ジーンズ |
| **広島県** | 広島市 | **かきの養殖**（全国1位）、**自動車**、原爆ドーム・厳島神社（世界文化遺産）、レモン |
| **山口県** | 山口市 | **周南市**などの石油化学コンビナート、セメント（秋吉台の石灰石）、ふぐ（下関） |
| **徳島県** | 徳島市 | すだち、にんじん、阿波おどり、**明石海峡大橋・大鳴門橋**で神戸と結ばれる |
| **香川県** | **高松市** | **ため池**、**香川用水**、讃岐うどん、小豆島のオリーブ、**瀬戸大橋**で岡山と結ばれる |
| **愛媛県** | **松山市** | **みかん**など**かんきつ類**、**宇和海の真珠・まだいの養殖**、今治市のタオル・造船 |
| **高知県** | 高知市 | **高知平野の促成栽培（なす・ピーマン）**、かつお、ゆず |

<div class="point" markdown="1">
**POINT 1　気候のちがいは「季節風」と「山地」で説明する**<span class="deru">入試</span>

| 地域 | 気候の特色 | 理由 | くらし・産業への影響 |
|---|---|---|---|
| **山陰** | **冬に雪や雨が多い**（日本海側の気候） | **北西の季節風**が日本海で水蒸気をふくみ、**中国山地**にぶつかる | 冬の雪に備える。日本なしなど |
| **瀬戸内** | **1年を通して降水量が少ない**・温暖 | 冬は**中国山地**、夏は**四国山地**が季節風をさえぎる | **水不足** → **ため池**・**香川用水**。晴れが多く**塩田**（昔）、みかん |
| **南四国** | **夏に雨がとても多い**・冬も温暖 | **南東の季節風**と**台風**。沖を**黒潮**が流れる | 冬の温暖さを生かした**促成栽培** |

</div>

<div class="point" markdown="1">
**POINT 2　水不足とのたたかい（香川県）**

- 香川県（讃岐平野）は大きな川がなく雨も少ない → 昔から**ため池**をたくさんつくった（満濃池など）。
- 1970年代に、四国山地の南を流れる**吉野川**から讃岐山脈の下をトンネルでくぐって水を引く **香川用水** が完成。
- それでも雨が少ない年は**給水制限**が行われることがある。

</div>

### 2　瀬戸内工業地域 ― 海を使った重化学工業

- 瀬戸内海の沿岸には、**塩田のあと地**や**埋め立て地**など、広い工業用地があった。
- 瀬戸内海は波がおだやかで、大きな船で**原料（原油・鉄鉱石）を運びこみ、製品を運び出す**のに便利。
- → 1960年代から、**石油化学コンビナート**や**製鉄所**が次々に建てられ、**瀬戸内工業地域**が発達した。

<div class="point" markdown="1">
**POINT 3　石油化学コンビナートとは？**<span class="deru">入試</span>

- 石油精製工場・石油化学工場・発電所などを**パイプラインで結んだ工場の集まり**。原油からガソリン・ナフサをつくり、そこからプラスチックや合成ゴム・化学せんいの原料をつくる。
- **コンビナート**＝「結合」という意味。となりの工場の製品が次の工場の原料になるので、ムダが少ない。

| 主な場所 | 県 | 工業 |
|---|---|---|
| **水島地区**（倉敷市） | 岡山県 | **石油化学**・**鉄鋼**・自動車 |
| **周南市**・岩国市 | 山口県 | **石油化学** |
| 福山市 | 広島県 | **鉄鋼** |
| 広島市・府中町 | 広島県 | **自動車** |
| 呉市・今治市・坂出市 | 広島・愛媛・香川 | **造船** |
| 新居浜市 | 愛媛県 | 化学（もとは別子銅山の関連工業） |

- 瀬戸内工業地域は、ほかの工業地帯・地域と比べて**化学工業の割合が高い**のが特徴（工業出荷額の構成グラフで見分ける）。<span class="deru">入試</span>

</div>

<div class="memo" markdown="1">
**本質**　原油も鉄鉱石も、ほとんどを**船で輸入**する。だから重化学工業の工場は「**港のすぐそば**」がいちばん。瀬戸内海は「波がおだやかな、大きな港」のようなもの。これが瀬戸内工業地域が発達した最大の理由。
</div>

<div class="point" markdown="1">
**POINT 4　橋ができて何が変わった？（よい点と課題）**<span class="deru">入試</span>

| よい点 | 課題 |
|---|---|
| 本州と四国の移動時間が**短縮**。天候で欠航しやすいフェリーにたよらなくてよい | **フェリーや高速船の便が減ったり、廃止されたり**した → 島の人や車のない人が不便に |
| 四国から大阪・神戸などへ**通勤・通学・買い物**ができる | 買い物客などが大都市に**吸い寄せられ**、地元の商店街の客が減る（**ストロー現象**） |
| 農産物・水産物を新鮮なまま**大都市へ出荷**しやすい | 通行料金が高いという声 |
| **観光客**が増えた（しまなみ海道のサイクリングなど） | |

</div>

<div class="memo" markdown="1">
**先生のひとこと**　**ストロー現象**は、ジュースをストローで吸うと、コップの中身が**口のほう（大都市）に全部吸われてしまう**イメージ。交通が便利になると、便利になったはずの地方から、人やお金が大都市に流れ出てしまうことがある。新幹線や高速道路でも起こるよ。
</div>

- 中国地方には**中国自動車道**・**山陽自動車道**、新幹線（山陽新幹線）が通り、瀬戸内側の都市が帯のようにつながる。山陰側は交通の整備がおくれてきた。

### 4　過疎と町おこし（地域おこし）

- **過疎**：人口が大きく減り、地域の生活（学校・病院・バス・商店）を続けるのが難しくなること。逆に人が集まりすぎるのが**過密**。<span class="deru">入試</span>
- 中国・四国地方では、**中国山地・四国山地の山間部**や**離島**で過疎が進んでいる。若い人が仕事を求めて都市へ出ていき、**高齢化**も進む。
- 65歳以上の人が半分以上になり、地域の共同作業などが難しくなった集落を「**限界集落**」とよぶことがある。

<div class="point" markdown="1">
**POINT 5　町おこし（地域おこし）の例**<span class="deru">入試</span>

| 地域 | 取り組み |
|---|---|
| **徳島県上勝町** | 料理にそえる**葉っぱ（つまもの）**を、高齢者が中心になって出荷。パソコンやタブレットで注文を確認 |
| 徳島県神山町 | 高速通信網を整え、都市の企業の**サテライトオフィス**を呼びこむ |
| 島根県（離島の町など） | **Iターン**（都会の人の移住）を受け入れ、特産品づくり |
| 高知県（山間の村など） | **ゆず**を加工してジュースやポン酢にし、全国に通信販売 |

- 生産（第一次産業）＋加工（第二次産業）＋販売・観光（第三次産業）を地域でまとめて行い、もうけを増やす取り組みを **6次産業化** という（1×2×3＝6）。
- 都市から地方への移住：**Uターン**（出身地にもどる）、**Iターン**（出身地以外の地方へ）、**Jターン**（出身地に近い地方都市へ）。

</div>

### 5　南四国と瀬戸内の農業・漁業

<div class="point" markdown="1">
**POINT 6　高知平野の促成栽培**<span class="deru">入試</span>

- 高知平野は**黒潮**の影響で**冬でも温暖**、日照時間も長い。
- **ビニールハウス**で**なす・ピーマン**などを育て、ほかの産地の出荷が少ない**冬〜春**に出荷 → 高い値段で売れる（**促成栽培**）。高知県の**なす**は全国有数。
- 以前はフェリー、今は**高速道路**や本州四国連絡橋を使い、**保冷トラック**で京阪神や東京へ運ぶ。

</div>

- **愛媛県のみかん**：日当たりと水はけのよい**山の斜面**（段々畑）で栽培。みかんの収穫量は **和歌山県・愛媛県・静岡県** が上位。いよかんなど、多くの種類のかんきつ類をつくる。
- **養殖業**：**広島湾のかき**（広島県は全国1位）、**宇和海（愛媛県）のまだい・真珠**。リアス海岸の入り江は波がおだやかで養殖に向く。
- **鳥取県**の日本なし、**岡山県**のもも・マスカット（ぶどう）も有名。鳥取砂丘ではかんがい設備を整えて、らっきょう・ながいもなどを栽培。

<div class="memo" markdown="1">
**本質**　九州の宮崎平野と高知平野は、**同じ理屈（黒潮→冬に温暖→促成栽培）**。地方ごとにバラバラに覚えるより「この自然条件なら、この産業」という**型**で覚えると、入試で初めて見る地域の問題でも解ける。
</div>
