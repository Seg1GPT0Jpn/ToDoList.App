# 中3公民 公民6「裁判所と三権分立」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜中心テーマは「権力から国民の自由と権利を守るしくみ」。司法権の独立／三審制／民事裁判と刑事裁判／被告人の権利／裁判員制度／違憲審査権と憲法の番人／三権分立と相互の抑制</p>

## 要点まとめ

### 1　司法と裁判所

- **司法**：争いごとや犯罪について、**法にもとづいて判断し、解決する**こと。司法を行う権限を**司法権**という。
- 憲法第76条①「すべて司法権は、**最高裁判所**及び法律の定めるところにより設置する**下級裁判所**に属する。」

| 裁判所 | 数 | おもな役割 |
|---|---|---|
| **最高裁判所** | 1か所（東京） | 最終の裁判所（**終審裁判所**）。長官と14人の裁判官の計**15人** |
| **高等裁判所** | 8か所 | おもに第二審。札幌・仙台・東京・名古屋・大阪・広島・高松・福岡 |
| **地方裁判所** | 50か所 | 多くの裁判の第一審。各都府県に1か所、北海道に4か所 |
| **家庭裁判所** | 50か所 | 家庭内の争い（離婚・相続など）や、**少年事件**をあつかう |
| **簡易裁判所** | 438か所 | 少ない金額の民事裁判や、軽い罪の刑事裁判 |

（高等〜簡易裁判所が**下級裁判所**）

### 2　司法権の独立

<div class="point" markdown="1">
**POINT 1　司法権の独立**<span class="deru">入試</span>

- 憲法第76条③「すべて**裁判官は、その良心に従ひ独立してその職権を行ひ、この憲法及び法律にのみ拘束される。**」
- 裁判所は、**国会や内閣など、ほかの権力から干渉を受けない**。裁判官は自分の良心と、憲法・法律だけにもとづいて判断する。
- なぜ？ → **公正な裁判**を行い、**国民の権利を守る**ため。もし政府が「この人を有罪にせよ」と命令できたら、政府に都合の悪い人が不当に罰せられてしまう。
- 裁判官の**身分保障**：裁判官は、次の場合以外はやめさせられない（第78条）。
　① 心身の故障で職務ができないと裁判で決定されたとき　② 国会の**弾劾裁判**でやめさせると判断されたとき　③ 最高裁判所の裁判官は、**国民審査**で、やめさせるべきだとする票が多数のとき

</div>

<div class="memo" markdown="1">
**発展**　**大津事件**（1891年）：来日中のロシア皇太子が、警備の巡査に切りつけられた。ロシアをおそれた政府は「死刑にせよ」と圧力をかけたが、大審院長の**児島惟謙**は「法律どおりに裁くべきだ」として、当時の法律にしたがって無期徒刑の判決にみちびいた。**司法権の独立**を守った例として有名（歴史の単元ともつながる）。
</div>

<div class="point" markdown="1">
**POINT 2　三審制**<span class="deru">入試</span>

- 1つの事件について、**3回まで**裁判を受けられるしくみ。
- 第一審の判決に不服 → 第二審の裁判所へ訴える＝**控訴**。第二審の判決に不服 → 第三審の裁判所へ訴える＝**上告**。
- なぜ？ → 裁判官も人間なので、まちがえることがある。**慎重に裁判を行い、まちがった判決（誤判）を防いで、人権を守る**ため。
- **再審**：判決が確定したあとでも、**新しい証拠**が見つかるなどして判決に疑いが出たとき、裁判をやり直すこと。無実の人が罰せられる**えん罪**を救うしくみ。死刑判決が確定していた人が、再審で**無罪**になった例もある。

</div>

### 4　民事裁判と刑事裁判

| | **民事裁判** | **刑事裁判** |
|---|---|---|
| あつかうもの | **個人や企業の間の争い**（お金の貸し借り、土地の境界、離婚、事故の損害賠償など） | **犯罪**（盗み・傷害・殺人など）。有罪か無罪か、どんな刑罰にするかを決める |
| 訴える人 | 訴えた人＝**原告** | **検察官**（犯罪の疑いのある人を裁判所に**起訴**する） |
| 訴えられた人 | **被告** | **被告人**（起訴される前は「被疑者」） |
| 特ちょう | 裁判の途中で、話し合いで解決する**和解**もある | **弁護人**（弁護士）が被告人の権利を守る |

- **行政裁判**：国や地方公共団体の行為（処分など）を国民がうったえる裁判。**民事裁判の一種**。
- 刑事裁判で「被告人」、民事裁判で「被告」と**呼び方がちがう**ことに注意。<span class="deru">入試</span>

### 5　刑事裁判と被告人の権利

- 刑事手続きでは、国（警察・検察）が強い力で人の自由をうばうので、**まちがいや行きすぎがないよう、憲法がくわしく権利を定めている**。

| 権利 | 日本国憲法 |
|---|---|
| **法定手続きの保障** | 第31条「何人も、法律の定める手続によらなければ、その生命若しくは自由を奪はれ、又はその他の刑罰を科せられない。」 |
| **令状主義** | 第33条：現行犯の場合を除き、裁判官が出す**令状**がなければ**逮捕されない**（捜索なども同じ。第35条） |
| **拷問の禁止** | 第36条「公務員による拷問及び残虐な刑罰は、絶対にこれを禁ずる。」 |
| **公開裁判・弁護人** | 第37条：**公平な裁判所の迅速な公開裁判**を受ける権利。**弁護人**をたのむ権利（自分でたのめないときは**国が付ける**＝国選弁護人） |
| **黙秘権** | 第38条①「何人も、**自己に不利益な供述を強要されない**。」　③ 本人の**自白しか証拠がない**ときは、有罪とされない |

- **推定無罪**：有罪の判決が確定するまでは、被告人は**無罪と推定**される。「**疑わしきは被告人の利益に**」（証拠が不十分なら無罪）。
- **えん罪**を防ぐため、取り調べの様子を録音・録画する**取り調べの可視化**が一部の事件で行われている。

<div class="memo" markdown="1">
**本質**　なぜ「悪いことをしたかもしれない人」にこんなに権利があるの？　それは、**つかまった人が本当に犯人とは限らない**から。もし自分が無実なのに疑われたら……と考えると、これらの権利は**すべての国民を守るためのもの**だとわかるね。
</div>

### 6　裁判員制度と司法制度改革

<div class="point" markdown="1">
**POINT 3　裁判員制度（2009年開始）**<span class="deru">入試</span>

- **国民が刑事裁判に参加**し、裁判官といっしょに**有罪か無罪か**、有罪なら**どんな刑罰にするか（量刑）**を決める制度。
- 対象：殺人・強盗致死傷などの**重大な刑事事件**の**第一審**（**地方裁判所**）。民事裁判は対象外。
- 構成：原則、**裁判官3人＋裁判員6人**。裁判員は**満18歳以上**の有権者から**くじ**で選ばれる。
- 評決：**過半数**で決める。ただし有罪とするには、その中に**裁判官と裁判員がそれぞれ1人以上**ふくまれていなければならない。
- 裁判員には、話し合いの内容などを外にもらさない**守秘義務**がある。
- 目的（なぜ？）：**国民の感覚や視点を裁判に反映**させ、司法への**理解と信頼**を深めるため。

</div>

- **司法制度改革**（裁判を国民にとって利用しやすく、わかりやすくする）
　**法テラス**（日本司法支援センター）：法律の相談先の案内や、費用の立てかえなど。
　**被害者参加制度**：犯罪の被害者や家族が、刑事裁判に参加して被告人に質問などができる。
　**検察審査会**：検察官が起訴しなかったことのよしあしを、くじで選ばれた国民が審査する。2回続けて「起訴すべき」と議決すると、強制的に起訴される。

### 7　違憲審査権と「憲法の番人」

<div class="point" markdown="1">
**POINT 4　違憲審査権（違憲立法審査権）**<span class="deru">入試</span>

- 第81条「最高裁判所は、一切の法律、命令、規則又は処分が**憲法に適合するかしないかを決定する権限**を有する**終審裁判所**である。」
- 違憲審査権は**すべての裁判所**がもつ。ただし最終的に決めるのは**最高裁判所** → **憲法の番人**とよばれる。
- 第98条①：憲法は国の**最高法規**で、憲法に反する法律などは**効力をもたない**。
- 裁判所は、実際の裁判（具体的な事件）を通して違憲かどうかを判断する。

</div>

| 年 | 最高裁判所が憲法違反とした法律の規定（おもな例） | 関係する権利 |
|---|---|---|
| 1973 | 刑法の**尊属殺人**（親などを殺したとき）の重い刑罰 | 法の下の平等 |
| 1975 | 薬事法の、薬局どうしの**距離制限** | 職業選択の自由 |
| 1976・1985 | 衆議院議員選挙の**議員定数の配分**（一票の格差） | 法の下の平等（選挙権の平等） |
| 2005 | 海外に住む日本人の選挙権の制限 | 選挙権 |
| 2008 | **国籍法**の、日本国籍の取得の条件 | 法の下の平等 |
| 2013 | 民法の、結婚していない両親の子の**相続分** | 法の下の平等 |
| 2015 | 民法の、**女性の再婚禁止期間**（100日をこえる部分） | 法の下の平等・両性の平等 |

<div class="memo" markdown="1">
**先生のひとこと**　国会は「多数決」で法律をつくる。でも多数決でも、少数の人の人権をうばう法律をつくってしまうことがある。それをストップするのが裁判所。公民4で学んだ「**多数決でも人権はうばえない**」を、しくみとして守っているのが違憲審査権なんだ。
</div>

<div class="point" markdown="1">
**POINT 5　三権分立（権力分立）**<span class="deru">入試</span>

- 国の権力を**立法権（国会）・行政権（内閣）・司法権（裁判所）**の3つに分け、**たがいに抑制し合い、均衡を保つ**（チェック・アンド・バランス）しくみ。
- 18世紀のフランスの思想家**モンテスキュー**が、著書『**法の精神**』で主張した。
- なぜ？ → 権力が1つの機関に集中すると、**権力が乱用され、国民の自由や権利がおびやかされる**から。権力を分けて、おたがいに見張らせることで、**国民の自由と権利を守る**。

| どこから → どこへ | はたらき |
|---|---|
| 国会 → 内閣 | **内閣総理大臣の指名**、**内閣不信任の決議**（衆議院） |
| 内閣 → 国会 | **衆議院の解散**、国会（臨時会など）の召集 |
| 国会 → 裁判所 | **弾劾裁判**（裁判官をやめさせるかどうかの裁判） |
| 裁判所 → 国会 | **法律の違憲審査** |
| 内閣 → 裁判所 | **最高裁判所長官の指名**、その他の裁判官の**任命** |
| 裁判所 → 内閣 | 命令・規則・処分の**違憲・違法審査**（行政裁判） |
| 国民 → 国会／内閣／裁判所 | **選挙**／**世論**／**国民審査** |

</div>

<div class="memo" markdown="1">
**先生のひとこと**　三権分立は「**じゃんけん**」に近い。グー・チョキ・パーのどれも、ほかのどれかに負ける可能性がある。だから誰も最強になれない。矢印は「**指名・任命する**」「**やめさせる・解散させる**」「**違憲かを判断する**」の3種類で整理すると覚えやすいよ。
</div>

<div class="point" markdown="1">
**入試直前チェック**

- □ 司法権の独立（第76条③）と、その理由（公正な裁判・権利を守る）を説明できる。
- □ 裁判官がやめさせられる3つの場合（心身の故障・弾劾裁判・国民審査）を言える。
- □ 三審制：控訴・上告。理由は「慎重に裁判し、誤判を防いで人権を守るため」。再審とえん罪。
- □ 民事裁判（原告・被告・和解）と刑事裁判（検察官・被告人・弁護人）を区別できる。行政裁判は民事の一種。
- □ 令状主義・黙秘権・弁護人を依頼する権利・推定無罪の意味を言える。
- □ 裁判員制度：2009年開始、重大な刑事事件の第一審（地方裁判所）、裁判官3人＋裁判員6人、18歳以上。
- □ 違憲審査権はすべての裁判所がもち、最終決定は最高裁判所（憲法の番人）。
- □ 三権分立の図の矢印6本と、国民からの3本を書ける。モンテスキュー『法の精神』。
