# 中3公民 公民4「民主政治・選挙と政党」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜中心テーマは「国民の意見を、どうやって政治に届けるか」。直接民主制と間接民主制／多数決と少数意見の尊重／選挙の4原則／小選挙区制・比例代表制とドント式／一票の格差／政党・与党と野党・連立政権／世論とメディアリテラシー</p>

## 要点まとめ

### 1　民主政治とは ― 「みんなで決める」政治

- **政治**：社会の中の対立をととのえ、みんなが従うきまりや方針を決めること。
- **民主主義（民主政治）**：国民（人民）が主役になって、話し合いで物事を決める政治。反対は、一人や少数の人が勝手に決める**専制政治（独裁政治）**。
- アメリカの**リンカン**大統領のことば「**人民の、人民による、人民のための政治**」は、民主主義の考え方を表す（1863年、ゲティスバーグでの演説）。<span class="deru">入試</span>

| | **直接民主制** | **間接民主制**（議会制民主主義・代議制） |
|---|---|---|
| しくみ | 国民（住民）が**直接**話し合い、決める | 国民が選挙で**代表者**を選び、代表者が**議会**で話し合って決める |
| 例 | 古代ギリシャのアテネの民会、スイスの一部の州の住民集会 | 日本の**国会**・地方議会、多くの国の政治 |
| 長所 | 一人一人の意見がそのまま反映される | 人口が多くても、時間をかけてくわしく話し合える |
| 短所 | 人数が多いと、集まることも話し合うことも難しい | 代表者が国民の意見とずれることがある |

- 日本は**間接民主制が基本**。日本国憲法の前文は「日本国民は、**正当に選挙された国会における代表者を通じて行動し**」で始まる。
- ただし日本にも**直接民主制のしくみ**がある：**憲法改正の国民投票**・**最高裁判所裁判官の国民審査**・地方自治の**住民投票**や**直接請求権**（条例の制定・改廃の請求、首長の解職請求など）。<span class="deru">入試</span>

<div class="memo" markdown="1">
**本質**　なぜ間接民主制なの？　日本の有権者は約1億人。1億人が1つの体育館に集まって、毎日の法律や予算を話し合うのは不可能だよね。だから「代わりに考えて決めてくれる人」を選ぶ。**選挙は、国民主権を実際に動かすためのスイッチ**なんだ。
</div>

### 2　多数決と少数意見の尊重

<div class="point" markdown="1">
**POINT 1　多数決のルールと、その注意点**<span class="deru">入試</span>

- 話し合っても全員の意見が一つにならないとき、**多数決**（多くの人が賛成した意見に決める）で決める。決まったことには、反対した人も従う。
- 多数決の長所：**一定の時間内に結論を出せる**（効率）。
- 多数決の注意点：
　① 決める前に**十分に話し合う**（反対の人の意見もよく聞く）。
　② **少数意見の尊重**：少数の意見にも正しいことがあるので、できるだけ取り入れる。
　③ 多数決でも**基本的人権をうばうことはできない**（多数の力で少数の人の権利を奪うのは、民主主義ではない）。
- 国会でも、議案は原則「**出席議員の過半数**」の多数決で決まる（憲法第56条）。

</div>

<div class="memo" markdown="1">
**先生のひとこと**　クラスの出し物を決めるとき、「劇」が20票、「お化け屋敷」が15票。多数決なら劇だね。でも、お化け屋敷派の「衣装を工夫すれば予算が安い」という意見を劇に取り入れたら、もっと良い出し物になる。これが**少数意見の尊重**。「対立 → 話し合い → 合意」の流れは公民1の「効率と公正」ともつながるよ。
</div>

### 3　選挙のしくみ ― 選挙の4原則

<div class="point" markdown="1">
**POINT 2　選挙の4原則**<span class="deru">入試</span>

| 原則 | 意味 | 反対のもの（昔の制度） |
|---|---|---|
| **普通選挙** | 一定の年齢以上の**すべての国民**が選挙権をもつ | **制限選挙**（税金を多く納めた人だけ、など） |
| **平等選挙** | 一人**1票**で、1票の**価値が同じ** | 身分や財産で1人が何票も持つ選挙 |
| **直接選挙** | 有権者が代表者を**直接**選ぶ | 間接選挙（選ばれた選挙人が代表者を選ぶ） |
| **秘密選挙** | **だれに投票したかを知られない**（無記名投票） | 記名投票・口頭での投票 |

- 憲法第15条③「公務員の選挙については、**成年者による普通選挙**を保障する。」
- 憲法第15条④「すべて選挙における**投票の秘密**は、これを侵してはならない。」
- 選挙のきまりは**公職選挙法**で定められている。

</div>

- 秘密選挙が必要な理由：だれに入れたかが知られると、上司や有力者の**圧力**で、本当に投票したい人に入れられなくなるから。

| 年（選挙法の制定・改正） | 選挙権をもつ人 | 全人口にしめる有権者の割合 |
|---|---|---|
| 1889年（最初の選挙は1890年） | **直接国税15円以上**を納める**満25歳以上の男子** | 約1％ |
| 1925年（**普通選挙法**） | **満25歳以上のすべての男子**（納税額の制限なし） | 約20％ |
| 1945年 | **満20歳以上の男女**（女性の参政権が実現） | 約50％ |
| 2015年（2016年の選挙から） | **満18歳以上の男女** | 約80％台 |

（割合はおおよその値）

| | **衆議院** | **参議院** |
|---|---|---|
| 議員定数 | **465人** | **248人** |
| 任期 | **4年**（**解散**があり、任期の途中で終わることも） | **6年**（**3年ごとに半数を改選**。解散はない） |
| 被選挙権（立候補できる年齢） | **満25歳以上** | **満30歳以上** |
| 選挙制度 | **小選挙区比例代表並立制**：小選挙区 **289人**＋比例代表 **176人**（全国を11ブロックに分ける） | **選挙区 148人**（原則都道府県単位）＋比例代表 **100人**（全国が1つの単位） |

- **選挙権**は衆議院も参議院も**満18歳以上**。<span class="deru">入試</span>
- 投票日に行けない人のために、**期日前投票**（投票日より前に投票）、不在者投票、海外に住む人の**在外投票**などがある。

<div class="memo" markdown="1">
**先生のひとこと**　数字は「**衆：465・4年・25歳**」「**参：248・6年・30歳**」とセットで覚えよう。参議院は「**さん**ぎいん＝**30**歳」「6年で3年ごとに半分入れかえ」。任期が長く解散もない参議院は、**じっくり考える院**だから年齢も高めなんだ。
</div>

| 制度 | しくみ | 長所 | 短所 |
|---|---|---|---|
| **小選挙区制** | 1つの選挙区から**1人**を選ぶ | **大きな政党が有利**で政権が安定しやすい。候補者をよく知って選べる | **死票が多い**（落選者に入れた票）。小さな政党は議席をとりにくい |
| **大選挙区制** | 1つの選挙区から**2人以上**を選ぶ | 死票が少なく、小さな政党も議席をとりやすい | 同じ政党の候補者どうしが争うこともある |
| **比例代表制** | **政党**に投票し、**得票数に応じて**議席を配分 | **死票が少ない**。国民のいろいろな意見が反映される | 小さな政党が多くなり、物事が決まりにくい（政治が不安定になりやすい） |

- **死票**：落選した候補者に入れられた票。議席に結びつかない票のこと。<span class="deru">入試</span>
- 衆議院の**小選挙区比例代表並立制**は、2つのよい所を組み合わせたもの。小選挙区と比例代表の両方に**重複立候補**でき、小選挙区で落選しても比例代表で当選（**復活当選**）することがある。

<div class="point" markdown="1">
**POINT 3　ドント式の計算（比例代表制の議席の配り方）**<span class="deru">入試</span>

手順：① 各政党の得票数を **1、2、3…で順に割る**。② 出てきた商（割り算の答え）の**大きい順に**、定数の分だけ議席を配る。

例：定数**6**人、A党1200票・B党900票・C党480票・D党300票

| | A党（1200） | B党（900） | C党（480） | D党（300） |
|---|---|---|---|---|
| ÷1 | **1200**（1位） | **900**（2位） | **480**（4位） | 300 |
| ÷2 | **600**（3位） | **450**（5位） | 240 | 150 |
| ÷3 | **400**（6位） | 300 | 160 | 100 |
| ÷4 | 300 | 225 | 120 | 75 |
| 議席 | **3人** | **2人** | **1人** | **0人** |

- 7位以下（300が3つ）は定数をこえるので、議席はない。
- 確かめ：議席の合計 3＋2＋1＋0 ＝ 6（定数と同じ）になればOK。

</div>

<div class="memo" markdown="1">
**先生のひとこと**　ドント式は「**割って、大きい順に、定数まで**」。表をかくとき、たてに÷1、÷2、÷3…と並べると、大きい順に丸をつけやすい。最後に**議席の合計＝定数**を必ずチェック！
</div>

### 5　一票の格差

- **一票の格差**：選挙区によって、**議員1人あたりの有権者数**がちがうため、**1票の価値に差**ができること。
- 例：Ｐ区は有権者40万人で1人当選、Ｑ区は有権者20万人で1人当選 → Ｑ区の1票はＰ区の1票の**2倍の重み**（Ｐ区の1票の価値はＱ区の2分の1）。

- 一票の格差は、憲法第14条の**法の下の平等**（＝**平等選挙**の原則）に反するとして、裁判で争われてきた。**最高裁判所**は衆議院議員選挙について「**違憲**」や「**違憲状態**」の判決を出している（ただし選挙そのものは無効にしていない）。<span class="deru">入試</span>
- 原因：都市に人口が集まり、地方の人口が減ったこと（**過密**と**過疎**）。対策として、選挙区の区割りや定数の見直しが行われている。

### 6　政党と政党政治

- **政党**：政治について同じ考えをもつ人々が集まり、**政権をとって政策を実現する**ことを目的につくる団体。
- 選挙のとき、政党は**政権公約**（**マニフェスト**：何を、いつまでに、どのように実現するかを示した約束）をかかげる。
- **政党政治**：政党を中心に行われる政治。国会で多数をしめた政党が内閣をつくる（議院内閣制 → 公民5）。

| 用語 | 意味 |
|---|---|
| **与党** | 内閣をつくり、政権を担当する政党 |
| **野党** | 与党以外の政党。政府の政策を**批判・監視**し、別の案を示す |
| **連立政権**（連立内閣） | **複数の政党**が協力してつくる政権。1つの政党だけでは過半数に足りないときなど |
| **二大政党制** | 2つの大きな政党が政権を争う（例：アメリカ・イギリス）。政権交代が起きやすい |
| **多党制** | 3つ以上の政党が議席を争う。連立政権になりやすい（例：日本、ドイツ） |
| **政党交付金** | 政党の活動を助けるため、国（税金）から政党に配られるお金（**政党助成法**） |

- 日本の政党政治の流れ：**1955年**から約40年、**自由民主党（自民党）**が政権を担当し続けた（**55年体制**）→ **1993年**、自民党以外の8党派による**非自民の連立政権**ができ55年体制が終わる → その後は**連立政権**が多い。2009年には選挙で民主党を中心とする政権へ、2012年には再び自民党を中心とする政権へ**政権交代**が起きた。

<div class="memo" markdown="1">
**本質**　なぜ野党が必要なの？　与党だけだと、まちがった政策をしても誰もブレーキをかけない。野党は「ちょっと待って！」と言う役。サッカーでいえば審判ではなく**相手チーム**。相手がいるから、与党も手をぬけない。そして選挙で国民の支持が移れば、**野党が次の与党になる**（政権交代）。
</div>

### 7　世論とメディア

- **世論**：政治や社会の問題について、**多くの人々がもっている意見**。民主政治は世論にもとづいて行われる。新聞社やテレビ局は**世論調査**で世論を調べる。
- **マスメディア**：新聞・テレビ・ラジオ・雑誌など、多くの人に情報を伝えるもの。世論をつくるのに大きな影響力がある。最近は**インターネット**・**SNS**の影響も大きい。
- **メディアリテラシー**：メディアからの情報を**うのみにせず、批判的に読み取り、正しく活用する力**。<span class="deru">入試</span>
　① だれが、何のために発信した情報か　② 根拠（データ・出典）はあるか　③ ほかのメディアと比べたか　④ 事実と意見を区別したか
- インターネット上には、うその情報（**フェイクニュース**）もある。自分が情報を**発信**するときにも責任がある。
- **圧力団体（利益団体）**：自分たちの利益のために、政党や政府にはたらきかける団体（経済団体・労働組合・農業団体など）。
- **無党派層**：支持する政党を特にもたない人々。選挙の結果を大きく左右する。
- 課題：**投票率の低下**、特に**若い世代の投票率が低い**こと。投票しないと、その世代の意見が政治に届きにくくなる。
