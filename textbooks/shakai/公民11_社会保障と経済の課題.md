# 中3公民 公民11「社会保障と経済の課題」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜中心テーマは「だれもが安心してくらし続けられる社会を、どう支えるか」。社会保障の4つの柱／少子高齢化と社会保障の負担／景気変動とインフレ・デフレ／公害と環境保全（環境基本法）／経済の持続可能性</p>

## 要点まとめ

### 1　社会保障とは ― 「もしも」に社会全体で備える

- 病気・けが・失業・老い・障がい・貧困などで生活が苦しくなったとき、**国が生活を保障する**しくみを**社会保障制度**という。
- 根拠は**日本国憲法第25条（生存権）**：「すべて国民は、**健康で文化的な最低限度の生活**を営む権利を有する。」<span class="deru">入試</span>
- 第25条②では、国が社会福祉・社会保障・公衆衛生の向上と増進に努めることも定めている。

| 年 | できごと |
|---|---|
| 1880年代 | ドイツで、世界で初めて本格的な**社会保険**がつくられる |
| 1942年 | イギリスで社会保障の計画（ベバリッジ報告）→ 戦後「**ゆりかごから墓場まで**」の社会保障へ |
| 1946年 | 日本国憲法の公布（第25条で生存権を保障） |
| 1961年 | 日本で、すべての国民が医療保険と年金に入る**国民皆保険・国民皆年金**が実現 |
| 2000年 | **介護保険制度**が始まる |

<div class="memo" markdown="1">
**本質**　なぜ個人でなく「社会」で備えるの？　大きな病気や長生きにかかるお金は、一人では予想も準備もできないほど大きい。でも、**大勢で少しずつお金を出し合っておけば**、困った人が出たときに助けられる。クラス全員で少しずつ出し合った「学級費」で、ボールがこわれたときに買い直すのと同じしくみだね。
</div>

<div class="point" markdown="1">
**POINT 1　4つの柱の見分け方**<span class="deru">入試</span>

- **社会保険**：加入している**すべての人**。ふだんから**保険料**を出し合い、病気・老後・失業などのときに給付を受ける。**医療保険**（病院の窓口負担が原則3割になる）、**年金保険**（老後などに年金）、**雇用保険**（失業したとき）、**労災保険**（仕事中のけが）、**介護保険**（**40歳以上**が保険料を納め、介護が必要になったらサービスを受ける）
- **公的扶助**：生活に困っている人。**生活保護**：最低限度の生活ができない人に、生活費・住宅費・教育費・医療費などを支給。**全額を税金**でまかなう
- **社会福祉**：社会的に弱い立場になりやすい人。高齢者・障がいのある人・子ども・ひとり親家庭などに、**施設やサービス**を提供（保育所・老人ホーム・障がい者の就労支援など）
- **公衆衛生**：**国民全体**。国民の健康を守り、病気を**予防**する。感染症の予防・予防接種・上下水道・ごみ処理など。中心は**保健所**

</div>

<div class="memo" markdown="1">
**先生のひとこと**　キーワードで一発判定！「**保険料**」「**年金**」「**介護**」→ 社会保険。「**生活保護**」→ 公的扶助。「**施設・高齢者・障がい・児童**」→ 社会福祉。「**予防・感染症・上下水道・保健所**」→ 公衆衛生。
</div>

- 65歳以上の人の割合（**高齢化率**）は**2020年に28.6％**で、世界でも最も高い水準。**1990年代後半に、老年人口が年少人口を上回った**。
- 一人の女性が一生に産む子どもの数の平均（**合計特殊出生率**）は**2023年に1.20**で、過去最低（人口を保つには約2.1が必要）。
- **こども家庭庁**（2023年発足）などを中心に、**少子化対策**（子育て支援・保育所の整備・育児休業の取りやすさなど）が進められている。

<div class="point" markdown="1">
**POINT 2　なぜ少子高齢化で社会保障が苦しくなるの？**<span class="deru">入試</span>

- 日本の年金は、**今働いている世代（現役世代）が納める保険料**で、**今の高齢者の年金**をまかなう考え方が基本（世代と世代の支え合い）。
- 高齢者がふえる → **年金・医療・介護の費用がふえる**。　子どもがへる → 将来の**支え手（現役世代）がへる**。
- その結果、**現役世代1人あたりの負担が重くなる**。

| 年 | 1965年 | 2012年 | 2050年（予測） |
|---|---|---|---|
| 65歳以上の1人を支える20〜64歳の人数 | 約9.1人（**胴上げ型**） | 約2.4人（**騎馬戦型**） | 約1.2人（**肩車型**） |

</div>

- 社会保障の費用は、**保険料**（働く人と会社が出す）と**税金**、そして**国債（借金）**でまかなわれている（→ 公民10：歳出の1位は社会保障関係費）。
- 解決策の例：保険料や税（消費税など）の**負担をふやす**／年金などの**給付をへらす**・支給開始年齢を上げる／高齢者や女性が**働き続けられる**社会にして支え手をふやす／**少子化対策**。

<div class="memo" markdown="1">
**本質**　社会保障は「**負担（税・保険料）**」と「**給付（サービス）**」のバランス。北ヨーロッパの国々のように**高福祉・高負担**（税は重いが、医療や教育が手厚い）の国もあれば、アメリカのように**低福祉・低負担**（税は軽いが、自分で民間の保険などに入る）に近い国もある。どちらが正解ではなく、**どんな社会をめざすかを国民が選ぶ**ことが大切。公民10の「大きな政府・小さな政府」と同じ話だよ。
</div>

| | **好況（好景気）** | **不況（不景気）** |
|---|---|---|
| 商品 | よく売れる → 生産がふえる | 売れ残る → 生産がへる |
| 雇用・賃金 | 雇用がふえ、賃金が上がる | **倒産や失業**がふえ、賃金が下がる |
| 物価 | 上がりやすい（**インフレーション**） | 下がりやすい（**デフレーション**） |

<div class="point" markdown="1">
**POINT 3　インフレーションとデフレーション**<span class="deru">入試</span>

- **物価**：いろいろな商品の価格をまとめて平均したもの。
- **インフレーション（インフレ）**：物価が**上がり続ける**こと → **お金の価値が下がる**。
　例 100円のパンが125円に → 1000円で買えるパンが **10個 → 8個** にへる。**預金や年金でくらす人**は困る。
- **デフレーション（デフレ）**：物価が**下がり続ける**こと → お金の価値は上がるが、企業のもうけがへり、賃金が下がる。
- **デフレスパイラル**：物価が下がる → 企業のもうけがへる → 賃金が下がる・失業がふえる → 物が売れない → さらに物価が下がる……という悪いくり返し。
- 日本は**1990年代後半から長くデフレ傾向**が続いた。2022年ごろからは、エネルギーや食料品の値上がり・円安などで**物価の上昇**が続いている。

</div>

- 景気の波を小さくするため、**政府は財政政策**、**日本銀行は金融政策**を行う（→ 公民10）。

| | 政府（財政政策） | 日本銀行（金融政策） |
|---|---|---|
| 不況のとき | 公共事業をふやす・減税 | 国債などを買う → 金利が下がる |
| 好況のとき | 公共事業をへらす・増税 | 国債などを売る → 金利が上がる |

<div class="memo" markdown="1">
**先生のひとこと**　インフレは「**お金が弱くなる**」、デフレは「**お金が強くなる**」と覚えよう。お年玉の1万円を10年間タンスにしまっておくと、インフレの時代には買える物がへってしまう。だから「物価」と「お金の価値」は**シーソーのように逆に動く**んだ。
</div>

### 5　公害と環境保全

- **公害**：企業の生産活動や人々の生活によって、地域の住民の**健康や生活環境がそこなわれる**こと。
- **高度経済成長期**（1950年代後半〜1970年代初め）に、経済成長を優先した結果、各地で深刻な公害が発生した。

<div class="point" markdown="1">
**POINT 4　四大公害病**<span class="deru">入試</span>

| 公害病 | 地域 | 原因 |
|---|---|---|
| **水俣病** | 熊本県・鹿児島県（**八代海**沿岸） | 工場の排水にふくまれた**有機水銀**（メチル水銀） |
| **新潟水俣病** | 新潟県（**阿賀野川**流域） | 工場の排水にふくまれた**有機水銀** |
| **イタイイタイ病** | 富山県（**神通川**流域） | 鉱山から流れ出た**カドミウム** |
| **四日市ぜんそく** | 三重県（**四日市市**） | 石油化学コンビナートの排煙にふくまれた**亜硫酸ガス**（大気汚染） |

- 四大公害裁判は、いずれも**被害者（原告）側が勝訴**した（1971〜1973年）。

</div>

| 年 | 環境を守るための取り組み |
|---|---|
| 1967年 | **公害対策基本法**の制定（公害を防ぐための基本的な法律） |
| 1971年 | **環境庁**の設置 |
| 1993年 | **環境基本法**の制定（公害対策基本法にかわり、**地球環境問題**にも対応） |
| 1997年 | **環境影響評価法**（**環境アセスメント**：開発の前に、環境への影響を調査・評価する）の制定 |
| 2000年 | **循環型社会形成推進基本法**の制定 |
| 2001年 | 環境庁が**環境省**になる |

- **循環型社会**：資源をむだなく使い、ごみをへらし、くり返し使う社会。そのために**3R**（**リデュース**＝ごみを出さない、**リユース**＝くり返し使う、**リサイクル**＝資源として再生利用）を進める。家電リサイクル法などのリサイクル法も整えられた。
- **汚染者負担の原則（PPP）**：公害の費用は、汚染を出した者が負担する、という考え方。

<div class="memo" markdown="1">
**本質**　なぜ公害が起きたの？　工場にとって、排水をきれいにする設備はお金がかかるだけで、もうけにならない。**市場（もうけ）にまかせるだけでは環境は守られない**。だから、**法律でルールを決め、国が監視する**必要がある。これも「政府の役割」の一つなんだ。
</div>

### 6　経済の持続可能性 ― 将来の世代につけを回さない

- **持続可能な社会**：将来の世代の人々も、今と同じように豊かにくらせる社会。
- これからの日本の経済の課題：

| 課題 | 内容 |
|---|---|
| 財政 | 国の借金（国債）が1000兆円をこえている → 将来の世代の負担 |
| 社会保障 | 少子高齢化で給付がふえ、支え手がへる → 負担と給付の見直し |
| 雇用 | パート・アルバイト・派遣などの**非正規雇用**が雇われて働く人の約4割 → 収入の格差・不安定な生活 |
| 働き方 | 長時間労働の見直し（**ワーク・ライフ・バランス**）、女性や高齢者・外国人が働きやすい環境づくり |
| 環境・資源 | 大量生産・大量消費・大量廃棄を見直し、**循環型社会**へ |

**入試直前チェック**

- 社会保障の根拠は**憲法第25条（生存権）**。4つの柱は**社会保険・公的扶助・社会福祉・公衆衛生**。
- 生活保護は**公的扶助**、介護保険は**社会保険**（**40歳以上**が保険料）、予防接種は**公衆衛生**。
- 少子高齢化 → 給付がふえ、支え手がへり、**現役世代の負担が重くなる**。
- 好況→物価上昇（**インフレ**）、不況→物価下落（**デフレ**）。インフレでお金の価値は**下がる**。
- 四大公害：**水俣病**（有機水銀）・**新潟水俣病**（有機水銀）・**イタイイタイ病**（カドミウム）・**四日市ぜんそく**（亜硫酸ガス）。
- 1993年**環境基本法**、2000年**循環型社会形成推進基本法**、**3R**。
