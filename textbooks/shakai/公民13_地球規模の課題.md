# 中3公民 公民13「地球規模の課題と持続可能な社会」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜中心テーマは「国境をこえる問題を、世界はどう協力して解決するか」。地球環境問題と国際的な取り組み（京都議定書・パリ協定）／資源・エネルギー問題／貧困と食料問題／ODAとNGO／SDGs／平和への取り組み（核軍縮）。公民分野の総まとめとして、入試形式の総合問題にも挑戦しよう</p>

## 要点まとめ

### 1　地球環境問題 ― 一つの国では解決できない

| 問題 | おもな原因 | おもな影響 |
|---|---|---|
| **地球温暖化** | 石油・石炭などの**化石燃料**を燃やして出る**二酸化炭素（CO₂）**などの**温室効果ガス**の増加 | 気温の上昇、**海面の上昇**（低い島国が水没の危機）、異常気象、生態系の変化 |
| **オゾン層の破壊** | スプレーや冷蔵庫に使われた**フロンガス** | 有害な**紫外線**がふえ、皮膚がんなどがふえるおそれ |
| **酸性雨** | 工場や自動車の排出ガスにふくまれる**硫黄酸化物・窒素酸化物** | 森林がかれる、湖の魚が死ぬ、建物がとける（国境をこえて被害が広がる） |
| **砂漠化** | 降水量の減少、**過放牧・過耕作**、森林の切りすぎ | 農地が失われ、食料不足に（アフリカの**サヘル**など） |
| **熱帯林の減少** | 焼畑のしすぎ、農地・牧場の開発、木材の輸出 | 二酸化炭素を吸収する森がへり、温暖化が進む。多くの生物が絶滅の危機に |

**本質**　なぜ地球環境問題は解決が難しいの？　CO₂を出した国も出していない国も、**被害は地球全体で受ける**。自分の国だけががまんして排出をへらすと、工場の生産がへって損をする。だから「ほかの国がやるなら、うちもやる」となりやすい。**全員が協力すれば全員が得をするのに、一人だけでは動きにくい**。これが国際的な**条約や約束**が必要な理由だよ。

### 2　環境を守る国際的な取り組み

| 年 | できごと |
|---|---|
| 1972 | **国連人間環境会議**（スウェーデンのストックホルム）。「**かけがえのない地球**」がスローガン。**国連環境計画（UNEP）**がつくられる |
| 1987 | **モントリオール議定書**（オゾン層を破壊するフロンの規制） |
| 1992 | **国連環境開発会議（地球サミット）**（ブラジルのリオデジャネイロ）。**気候変動枠組条約**・生物多様性条約が結ばれる |
| 1997 | **京都議定書**（京都で開かれた会議で採択）<span class="deru">入試</span> |
| 2015 | **パリ協定**（フランスのパリで開かれた会議で採択）<span class="deru">入試</span>、**SDGs**の採択 |

<div class="point" markdown="1">
**POINT 1　京都議定書とパリ協定のちがい**<span class="deru">入試</span>

| | **京都議定書**（1997年） | **パリ協定**（2015年） |
|---|---|---|
| 削減の対象 | **先進国だけ**に温室効果ガスの削減を義務づけた | **発展途上国をふくむすべての参加国**が取り組む |
| 目標の決め方 | 国ごとに削減の数値目標を決めた（日本は1990年比で6％削減） | 各国が**自分で目標を決めて**提出し、取り組みを報告する |
| 全体の目標 | ― | 産業革命前からの気温上昇を**2℃より十分低く**おさえ、**1.5℃**におさえる努力をする |
| 課題 | 排出量の多い**中国やインドに義務がなく**、アメリカも離脱した | 目標の達成は義務ではない |

</div>

<div class="memo" markdown="1">
**先生のひとこと**　京都議定書の問題点は「**先進国だけ**」。発展途上国は「温暖化の原因をつくってきたのは先進国だ。私たちもこれから発展したい」と主張し、先進国は「排出量の多い途上国も参加しないと意味がない」と主張した。この**対立**を乗りこえて、**全員参加**のしくみにしたのがパリ協定。公民1の「対立と合意」そのものだね。日本は**2050年までに温室効果ガスの排出を実質ゼロ（カーボンニュートラル）**にすることを目標にしている。
</div>

### 3　資源・エネルギー問題

- 石油・石炭・天然ガスなどの**化石燃料**は、**限りがある**うえに、燃やすと**CO₂**を出す。また、産出地が**かたよっている**（石油は西アジアの**ペルシア湾**岸に多い）。
- 日本はエネルギー資源のほとんどを**輸入**にたよる。エネルギー自給率は**1割程度**（2020年代）。原油は**西アジア（中東）**から9割以上を輸入している。

- **2011年**の東日本大震災で**福島第一原子力発電所の事故**が起き、原子力発電の割合が大きく下がった。その分を**火力**がおぎなっている。

| 発電方法 | 長所 | 短所 |
|---|---|---|
| **火力** | 発電量を調整しやすい | **CO₂を多く出す**。燃料の多くを輸入にたよる |
| **原子力** | 発電のときにCO₂を出さない。少ない燃料で大きな電力 | 事故のときの被害が大きい。**放射性廃棄物**の処分 |
| **再生可能エネルギー**（太陽光・風力・地熱・バイオマス・水力） | **CO₂をほとんど出さず、なくならない** | 天候などで**発電量が不安定**。費用が高く、広い土地が必要なものも |

### 4　貧困と食料の問題

- 世界の人口は**約80億人**（2022年）。特に**アフリカ**や南アジアなどの発展途上国で人口が急増している（**人口爆発**）。
- 世界には、世界銀行が定める基準（1日に使えるお金がごくわずか）に満たない**極度の貧困**の人々や、十分な食料が得られない**飢餓**に苦しむ人々が、それぞれ**数億人**いる。
- 貧困の結果、子どもが学校に行けない → 読み書きができず、よい仕事につけない → また貧困に……という**貧困の連鎖**が起きる。
- 一方で、先進国では**食べられるのに捨てられる食品（食品ロス）**が多い。日本の食品ロスは**約472万トン**（2022年度）で、家庭と事業者から**半分ずつ**出ている。
- 日本の**食料自給率**は**38％**（カロリーベース、2022年度）で、先進国の中でも低い。

<div class="memo" markdown="1">
**本質**　世界全体では、すべての人が食べられるだけの食料は生産されている。それなのに飢える人がいるのは、**食料が「お金のある所」に集まり、貧しい人には届かない**から。つまり食料問題は、量の問題であると同時に**分配と貧困の問題**なんだ。
</div>

### 5　ODAとNGO ― 国と市民の国際協力

<div class="point" markdown="1">
**POINT 2　ODAとNGO**<span class="deru">入試</span>

| | **ODA（政府開発援助）** | **NGO（非政府組織）** |
|---|---|---|
| だれが | **政府**（日本では**JICA（国際協力機構）**などが実施） | **民間の団体**（国や政府から独立） |
| 内容 | 発展途上国への**資金協力**（道路・発電所などの建設）や**技術協力**（専門家の派遣、JICA海外協力隊） | 医療・教育・難民支援・環境保護など。きめ細かい現地での活動 |
| 例 | 日本のODAは**アジア**向けが多く、道路や港などの**社会資本の整備**に力を入れてきた。1990年代には援助額が**世界1位** | **国境なき医師団**（1999年ノーベル平和賞）、地雷の除去を行う団体など |

</div>

- ODAは「**魚をあたえるより、魚のとり方を教える**」ように、途上国が自分の力で発展できるよう**人づくり（技術協力）**も重視している。
- 営利を目的としない民間の団体を広く**NPO（非営利組織）**ともいう。日本では1998年にNPO法が制定された。

### 6　SDGs ― 2030年までの世界の目標

- **SDGs（持続可能な開発目標）**：**2015年**に国連で採択された、**2030年**までに達成をめざす**17の目標**。合言葉は「**誰一人取り残さない**」。<span class="deru">入試</span>
- 2000年に決められた**MDGs（ミレニアム開発目標）**が発展途上国中心だったのに対し、SDGsは**先進国もふくむすべての国**の目標。

### 7　平和への取り組み ― 核軍縮と地域紛争

| 年 | できごと |
|---|---|
| 1945 | **広島**（8月6日）・**長崎**（8月9日）に原子爆弾が投下される |
| 1954 | アメリカの水爆実験で、日本の漁船**第五福竜丸**が被ばく → 翌年、第1回原水爆禁止世界大会（広島） |
| 1963 | **部分的核実験禁止条約**（大気圏内・宇宙・水中での核実験を禁止） |
| 1968 | **核拡散防止条約（NPT）**（核兵器をもつ国がふえるのを防ぐ） |
| 1971 | 国会で**非核三原則**（核兵器を「**持たず、つくらず、持ちこませず**」）を決議（1967年に佐藤栄作首相が表明） |
| 1987 | アメリカとソ連が**中距離核戦力（INF）全廃条約**に調印（2019年に失効） |
| 1996 | **包括的核実験禁止条約（CTBT）**採択（地下をふくむすべての核爆発実験を禁止。まだ発効していない） |
| 2017 | **核兵器禁止条約**採択（2021年発効）。核兵器の開発・保有・使用などを全面的に禁止。核保有国や日本は参加していない |
| 2024 | 被爆者の団体である**日本原水爆被害者団体協議会（日本被団協）**がノーベル平和賞を受賞 |

- 冷戦の終結後も、**民族や宗教の対立**による**地域紛争**や、2001年のアメリカ同時多発テロのような**テロリズム**が起きている。紛争によって住む場所を追われた**難民**は、UNHCRなどが支援している。
- 日本は**唯一の戦争被爆国**として、核兵器のない世界をうったえていく役割がある。

<div class="memo" markdown="1">
**本質（公民のまとめ）**　公民で学んだことは、すべて「**一人一人を個人として尊重し、だれもが安心してくらせる社会をどうつくるか**」につながっている。憲法（人権）→ 政治（国民主権・三権分立）→ 経済（市場・財政・社会保障）→ 国際社会（国連・SDGs）。どの場面でも、**対立 → 話し合い → 合意**、そして**効率と公正**の両方を考えることが大切。入試の総合問題も、この視点で考えれば迷わない。
</div>

**入試直前チェック**

- 温暖化＝**温室効果ガス（CO₂）**、オゾン層＝**フロン**、酸性雨＝**硫黄酸化物・窒素酸化物**。
- 1972年**国連人間環境会議**、1992年**地球サミット**、1997年**京都議定書**（先進国のみ）、2015年**パリ協定**（すべての国）。
- 日本の発電は**火力**が中心。再生可能エネルギーは**CO₂を出さないが不安定**。
- **ODA**＝政府、**NGO**＝民間。**SDGs**は2015年採択・**17の目標**・2030年まで・「誰一人取り残さない」。
- **NPT**（1968年）、**CTBT**（1996年、未発効）、**核兵器禁止条約**（2017年、日本は不参加）、**非核三原則**。

### 標準

#### <span class="no">4</span> 地球温暖化を防ぐ国際的な取り決めについて、次の各問いに答えなさい。

(1) 1997年に採択され、先進国に温室効果ガスの削減を義務づけた取り決めを何というか。
(2) (1)の取り決めの問題点として最も適するものを、次の1〜4の中から一つ選び、その番号を答えなさい。
　1．すべての国に同じ削減目標を義務づけたため、発展途上国が反発した。
　2．排出量の多い中国やインドなどの発展途上国に、削減の義務がなかった。
　3．削減の目標を、各国が自由に決めることになっていた。
　4．フロンガスの規制だけを対象にしていた。
(3) 2015年に採択されたパリ協定で、産業革命前からの気温上昇を何℃におさえる努力をするとしたか。

#### <span class="no">5</span> 要点まとめの「国別の二酸化炭素排出量の割合（2021年）」のグラフについて、次の各問いに答えなさい。

(1) 中国とアメリカの排出量を合わせると、世界全体のおよそ何％になるか。整数で答えなさい。
(2) グラフから読み取れることとして最も適するものを、次の1〜4の中から一つ選び、その番号を答えなさい。
　1．日本の排出量は、世界の上位5か国に入っていない。
