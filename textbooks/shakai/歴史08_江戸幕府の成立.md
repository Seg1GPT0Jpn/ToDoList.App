### 1　江戸幕府の成立

- **なぜ**：1598年、豊臣秀吉が死去 → 幼い **豊臣秀頼** があとをつぎ、家臣たちが対立。
- **何が**：**1600年 関ヶ原の戦い**（岐阜県）で、五大老の筆頭 **徳川家康**（東軍）が、豊臣方の **石田三成**（西軍）らを破る。
- **どうなった**：**1603年**、家康が **征夷大将軍** に任じられ、**江戸** に幕府を開く。1605年には将軍職を子の **秀忠** にゆずり、徳川家が代々将軍をつぐことを示した。
- **1614・1615年 大阪の陣** で **豊臣氏をほろぼし**、全国支配を固めた。

### 2　幕藩体制（幕府と藩が全国を支配するしくみ）

- **幕府**：将軍が直接支配。**幕領**（天領・直轄地）は約400万石。**旗本・御家人**（将軍直属の家臣）の領地とあわせると **全国の石高の約4分の1**。
　→ さらに **江戸・京都・大阪・長崎** などの重要都市や、**佐渡金山**・**石見銀山** などの鉱山も直接支配 → 経済力は圧倒的。<span class="deru">入試</span>
- **藩**：**1万石以上** の領地をあたえられた武士 ＝ **大名**。大名の領地と、その支配のしくみが **藩**（約260〜270）。藩の政治は大名が自由に行った。
- 幕府と藩が、土地と人々を支配する体制 ＝ **幕藩体制**。

### 3　大名の配置（大名を3種類に分けて、うまく置いた）

<div class="point" markdown="1">
**POINT 1　親藩・譜代・外様**<span class="deru">入試</span>

| 種類 | どんな大名？ | 配置 | 例 |
|---|---|---|---|
| **親藩** | **徳川家の一族** | 重要な地域 | **御三家**（**尾張**・**紀伊**・**水戸**）。将軍のあとつぎを出す |
| **譜代大名** | **関ヶ原の戦い以前** から徳川家に従っていた大名 | **江戸の近く・重要な地域** | 井伊氏（彦根）など。**老中** などの役職につく |
| **外様大名** | **関ヶ原の戦いのころ以降** に従った大名 | **江戸から遠い地域**（九州・東北など） | **島津氏**（薩摩）・**毛利氏**（長州）・前田氏（加賀）・伊達氏（仙台） |

**なぜこう配置？** → 信用できない外様大名を **江戸から遠ざけ**、そのあいだに親藩・譜代を置いて **見張らせる** ため。

</div>

<div class="memo" markdown="1">
**発展**　江戸から遠くに置かれた外様の **薩摩藩（島津氏）** と **長州藩（毛利氏）** は、約260年後、江戸幕府をたおす中心になる（→ 歴史12「開国と明治維新」）。「遠ざけた相手に最後にやられる」という歴史のおもしろさだね。
</div>

### 4　大名と朝廷の統制

<div class="point" markdown="1">
**POINT 2　武家諸法度と参勤交代**<span class="deru">入試</span>

- **武家諸法度**：大名が守るべききまり。**1615年**（2代 **秀忠** のとき）に初めて出され、将軍がかわるごとに出し直された。
　内容：**城を新しく築くことの禁止**・修理するときは届け出る、**大名どうしが勝手に結婚することの禁止** など。破った大名は **領地を取り上げ・減らし・移す**（改易・減封・転封）。
- **参勤交代**：**1635年**、3代将軍 **徳川家光** が武家諸法度に加えて制度化。大名は **1年おきに江戸と領地を往復**。**妻子は江戸に住まわせる**（人質の役割）。

| | 内容 |
|---|---|
| **ねらい** | 大名に将軍への **忠誠** をちかわせ、**大名を統制する** |
| **結果①（大名）** | 大名行列や江戸での生活に **大きな出費** → **藩の財政が苦しく** なり、反乱を起こす力が弱まった |
| **結果②（社会）** | **街道・宿場町が整備** され、**江戸が大都市** として発展。地方と江戸の **文化の交流** も進んだ |

</div>

<div class="ex" markdown="1">
**史料**　武家諸法度（1615年・一部）
「一、諸国ノ居城、修補ヲ為スト雖モ、必ズ言上スベシ。況ンヤ新儀ノ構営堅ク停止令ムル事」
「一、私ニ婚姻ヲ締ブベカラザル事」
（現代語訳）大名の城は、修理する場合でも必ず幕府に届け出ること。まして新しく城を築くことはかたく禁止する。／幕府の許可なく、大名どうしで結婚してはならない。

**史料**　武家諸法度（1635年・家光のとき・一部）
「一、大名小名、在江戸交替相定ル所也。毎歳夏四月中参勤致スベシ」
（現代語訳）大名は、江戸と領地を交代で行き来すると定める。毎年4月中に江戸へ参勤すること。
</div>

- **朝廷の統制**：**禁中並公家諸法度**（1615年）で、天皇や公家の行動を制限。**京都所司代** が朝廷を監視。
- 一国一城令（1615年）：大名の城を **1つの国に1つだけ** に。

<div class="memo" markdown="1">
**先生のひとこと**　城を勝手に建てるな、勝手に結婚するな（＝同盟を組むな）、1年おきに江戸に来い、家族は江戸に置いていけ……。**全部「大名に反乱させない」ためのルール**だと考えれば、まる暗記しなくても理由が書けるよ。
</div>

<figcaption>江戸時代の身分別人口の割合（江戸時代後半ごろの推定。「他」は公家・僧侶・神官、えた・ひにんとされた人々など、約3％）</figcaption>

| 身分 | くらし・役割 |
|---|---|
| **武士** | 支配する身分。**名字・帯刀**（刀を差す）の特権。城下町に住み、幕府や藩から **米（俸禄）** を受け取る |
| **百姓** | 人口の大部分。おもに農村に住み、**年貢（米）** を納める。土地を持つ **本百姓** と、持たない **水のみ百姓** |
| **町人** | 城下町に住む **商人・職人**。営業税を納める |

- **村のしくみ**：有力な本百姓が **村役人**（**庄屋〈名主〉**・組頭・百姓代）となり、村を運営し年貢を集めた。
- **五人組**：百姓を5戸前後で1組にし、**年貢の納入や犯罪の防止に連帯責任** を負わせた。<span class="deru">入試</span>
- **年貢**：収穫の **4〜5割**（「四公六民」「五公五民」）。幕府や藩の財政をささえた → だから百姓の生活を細かく統制した。
- **えた・ひにん** とされた人々は、厳しく差別された。住む場所・服装などを制限されながらも、農業や皮革業・芸能などで社会をささえた。

<div class="memo" markdown="1">
**本質**　秀吉の **兵農分離**（太閤検地・刀狩）が、江戸時代に **身分制度** として完成した。身分は基本的に親から子へ受けつがれ、変えるのは難しかった。「年貢を確実に取る」という目的から考えると、五人組も村役人もしくみがよくわかる。
</div>

### 6　朱印船貿易から鎖国へ

- **朱印船貿易**：家康は貿易の利益を重視し、大名や商人に **朱印状**（海外渡航の許可証）をあたえた。朱印船は **東南アジア** へ。
　→ 各地に **日本町** ができた（タイの **アユタヤ** では **山田長政** が活躍）。輸入：**生糸・絹織物**、輸出：**銀**。
- しかし、**キリスト教の信者が増え続けた** → 幕府は、信者が **神への信仰を将軍への忠誠より優先** して団結すること、スペイン・ポルトガルの **侵略** を警戒。

<div class="point" markdown="1">
**POINT 3　鎖国への道（なぜ → 何が → どうなった）**<span class="deru">入試</span>

| 年 | できごと | ねらい |
|---|---|---|
| 1612・13 | **禁教令** | キリスト教を禁止 |
| 1624 | **スペイン船** の来航禁止 | 布教をするカトリックの国を排除 |
| 1635 | 日本人の **海外渡航・帰国を禁止**（朱印船貿易も終わる） | 外国との接触を幕府が独占 |
| 1637〜38 | **島原・天草一揆** | ↓ キリスト教への警戒が決定的に |
| 1639 | **ポルトガル船** の来航禁止 | |
| 1641 | **オランダ商館を平戸から長崎の出島** へ | 貿易を **幕府が管理・独占** → **鎖国の体制** |

</div>

- **島原・天草一揆（1637〜38年）**：島原（長崎県）・天草（熊本県）で、**キリスト教徒への迫害** と **重い年貢** に苦しむ人々が、少年 **天草四郎（益田時貞）** を総大将に起こした一揆。幕府は大軍で鎮圧。
- **キリスト教の取りしまり**：**絵踏**（キリストやマリアの像を踏ませる）、**宗門改**（仏教徒であることを **寺に証明** させる＝**寺請制度**）。
- **オランダが許された理由**：オランダは **プロテスタント** の国で、**キリスト教を布教しなかった** から。<span class="deru">入試</span>
- オランダ商館長は **オランダ風説書** を幕府に提出 → 幕府は **海外の情報を独占** した。

<div class="memo" markdown="1">
**注意**　「鎖国」といっても **完全に国を閉じたわけではない**。幕府が **窓口と相手国をしぼって管理** した、ということ。ゲームでいえば「フレンド申請は運営が許可した相手だけ」の状態だね。
</div>

### 7　鎖国下の4つの窓口

<div class="point" markdown="1">
**POINT 4　4つの窓口と相手**<span class="deru">入試</span>

| 窓口 | 相手 | 内容 |
|---|---|---|
| **長崎**（幕府が直接） | **オランダ**・**中国（明・清）** | オランダは **出島**、中国人は **唐人屋敷** に住まわせる。生糸・絹織物・薬などを輸入 |
| **対馬藩**（宗氏） | **朝鮮** | 1607年に国交回復。将軍の代がわりなどに **朝鮮通信使** が江戸へ（江戸時代に計12回）。釜山の倭館で貿易 |
| **薩摩藩**（島津氏） | **琉球王国** | 1609年に征服。琉球は中国にも朝貢を続ける → 薩摩藩は **中国の産物** を手に入れた。将軍や琉球国王の代がわりに使節が江戸へ |
| **松前藩**（松前氏） | **蝦夷地のアイヌの人々** | 交易を独占。不利な交易に反発した **シャクシャイン** が1669年に戦いを起こす |

</div>

<div class="memo" markdown="1">
**先生のひとこと**　4つの窓口は「**長崎＝オランダ・中国、対馬＝朝鮮、薩摩＝琉球、松前＝アイヌ**」の4ペアで丸暗記OK。入試では「朝鮮通信使を仲立ちしたのはどの藩？」→ **対馬藩**、がねらわれやすい。
</div>

### 入試直前チェック

- **1600年 関ヶ原の戦い** → **1603年 江戸幕府**。**大阪の陣（1614・15）** で豊臣氏滅亡。
- 幕領は全国の石高の約4分の1（旗本領ふくむ）。重要都市・鉱山も直接支配。ふだんの政治は **老中**。
- 大名：**親藩**（御三家）・**譜代**（江戸近く）・**外様**（遠く）。
- **武家諸法度**（城の新築・無断結婚の禁止）、**参勤交代**（1635年・家光）→ 大名の出費が増え、街道と江戸が発展。
- 身分：百姓が約85％。**五人組** で連帯責任。村役人は **庄屋（名主）**。
- 鎖国への流れ：**禁教令 → スペイン船禁止（1624）→ 日本人の渡航禁止（1635）→ 島原・天草一揆（1637）→ ポルトガル船禁止（1639）→ 出島（1641）**。
- オランダが許されたのは **布教しなかった** から。**絵踏・宗門改**。
- 4つの窓口：**長崎**（オランダ・中国）・**対馬**（朝鮮）・**薩摩**（琉球）・**松前**（アイヌ）。

### 基本
