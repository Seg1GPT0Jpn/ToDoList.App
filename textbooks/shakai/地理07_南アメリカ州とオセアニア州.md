# 中1地理 地理7「南アメリカ州とオセアニア州」

<p class="lead">対象：中学1年 地理（小5から挑戦OK）｜アンデス山脈とアマゾン川・熱帯林の減少／ブラジルの農業とバイオエタノール／混血とポルトガル語・スペイン語／オーストラリアの鉱産資源と羊・白豪主義から多文化社会へ／アジアとの結びつき／太平洋の島々と海面上昇</p>

## 要点まとめ

### 1　南アメリカの自然 ── 西の「壁」アンデス、中央の「森」アマゾン

<div class="cols2" markdown="1">

| 地名 | ここだけ覚える |
|---|---|
| **アンデス山脈** | 大陸の**西側**を南北に走る**高くけわしい山脈**（6000m級の山が連なる） |
| **アマゾン川** | **流域面積が世界最大**の川。赤道付近を西から東へ流れ**大西洋**へ |
| **セルバ** | アマゾン川流域の**熱帯雨林** |
| **パンパ** | アルゼンチンの**ラプラタ川**流域の**温帯草原**。小麦・牛 |
| **アタカマ砂漠** | チリ北部の太平洋岸。世界で最も乾燥した地域の一つ |

- **赤道**が、エクアドル・コロンビア・**ブラジル北部**を通る。
- 南半球の部分が広いので、**季節は日本と逆**。ブラジル南部やアルゼンチンでは、12月〜2月が夏。
- 南へ行くほどすずしくなる：北部は**熱帯** → 中部〜南部は**温帯** → 南のはし近くは寒冷。

</div>

<div class="memo" markdown="1">
**本質**　赤道直下なのに、なぜアンデスの高地は**すずしい**のか？　気温は**100m高くなるごとに約0.6度下がる**からだ。標高4000mなら、低地より**約24度**も低い。だから同じ赤道付近でも、低地はバナナ、上がるにつれてとうもろこし → **じゃがいも**（寒さに強い）→ 草しか育たない高さでは**リャマ・アルパカの放牧**、と**高さによって作るものが変わる**。リャマは荷物運び、アルパカは毛をとるのに使う。かつてここに**インカ帝国**が栄え、**マチュピチュ**の遺跡が残っている。
</div>

### 2　南アメリカの歴史と人々 ── 混血と2つの言語

| 時期 | できごと |
|---|---|
| 〜15世紀 | **先住民**（インディオ／インディヘナ）の文明。アンデスの**インカ帝国**など |
| 16世紀〜 | **スペイン**と**ポルトガル**が侵略し**植民地**に。先住民はヨーロッパから持ちこまれた病気や強制労働で激減 |
| 16〜19世紀 | 大農園（さとうきびなど）の働き手として、**アフリカ**から多くの人々が**奴隷**として連れてこられた |
| 19世紀前半 | 多くの国が独立 |
| 20世紀〜 | **日本**からも移民。**1908年**に始まった**ブラジル**への移住など → ブラジルは**日系人**が世界で最も多い国（約200万人とされる） |

<div class="point" markdown="1">
**POINT 1　言語・宗教・混血**<span class="deru">入試</span>

- **ブラジル**は**ポルトガル**の植民地だった → 公用語は**ポルトガル語**。
- **ブラジル以外のほとんどの国**（アルゼンチン・チリ・ペルーなど）は**スペイン**の植民地だった → **スペイン語**。
- 宗教：スペイン・ポルトガルが広めた**キリスト教（カトリック）**が中心。
- **先住民・ヨーロッパ系・アフリカ系**の人々が混ざり合い、**混血**の人々も多い。先住民とヨーロッパ系の混血を**メスチソ**という。国によって人々の構成がちがう（アルゼンチンはヨーロッパ系が多い、ペルー・ボリビアは先住民とメスチソが多い、ブラジルは多様）。

</div>

<div class="memo" markdown="1">
**先生の一言**　「ブラジルだけポルトガル語」はテストの超定番。南アメリカの地図で、いちばん大きいブラジルだけ**ポ**、残りはぜんぶ**ス**と覚えよう。また、日本の群馬県大泉町や愛知県・静岡県には、働きに来たブラジルの日系人が多くくらしていて、ポルトガル語の看板も見られるよ。
</div>

### 3　ブラジルの農業・鉱業と、アマゾンの開発

| 時期 | ブラジルの輸出の中心 |
|---|---|
| 1960年代ごろ | **コーヒー豆**が輸出の大半（モノカルチャー経済） |
| 現在（2020年代） | **大豆**・**鉄鉱石**・**原油**・肉類・砂糖など**多角化**。自動車・航空機などの工業も発達 |

- ブラジルは**コーヒー豆**・**さとうきび**・**大豆**の生産が**世界1位**（2020年代）。オレンジ・牛肉・とり肉の輸出も多い。<span class="deru">入試</span>
- 鉱産資源：**鉄鉱石**（ブラジルは世界有数の産出国。日本の輸入先でオーストラリアにつぐ）、**銅**（**チリ**が世界1位）、**原油**（ベネズエラ・ブラジル）、銀（ペルー）。
- ブラジルは急速に経済が成長し、**BRICS**（ブラジル・ロシア・インド・中国・南アフリカなど）の一つ。一方、大都市には**スラム**（ブラジルでは**ファベーラ**）があり、**貧富の差**が大きい。

<div class="point" markdown="1">
**POINT 2　バイオエタノール（バイオ燃料）**<span class="deru">入試</span>

- **さとうきび**や**とうもろこし**などの**植物**から作るアルコール燃料。ブラジルでは**さとうきび**から作り、**自動車の燃料**（ガソリンにまぜる）として広く使う。
- **よい点**：植物は育つときに**二酸化炭素を吸収**するので、燃やしても大気中の二酸化炭素は増えにくいと考えられている（**地球温暖化対策**）。石油にたよらずにすむ。
- **問題点**：畑を広げるために**森林が切りひらかれる**。食料になる作物を燃料に使うので、**食料の価格が上がる**おそれがある。

</div>

### 4　オーストラリアの自然と産業

- **オーストラリア大陸**は**六大陸で最小**。国土の**半分以上が乾燥帯**（砂漠・草原）。人口（約2600万人、2022年ごろ）の多くは、気候が温暖な**南東部・南西部の海岸**の都市（**シドニー**・**メルボルン**など）に集中。首都は**キャンベラ**。<span class="deru">入試</span>
- 南半球なので**季節は日本と逆**。経度は日本と近いので**時差が小さい**（1〜2時間程度）。

**POINT 3　「降水量」で決まる農牧業と、豊かな鉱産資源**<span class="deru">入試</span>

- 内陸ほど雨が少ない → 海岸に近い**雨の多い地域**は**酪農・さとうきび**、**やや乾燥**した地域は**小麦・羊**、**さらに乾燥**した地域は**牛・羊の放牧**、中央部は**砂漠**。
- **羊**：毛をとる**メリノ種**。羊毛の生産・輸出は世界有数。地下水（**掘り抜き井戸**）を利用して放牧してきた地域もある。**牛肉**も日本へ多く輸出（「オージービーフ」）。
- **鉱産資源**：**鉄鉱石**（**北西部**）、**石炭**（**東部**）、ボーキサイト（アルミニウムの原料）、金、天然ガスなど。地表から直接ほり進める**露天掘り**で、大規模に安く採掘する。
- 日本の**鉄鉱石**・**石炭**・**液化天然ガス（LNG）**の輸入相手国の**第1位はオーストラリア**（2022年）。

</div>

<div class="memo" markdown="1">
**先生の一言**　オーストラリアの鉄鉱石は、巨大な鉱山からとった鉱石を**長い貨物列車**で港に運び、大型船で日本や中国へ送る。日本の製鉄所が海ぞいにあるのは、こうして**船で運ばれてくる原料**を受け取るため。「オーストラリアの鉄鉱石 → 日本の鉄 → 自動車」と、世界はつながっているんだ。
</div>

### 5　オーストラリアの社会 ── 白豪主義から多文化社会へ

| 時期 | できごと |
|---|---|
| もともと | 先住民**アボリジニ**（ニュージーランドでは**マオリ**）がくらす |
| 18世紀後半〜 | **イギリス**の植民地に。ヨーロッパ系の移民が増え、先住民は土地をうばわれた |
| 20世紀前半〜 | **白豪主義**：**ヨーロッパ系以外（特にアジア系）の移民を制限**する政策 |
| **1970年代** | 白豪主義を**廃止** → **多文化主義**へ。**アジアからの移民**が増加（中国・インド・ベトナムなど） |
| 現在 | 先住民の文化や権利を尊重する動き。さまざまな文化を認め合う**多文化社会** |

<div class="cols2" markdown="1">

| | 1960年ごろ | 現在（2020年代） |
|---|---|---|
| おもな輸出品 | **羊毛**・小麦・肉類 | **鉄鉱石**・**石炭**・**天然ガス** |
| 最大の輸出相手国 | **イギリス** | **中国** |
| 上位の相手国 | ヨーロッパ・アメリカ | **中国・日本・韓国**などアジア |

- 「**イギリス（ヨーロッパ）中心**」から「**アジア・太平洋中心**」へ。<span class="deru">入試</span>
- **なぜ？**　①イギリスがヨーロッパの国々との結びつきを強めた　②**日本・中国などアジアの工業が発展**し、鉄鉱石・石炭が大量に必要になった　③アジアは**距離が近い**。
- **APEC（アジア太平洋経済協力会議）**は1989年、オーストラリアのよびかけで発足。

</div>

- 旗に**イギリスの国旗**がえがかれているのは、イギリスとの歴史的な結びつきのなごり（ニュージーランドも同じ）。
- **ニュージーランド**：**西岸海洋性気候**で牧草がよく育ち、**羊・牛（酪農）**がさかん。**人口より羊の数のほうが多い**。先住民**マオリ**の言葉が公用語の一つ。

### 6　太平洋の島々と海面上昇

<div class="cols2" markdown="1">

| 地域 | 意味・おもな島 |
|---|---|
| **メラネシア** | 「黒い島々」。パプアニューギニア・フィジーなど |
| **ミクロネシア** | 「小さな島々」。グアム・パラオなど |
| **ポリネシア** | 「多くの島々」。ハワイ・ツバル・トンガ・ニュージーランドなど |

- 島には、**火山島**と、**さんご礁**でできた低い島がある。
- 産業：**観光**、**漁業**（まぐろ・かつお）、ココやしからつくる**コプラ**など。

</div>

<div class="point" markdown="1">
**POINT 4　海面上昇で「しずむ」おそれのある国**<span class="deru">入試</span>

- **ツバル**などのさんご礁の島国は、国土のほとんどが**海抜数m以下**。
- **地球温暖化**で、海水があたためられてふくらんだり、陸の氷がとけたりして**海面が上昇**すると、**国土が水没**するおそれ。高潮の被害、**海水が地下水にしみこみ飲み水や畑に影響**するなどの問題がすでに起きている。
- **温暖化の原因（二酸化炭素など）を多く出しているのは先進国や大きな国**なのに、被害を受けるのは小さな島国 → 国際的な協力が必要。

</div>

### 7　入試直前チェック

- **アンデス山脈**（西・高い）、**アマゾン川**（流域面積世界最大）、**セルバ**（熱帯雨林）、**パンパ**（アルゼンチンの草原）。
- アンデスの高地：**高さで作物が変わる**（とうもろこし → じゃがいも → **リャマ・アルパカ**）。**インカ帝国**。
- **ブラジル＝ポルトガル語**、ほかの多くの国＝**スペイン語**。カトリック。**混血**（メスチソ）。ブラジルは**日系人**最多。
- ブラジル：**コーヒー豆・さとうきび・大豆**が世界1位。コーヒー中心 → **多角化**。**バイオエタノール**（さとうきび）。
- アマゾンの開発 → **熱帯林の減少** → 温暖化・生物多様性・先住民。**持続可能な開発**。
- オーストラリア：**乾燥帯が多く**、人口は**南東部・南西部**に集中。**羊**（メリノ種）・牛・小麦。**鉄鉱石（北西部）・石炭（東部）**、**露天掘り**。日本の鉄鉱石・石炭の最大の輸入先。
- **白豪主義**（アジア系移民の制限）→ 1970年代に廃止 → **多文化主義**。先住民**アボリジニ**、NZは**マオリ**。
- 貿易相手：**イギリス → 中国・日本などアジア**。**APEC**。
- **ツバル**など：**地球温暖化 → 海面上昇 → 水没のおそれ**。

### 基本
