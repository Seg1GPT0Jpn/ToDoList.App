# 中2地理 地理15「関東地方」

<p class="lead">対象：中学2年 地理（小5から挑戦OK）｜関東平野と関東ローム・からっ風・首都東京への一極集中と過密・昼間人口と夜間人口・京浜／京葉／北関東工業地域・近郊農業・わたしたちの神奈川県</p>

## 要点まとめ

### 1　関東地方のすがた ＝ 日本の人口の約3分の1が住む地方

- **1都6県**。人口は約4400万人で、**日本の人口の約3分の1**が集まる（2020年国勢調査）。
- 首都 **東京** を中心に、通勤・通学で結びついた **東京大都市圏** をつくっている。

<div class="point" markdown="1">
**関東地方の1都6県と都県庁所在地・主な産物**<span class="deru">入試</span>

| 都県 | 都県庁所在地 | 主な産物・ひとこと |
|---|---|---|
| **東京都** | 東京（新宿区に都庁） | 首都。**印刷・出版**、本社・大学・テレビ局が集中。**小笠原諸島**（世界自然遺産） |
| **神奈川県** | **横浜市** | 人口は東京都に次いで全国2位。**京浜工業地帯**。三浦半島の野菜、**三崎港**のまぐろ |
| **埼玉県** | **さいたま市** | ベッドタウン（東京へ通勤）。近郊農業（ねぎ・ほうれんそうなど）。さいたま新都心 |
| **千葉県** | 千葉市 | **京葉工業地域**（化学・鉄鋼）。**落花生**（全国1位）・ねぎ。**銚子港**。**成田国際空港** |
| **茨城県** | **水戸市** | 近郊農業（**ピーマン・はくさい・メロン**など）。**筑波研究学園都市**。日立市の電気機械 |
| **栃木県** | **宇都宮市** | **いちご**（全国1位）・かんぴょう。北関東工業地域。日光の社寺（世界文化遺産） |
| **群馬県** | **前橋市** | **嬬恋村のキャベツ**（高原野菜）、こんにゃくいも。太田市の自動車。富岡製糸場（世界文化遺産） |

</div>

- 県名と県庁所在地の名前が同じなのは **千葉県だけ**。神奈川→**横浜**、茨城→**水戸**、栃木→**宇都宮**、群馬→**前橋**、埼玉→**さいたま**（ひらがな）。<span class="deru">入試</span>

### 2　自然 ── 日本最大の平野と、火山灰の台地

<div class="cols2" markdown="1">

| 地形 | ポイント |
|---|---|
| **関東平野** | **日本最大の平野** |
| **関東ローム** | 富士山・浅間山などの**火山灰**が積もった赤土。台地をおおう |
| **利根川** | **流域面積が日本最大**の川。千葉県の銚子で太平洋へ |
| **霞ヶ浦** | 日本で2番目に大きい湖（茨城） |
| **房総半島・三浦半島** | 東京湾をはさむ2つの半島 |

- **台地**（関東ロームにおおわれた高い土地）は水を得にくい → **畑**や**住宅地**・ゴルフ場に。
- **低地**（川沿い）は水が得やすい → **水田**。

</div>

<div class="point" markdown="1">
**関東の気候 ── 冬の「からっ風」**<span class="deru">入試</span>

- 冬は、日本海側に雪を降らせたあとの**かわいた北西の季節風**が山をこえてふき下ろす ＝ **からっ風**。→ 冬は**晴れて乾燥**する。
- 群馬県などでは、からっ風を防ぐため、家の北側や西側に**防風林（屋敷林）**をつくってきた。
- 夏は南東の季節風で**蒸し暑い**。内陸の群馬・埼玉では、夏に**40℃をこえる**こともある。
- 都心では、ビルやアスファルト、車・エアコンの熱で、まわりより気温が高くなる **ヒートアイランド現象**。短い時間に狭い範囲で降る**局地的大雨（ゲリラ豪雨）**も起こりやすい。

</div>

### 3　首都東京と一極集中

<div class="point" markdown="1">
**なぜ東京に集まるのか ＝ 「中心」が全部そろっているから**<span class="deru">入試</span>

| 分野 | 東京にあるもの |
|---|---|
| **政治** | **国会議事堂・最高裁判所・中央省庁**（霞が関） |
| **経済** | 大企業の**本社**、銀行の本店、外国企業の日本支社 |
| **情報・文化** | テレビ局・新聞社・**出版社**（→**印刷業**がさかん）、美術館・博物館 |
| **教育** | 大学・専門学校が多い → 若い人が集まる |

- 人・もの・お金・情報が東京に集まりすぎること ＝ **一極集中**。

</div>

<div class="cols2" markdown="1">

**過密による問題**
- 朝夕の**通勤ラッシュ**、交通渋滞
- **地価（土地の値段）**が高い → 住宅が郊外へ
- **ごみ**の増加、**ヒートアイランド現象**
- 大地震のとき**帰宅困難者**が大量に出るおそれ

**解決への取り組み**
- **副都心**：新宿・渋谷・池袋（都心の機能を分ける）
- **新都心**：**みなとみらい21**（横浜）・**幕張新都心**（千葉）・**さいたま新都心**
- **筑波研究学園都市**（茨城）：研究機関を移した
- **再開発**：湾岸の埋立地にオフィスや**高層マンション** → 都心に住む人がまた増える（**都心回帰**）

</div>

<div class="point" markdown="1">
**昼間人口と夜間人口**<span class="deru">入試</span>

- **夜間人口**＝そこに**住んでいる**人の数（ふつうの人口）。
- **昼間人口**＝夜間人口 ＋（通勤・通学で**入ってくる**人）−（**出ていく**人）。
- **東京都心**（千代田区・中央区・港区など）：会社や学校が多い → **昼間人口 ＞ 夜間人口**。千代田区は昼間人口が夜間人口の10倍以上。
- **まわりの県**（神奈川・埼玉・千葉）：東京へ通う人が多い**ベッドタウン** → **昼間人口 ＜ 夜間人口**。
- **昼夜間人口比率**（％）＝ 昼間人口 ÷ 夜間人口 × 100。東京都は100を大きく上回り（約120）、神奈川・埼玉・千葉は100を下回る（約90）（2020年）。

</div>

### 4　関東の工業 ── 臨海部から内陸部へ

<div class="point" markdown="1">
**3つの工業地帯・地域**<span class="deru">入試</span>

| 名前 | 場所 | 特色 |
|---|---|---|
| **京浜工業地帯** | **東京・川崎・横浜**の東京湾岸 | **機械**が中心。東京は情報が集まるので**印刷業**、川崎・横浜の臨海部に**鉄鋼・石油化学**。かつては出荷額が日本一 → 工場の移転などで割合が下がった |
| **京葉工業地域** | 千葉県の東京湾岸の**埋立地** | **化学（石油化学）**の割合が高い（市原市のコンビナート）、**鉄鋼**（君津市・千葉市） |
| **北関東工業地域** | 群馬・栃木・茨城の**内陸** | **高速道路**沿いの**工業団地**。**自動車**（群馬県太田市）・**電気機械**（茨城県日立市）・食料品 |

- なぜ内陸へ？ → 東京湾岸は**土地が高く・せまい**／**高速道路**（関越・東北・常磐・北関東自動車道）ができてトラックで運びやすくなった／**地価が安く広い土地**がある。
- 北関東工業地域には、ブラジルなどから来た**外国人労働者**も多く働いている。

</div>

### 5　関東の農業・漁業 ── 大消費地に近い強み

<div class="point" markdown="1">
**近郊農業**＝大都市の近くで、**野菜・花・くだもの**などを作り、新鮮なうちに都市へ出荷する農業<span class="deru">入試</span>

- **長所**：①**新鮮**なまま届けられる　②**輸送費**が安い　③朝とってその日のうちに店に並ぶ。
- 茨城県・千葉県は、野菜の産出額が全国の上位。**保冷トラック**と**高速道路**で、遠くの産地とも競争している。
- **群馬県嬬恋村**：夏でもすずしい高原で**キャベツ**（**高原野菜**・**抑制栽培**）。
- **栃木県**：**いちご**（「とちおとめ」など）。**千葉県**：**落花生**。
- **畜産**：千葉・茨城・群馬などで、**豚・にわとり（鶏卵）・乳牛**。
- **漁業**：**銚子港**（千葉）は水あげ量が全国有数。親潮と黒潮がぶつかる**潮目**の近く。

### 7　関東地方の交通とこれから

- **成田国際空港**（千葉）：**貿易額が日本最大級の港**。**半導体・電子部品・医薬品**など、**小さくて軽く高価なもの**を航空機で運ぶ。<span class="deru">入試</span>
- **東京国際空港（羽田）**：国内線の中心。国際線も増えた。
- **東京湾アクアライン**（川崎〜千葉県木更津）、**圏央道**（都心から約40〜60kmを環状に結ぶ）→ 都心を通らずに移動でき、沿線に物流施設や工場が増えた。
- 課題：**首都直下地震**への備え（帰宅困難者・木造住宅の密集地）、都心の**過密**と、郊外の**高齢化**・空き家。

### 入試直前チェック

- **関東平野**＝日本最大の平野／**関東ローム**＝火山灰の赤土（台地は畑・住宅地）／**利根川**＝流域面積日本最大。
- 冬の**からっ風**＝かわいた北西の季節風 → 関東は冬に晴れて乾燥。
- **一極集中**と**過密**。対策は**副都心**・**新都心**（みなとみらい21・幕張・さいたま）・**筑波研究学園都市**。
- **昼間人口**：都心 ＞ 夜間人口、まわりの県（神奈川など）は ＜。比率 ＝ 昼間 ÷ 夜間 × 100。
- **京浜**＝機械・印刷（東京）／**京葉**＝**化学**が最大／**北関東**＝高速道路沿いの工業団地・自動車。
- **近郊農業**＝新鮮・輸送費が安い。**嬬恋村のキャベツ**、**栃木のいちご**、**千葉の落花生**。
- 神奈川：横浜（開港・**みなとみらい21**）・川崎（工業・公害の克服）・**三浦半島**（温暖・野菜・三崎のまぐろ）・箱根（火山・温泉）。
- **成田国際空港**＝貿易額最大級。軽くて高価なもの（電子部品など）。
