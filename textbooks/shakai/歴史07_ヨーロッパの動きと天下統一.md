# 中2歴史 歴史7「ヨーロッパ人の来航と天下統一（織田・豊臣）」

<p class="lead">対象：中学2年 歴史（小5から挑戦OK）｜十字軍・ルネサンス・宗教改革・大航海時代 → 鉄砲とキリスト教の伝来・南蛮貿易 → 織田信長・豊臣秀吉の天下統一 → 桃山文化</p>

### 1　中世ヨーロッパと十字軍

- 中世ヨーロッパでは **キリスト教**（**ローマ教皇**を頂点とする**カトリック教会**）が大きな力をもっていた。
- 11世紀、**イスラム勢力**（セルジューク朝）が聖地 **エルサレム** を支配 → ローマ教皇のよびかけで **十字軍** を派遣（**1096年〜**、約200年）。
- 結果：聖地の奪回は**失敗**。しかし、遠征によって **イスラム世界との交流** がさかんになり、進んだ学問（数学・医学など）や、イスラム世界に残っていた **古代ギリシャ・ローマの文化** がヨーロッパに伝わった。また、教皇の権威がおとろえ、**イタリアの都市**（ベネチア・ジェノバなど）が地中海貿易で栄えた。

<div class="point" markdown="1">
**POINT 1　なぜ→何が→どうなった：十字軍**

**なぜ**　イスラム勢力が聖地エルサレムを支配した　→　**何が**　ローマ教皇のよびかけで十字軍を送った　→　**どうなった**　奪回は失敗。でも **イスラム文化・古代ギリシャ・ローマ文化が流入** し、**ルネサンス**の土台に。

</div>

### 2　ルネサンス（文芸復興）

- **14世紀** ごろ **イタリア** の都市から始まり、ヨーロッパ各地に広がった。
- 意味：「**再生・復活**」。教会の教えにしばられず、**古代ギリシャ・ローマの文化を手本に、人間らしい生き方や個性を表現**しようとする動き。

| 人物 | 作品・業績 |
|---|---|
| **レオナルド・ダ・ビンチ** | 「**モナ・リザ**」「最後の晩さん」。科学・技術でも活躍 |
| **ミケランジェロ** | 「**ダビデ**」像、システィーナ礼拝堂の天井画 |
| ボッティチェリ | 「ビーナスの誕生」 |

- 科学技術の発達：**羅針盤**・**火薬**・**活版印刷術**（グーテンベルクが改良）が実用化 → **羅針盤は遠洋航海**、**活版印刷は宗教改革の考えを広める**のに役立った。<span class="deru">入試</span>
- **コペルニクス**らが **地動説** をとなえた（教会の天動説と対立）。

### 3　宗教改革

- **1517年**、ドイツの **ルター** が、ローマ教皇が資金集めのために **免罪符**（贖宥状）を売ることを批判 → 「**聖書だけが信仰のよりどころ**」と主張。
- スイスでは **カルバン** が改革を進めた。
- 改革を支持した人々 ＝ **プロテスタント**（「抗議する者」）。
- カトリック側も立て直し → **イエズス会** をつくり、**アジアやアメリカ大陸への布教** に力を入れた（→ ザビエルが日本へ）。<span class="deru">入試</span>

<div class="point" markdown="1">
**POINT 2　宗教改革とザビエル来日のつながり**

| | プロテスタント | カトリック |
|---|---|---|
| 中心 | ルター・カルバン | ローマ教皇・**イエズス会** |
| 考え | **聖書** 中心 | 教会・教皇の権威 |
| 広がった国 | ドイツ北部・イギリス・**オランダ** など | イタリア・**スペイン**・**ポルトガル** など |

ヨーロッパで信者が減ったカトリックは、**海外で信者を増やそう** とした → だから **スペイン・ポルトガルの船に宣教師が乗って** 日本へ来た。

</div>

### 5　鉄砲とキリスト教の伝来・南蛮貿易

<div class="point" markdown="1">
**POINT 3　2つの「伝来」**<span class="deru">入試</span>

| | 鉄砲 | キリスト教 |
|---|---|---|
| 年 | **1543年** | **1549年** |
| 場所 | **種子島**（鹿児島県） | **鹿児島** |
| だれが | 中国船に乗っていた **ポルトガル人** | **イエズス会** の宣教師 **フランシスコ・ザビエル**（スペイン出身） |
| その後 | **堺**（大阪）・**国友**（滋賀）などでさかんに生産 → **戦い方が変わり**（足軽の鉄砲隊）、**城のつくりも変わった**（石垣・天守）→ 全国統一を早めた | 西日本を中心に広まる。**キリシタン大名**（大友宗麟・有馬晴信・大村純忠ら）も現れ、**1582年 天正遣欧使節**（4人の少年）をローマ教皇のもとへ派遣 |

</div>

- **南蛮貿易**：ポルトガル人・スペイン人（＝**南蛮人**）との貿易。**長崎・平戸** などの港で行われた。

| 日本の輸入品 | 日本の輸出品 |
|---|---|
| **生糸**・絹織物（中国産）、**鉄砲**・**火薬**、時計・ガラス製品 | **銀**（石見銀山など。当時、世界の銀のかなりの部分を日本が産出） |

- 貿易と布教は一体 → 大名は **貿易の利益** をねらってキリスト教を保護することもあった。
- 宣教師は学校（コレジオ）や病院をつくり、信者を増やした。

### 6　織田信長の統一事業

- 尾張（愛知県西部）の戦国大名。
- **1560年 桶狭間の戦い**：駿河の **今川義元** を破る。
- 1568年 **足利義昭** を立てて京都に入る → **1573年 義昭を京都から追放 → 室町幕府がほろびる**。
- **1575年 長篠の戦い**：**鉄砲** を大量に使い、**武田勝頼**の騎馬隊を破る。<span class="deru">入試</span>
- **安土城**（滋賀県・琵琶湖のほとり）を築き、統一の拠点に。
- 仏教勢力との対立：**比叡山延暦寺** を焼き打ち（1571年）、**一向一揆** と戦い、**石山本願寺** を降伏させた（1580年）。
- 一方、**キリスト教は保護**（仏教勢力をおさえるため・南蛮貿易のため）。
- **1582年 本能寺の変**：家臣の **明智光秀** にそむかれ、京都の本能寺で自害。

<div class="point" markdown="1">
**POINT 4　信長の経済政策（なぜ → 何を → どうなった）**<span class="deru">入試</span>

| 政策 | 内容 | ねらい |
|---|---|---|
| **楽市・楽座** | 市での税を免除し、**座**（商工業者の同業組合）の **特権を廃止** → だれでも自由に商売できるように | **商工業をさかんにする**（城下町に人を集める） |
| **関所の廃止** | 各地の関所をなくす | **人や物の行き来**を自由に |
| **堺の支配** | 豊かな自治都市 **堺** を直接支配 | 経済力と **鉄砲** の確保 |

</div>

<div class="ex" markdown="1">
**史料**　安土山下町中掟書（1577年・一部）
「当所中楽市として仰せ付けらるるの上は、諸座・諸役・諸公事等、ことごとく免許の事」
（現代語訳）この安土の町は楽市とするので、座の特権・いろいろな税や負担は、すべて免除する。
</div>

### 7　豊臣秀吉の全国統一

- 信長の家臣。**明智光秀** を山崎の戦いで倒し、信長の後継者に。
- **大阪城** を築いて本拠地に（1583年〜）。**関白**（1585年）・**太政大臣** に任じられ、朝廷の権威も利用。
- **1590年**、小田原の **北条氏** をほろぼし、東北の大名も従えて **全国統一**。

<div class="point" markdown="1">
**POINT 5　太閤検地と刀狩 → 兵農分離**<span class="deru">入試</span>

| | **太閤検地**（1582年〜） | **刀狩**（1588年 刀狩令） |
|---|---|---|
| 内容 | **ものさし・ますを統一** し、全国の田畑の **面積・よしあし** を調べ、予想される収穫量を **石高**（米の量）で表した。耕作者を **検地帳** に登録 | 百姓から **刀・やり・鉄砲などの武器** を取り上げた |
| ねらい | **年貢を確実に取る**。百姓に土地の耕作権を認めるかわりに **年貢を納める義務** を負わせた | **一揆を防ぐ**。百姓を **農業に専念** させる |
| 結果 | 荘園の複雑な土地の権利が整理され、**荘園制は完全に消えた**。大名の領地も石高で表すように | 武士と百姓の区別がはっきり |

→ 2つをあわせて **兵農分離**（武士と農民の身分の区別）が進んだ。江戸時代の身分制度の土台になる。

</div>

<div class="ex" markdown="1">
**史料**　刀狩令（1588年・一部）
「諸国百姓、刀、脇指、弓、やり、てっぽう、其外武具のたぐい所持候事、堅く御停止候。」
（現代語訳）全国の百姓が、刀・脇差・弓・やり・鉄砲、その他の武器を持つことを、かたく禁止する。
※ 取り上げた刀は「大仏をつくるくぎなどに使う」とされた（＝百姓を納得させるための理由）。
</div>

- **キリスト教への政策**：はじめは保護 → 長崎がイエズス会に寄進されていたことなどを知り、**1587年 バテレン追放令**（宣教師の国外追放）。ただし **南蛮貿易は続けた** ので、取りしまりは不徹底。
- **朝鮮侵略**：明（中国）の征服をめざし、朝鮮に大軍を送る。**1592年 文禄の役**、**1597年 慶長の役**。朝鮮では **李舜臣** の水軍や民衆の抵抗、明の援軍にあい苦戦 → **1598年 秀吉の死** で撤退。
　影響：朝鮮の国土が荒れ、多くの人が犠牲に。豊臣氏の力が弱まる。日本へ連れてこられた朝鮮の陶工により **有田焼**（佐賀県）などの焼き物が始まった。

<div class="memo" markdown="1">
**先生のひとこと**　信長と秀吉、ごちゃまぜになりやすい！　**信長＝「壊す人」**（室町幕府・延暦寺・座・関所を壊して自由に）、**秀吉＝「整える人」**（検地・刀狩で身分と土地を整理）とキャラで分けよう。ちなみに家康まで入れた有名なたとえ「織田がつき　羽柴がこねし天下もち　座りしままに食うは徳川」も、この順番を覚えるのに便利だよ。
</div>

### 8　桃山文化

- 信長・秀吉の時代の文化。**大名や大商人** の **豪華で力強い** 文化。仏教の影響がうすれ、**南蛮文化** の影響も。

| 分野 | 人物・作品 |
|---|---|
| 建築 | **天守閣** をもつ巨大な城：**安土城**・**大阪城**・**姫路城**（世界遺産） |
| 絵画 | **狩野永徳**「**唐獅子図屏風**」。城のふすまや屏風に金ぱくを使った **障壁画** |
| 茶の湯 | **千利休** が **わび茶** を完成（質素・静かさを重んじる） |
| 芸能 | **出雲の阿国** が **かぶき踊り**（→ 歌舞伎のはじまり）。三味線にあわせた浄瑠璃 |
| 南蛮文化 | **活版印刷**（キリスト教の本・ローマ字の本）、地球儀、パン・カステラ・カルタ・タバコ、南蛮屏風 |
| 焼き物 | 朝鮮の陶工による **有田焼**・萩焼など |

<div class="memo" markdown="1">
**注意**　文化の比較はよく出る。**北山文化**（足利義満・金閣）／**東山文化**（足利義政・銀閣・書院造・水墨画）／**桃山文化**（信長・秀吉・城・狩野永徳・千利休）。「わび茶」は千利休、「水墨画」は雪舟（室町）と区別しよう。
</div>

### 入試直前チェック

- 十字軍の結果、**イスラム文化** や **古代ギリシャ・ローマ文化** が伝わり、**ルネサンス** の土台になった。
- **ルター（1517年）** は **免罪符** の販売を批判 → **プロテスタント**。カトリックは **イエズス会** で海外布教。
- 新航路開拓の目的は **香辛料** と **布教**。コロンブス（**1492**）・バスコ・ダ・ガマ（**1498**）・マゼラン船隊（**1522** 世界一周）。
- **1543年 鉄砲（種子島・ポルトガル人）**、**1549年 ザビエル（鹿児島）**。
- 南蛮貿易：輸入は **生糸・鉄砲・火薬**、輸出は **銀**。
- 信長：**桶狭間（1560）→ 室町幕府滅亡（1573）→ 長篠（1575・鉄砲）→ 本能寺の変（1582）**。**楽市・楽座** で商工業を活発に。
