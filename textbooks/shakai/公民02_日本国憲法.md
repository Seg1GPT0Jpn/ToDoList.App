# 中3公民 公民2「人権思想の歩みと日本国憲法の基本原理」

<p class="lead">対象：中学3年 公民（小5から挑戦OK）｜ロック・モンテスキュー・ルソー・人権の歴史・立憲主義と法の支配・大日本帝国憲法との比較・日本国憲法の3つの基本原理・天皇の国事行為・平和主義・憲法改正</p>

## 要点まとめ

<div class="memo" markdown="1">
**本質**　憲法は「**国民が国家（権力）をしばるための約束**」。ふつうの法律は国が国民に「〜しなさい」と命じるものだけど、憲法は向きが逆で、**国民が政府に「人権をおかすな」「勝手に権力を使うな」と命じるもの**。これが**立憲主義**。この単元はすべてこの一点につながっているよ。
</div>

### 1　人権思想を生んだ3人の思想家 <span class="deru">入試</span>

17〜18世紀のヨーロッパでは、国王が「王の権力は神から授けられたもの」（**王権神授説**）として、思うままに政治を行う**絶対王政**が続いていた。これに対して、「人は生まれながらに自由で平等な権利（**自然権**）をもつ」という考えが生まれた。

| 思想家 | 国 | 著書（年） | おもな主張 | 影響 |
|---|---|---|---|---|
| **ロック** | イギリス | 『**統治二論**』（1690年） | 政府は人々の自然権を守るためにつくられる。政府が権利をおかしたら、人々は**抵抗する権利**（抵抗権）をもつ | **アメリカ独立宣言** |
| **モンテスキュー** | フランス | 『**法の精神**』（1748年） | 権力を**立法・行政・司法**に分け、たがいに抑制させる＝**三権分立** | アメリカ合衆国憲法など |
| **ルソー** | フランス | 『**社会契約論**』（1762年） | 社会は人々の契約で成り立ち、主権は人民にある＝**人民主権** | **フランス革命** |

<div class="memo" markdown="1">
**先生のひとこと**　覚え方は「**ロック＝抵抗、モンテ＝三権、ルソー＝人民**」。モンテスキューは「権力は1人にまとめると必ず暴走する。だから**3つに分けて見張らせよう**」と考えた。クラスの係を1人に全部やらせると、ズルし放題になるのと同じだね。
</div>

### 2　人権の歴史（年表）<span class="deru">入試</span>

| 年 | できごと（国） | ポイント |
|---|---|---|
| 1215 | **マグナ・カルタ**（イギリス） | 貴族が国王の権力を制限。法の支配の出発点 |
| 1689 | **権利章典**（イギリス） | **名誉革命**の後。議会の同意なしに課税や法律の停止をしてはならない → **議会政治**の基礎 |
| 1776 | **独立宣言**（アメリカ） | 「すべての人は平等につくられ」、生命・自由・幸福追求の権利をもつ。ロックの影響 |
| 1789 | **人権宣言**（フランス） | **フランス革命**の中で発表。「人は生まれながらに自由で、権利において平等」。国民主権 |
| 1919 | **ワイマール憲法**（ドイツ） | 「すべての人に**人間に値する生活**を保障」＝**社会権（生存権）を初めて保障** |
| 1948 | **世界人権宣言**（国際連合） | 各国が達成すべき人権の共通の基準 |
| 1966 | **国際人権規約**（国際連合） | 世界人権宣言に**法的な拘束力**をもたせた条約 |

<div class="memo" markdown="1">
**本質**　18世紀に勝ち取った人権は「**国家からの自由**」＝**自由権**（国は口出しするな）。ところが19世紀に産業革命が進むと、自由な競争の結果、**貧富の差・長時間労働**が広がった。そこで20世紀には「**国家による自由**」＝**社会権**（国は人間らしい生活を保障せよ）が生まれた。その最初が**ワイマール憲法**。「自由権→社会権」の順番と理由は入試の記述で問われるよ。
</div>

- **法の支配**：権力者も、国民の代表がつくった**法に従わなければならない**という考え方。
- **立憲主義**：**憲法によって国の権力を制限し、国民の人権を守る**という考え方。
- **憲法は国の最高法規**：憲法に反する法律や命令は効力をもたない。

<div class="point" markdown="1">
**POINT 1　条文で見る立憲主義**

**第98条①**　この憲法は、国の最高法規であつて、その条規に反する法律、命令、詔勅及び国務に関するその他の行為の全部又は一部は、その効力を有しない。

**第99条**　天皇又は摂政及び国務大臣、国会議員、裁判官その他の公務員は、この憲法を尊重し擁護する義務を負ふ。

- 法の強さの順：**憲法 ＞ 法律（国会）＞ 命令（政令＝内閣、省令＝各省）＞ 条例（地方議会。法律の範囲内）**
- 第99条で憲法を守る義務を負うのは、**権力をもつ側（公務員など）**で、**「国民」は入っていない**。憲法は**権力をしばるもの**だから。<span class="deru">入試</span>

</div>

### 4　大日本帝国憲法と日本国憲法の比較 <span class="deru">入試</span>

| | **大日本帝国憲法** | **日本国憲法** |
|---|---|---|
| 公布・施行 | 1889年2月11日公布、1890年11月29日施行 | **1946年11月3日**公布、**1947年5月3日**施行 |
| つくった人 | **天皇**が定めて国民にあたえる（**欽定憲法**） | **国民**が定める（**民定憲法**） |
| 主権 | **天皇** | **国民** |
| 天皇の地位 | 神聖不可侵。国の**元首**として**統治権**をもつ | 日本国と日本国民統合の**象徴** |
| 国民の権利 | 「臣民の権利」として**法律の範囲内**で認められる | 侵すことのできない**永久の権利**（基本的人権） |
| 軍隊 | 天皇が軍隊を指揮する（**統帥権**）。国民に**兵役の義務** | **戦争の放棄**・戦力の不保持（第9条） |
| 国会（議会） | 帝国議会（**貴族院**と衆議院）。天皇の協賛機関 | **国権の最高機関**、唯一の立法機関（衆議院と**参議院**） |
| 内閣 | 各大臣が天皇を助ける（輔弼）。憲法に内閣の規定なし | 国会に対して責任を負う（**議院内閣制**） |
| 裁判所 | 天皇の名において裁判を行う | **司法権の独立** |
| 地方自治 | 規定なし | 規定あり（第8章） |
| 改正 | 天皇が発議し、帝国議会が議決 | **国会が発議**し、**国民投票**で承認 |

- 日本国憲法の制定：1945年に**ポツダム宣言**を受け入れて降伏 → **GHQ**（連合国軍総司令部）が憲法改正を指示 → 日本政府の案は天皇主権を残していたため、GHQが草案を作成 → それをもとにした政府案を**帝国議会**で審議・修正して成立。
- 11月3日は「**文化の日**」、5月3日は「**憲法記念日**」。

<div class="ex" markdown="1">

**前文（一部）**　日本国民は、正当に選挙された国会における代表者を通じて行動し、われらとわれらの子孫のために、諸国民との協和による成果と、わが国全土にわたつて自由のもたらす恵沢を確保し、政府の行為によつて再び戦争の惨禍が起ることのないやうにすることを決意し、ここに主権が国民に存することを宣言し、この憲法を確定する。

**第11条**　国民は、すべての基本的人権の享有を妨げられない。この憲法が国民に保障する基本的人権は、侵すことのできない永久の権利として、現在及び将来の国民に与へられる。

- **国民主権**：国民が**代表者（国会議員）を選挙**して政治を行う＝**間接民主制**（議会制民主主義）が中心。直接国民が決めるもの：**憲法改正の国民投票**・最高裁判所裁判官の**国民審査**・地方の住民投票など。

### 6　天皇の地位と国事行為 <span class="deru">入試</span>

<div class="point" markdown="1">
**POINT 2　象徴天皇制**

**第1条**　天皇は、日本国の象徴であり日本国民統合の象徴であつて、この地位は、主権の存する日本国民の総意に基く。

**第3条**　天皇の国事に関するすべての行為には、内閣の助言と承認を必要とし、内閣が、その責任を負ふ。

**第4条①**　天皇は、この憲法の定める国事に関する行為のみを行ひ、国政に関する権能を有しない。

- **国事行為**：憲法に定められた、政治に関係しない形式的・儀礼的な仕事。必ず**内閣の助言と承認**が必要で、**責任は内閣**が負う。

| 国事行為のおもな例 | 実際に決めるのは |
|---|---|
| **内閣総理大臣の任命**（第6条） | **国会**が指名 |
| **最高裁判所長官の任命**（第6条） | **内閣**が指名 |
| 憲法改正・法律・政令・条約の**公布** | 国会・内閣 |
| **国会の召集**、**衆議院の解散** | 内閣 |
| 国務大臣の任免の認証、**栄典の授与**、外国の大使・公使の接受、儀式を行う | 内閣 |

</div>

<div class="memo" markdown="1">
**注意**　「条約を**結ぶ**（締結）」のは**内閣**、「条約を**承認**」するのは**国会**、天皇は条約を「**公布**」するだけ。「任命」と「指名」もセットで区別しよう。天皇が政治の中身を決めない理由は、**主権が国民にあるから**。天皇が政治的な力をもつと、戦前のように国民の代表のコントロールがきかなくなるおそれがあるからだね。
</div>

### 7　平和主義 <span class="deru">入試</span>

<div class="point" markdown="1">
**POINT 3　第9条**

**第9条①**　日本国民は、正義と秩序を基調とする国際平和を誠実に希求し、国権の発動たる戦争と、武力による威嚇又は武力の行使は、国際紛争を解決する手段としては、永久にこれを放棄する。
**②**　前項の目的を達するため、陸海空軍その他の戦力は、これを保持しない。国の交戦権は、これを認めない。

- キーワード：**戦争の放棄**・**戦力の不保持**・**交戦権の否認**。

</div>

- **自衛隊**：1950年の警察予備隊 → 1952年保安隊 → **1954年に自衛隊**。政府は「**自衛のための必要最小限度の実力**」は憲法が禁じる戦力にあたらないと説明。災害派遣でも活躍。
- **日米安全保障条約**：**1951年**、サンフランシスコ平和条約と同時に結ぶ（1960年に改定）。日本の領域が攻撃されたら日米が共同で対応し、日本は**アメリカ軍の駐留**を認める。在日米軍専用施設の面積の**約7割が沖縄県**に集中。
- **非核三原則**：核兵器を「**持たず、つくらず、持ちこませず**」（1971年に国会で決議）。日本は唯一の**被爆国**として核兵器の廃絶をうったえる。
- **PKO（国連平和維持活動）**：1992年に**PKO協力法**、同年カンボジアに自衛隊を派遣。
- **集団的自衛権**：同盟国が攻撃されたとき、自国が攻撃されていなくても共に防衛する権利。2014年に政府が**限られた場合に行使できる**と解釈を変え、2015年に安全保障関連法が成立。
- **文民統制**（シビリアン・コントロール）：自衛隊の最高指揮権は**内閣総理大臣**。内閣総理大臣と国務大臣は**文民**（軍人でない人）でなければならない（第66条②）。

**第96条①**　この憲法の改正は、各議院の総議員の三分の二以上の賛成で、国会が、これを発議し、国民に提案してその承認を経なければならない。この承認には、特別の国民投票又は国会の定める選挙の際行はれる投票において、その過半数の賛成を必要とする。

<div class="point" markdown="1">
**POINT 4　なぜ憲法改正はふつうの法律より難しいのか（しくみの理由）**

- 法律は、国会で**出席議員の過半数**の賛成で成立する。憲法改正は「**総議員の3分の2以上**」＋「**国民投票**」が必要で、ずっと厳しい（このような憲法を**硬性憲法**という）。
- 理由：憲法は**国の最高法規**であり、**権力をしばって人権を守る**ためのもの。そのときどきの多数派や権力者の都合で、簡単に人権を制限する方向へ変えられないようにするため。そして最後は**主権者である国民が直接決める**（国民主権）。
- 国民投票の具体的な手続きは**国民投票法**（2007年制定）で定められている。日本国憲法は、これまで一度も改正されていない（2025年まで）。

- 大日本帝国憲法＝**欽定**・天皇主権・法律の範囲内の権利。日本国憲法＝**民定**・国民主権・永久の権利。
- 日本国憲法 **1946.11.3公布、1947.5.3施行**。
- 天皇は**象徴**。国事行為には**内閣の助言と承認**、責任は**内閣**。
- 9条＝**戦争の放棄・戦力の不保持・交戦権の否認**。非核三原則＝持たず・つくらず・持ちこませず。
- 改正＝各議院の**総議員の3分の2以上**で国会が**発議** → **国民投票で過半数** → **天皇が国民の名で公布**。
