# 中1地理 地理3「アジア州」

<p class="lead">対象：中学1年 地理（小5から挑戦OK）｜アジアの自然と季節風・稲作・中国・韓国・東南アジア（ASEAN）・南アジア（インド）・西アジアと中央アジア（石油）</p>

## 要点まとめ

### 1　アジアの自然と季節風（モンスーン）

- アジア州は**世界の人口の約6割**がくらす州。面積も最大（ユーラシア大陸の大部分）。
- 地形：**ヒマラヤ山脈**（世界最高峰エベレスト）・**チベット高原**＝「世界の屋根」。ここから**長江（チャンチアン）・黄河（ホワンホー）・メコン川・ガンジス川・インダス川**などの大河が流れ出す。大河の下流には**平野**が広がり、人口が集中する。
- 気候：東アジア・東南アジア・南アジアの海沿いは**季節風（モンスーン）**の影響で**雨が多い**。西アジア・中央アジアは**乾燥帯**が広い。

<div class="point" markdown="1">
**POINT 1　季節風（モンスーン）＝季節によって向きが変わる風**<span class="deru">入試</span>

- **夏**：海から大陸へ向かって吹く → **海の湿った空気**を運ぶ → **雨季**（大雨）
- **冬**：大陸から海へ向かって吹く → **乾いた風** → **乾季**
- 夏の季節風の向き：南アジア・東南アジアでは**南西**から、東アジア（日本など）では**南東**から。

### 2　季節風と稲作 ＝ アジアは「米の大陸」

- 稲は**高温で、たくさんの水**が必要 → 夏に季節風が大雨を降らせる東・東南・南アジアで**稲作**がさかん。
- 1年に2回同じ作物（米）をつくる**二期作**（東南アジアの大河のデルタなど）。
- 雨の少ない地域では**小麦**（中国北部・インド北西部）、乾燥地域では**牧畜**（遊牧）。

| 米の生産（2022年） | 世界での割合（約） |
|---|---|
| 1位 **中国** | 27% |
| 2位 **インド** | 25% |
| 3位 バングラデシュ | 7% |
| 4位 インドネシア | 7% |
| 5位 ベトナム | 5% |

- 上位はすべてアジアの国。**中国とインドだけで世界の半分以上**。<span class="deru">入試</span>
- ただし**輸出**の1位は**インド**、続いて**タイ・ベトナム**など。中国は生産1位でも、人口が多く**国内で食べる**ので輸出は少ない。

### 3　中国（中華人民共和国）

**(1) 人口と民族**
- 人口は約14億人（2023年にインドにぬかれて世界2位）。**漢族（漢民族）が約9割**、ほかに**55の少数民族**（チョワン族・ウイグル族・チベット族・モンゴル族など）。少数民族の多い地域は**自治区**。
- **一人っ子政策**（1979〜2015年）：人口の急増をおさえるため、一組の夫婦の子どもを原則1人に制限した。
　→ 人口の増加はおさえられたが、**少子高齢化**が急速に進んだ → 2016年から2人まで、2021年から3人までに緩和。<span class="deru">入試</span>

**(2) 経済の発展 ＝「世界の工場」**
- 1970年代末から**改革開放**政策：外国の資本と技術を受け入れる。
- **経済特区**：外国企業を招くため、税金を安くするなどの優遇をした地区。**シェンチェン（深圳）**・アモイなど**南部の沿岸部**に設けられた。<span class="deru">入試</span>
- 安くて豊富な労働力 → 衣類・電気製品・パソコンなどを大量生産 → 「**世界の工場**」。現在は人々が豊かになり、多くのものを買う「**世界の市場**」にも。
- 課題：**沿岸部と内陸部の経済格差**（内陸から沿岸の都市へ出かせぎ）→ 内陸の開発を進める**西部大開発**。**大気汚染**などの環境問題。

### 4　韓国（大韓民国）

- 1960年代から工業化が急速に進み、台湾・ホンコン・シンガポールとともに**アジアNIES（新興工業経済地域）**とよばれた。
- 現在は**半導体**・スマートフォン・自動車・造船などの**先端技術産業**がさかん。音楽やドラマなどの文化も世界に広がる。
- 首都**ソウル**とその周辺に人口の約半分が集中（**一極集中**）。
- 文化：文字は**ハングル**。**儒教**の教えが生活に根づき、年長者を敬う。キリスト教の信者も多い。冬の寒さに合わせた床暖房**オンドル**、キムチなどの保存食。

### 5　東南アジア

**(1) 自然と農業**
- 大部分が**熱帯**。メコン川・チャオプラヤ川などの下流で**稲作**（二期作）。**タイ・ベトナム**は米の輸出国。
- **プランテーション**：植民地時代に欧米の人々が開いた、輸出用の作物を大規模に栽培する農園。<span class="deru">入試</span>

| 作物 | おもな生産国 | メモ |
|---|---|---|
| **天然ゴム** | **タイ**（世界1位）・インドネシア | タイヤなどの原料 |
| **油やし**（パーム油） | **インドネシア・マレーシア**（2国で世界の8割以上） | 食用油・せっけん。農園開発で熱帯林が減少 |
| **バナナ** | フィリピン（ミンダナオ島） | 日本へ多く輸出 |
| **コーヒー** | ベトナム（世界2位） | |

**(2) 工業化とASEAN**
- 1980年代以降、各国が**工業団地**をつくり、外国企業（日本企業も多い）を招いた → 安い労働力で電気製品・自動車などを生産・輸出。
- **ASEAN（東南アジア諸国連合）**：1967年に5か国で結成。現在は東南アジアのほぼすべての国が加盟（2025年に東ティモールが加わり11か国）。加盟国間の**関税をなくし**、経済・政治で協力。<span class="deru">入試</span>
- **華人**：中国から移り住んだ人々とその子孫。商業などで経済に大きな力をもつ（シンガポールでは人口の約4分の3）。
- 都市に人口が集まり、交通渋滞や**スラム**（生活環境の悪い地区）が問題に。

| タイの輸出品（上位） | 1位 | 2位 | 3位 |
|---|---|---|---|
| 1980年 | 米 | 野菜（キャッサバなど） | 天然ゴム |
| 2022年 | **機械類** | **自動車** | （工業製品が続く） |

→ 農産物中心から**工業製品中心**へ。これが「工業化」の証拠。<span class="deru">入試</span>

**(3) 宗教**：**インドネシア・マレーシア＝イスラム教**、**タイ＝仏教**、**フィリピン＝キリスト教（カトリック）**（スペインの植民地だったため）。

### 6　南アジア（インドなど）

- インドの人口は世界1位（2023年〜）。**ヒンドゥー教**徒が約8割（牛を神聖視、ガンジス川で沐浴）。パキスタン・バングラデシュは**イスラム教**、スリランカは**仏教**が多い。
- 農業：降水量で作物が分かれる。

| 地域 | 自然条件 | 作物 |
|---|---|---|
| ガンジス川下流・東部（バングラデシュなど） | 降水量が多い | **稲**、**ジュート**（麻袋の原料） |
| 北西部（パンジャブ地方） | 降水量が少なめ（かんがいを利用） | **小麦** |
| デカン高原 | 綿花の栽培に適した黒い土 | **綿花** |
| アッサム地方・スリランカ | 雨が多く、水はけのよい丘 | **茶** |

<div class="point" markdown="1">
**POINT 2　インドでICT（情報通信技術）産業が発展した理由**<span class="deru">入試</span>

1. **英語**を話せる人が多い（かつて**イギリスの植民地**だった）→ アメリカ企業と仕事がしやすい。
2. **数学の教育**に力を入れ、優秀な技術者が多い。賃金がアメリカなどより**安い**。
3. アメリカとの**時差が約半日** → アメリカが夜の間にインドで仕事を進め、**24時間**作業を続けられる。
4. 新しい産業なので、身分制度（**カースト**）による職業の制限を受けにくい。
- 中心都市は南部の**ベンガルール（バンガロール）**。自動車工業も成長している。

</div>

### 7　西アジア・中央アジア

- 大部分が**乾燥帯**（砂漠・ステップ）。**オアシス**で**なつめやし**や小麦、らくだ・羊の**遊牧**。
- **イスラム教**が広く信仰され、アラビア語を話す人が多い。聖地**メッカ**はサウジアラビアにある。
- **ペルシア湾**沿岸は世界有数の**石油（原油）**の産地。サウジアラビア・アラブ首長国連邦（UAE）・クウェート・イラン・イラクなど。
- **OPEC（石油輸出国機構）**：1960年、産油国が結成。原油の生産量や価格に大きな影響力をもつ。<span class="deru">入試</span>
- 石油で得た資金で道路・空港・高層ビルなどを建設（UAEの**ドバイ**など）。石油はいつかなくなるので、**観光・金融**など石油にたよらない産業の育成も進める。工事などで**外国人労働者**が多い。
- **日本は原油の9割以上を西アジア（中東）から輸入**（2022年。サウジアラビアとUAEがそれぞれ約4割）。<span class="deru">入試</span>
- **中央アジア**（カザフスタン・ウズベキスタンなど）：かつて**ソ連**の一部。石油・天然ガスや、**レアメタル**（希少金属。スマートフォンなどに使う）が豊富。綿花栽培のかんがいで川の水を使いすぎ、**アラル海が大きく縮小**した。
