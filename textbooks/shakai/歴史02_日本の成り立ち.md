# 中1歴史 歴史2「日本の成り立ち（旧石器・縄文・弥生・古墳）」

<p class="lead">対象：中学1年 歴史（小5から挑戦OK）｜旧石器時代と岩宿遺跡／縄文時代と三内丸山遺跡／稲作と身分・くにの成立／中国の歴史書に見える倭（奴国・卑弥呼）／古墳と大和政権／渡来人</p>

## 要点まとめ

### 0　この単元の大きな流れ

<div class="point" markdown="1">
**POINT 1　「食べ物の手に入れ方」が社会を変えた**<span class="deru">入試</span>

| 時代 | 食料 | 道具 | 社会のようす |
|---|---|---|---|
| **旧石器時代** | 狩り・採集（大型動物を追う） | **打製石器** | 移動生活。身分の差なし |
| **縄文時代** | 狩り・漁・採集（木の実・貝・魚） | **縄文土器**・磨製石器・弓矢 | 定住（**たて穴住居**）。身分の差・貧富の差は**ほとんどない** |
| **弥生時代** | **稲作**（米づくり）が広まる | **弥生土器**・**石包丁**・**青銅器**・**鉄器** | 米をたくわえる → **貧富と身分の差** → 争い → **くに**ができる |
| **古墳時代** | 稲作がさらに広まる | **須恵器**・鉄器 | 各地の豪族が**古墳**をつくる → **大和政権**が各地を従える |

なぜ？→ 米は**たくわえられる** → たくさん持つ人と持たない人ができる → 土地や水をめぐって**争い** → 強いむらが弱いむらを従え、**くに**（小さな国）になる → くにがまとまって**大きな国**へ。

</div>

### 1　旧石器時代 ── 日本列島は大陸と陸続きだった

- **氷河時代**は海面が今より低く、日本列島は**大陸と陸続き**。**ナウマンゾウ**や**オオツノジカ**などを追って人々がやってきた（長野県の**野尻湖**で化石や石器が見つかっている）。
- **岩宿遺跡**（**群馬県**）：**相沢忠洋**が1946年ごろ、関東ローム層（火山灰の地層）から**打製石器**を発見。→ **日本にも旧石器時代があった**ことが証明された。<span class="deru">入試</span>
- 約1万年前、氷河時代が終わって海面が上がり、**今の日本列島の形**ができた。

### 2　縄文時代（約1万数千年前〜）

- **縄文土器**：表面に**縄目の文様**があることが多い。**厚手で黒褐色**。食べ物を煮たり、たくわえたりする。
- **たて穴住居**：地面を掘り下げて柱を立て、屋根をかけた家。むらをつくって**定住**。
- **貝塚**：食べた貝のからや動物の骨などを捨てた場所。当時の食生活がわかる。**大森貝塚**（東京都）は1877年にアメリカ人の**モース**が発見。
- **土偶**：土でつくった人形（女性の形が多い）。**豊かな実りや安産、魔よけ**を祈ったと考えられる。
- **三内丸山遺跡**（**青森県**）：大きな集落あと。**大型の掘立柱建物**のあと、**クリの栽培**、遠くの地域との**交易**（新潟県産のヒスイ、北海道産の黒曜石）のあとが見つかった。→ 縄文人は思った以上に豊かで、広く交流していた。<span class="deru">入試</span>

<div class="memo" markdown="1">
**先生のひとこと**　縄文の「縄」は土器の模様のこと。土器ができると、ドングリのアクを煮てぬいたり、貝を煮たりできて、**食べられる物が一気に増えた**。土器は縄文人にとっての「最新の調理家電」だったんだ。
</div>

### 3　弥生時代（紀元前4世紀ごろ〜）── 稲作が社会を変えた

- **稲作**が**大陸（中国・朝鮮半島）から九州北部**に伝わり、やがて東日本まで広まる。
- **石包丁**：稲の**穂先をつみ取る**道具。　**高床倉庫**：収穫した**米をたくわえる**倉庫（床を高くして湿気とネズミを防ぐ）。<span class="deru">入試</span>
- **弥生土器**：**うすくてかたく、赤褐色**。東京都文京区の**弥生町**で発見されたので「弥生」。
- **金属器**が大陸から伝わる。
　**青銅器**（**銅鐸**・銅剣・銅矛・銅鏡）→ おもに**祭り**の道具。
　**鉄器** → **農具・工具・武器**など実用の道具。
- **登呂遺跡**（静岡県）：水田あと・高床倉庫あと。
- **吉野ヶ里遺跡**（**佐賀県**）：まわりを**堀やさく**で囲んだ大きな集落（**環濠集落**）。物見やぐらのあと、首のない人骨や矢じりのささった人骨 → **むらどうしの争い**があった証拠。<span class="deru">入試</span>

<div class="cols2" markdown="1">

| | **縄文土器** | **弥生土器** |
|---|---|---|
| 厚さ | 厚手 | うす手 |
| 色 | 黒褐色 | 赤褐色 |
| かたさ | もろい | かたい |
| 文様 | 縄目など | 少ない |

| | **青銅器** | **鉄器** |
|---|---|---|
| おもな使い道 | **祭り**（宝物） | **実用**（農具・武器） |
| 例 | 銅鐸・銅剣・銅鏡 | くわ先・刀・斧 |

</div>

### 4　中国の歴史書に見える日本（倭）<span class="deru">入試</span>

当時の日本には**文字の記録がない**。だから、中国の歴史書が日本のようすを知る手がかりになる。中国では日本を「**倭**」、日本人を「倭人」とよんだ。

| 歴史書 | 時期 | 書かれていること |
|---|---|---|
| 『**漢書**』地理志 | 紀元前1世紀ごろ | 倭は**100余りの国**に分かれ、定期的に漢（楽浪郡）に使いを送っていた |
| 『**後漢書**』東夷伝 | **57年** | **奴国**（今の福岡市付近）の王が後漢に使いを送り、皇帝（光武帝）から**金印**を授けられた |
| 『**魏志**』倭人伝 | 3世紀 | **邪馬台国**の女王**卑弥呼**が**30ほどの国**を従えた。**239年**、**魏**に使いを送り「**親魏倭王**」の称号と金印、銅鏡などを授けられた |
| 『**宋書**』倭国伝 | 5世紀 | **倭の五王**（讃・珍・済・興・武）が中国の南朝（宋）に使いを送った |

- 金印は江戸時代（1784年）に**福岡県の志賀島**で発見された。「**漢委奴国王**」と刻まれている。
- **なぜ中国に使いを送った？** 中国の皇帝から**王と認めてもらう**ことで、ほかのくにより優位に立ち、**鉄や鏡などの進んだ品**を手に入れるため。

<div class="memo" markdown="1">
**発展**　史料を読もう（『魏志』倭人伝の一部。漢文を書き下したもの）。
「其の国、本亦男子を以て王と為す。住まること七、八十年。倭国乱れ、相攻伐すること歴年、乃ち共に一女子を立てて王と為す。名づけて卑弥呼と曰ふ。鬼道に事へ、能く衆を惑はす。」
（訳：その国も、もとは男の王がいた。70〜80年たったころ、倭国は乱れ、何年も攻め合った。そこで国々は相談して一人の女性を王にした。名を卑弥呼という。まじない（占い）を行い、人々をうまく従わせた。）
→ 争いを終わらせるために、**国々が共同で女王を立てた**こと、卑弥呼が**宗教的な力**で治めたことが読み取れる。邪馬台国の場所は、**近畿説**と**九州説**があり、まだ決着していない。
</div>

### 5　古墳と大和政権（3世紀後半〜）

- **古墳**：王や豪族の大きな墓。3世紀後半から、**近畿地方**を中心に各地につくられた。
- **前方後円墳**：前が四角（方）、後ろが円い形。日本独特の形。<span class="deru">入試</span>
- **大仙（大山）古墳**（**大阪府堺市**）：全長が約500mもある、**日本最大**の前方後円墳（**仁徳天皇の墓**と伝えられる）。2019年に「**百舌鳥・古市古墳群**」として**世界文化遺産**に。
- **はにわ**：古墳の上やまわりに並べられた**素焼きの焼き物**（人・馬・家・円筒など）。
- 古墳の中には**鏡・玉・鉄の武器やよろい**などの**副葬品**。

<div class="point" markdown="1">
**POINT 2　大和政権（ヤマト王権）**<span class="deru">入試</span>

- 3世紀後半、**奈良盆地（大和）を中心とする近畿地方**の有力な豪族たちが連合してつくった勢力。王は**大王**（のちの天皇）。
- **5世紀**には、**九州地方から東北地方南部**までの豪族を従えた。
　証拠：**稲荷山古墳**（**埼玉県**）の**鉄剣**と、**江田船山古墳**（**熊本県**）の**鉄刀**に、どちらも「**ワカタケル大王**」の名が刻まれている。→ 東と西の遠く離れた地域が、同じ大王に従っていた。
- **朝鮮半島**とのかかわり：**高句麗・百済・新羅**と小国の集まり**伽耶（加羅）地域**。大和政権は**鉄**を求めて**百済や伽耶**と結び、**高句麗**と戦った（好太王碑に記録）。
- **倭の五王**が中国の**南朝（宋）**に使いを送り、朝鮮半島での立場を有利にしようとした。五王の「**武**」は**ワカタケル大王（雄略天皇）**と考えられている。

</div>

### 6　渡来人 ── 大陸の技術と文化を伝えた人々

- 戦乱をさけて、**中国や朝鮮半島から日本に移り住んだ人々**を**渡来人**という。大和政権は渡来人を重く用い、記録や外交、財政などを担当させた。
- 伝えたもの：<span class="deru">入試</span>
　**須恵器**（のぼり窯で高温で焼いた、**かたくて灰色**の土器）・**機織り**・土木技術（ため池づくり）・鉄器づくり
　**漢字**・**儒教（儒学）**・**仏教**（6世紀に**百済**から正式に伝わる）

<div class="memo" markdown="1">
**先生のひとこと**　渡来人は、今でいう「海外から来たエンジニアとIT担当」。文字（漢字）が読み書きできる人がいなかったら、外交の手紙も税の記録もつくれない。**大和政権が強くなれた理由の一つ**が渡来人なんだ。
</div>
