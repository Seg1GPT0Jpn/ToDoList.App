## 要点まとめ

### 1　気候は「気温」と「降水量」で決まる

- **気候**：ある場所で毎年くり返される、1年間の天気の平均的なようす。**気温**と**降水量**の2つで特徴をつかむ。
- 気候は、まず**緯度**で大きく決まる。赤道付近は太陽が真上近くから照るので暑く、極に近いほど光がななめに当たるので寒い。
- 同じ緯度でも、**海からの距離・風・海流・標高**で気候は変わる。
　海の近く → 年較差が小さい（海は温まりにくく冷めにくい）／大陸の内陸 → 年較差が大きい／標高が高い → 気温が低い（**100m上がるごとに約0.6℃下がる**）
- **南半球は季節が北半球と逆**。1月ごろが夏、7月ごろが冬。<span class="deru">入試</span>

<div class="memo" markdown="1">
**本質**　この単元は「**自然条件（気候）→ 手に入るもの（植物・材料・作物）→ 生活（衣食住）**」の順に考えるのがコツ。たとえば「雨が少ない → 木が育たない → 木材がない → 土で家をつくる」。理由のくさりをつなげれば、暗記しなくても答えが出せるようになるよ。
</div>

### 2　5つの気候帯と気候区<span class="deru">入試</span>

| 気候帯 | 気候区 | 特徴（植物のようす） | 代表的な都市 |
|---|---|---|---|
| **熱帯** | **熱帯雨林気候** | 1年中高温で雨が多い。夕方に**スコール**（短時間の強い雨）（**熱帯雨林**＝密林） | シンガポール |
| | **サバナ気候** | 1年中高温。**雨季**と**乾季**がある（草原にまばらな木＝**サバナ**） | バンコク |
| **乾燥帯** | **砂漠気候** | 雨がほとんど降らない。昼と夜の気温差が大きい（砂漠。水がわく所は**オアシス**） | カイロ・リヤド |
| | **ステップ気候** | 短い雨季がある（丈の短い草原＝**ステップ**） | 砂漠のまわり |

| 気候帯 | 気候区 | 特徴（植物のようす） | 代表的な都市 |
|---|---|---|---|
| **温帯** | **温暖湿潤気候** | 四季がはっきり。夏は高温で雨が多い | 東京・シャンハイ |
| | **西岸海洋性気候** | 夏すずしく、冬も高緯度のわりに温暖。1年中平均して雨（牧草地が多い） | ロンドン・パリ |
| | **地中海性気候** | **夏に乾燥**し、**冬に雨**（オリーブなど乾燥に強い木） | ローマ・パース |
| **冷帯（亜寒帯）** | — | 冬は長く寒さがきびしいが、夏は気温が上がる（**タイガ**＝針葉樹の森） | モスクワ |
| **寒帯** | **ツンドラ気候** | 短い夏だけ地表の氷がとける（こけ類・草） | バロー |
| | **氷雪気候** | 1年中、氷と雪におおわれる（植物はほとんどない） | 南極・グリーンランド内陸 |

- このほか、標高が高い所には **高山気候**（例：アンデス山脈の**クスコ**、チベット高原）。**1年中すずしく、年較差が小さい**。
- **冷帯は北半球にしかない**（南半球の高緯度には大きな陸地がなく、海が広がるため）。<span class="deru">入試</span>
- 気候帯は赤道を中心に、南北へ「熱帯 → 乾燥帯 → 温帯 → 冷帯 → 寒帯」とおおよそ**帯のように**並ぶ。乾燥帯は**回帰線（緯度20〜30度）付近**と**大陸の内陸**に多い。

<div class="memo" markdown="1">
**発展**　なぜ緯度20〜30度に砂漠が多いのか。赤道付近で温められた空気は上へのぼって雨を降らせ、乾いた空気になって緯度20〜30度あたりで下りてくる。下りてくる空気は雲ができにくいので、雨が少ない。サハラ砂漠やアラビア半島の砂漠がこの位置にあるのはこのため（高校の地理で「亜熱帯高圧帯」として学ぶ）。
</div>

### 3　雨温図の読み方

<div class="point" markdown="1">
**POINT 1　雨温図のきまり**

- **折れ線グラフ＝気温**（左の目もり・℃）、**棒グラフ＝降水量**（右の目もり・mm）。目もりを**左右とも**必ず確かめる。
- **年較差**＝（最も暖かい月の平均気温）−（最も寒い月の平均気温）。**年降水量**＝12か月の降水量の合計。
- 折れ線が**山形**（7月ごろが高い）→ 北半球、**谷形**（7月ごろが低い）→ **南半球**。

</div>

| 気温は1年中高いが、棒が**ない時期（乾季）**がある | **サバナ気候** |
| **棒がほとんどない** | **砂漠気候** |
| 気温の線が**低い所でほぼ真横**（年較差が小さく、10℃前後） | **高山気候** |
| 棒が**夏に低く冬に高い**（降水量のグラフが「谷形」） | **地中海性気候** |
| 棒が**低めでそろっている**、冬が0℃より上、夏が20℃に届かない | **西岸海洋性気候** |
| 冬は0℃を大きく下回るが、夏は15〜20℃ほどまで上がる（年較差がとても大きい） | **冷帯** |
| 夏でも10℃に届かない | **寒帯** |

</div>

<div class="memo" markdown="1">
**先生のひとこと**　ローマ（地中海性）と東京（温暖湿潤）は年平均気温がほぼ同じ（約16℃）。ちがいは**雨が夏に降るか冬に降るか**。「気温が同じなら、雨の季節を見よ」は入試の決まり文句だよ。
</div>

### 6　世界の宗教とくらし

**POINT 3　三大宗教とヒンドゥー教**<span class="deru">入試</span>

- **ハラル（ハラール）**：イスラム教のきまりにしたがって用意された食品など。日本でも、観光客などのために**ハラル認証**の食品や、空港・駅の**礼拝室**が増えている。
- **ユダヤ教**（エルサレムが聖地）、日本の**神道**のように、特定の民族と結びついた宗教もある。

<div class="memo" markdown="1">
**本質**　宗教のきまりも、生まれた土地の自然と関係があると考えられている。たとえば暑く乾いた西アジアでは、豚は水や日かげを多く必要とし、遊牧には向かない動物だった。宗教を「変わったきまり」と見るのではなく、**その土地でくらすための知恵**とセットで理解し、たがいの文化を尊重することが大切だよ。
</div>
