# 中2歴史 歴史13「立憲国家の成立と日清・日露戦争」

<p class="lead">対象：中学2年 歴史（小5から挑戦OK）｜自由民権運動・大日本帝国憲法と帝国議会・条約改正・日清戦争・日露戦争・韓国併合・辛亥革命</p>

## 要点まとめ

### 0　この単元の流れ（なぜ→何が→どうなった）

明治政府の大きな目標は「**欧米に負けない国になり、不平等条約を改正すること**」。そのために「憲法と議会をもつ近代国家」をつくり、「戦争に勝って強国と認められる」道を進んだ。

| | なぜ起きた？ | 何が起きた？ | どうなった？ |
|---|---|---|---|
| ① | 政府が**薩摩・長州出身者中心（藩閥政府）**で、国民の声が届かない | **自由民権運動**（国会を開け！） | 政府は**国会開設を約束**→憲法づくりへ |
| ② | 欧米に「近代国家」と認めてもらう必要 | **大日本帝国憲法**・**帝国議会** | アジアで初の**立憲国家**に |
| ③ | 朝鮮をめぐって清と対立 | **日清戦争**→**下関条約** | **三国干渉**でロシアと対立へ |
| ④ | 満州・韓国をめぐってロシアと対立 | **日露戦争**→**ポーツマス条約** | **韓国併合**、条約改正の完成 |

### 2　自由民権運動 ―「国民を政治に参加させよ！」

- **なぜ**：明治政府は、薩摩・長州など一部の藩の出身者が動かす**藩閥政府**。征韓論で政府を去った**板垣退助**らは「一部の役人だけで政治を決めるのはおかしい」と考えた。
- **何が**：1874年 **民撰議院設立の建白書**を政府に提出 → 国民が選んだ議員による議会（国会）を開け、という運動＝**自由民権運動**。
　・西南戦争（1877）で武力による反乱が終わると、**言論**（新聞・演説）による運動が広がる。
　・1880年 **国会期成同盟** 結成。士族だけでなく、地主・商工業者・農民にも広がった。
　・民間でも憲法案（**私擬憲法**）がつくられた。例：**五日市憲法**（東京都あきる野市で発見）。
- **どうなった**：1881年、政府は**国会開設の勅諭**を出し、**10年後（1890年）に国会を開く**ことを約束。

<div class="cols2" markdown="1">

| 政党（1880年代） | 中心人物 | 特色 |
|---|---|---|
| **自由党**（1881） | **板垣退助** | フランス流の急進的な考え |
| **立憲改進党**（1882） | **大隈重信** | イギリス流の議会政治をめざす |

- その後、不景気（松方財政のデフレ）で苦しむ農民が**秩父事件**（1884）などの激化事件を起こし、政府は運動を取りしまった。

</div>

### 3　大日本帝国憲法と帝国議会

- 伊藤博文はヨーロッパで、**君主の権力が強いドイツ（プロイセン）の憲法**を中心に学んだ。<span class="deru">入試</span>
- 1885年 **内閣制度**（初代内閣総理大臣＝伊藤博文）→ 1889年2月11日 **大日本帝国憲法** 発布。

<div class="point" markdown="1">
**POINT 1　大日本帝国憲法のしくみ**<span class="deru">入試</span>

| 項目 | 内容 |
|---|---|
| 主権 | **天皇**（天皇が国の元首として統治権をもつ） |
| 形式 | **天皇が国民にあたえる**形（**欽定憲法**） |
| 天皇の権限 | 陸海軍を指揮（**統帥権**）、条約を結ぶ、戦争を始める・終える、議会の召集・解散 |
| 国民 | 「**臣民**」とよばれる。権利は**法律の範囲内**で認められる（法律で制限できる） |
| 議会 | **帝国議会**＝**貴族院**（皇族・華族・天皇が任命した議員）と**衆議院**（国民の選挙）の**二院制** |
| 内閣 | 天皇を助けて政治を行い、**天皇に対して責任**を負う |

</div>

<div class="point" markdown="1">
**POINT 2　最初の選挙（1890年）の選挙権**<span class="deru">入試</span>

選挙権は **直接国税15円以上** を納める **満25歳以上の男子** だけ。
→ 有権者は約45万人、**総人口の約1.1％**。ほとんどが地主など豊かな人だった。

</div>

- **教育勅語**（1890）：忠君愛国（天皇に忠義をつくし国を愛する）の道徳を学校教育の柱に。
- 第1回帝国議会では、**民権派（民党）が衆議院の多数**をしめ、予算をめぐって政府と対立した。

<div class="memo" markdown="1">
**本質**　憲法の役割は「**国の権力をしばるルールブック**」。大日本帝国憲法は、議会や権利を定めた点で「アジア初の近代的憲法」だが、天皇の権限がとても大きく、国民の権利は法律でいくらでも制限できた。だから戦後、**日本国憲法**（国民主権・基本的人権の尊重）に変わる。公民で比べる表が出るので、今から「天皇主権 ⇔ 国民主権」「法律の範囲内 ⇔ 侵すことのできない永久の権利」を意識しておこう。
</div>

### 4　条約改正の歩み（約40年の大仕事）

幕末の**日米修好通商条約**などには、日本に不利な2つの点があった。

| 不平等な点 | どういうこと？ | 改正した年・人物 |
|---|---|---|
| **領事裁判権（治外法権）を認めた** | 日本で罪をおかした外国人を、日本の法律で裁けない | **1894年**・**陸奥宗光**（外務大臣）<br>→ **イギリス**との条約で撤廃 |
| **関税自主権がない** | 輸入品にかける税（関税）を日本が自由に決められない | **1911年**・**小村寿太郎**（外務大臣）<br>→ **アメリカ**との条約で回復 |

<div class="cols2" markdown="1">

**改正までの道のり**
1. 1871〜73年 **岩倉使節団**：交渉したが失敗 → 「まず国の近代化を」。
2. 1880年代 **井上馨**：**欧化政策**（**鹿鳴館**で舞踏会）→ 国民の反発で失敗。
3. 1886年 **ノルマントン号事件**：イギリス船が沈没し、日本人乗客は全員死亡。イギリス人船長は領事裁判で**軽い罰**だけ → **領事裁判権撤廃**を求める世論が高まる。
4. 憲法・議会をもつ近代国家になり、1894年に領事裁判権撤廃（日清戦争の直前）。
5. 日露戦争で国際的地位が上がり、1911年に関税自主権回復。

</div>

<div class="memo" markdown="1">
**先生のひとこと**　「**む**つ→**りょ**う事、**こ**むら→**かん**税」で「**むりょう、こかん**」。順番は「裁判（自国の人を守る）が先、お金（関税）があと」。**陸奥＝1894、小村＝1911**のセットで覚えよう。
</div>

### 5　日清戦争と下関条約・三国干渉

- **なぜ**：日本も清も**朝鮮**に影響力を広げようと対立。1894年、朝鮮で**甲午農民戦争**（東学を信じる農民の反乱）が起こり、日清両国が出兵 → **日清戦争**（1894〜95）。
- **何が**：近代的な軍隊を整えた日本が勝利 → 1895年 **下関条約**（日本全権：**伊藤博文・陸奥宗光**）。

<div class="point" markdown="1">
**POINT 3　下関条約（1895年）の内容**<span class="deru">入試</span>

1. 清は**朝鮮の独立**を認める。
2. 清は **遼東半島・台湾・澎湖諸島** を日本にゆずる。
3. 清は**賠償金2億両**（当時の日本円で約3億1千万円）を日本に支払う。
4. 清は新たに港を開く。

</div>

- **どうなった（三国干渉）**：**ロシア・ドイツ・フランス**が「遼東半島を清に返せ」と要求 → 日本は力が足りず**返還**。国内では「臥薪嘗胆（がしんしょうたん。将来のためにがまんする）」が合言葉になり、**ロシアへの反感**が高まった。
- その後ロシアは遼東半島の**旅順・大連**を借りる → 日本はますますロシアを警戒。
- 賠償金の一部で **八幡製鉄所**（福岡県）を建設（1901年操業）→ 重工業の発展へ。
- **台湾**には**台湾総督府**を置いて植民地支配。

### 6　日露戦争とポーツマス条約

- **なぜ**：1900年の**義和団事件**（「扶清滅洋」をかかげた中国の民衆の反乱）のあと、ロシアが**満州**に軍を居座らせ、韓国にも勢力をのばした。ロシアの南下をおそれる**イギリス**と日本が **日英同盟**（1902）を結ぶ。
- **何が**：1904年 **日露戦争**。日本は旅順を落とし、日本海海戦（東郷平八郎）でも勝利。しかし日本は戦費・兵力が限界、ロシアも国内で革命運動 → アメリカ大統領（**セオドア・ローズベルト**）の仲介で講和。
- 国内には戦争に反対する声も：**内村鑑三**（キリスト教徒の立場）、**幸徳秋水**（社会主義の立場）、**与謝野晶子**（詩「**君死にたまふことなかれ**」）。

<div class="point" markdown="1">
**POINT 4　ポーツマス条約（1905年）の内容**<span class="deru">入試</span>

日本全権：**小村寿太郎**
1. ロシアは、**韓国における日本の優越権**を認める。
2. **旅順・大連の租借権**と、**長春以南の鉄道**（のちの南満州鉄道）の権利を日本にゆずる。
3. **北緯50度以南の樺太（サハリン）**を日本にゆずる。
→ **賠償金はなし**！ → 重い税にたえてきた国民が怒り、**日比谷焼き打ち事件**が起こった。

</div>

### 7　韓国併合と辛亥革命

<div class="cols2" markdown="1">

**韓国併合**<span class="deru">入試</span>
- 1905年 韓国を**保護国**にし、外交権をうばう。**韓国統監府**を置く（初代統監 **伊藤博文**）。
- 韓国では各地で抵抗運動（義兵運動）。1909年、伊藤博文が**安重根**に暗殺される。
- **1910年 韓国併合** → 朝鮮を植民地に。**朝鮮総督府**を置いて支配。学校で日本語・日本の歴史を教えるなど、同化政策を進めた。
- 土地調査事業で土地を失った農民も多かった。

**辛亥革命**<span class="deru">入試</span>
- 清は列強に国土を分割され、国力が弱まっていた。
- **孫文**が**三民主義**（民族の独立・民権の伸長・民生の安定）をとなえ、革命運動を指導。
- **1911年 辛亥革命** → **1912年 中華民国**成立（首都 **南京**、臨時大総統 **孫文**）。アジアで最初の共和国。
- 清の皇帝が退位して**清がほろびる**。その後、**袁世凱**が権力をにぎる。

</div>

- 日露戦争後、日本は1906年に **南満州鉄道株式会社（満鉄）** を設立し、満州への進出を強めた。
- 日本の勝利は、欧米の支配に苦しむアジアの人々を勇気づけた一方、日本自身が**列強の仲間入り**をして、朝鮮・中国を支配する側に回った。

<div class="memo" markdown="1">
**本質**　この単元の日本は「**不平等条約で苦しむ側**」から「**朝鮮や中国に不平等を押しつける側**」へと変わっていく。条約改正の完成（1911）と韓国併合（1910）がほぼ同じ時期なのは偶然ではない。「欧米に認められる＝列強と同じように植民地をもつ」という時代だったことを、流れとしてつかもう。
</div>

### 入試直前チェック

- 自由民権運動のきっかけは、**板垣退助**らの**民撰議院設立の建白書**（1874）。
- **自由党＝板垣退助**、**立憲改進党＝大隈重信**。初代内閣総理大臣＝**伊藤博文**（1885）。
- 大日本帝国憲法（1889）は**ドイツ（プロイセン）**の憲法を参考。主権は**天皇**、国民の権利は**法律の範囲内**。
- 最初の選挙権：**直接国税15円以上・満25歳以上の男子**（人口の約1.1％）。帝国議会は**貴族院と衆議院**。
- 領事裁判権の撤廃：**1894年・陸奥宗光**。関税自主権の回復：**1911年・小村寿太郎**。
- 下関条約：**遼東半島・台湾・澎湖諸島**、賠償金あり → **三国干渉（露・独・仏）**で遼東半島を返還。
- ポーツマス条約：**南樺太**・旅順と大連の租借権・長春以南の鉄道、**賠償金なし** → 日比谷焼き打ち事件。
- 1910年 **韓国併合**（朝鮮総督府）、1911年 **辛亥革命** → 1912年 **中華民国**（孫文）。
