# 五教科テキスト 執筆ルール（スタイルガイド）

このテキストは、小学5年生2人（週1回の個別指導）が、小5から中3まで使い続けて**神奈川県の公立高校入試**まで挑める五教科の教材です（教科ごとに1冊。英・理・社・国は巻末に全解答、算数・数学は解答を別冊）。
書き手は「生徒から『教え方がうまい！』と大人気の、親しみやすく優秀な塾講師」です。**受験生の役に立つこと**をいちばんに考えて書いてください。

## 1. 全教科共通のルール

### 中身
- **本質と予備知識を厚く書く。** 「なぜそうなるのか」「そもそも何なのか」を、公式や用語の前に説明する。暗記の羅列にしない。
- **大事なことは学年や範囲をこえても書く。** そのときは `<div class="memo" markdown="1">` の1行目を `**発展**` または `**本質**` にして区別する。（例：英語の5文型、比較は「2つの文を比べる」ものだという考え方、数学の解の公式の導き方、理科の原子の構造、など）
- 小5でも中学の内容に挑めるように、**むずかしい言葉は最初に言いかえる**。身近な例え（ゲーム・お菓子・部活・学校生活など）を使う。
- **正確さが最優先。** 用語は中学校の教科書（学習指導要領）に合わせる。数値・年号・計算・答えは**必ず自分で検算する**。自信のない細かい数値は書かない（書くなら「約」「〜ごろ」）。統計は年を書く。
- **神奈川入試の形式**を各単元に入れる：「Kさんは〜。〜として最も適するものを、次の1〜4の中から一つ選び、その番号を答えなさい。」、英語の「使わない語が1つまじった並べかえ」、条件英作文、資料の読み取り、記述など。
- **著作権のある文章（教科書・入試問題・小説・評論の本文）を写さない。** 読解用の文章はすべて自分で書く。古典（竹取物語・枕草子・徒然草・平家物語・おくのほそ道・論語・漢詩・和歌・俳句など著作権の切れたもの）は原文を引用してよい。現代語訳は自分で書く。
- 参考にしてよい塾教材データ（形式・難しさの参考。文章はそのまま写さない）：
  `/tmp/claude-0/-home-user-ToDoList-App/cd359a47-45a5-5281-83cd-a859d5231d4d/scratchpad/ref/data/` の `jh_packs/<単元>/lesson.json`・`exercise.json`、`mock_exam/kng_mock_r8_02_*.json`（神奈川形式の模試）。単元の一覧は `ref/schemas/curriculum_map.json`。

### 書き方
- **余白をなるべく作らない。** `<div class="pagebreak"></div>` は使わない。解答欄の線（`<div class="line"></div>`）は記述問題だけにし、1問につき1〜2本まで。計算スペースは数学だけ必要に応じて可。
- 絵文字は**算数・数学の見出し以外では使わない**。モノクロ印刷前提（色は黒とグレーだけ）。
- 1つのファイル＝1つの単元。**1行目は指示された見出し（タイトル）をそのまま**書く（`# ` から始める）。
- 解答・解説は、ファイルの最後に、指示された見出し（「解答」を含む `## ` 見出し）から書く。**その見出しより前が本文、後ろが解答**として、本を組むときに自動で巻末（算数・数学は別冊）へ移される。
- 改行はそのまま改行になる（nl2br）。段落を分けるときは空行。
- `$` は数式の記号として使われるので、お金のドルは「10ドル」と書き、`$` を文中に使わない。
- `<div …>` の中で Markdown を使うときは必ず `markdown="1"` をつけ、開始タグと終了タグの前後に空行を入れる。

### 図
- 図はインライン SVG：`<figure><svg width=… height=… viewBox=… xmlns="http://www.w3.org/2000/svg" font-family="Noto Sans JP, sans-serif" font-size="13">…</svg><figcaption>…</figcaption></figure>`
- 線は黒、塗りはグレー（#e4e4e4 など）。座標・角度・比は計算して正確に。
- 正確に描けない地図は描かない（「模式図」と明記するか、表で表す）。

## 3. 教科ごとの形式

### 英語（見本：`textbooks/eigo/U01-1_be動詞の文.md`、`U01-M_まとめの問題.md`）
- 1行目：`# 中1英語 Unit 2-1「三人称単数現在」` のように、指示されたタイトル。
- `<p class="lead">ねらい：…</p>` → `## 文法のポイント` → POINT の枠を4〜7個（**要点＋例文（英文と和訳）**）。本質・発展の memo を1〜2個。
- `## 練習問題` → `### 基本` `### 標準` `### 入試にチャレンジ`。**文法の演習をとにかくたくさん**：大問10〜13、小問50〜70。空所補充・選択・書きかえ・誤文訂正・並べかえ（使わない語つきを必ず入れる）・和文英訳・対話文・短い読解・条件英作文など。
- `## 解答・解説` → 全体を `<div class="kaito" markdown="1">` で囲み、大問ごとに `#### <span class="no">1</span>` で、正解と短い解説（なぜそうなるか・つまずき）。
- **まとめの問題**（ファイル名が `-M_` のもの）：その Unit 全体の総合問題。チェックリストの memo → `## まとめの問題` → 大問8〜10・小問40前後（読解と条件英作文を必ずふくむ）→ `## 解答・解説`。
- 英語で特に大事にすること：**5文型（SV・SVC・SVO・SVOO・SVOC）で文の骨組みを見る**習慣（どの単元でも、必要なところで文型を示す）、品詞、句と節、**比較は「2つの文を比べる」もの**（元の2つの文を考えてから比較の文にする）、受け身は「能動態の文の目的語を主語にした文」、関係代名詞は「2つの文を1つにする」、など**文法の本質**を必ず書く。

### 算数・数学（見本：`textbooks/sansu-sugaku/小5-16_割合.md`。この構成とデザイン部品をそのまま使う）
- 1行目：`# 📚 小5-01　整数と小数のしくみ` のように、指示されたタイトル。2行目にその単元の対象・目安・つながる先を太字で1行。
- `## 👨‍🏫 導入・その単元についての歴史や詳細など`：`<div class="history" markdown="1">`（歴史・人物・由来）、話しかけ、`<div class="mokuhyo" markdown="1">`（目標を番号つきで3〜5個）、`> 💬 **先生のひとこと**`。
- `## 📖 ポイント（解説）`（全体の約3割）：`### 小見出し`（自動でA・B・Cがつく）、`<div class="koushiki" data-title="〇〇の公式" markdown="1">`（公式・きまり）、図（SVG）、表、`<span class="toi">問1</span>`（本文中の小さな確認）、例え話の引用ブロック。**公式の意味と導き方（本質）**を書く。
- `## ✏️ 解いてみよう！（例題）`（約2割）：`<div class="rei" data-label="例題" data-num="1" markdown="1">` を2〜4個。中は「**題名**」→問題文→ **STEP 1 …** のステップ解説→ **答え**。
- `## 🚀 チャレンジ問題（演習）`（約5割）：`### 基礎レベル`（3〜4問）`### 標準レベル`（2〜3問）`### 挑戦レベル`（1問）。各問は `<div class="renshu" data-label="基礎" data-num="1" markdown="1">` で、(1)(2)… の小問を入れて量を確保する（小問合計25〜35）。神奈川入試形式の選択問題を1問以上。
- `## 💡 解答と解説（別冊）`：大問ごとに `### 【1】` などの見出しで、答え・途中式・**ワンポイント**（なぜ・つまずき）。最後に `### 👨‍🏫 先生用メモ`（時間配分・つまずき・声かけ・2人で解く工夫）。この部分は別冊になる。
- 数式：中学の単元は KaTeX（`$x^2+3x$`、`$\dfrac{1}{2}$`、`$\sqrt{2}$`）を使ってよい。小学の単元はふつうの文字（×・÷・□）を中心に。
- 部品：`history`・`mokuhyo`・`koushiki`・`rei`・`renshu`・`toi`（CSS は `tools/math.css`）。

### 理科・社会（見本：`textbooks/rika/物理1_光の性質.md`、`textbooks/shakai/地理01_世界のすがた.md`）
- 1行目：`# 中1理科 物理2「音の性質」`、`# 中2地理 地理9「…」` のように、指示されたタイトル。
- `<p class="lead">…</p>` → `## 要点まとめ`：**A4で3.5〜4ページ**。短い箇条書き・表・図・太字・入試マーク中心で密度高く。memo（先生のひとこと・本質・発展）を数か所。単元の最後に「入試直前チェック」の箇条書き。
- `## 練習問題`：**A4で3.5〜4ページ**。`### 基本` `### 標準` `### 入試にチャレンジ`、大問10〜12・小問40前後。用語・選択・計算・作図の説明・資料やグラフの読み取り・記述。神奈川入試形式の選択問題を5問以上。
- `## 解答・解説`：`<div class="kaito" markdown="1">` で囲み、大問ごとに正解と短い解説。
- 社会は、地理は地図・統計の読み方、歴史は**流れ（なぜ起きたか→何が起きたか→どうなったか）**と年表、公民は**しくみの理由**（なぜ三権分立か、など）を重視。歴史には年表（表）を必ず入れる。

### 国語（見本：`textbooks/kokugo/中1_文法1_言葉の単位と文節.md`）
- 英語と同じ形式（`## 文法のポイント`（読解の単元は `## 読み方のポイント`、古典は `## 古典のポイント` などでよい）→ POINT の枠 → `## 練習問題`（基本・標準・入試にチャレンジ、大問8〜12・小問40〜60）→ `## 解答・解説`（kaito））。
- **文法のまとめを重視**：品詞・活用表・識別のしかたは、表で一覧にする。
- 読解の単元：POINT で「読み方の手順・設問の型」を教え、**自分で書いたオリジナルの文章**（600〜1200字程度）を2つ以上使って設問を出す。
- 古典：原文・歴史的仮名遣いの読み・現代語訳・重要古語の表・文法（係り結びなど）。
- 作文：条件の読み方・構成の型・**模範解答**と、よくある減点例。
