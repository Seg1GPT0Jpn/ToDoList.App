# 📚 中2-09　平行と合同②　合同条件と証明

**対象：中学2年（図形の調べ方・証明）｜目安：100分｜つながる先：中2「三角形と四角形」→ 中3「相似」「円周角」→ 神奈川入試 問3（証明の穴うめ・図形）**

---

## 👨‍🏫 導入・その単元についての歴史や詳細など

<div class="history" markdown="1">

古代ギリシャの **タレス**（紀元前6世紀ごろ）は、「対頂角は等しい」「二等辺三角形の底角は等しい」などを、**理由をつけて説明した最初の人**と伝えられています。それまでの数学は「こうすればうまくいく」という**やり方の集まり**でしたが、タレスからは「**なぜそうなるのか**」を言葉の筋道で示すようになりました。
この「筋道」を集大成したのが、ユークリッドの『原論』（紀元前300年ごろ）です。わずかな約束から出発して、数百もの図形の性質を1つずつ証明していくこの本は、2000年以上も世界中で教科書として読まれてきました。
「証明」は、数学者だけのものではありません。**根拠を示して、だれもが納得する説明をする力**は、裁判でもプログラミングでも、毎日の話し合いでも使われています。

</div>

いよいよ中学数学の山場、「**証明**」です。
「証明って、何を書けばいいかわからない…」という声を毎年聞きます。でも安心してください。証明には**決まった型**があります。サッカーにフォーメーションがあるように、型どおりに材料を並べれば、ちゃんと点が取れるのです。今日はその型を、**見本の答案**で体にしみこませます。

<div class="mokuhyo" markdown="1">

この単元でできるようになることを、目標としてまとめました。

1. 合同の記号 ≡ を使い、対応する頂点の順に正しく書ける。
2. 三角形の合同条件3つを言え、図や条件から合同条件を判断できる。
3. 「ならば」の文で、仮定と結論を区別できる。
4. 「**仮定 → 根拠 → 結論**」の型で、合同を使った証明を書ける。
5. 逆の意味がわかり、逆が正しいとは限らないことを反例で示せる。

</div>

> 💬 **先生のひとこと**
> 神奈川の入試では、毎年「証明」が出ます。形式は「証明の一部を選択肢から選んで穴うめする」もの。つまり、**型がわかっていれば確実に取れる問題**です。そして型がわかると、自分で書く証明もこわくなくなります。

**合同な図形では、対応する線分の長さ・対応する角の大きさはそれぞれ等しい。**
△ABC と △DEF が合同であることを **△ABC≡△DEF** と書く。
**対応する頂点を同じ順に書く**（A と D、B と E、C と F が対応）。

対応の順に書くのには理由があります。△ABC≡△DEF と書いてあれば、**順番どおりに読むだけで**「AB＝DE」「∠C＝∠F」などが分かるのです。△ABC≡△EFD と書くと、まるで A と E が重なるように読めてしまうので、まちがいです。

### 三角形の合同条件

2つの三角形が合同かどうか、6つ（辺3つ・角3つ）を全部調べる必要はありません。**次のどれか1つ**がいえれば合同です。

<div class="koushiki" data-title="三角形の合同条件" markdown="1">

**① 3組の辺がそれぞれ等しい。**
**② 2組の辺とその間の角がそれぞれ等しい。**
**③ 1組の辺とその両端の角がそれぞれ等しい。**

</div>

**なぜこの3つなのか？** 中1の作図を思い出してください。「3辺の長さ」「2辺とその間の角」「1辺とその両端の角」がわかれば、**三角形はコンパスと定規でただ1通りにかける**のでした。かいた三角形が1通りなら、同じ条件の三角形はみんなぴったり重なる ── だから合同なのです。

<div class="memo" markdown="1">

**注意**
「2組の辺と、**間ではない**角」では合同とはいえません。下の図のように、AB＝4cm、AC＝3.2cm、∠B＝50° の三角形は2通りできてしまうからです。また、「3組の角がそれぞれ等しい」も合同とはいえません（形は同じでも、大きさがちがう三角形がつくれます。これは中3の「相似」になります）。

### 仮定と結論

「○○○ **ならば** □□□」という文で、○○○の部分（わかっていること）を **仮定**、□□□の部分（説明したいこと）を **結論** といいます。

| 文 | 仮定 | 結論 |
|---|---|---|
| △ABC≡△DEF ならば、AB＝DE | △ABC≡△DEF | AB＝DE |
| ℓ∥m ならば、錯角は等しい | ℓ∥m | 錯角は等しい |
| AO＝BO、CO＝DO ならば、AC＝BD | AO＝BO、CO＝DO | AC＝BD |

**証明** とは、**仮定から出発して、正しいと認められていること（根拠）を使い、結論を導くこと**です。

### 証明の書き方の型 ── 仮定 → 根拠 → 結論

<div class="koushiki" data-title="合同を使った証明の型" markdown="1">

**（1行目）** △○○○ と △□□□ において、　← どの三角形の合同を示すか宣言
**（材料）** 仮定より、○○＝□□　…①　← **根拠** ＋ **等しいもの** ＋ 番号
　　　　　 ○○○だから、○○＝□□　…②
　　　　　 ○○○だから、∠○＝∠□　…③
**（合同）** ①、②、③より、〔合同条件〕から、△○○○≡△□□□
**（結論）** 合同な図形の対応する辺（角）は等しいから、○○＝□□

</div>

**書く前の4ステップ**

1. **図に仮定を書きこむ**（等しい辺に印、平行に＞の印）。
2. **結論から逆にたどる**。「AC＝BD を言いたい → AC と BD をふくむ三角形は？ → △AOC と △BOD だ」
3. **材料を3つ集める**。仮定で足りない分は、対頂角・共通な辺・平行線の錯角などから見つける。
4. 型どおりに書く。**根拠のない行は1行もない**ように。

<div class="koushiki" data-title="根拠に使えること一覧" markdown="1">

**仮定**（問題文で与えられたこと）
**対頂角は等しい**　　**共通な辺（共通な角）**
**平行線の同位角・錯角は等しい**　　**同位角・錯角が等しければ平行**
**三角形の内角の和は 180°**　　**三角形の外角は、となりにない2つの内角の和**
**中点の意味**（M が AB の中点 → AM＝BM）　　**角の二等分線の意味**
**正三角形の3つの辺・3つの角は等しい**（小学校で学んだ性質）
**三角形の合同条件**　　**合同な図形の対応する辺・角は等しい**

</div>

> 🎮 **ゲームで例えると**
> 証明は「アイテムを3つそろえると合同の扉が開く」ゲームです。アイテムは「等しい辺」か「等しい角」。仮定でもらえるアイテムもあれば、対頂角や共通な辺のように**図の中に落ちている**アイテムもあります。

### 逆

「○○○ならば□□□」の仮定と結論を入れかえた「□□□ならば○○○」を、もとの文の **逆** といいます。
**正しい文の逆が、正しいとは限りません。** 正しくないことを示すには、成り立たない例（**反例**）を1つあげれば十分です。

| もとの文（正しい） | 逆 | 逆は正しい？ |
|---|---|---|
| 2直線が平行ならば、同位角は等しい | 同位角が等しいならば、2直線は平行 | 正しい |
| $x=2$ ならば、$x^2=4$ | $x^2=4$ ならば、$x=2$ | 正しくない（反例：$x=-2$） |
| △ABC≡△DEF ならば、面積は等しい | 面積が等しいならば、△ABC≡△DEF | 正しくない（反例：底辺4・高さ3と、底辺6・高さ2の三角形） |

<span class="toi">問2</span> 「正三角形ならば、二等辺三角形である」の逆を書き、正しいかどうか答えなさい。

## 💡 解答と解説（別冊）

### 問1〜問2
問1　辺 CA に対応する辺は **辺 FD**、∠B に対応する角は **∠E**
問2　逆：「二等辺三角形ならば、正三角形である」　**正しくない**（反例：辺の長さが 5cm、5cm、3cm の三角形）

### 【1】
(1) **辺 EF**　(2) **∠B**　(3) **4cm**
(4) ∠C＝180°−75°−45°＝60°。∠F は ∠C に対応するので **60°**

**ワンポイント**：△ABC≡△DEF の「書いた順」を見れば、図を見なくても対応がわかります。

### 【2】
**アとオ**：3組の辺がそれぞれ等しい（4cm、5cm、6cm）
**イとカ**：2組の辺とその間の角がそれぞれ等しい（4cm、5cm、その間の角 50°）
**ウとエ**：1組の辺とその両端の角がそれぞれ等しい（5cm、その両端の角 40° と 70°）

**ワンポイント**：エ・カは、ウ・イを裏返した（対称移動した）形です。裏返しても合同。向きや位置にまどわされず、**等しいものとその位置関係**だけを見ます。

### 【3】
(1) 仮定：△ABC≡△DEF　結論：∠A＝∠D
(2) 仮定：$x$ が4の倍数　結論：$x$ は偶数
(3) 仮定：ℓ∥m　結論：同位角は等しい
(4) 仮定：（三角形の）2つの角が等しい　結論：二等辺三角形である

**ワンポイント**：(4) のように「ならば」がない文は、「三角形の2つの角が等しい**ならば**、その三角形は二等辺三角形である」と言いかえると見つけやすくなります。

### 【4】
(1) 逆：$x$ が偶数ならば、$x$ は4の倍数である。**正しくない**（反例：$x=6$）
(2) 逆：△ABC と △DEF の周の長さが等しいならば、△ABC≡△DEF である。**正しくない**（反例：3辺が 3cm、4cm、5cm の三角形と、4cm、4cm、4cm の三角形）
(3) 逆：錯角が等しいならば、2直線は平行である。**正しい**
(4) 逆：$ab>0$ ならば、$a>0$、$b>0$ である。**正しくない**（反例：$a=-1$、$b=-2$）
(5) 逆：3つの角が等しい三角形は、正三角形である。**正しい**

**ワンポイント**：反例は「仮定にはあてはまるのに、結論にはあてはまらない例」。(1) なら「偶数だけど4の倍数ではない数」をさがします。

### 【5】
(1) **BC＝EF**（∠B が辺 AB と BC の間の角になる）
(2) **∠A＝∠D**（辺 AB の両端の角が ∠A と ∠B になる）
(3) （解答例）**AC＝DF を加えると「2組の辺と、その間ではない角」が等しいことになる。この条件では、ポイントの図の △ABC と △ABC′ のように、ちがう形の三角形が2通りできることがあるので、合同とは限らない。**

### 【6】
**(a) 1　(b) 3　(c) 3**

**ワンポイント**：(a) は「2つの三角形が**共有している辺**」。たこ形の対角線 AC は、両方の三角形の辺になっています。(a) の 2 は、それを使うと「2組の辺とその間の角」になりそうですが、∠BAC＝∠DAC はまだ**証明されていない**ので根拠にできません。

### 【7】
（証明）△ABC と △DCB において、
仮定より、AB＝DC　…①
仮定より、AC＝DB　…②
BC は共通　…③
①、②、③より、3組の辺がそれぞれ等しいから、
△ABC≡△DCB
合同な図形の対応する角は等しいから、∠ABC＝∠DCB

**ワンポイント**：△ABC と △DCB の**頂点の順番**に注意。A↔D、B↔C、C↔B が対応します。「△ABC≡△DBC」と書くと、対応がずれて減点されます。

### 【8】
(1)（証明）△ABM と △ECM において、
仮定より、BM＝CM　…①
AB∥DE より、錯角は等しいから、∠ABM＝∠ECM　…②
対頂角は等しいから、∠AMB＝∠EMC　…③
①、②、③より、1組の辺とその両端の角がそれぞれ等しいから、
△ABM≡△ECM
合同な図形の対応する辺は等しいから、AB＝EC
(2) （解答例）**△ABM≡△ECM で、AM と EM は対応する辺だから。**

**ワンポイント**：辺 BM の両端の角は ∠B と ∠M。②（∠B）と③（∠M）がちょうど「両端の角」になっています。

### 【9】
(1)（証明）△ADC と △ABE において、
△ABD は正三角形なので、AD＝AB　…①
△ACE は正三角形なので、AC＝AE　…②
∠DAC＝∠DAB＋∠BAC＝60°＋∠BAC
∠BAE＝∠CAE＋∠BAC＝60°＋∠BAC
よって、∠DAC＝∠BAE　…③
①、②、③より、2組の辺とその間の角がそれぞれ等しいから、
△ADC≡△ABE
合同な図形の対応する辺は等しいから、DC＝BE
(2) **120°**
△ADC≡△ABE より ∠ADC＝∠ABE、つまり ∠ADP＝∠ABP。DC と AB の交点を Q とすると、△ADQ と △PBQ で、∠ADQ＝∠PBQ、∠AQD＝∠PQB（対頂角）なので、残りの角も等しく ∠BPQ＝∠DAQ＝60°。よって ∠BPC＝180°−60°＝**120°**

**ワンポイント**：(1) は**共通な角 ∠BAC に 60° をたす**のがカギ。等しい角が直接見つからないときは「等しいもの＋同じもの」で作ります。(2) は、△ABE が △ADC を点 A を中心に 60° 回転させた形になっていることからもわかります（回転すると、直線 DC は 60° かたむいて直線 BE に重なる）。

- **時間配分の目安（100分）**：導入5分 → 合同と記号10分 → 合同条件15分（作図で「1通りに決まる」を確認）→ 仮定と結論5分 → 証明の型20分（例題2・3を板書で写させる）→ 逆5分 → 演習35分 → 丸つけ5分
- **つまずきやすい所**：対応する頂点の順、「間の角」「両端の角」の確認もれ、根拠のない行、結論を根拠に使ってしまう（循環）。
- **声かけ例**：「その行の根拠は何？」「結論の辺をふくむ三角形はどれ？」「アイテムはあといくつ？」
- **2人で解く工夫**：1人が証明を1行ずつ読み上げ、もう1人が「根拠は？」と毎行たずねる。【6】のような穴うめは、選ばなかった選択肢がなぜだめかを相手に説明させると、型の理解が深まります。
