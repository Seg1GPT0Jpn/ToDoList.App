## 👨‍🏫 導入・その単元についての歴史や詳細など

<div class="history" markdown="1">

紀元前300年ごろ、ギリシャの **ユークリッド**（エウクレイデス）がまとめた『原論』の第7巻に、2つの数の最大公約数を求める方法がのっています。「大きいほうから小さいほうを取りのぞく。のこりで、また取りのぞく……」というやり方で、これが今日の主役 **ユークリッドの互除法**（ごじょほう）です。
「互いに除する（わる）」という名前のとおり、2つの数でかわりばんこにわり算をくり返します。2300年以上前の方法なのに、今でもコンピュータの中で毎日、数えきれないほど使われています。インターネットの暗号（RSA暗号）の計算でも、この互除法が欠かせません。**世界でいちばん長く現役で働いているアルゴリズム（計算の手順）** といわれることもあります。

</div>

小5で「最大公約数」を、約数を全部書き出して求めましたね。では、$1071$ と $1029$ の最大公約数は？ 約数を全部書き出すのは大変です。素因数分解しようにも、どの素数でわれるのか、すぐにはわかりません。
ところが互除法を使うと、**わり算たった3回** で答えが出ます。しかも「なぜそれで正しいのか」は、中2の文字式の説明だけで証明できるんです。今日は、公式を覚える授業ではありません。**約数の個数・総和の公式も、$ab=GL$ も、互除法も、全部自分で導く** 授業です。

これは高校の **数学A「数学と人間の活動」（整数の性質）** で学ぶ内容です（LEVEL 3〜4）。難関私立・国立高校の入試や、数学オリンピックの予選でもよく使われる考え方です。

<div class="mokuhyo" markdown="1">

この単元でできるようになることを、目標としてまとめました。

1. 素因数分解から、約数の個数と約数の総和を求める公式を導き、使える。
2. 最大公約数 $G$・最小公倍数 $L$ を $a=Ga'$、$b=Gb'$ と表し、$ab=GL$ を証明して使える。
3. ユークリッドの互除法で最大公約数を求め、**なぜ正しいかを答案の形で証明** できる。
4. 互除法を「長方形を正方形で切り取っていく図」で説明できる。
5. 互除法を、文字をふくむ数の最大公約数や、分数がこれ以上約分できないことの証明に応用できる。

</div>

## 📖 ポイント（解説）

### 約数の個数と総和 ― 素因数分解から「表」で導く

**① 意味**　$72$ の約数は何個あるでしょう。1つずつわってもよいですが、$720$ や $10000$ になると大変です。素因数分解（中1）を使うと、計算だけで個数も総和も出せます。

**② 導出**　$72=2^3\times3^2$ です。$72$ の約数は「$72$ の設計図の部品を、一部だけ使って作った数」なので、
**（$2$ を $0$〜$3$ 個使う）×（$3$ を $0$〜$2$ 個使う）** の形をしています。表にすると、

| × | $1$ | $3$ | $3^2=9$ |
|---|---|---|---|
| $1$ | $1$ | $3$ | $9$ |
| $2$ | $2$ | $6$ | $18$ |
| $2^2=4$ | $4$ | $12$ | $36$ |
| $2^3=8$ | $8$ | $24$ | $72$ |

表のマスと約数が、**ちょうど1対1** に対応します（素因数分解はただ1通りなので、同じ約数が2つのマスに出ることはありません）。

- **個数**：たてが $3+1=4$ 通り、横が $2+1=3$ 通りなので、マスは $4\times3=12$ 個。
- **総和**：表の全部のマスの和は、展開を逆に見ると $(1+2+4+8)\times(1+3+9)$ です。実際にこれを展開すると、表の12マスの数がちょうど1回ずつ出てきますね。$15\times13=195$。

<div class="koushiki" data-title="約数の個数と総和の公式" markdown="1">

自然数 $N$ が $N=p^a\times q^b\times r^c$（$p,\ q,\ r$ は異なる素数）と素因数分解されるとき
**約数の個数**＝$(a+1)(b+1)(c+1)$
**約数の総和**＝$(1+p+p^2+\cdots+p^a)(1+q+\cdots+q^b)(1+r+\cdots+r^c)$
（素数が2種類なら2つのかっこ、4種類なら4つのかっこ。「$+1$」は「その素数を $0$ 個使う」の分）

</div>

<span class="toi">問1</span> $200$ の約数の個数と総和を求めなさい。

<div class="memo" markdown="1">

**本質**　約数の個数が奇数になるのはどんなとき？
約数は「$d$ と $\dfrac{N}{d}$」のペアで見つかります（小5の「かけ算のペア」）。ペアの相手が自分自身になる、つまり $d\times d=N$ となるのは、$N$ が **平方数（ある自然数の2乗）** のときだけです。だから **約数の個数が奇数 ⇔ $N$ が平方数**。公式で見ても、$(a+1)(b+1)$ が奇数 ⇔ $a,\ b$ がすべて偶数 ⇔ 平方数、とぴったり一致します。

</div>

### 最大公約数 $G$ と最小公倍数 $L$ ― 「$a=Ga'$、$b=Gb'$」とおく

2つの自然数 $a,\ b$ の最大公約数を $G$、最小公倍数を $L$ と書くことにします。また、**最大公約数が $1$ である2つの数を「互いに素（たがいにそ）」** といいます（例：$8$ と $15$ は互いに素）。

$a,\ b$ はどちらも $G$ の倍数なので、
$$a=Ga',\quad b=Gb'\quad（a',\ b' は互いに素な自然数）$$
と表せます。$a',\ b'$ が互いに素なのは、もし $a',\ b'$ に $1$ より大きい公約数 $k$ があれば、$Gk$ が $a,\ b$ の公約数になり、$G$ が「最大」であることに反するからです。

例：$a=84,\ b=120$ なら $G=12$ で、$84=12\times7$、$120=12\times10$（$7$ と $10$ は互いに素）。

<div class="koushiki" data-title="G と L の関係" markdown="1">

$a=Ga'$、$b=Gb'$（$a',\ b'$ は互いに素）のとき
**$L=Ga'b'$**　　そして　**$ab=GL$**（2つの数の積＝最大公約数×最小公倍数）

</div>

**② 証明**（$ab=GL$ のほう）
$L=Ga'b'$ を認めると、$ab=Ga'\times Gb'=G\times(Ga'b')=GL$ となる。

$L=Ga'b'$ の理由：$a$ と $b$ の公倍数 $M$ は $a=Ga'$ の倍数なので $M=Ga'k$（$k$ は自然数）と書ける。$M$ は $b=Gb'$ の倍数でもあるから、$Ga'k$ は $Gb'$ の倍数、つまり $a'k$ は $b'$ の倍数。ここで $a'$ と $b'$ は共通の素因数をもたないので、$b'$ の素因数はすべて $k$ の中に入っていなければならない（素因数分解はただ1通り）。よって $k$ は $b'$ の倍数で、いちばん小さいのは $k=b'$。したがって最小公倍数は $L=Ga'b'$。

<span class="toi">問2</span> $a=84,\ b=120$ のとき、$ab$ と $GL$ を計算して、等しいことを確かめなさい。

### ユークリッドの互除法 ― 手順

<div class="koushiki" data-title="ユークリッドの互除法" markdown="1">

**① 大きい数 $a$ を小さい数 $b$ でわり、余り $r$ を出す。**（$a=bq+r$）
**② $r=0$ なら、$b$ が最大公約数。**
**③ $r\neq0$ なら、「$a$ と $b$」を「$b$ と $r$」に取りかえて、① にもどる。**
→ 余りが $0$ になったときの **わる数** が最大公約数。

</div>

$1071$ と $1029$ でやってみます。

| わられる数 | ＝ | わる数 × 商 ＋ 余り |
|---|---|---|
| $1071$ | ＝ | $1029\times1+42$ |
| $1029$ | ＝ | $42\times24+21$ |
| $42$ | ＝ | $\mathbf{21}\times2+0$ |

余りが $0$ になったときのわる数 $21$ が、最大公約数です。（たしかめ：$1071=21\times51$、$1029=21\times49$、$51=3\times17$ と $49=7^2$ は互いに素 ✓）
数が「$1071,\ 1029$」→「$1029,\ 42$」→「$42,\ 21$」と **どんどん小さくなる** ので、いつか必ず余りが $0$ になって終わります。

### なぜ正しいのか ― 互除法の証明

互除法の心臓部は、次の1つの事実です。

<div class="koushiki" data-title="互除法の原理" markdown="1">

自然数 $a,\ b$ について、$a$ を $b$ でわった商を $q$、余りを $r$ とする（$a=bq+r$）。このとき
**（$a$ と $b$ の最大公約数）＝（$b$ と $r$ の最大公約数）**

</div>

**証明（答案）**
$a$ と $b$ の公約数全体と、$b$ と $r$ の公約数全体が、まったく同じであることを示す。

(i) $d$ を $a$ と $b$ の公約数とすると、整数 $m,\ n$ を使って $a=dm$、$b=dn$ と表せる。このとき
$r=a-bq=dm-dnq=d(m-nq)$
$m-nq$ は整数だから、$r$ は $d$ の倍数である。よって $d$ は $b$ と $r$ の公約数である。

(ii) $e$ を $b$ と $r$ の公約数とすると、整数 $s,\ t$ を使って $b=es$、$r=et$ と表せる。このとき
$a=bq+r=esq+et=e(sq+t)$
$sq+t$ は整数だから、$a$ は $e$ の倍数である。よって $e$ は $a$ と $b$ の公約数である。

(i)(ii)より、「$a$ と $b$ の公約数」と「$b$ と $r$ の公約数」は同じものの集まりである。したがって、その中でいちばん大きいもの、つまり最大公約数も等しい。（証明終わり）

この事実を、余りが $0$ になるまでくり返し使うと、
$G(1071,\ 1029)=G(1029,\ 42)=G(42,\ 21)=21$
となります（$42$ は $21$ でわり切れるので、$42$ と $21$ の最大公約数は $21$ そのもの）。

<div class="memo" markdown="1">

**本質**　「公約数の集まりが同じ」が証明のカギ
中2の「文字式による説明」とまったく同じ型です。「$d$ の倍数」を $dm$ とおき、目的の形 $d\times$（整数）に変形しただけ。**「最大」を直接比べるのではなく、「公約数が全部同じ」を示す** のがうまいところです。同じものの集まりなら、最大のものも同じに決まっていますからね。

</div>

- 横 $21$ からたて $15$ の正方形を **1個** 切り取ると、$6\times15$ の長方形がのこる。…$21=15\times1+6$
- $6\times15$ から $6$ の正方形を **2個** 切り取ると、$6\times3$ がのこる。…$15=6\times2+3$
- $6\times3$ から $3$ の正方形を **2個** 切り取ると、ぴったりなくなる。…$6=3\times2+0$

最後の正方形の1辺 $3$ が、$21$ と $15$ の最大公約数です。なぜなら、**1辺 $3$ の正方形は、それより前に切り取ったどの正方形もすき間なくしきつめられる** ので、もとの長方形全体を1辺 $3$ のタイルでしきつめられるからです。そして、「1辺 $d$ のタイルで長方形をしきつめられる ⇔ $d$ がたて・横の公約数」ですから、互除法は「**しきつめられる最大のタイル**」を見つける方法だといえます。

<span class="toi">問3</span> たて $36$、横 $84$ の長方形を、同じように正方形で切り取っていきます。どんな大きさの正方形が何個ずつ切り取れますか。また、$36$ と $84$ の最大公約数を答えなさい。

### 互除法の応用 ― 文字の入った数にも使える

互除法の原理は「$a=bq+r$ なら $G(a,\ b)=G(b,\ r)$」でした。この $q$ は **整数でありさえすればよい** ので、文字式にも使えます。
例：$n$ が自然数のとき、$5n+3$ と $2n+1$ の最大公約数は？

$5n+3=(2n+1)\times2+(n+1)$
$2n+1=(n+1)\times1+n$
$n+1=n\times1+1$

よって $G(5n+3,\ 2n+1)=G(2n+1,\ n+1)=G(n+1,\ n)=G(n,\ 1)=1$。どんな自然数 $n$ でも、$5n+3$ と $2n+1$ は互いに素です。
（$n=4$ なら $23$ と $9$、$n=10$ なら $53$ と $21$ ✓）

<div class="memo" markdown="1">

**発展**　国際数学オリンピックにも出た考え方
1959年の **第1回国際数学オリンピック** の第1問は、「どんな自然数 $n$ でも、ある分数がこれ以上約分できないことを示せ」というものでした。分子と分母が互いに素 ⇔ 約分できない、なので、互除法で最大公約数が $1$ になることを示せば終わりです。演習【8】で同じタイプに挑戦しましょう。

</div>

## ✏️ 解いてみよう！（例題）

<div class="rei" data-label="例題" data-num="1" markdown="1">

**約数の個数と総和**
$360$ の約数の個数と、約数の総和を求めなさい。

**STEP 1　素因数分解する**
$360=2^3\times3^2\times5$
**STEP 2　個数は「（指数＋1）の積」**
$(3+1)(2+1)(1+1)=4\times3\times2=24$（個）
**STEP 3　総和は「かっこの積」**
$(1+2+4+8)(1+3+9)(1+5)=15\times13\times6=1170$

**答え　個数 24個、総和 1170**

</div>

<div class="rei" data-label="例題" data-num="2" markdown="1">

**互除法で最大公約数を求め、約分する**
$\dfrac{391}{667}$ を約分しなさい。

**STEP 1　互除法**
$667=391\times1+276$
$391=276\times1+115$
$276=115\times2+46$
$115=46\times2+23$
$46=23\times2+0$　→ 最大公約数は $23$
**STEP 2　分子・分母を $23$ でわる**
$391\div23=17$、$667\div23=29$

**答え　$\dfrac{17}{29}$**

</div>

<div class="rei" data-label="例題" data-num="3" markdown="1">

**$G$ と $L$ から2つの数を求める**
最大公約数が $12$、最小公倍数が $180$ である2つの自然数 $a,\ b$（$a<b$）の組をすべて求めなさい。

**STEP 1　$a=12a'$、$b=12b'$ とおく**
$a',\ b'$ は互いに素な自然数で、$a'<b'$。
**STEP 2　$L=Ga'b'$ を使う**
$12a'b'=180$ より $a'b'=15$
**STEP 3　互いに素な組を選ぶ**
$(a',\ b')=(1,\ 15),\ (3,\ 5)$（どちらも互いに素 ✓）
**STEP 4　もどす**
$(a,\ b)=(12,\ 180),\ (36,\ 60)$
**たしかめ**　$36=2^2\times3^2$、$60=2^2\times3\times5$ → $G=2^2\times3=12$、$L=2^2\times3^2\times5=180$ ✓

**答え　$(a,\ b)=(12,\ 180),\ (36,\ 60)$**

</div>

<div class="rei" data-label="例題" data-num="4" markdown="1">

**文字をふくむ数の最大公約数**
$n$ を自然数とする。$n+5$ と $2n+3$ の最大公約数として考えられる数をすべて求めなさい。

**STEP 1　互除法の原理を使う**
$2n+3=(n+5)\times2-7$ と、マイナスの余りでもよいので「$2n+3-2(n+5)=-7$」を使う。
$d$ が $n+5$ と $2n+3$ の公約数なら、$d$ は $(2n+3)-2(n+5)=-7$ もわり切る。つまり $d$ は $7$ の約数。
**STEP 2　候補をしぼる**
$7$ の約数は $1$ と $7$ だけ。よって最大公約数は $1$ か $7$。
**STEP 3　両方とも実際に起こるか確かめる**
$n=1$：$6$ と $5$ → 最大公約数 $1$。
$n=2$：$7$ と $7$ → 最大公約数 $7$。

**答え　$1,\ 7$**

</div>

> 💬 **先生のひとこと**
> 例題4の STEP 3 は省略しがちですが、**大事な一歩** です。STEP 2 でわかるのは「$1$ か $7$ のどちらか」まで。「本当に $7$ になる $n$ があるか」を確かめて、はじめて「考えられる数は $1$ と $7$」と言い切れます。

## 💡 解答と解説（別冊）

### 問1〜問3
**問1**　$200=2^3\times5^2$　個数 $(3+1)(2+1)=$ **12個**、総和 $(1+2+4+8)(1+5+25)=15\times31=$ **465**
**問2**　$ab=84\times120=10080$、$GL=12\times840=10080$（$L=12\times7\times10=840$）で等しい。
**問3**　$84=36\times2+12$ → **1辺36の正方形2個**、$36=12\times3$ → **1辺12の正方形3個**。最大公約数は **12**

### 【1】
(1) $180=2^2\times3^2\times5$　個数 $3\times3\times2=$ **18個**、総和 $7\times13\times6=$ **546**
(2) $1000=2^3\times5^3$　個数 $4\times4=$ **16個**、総和 $15\times156=$ **2340**
(3) $1024=2^{10}$　個数 **11個**、総和 $1+2+\cdots+1024=$ **2047**
(4) $496=2^4\times31$　個数 $5\times2=$ **10個**、総和 $31\times32=$ **992**

**ワンポイント**：(3) の総和は $2048-1$ です。$1+2+4+\cdots+2^{10}=2^{11}-1$ になるのは、$1$ を足すと $1+1=2$、$2+2=4$、…と次々に倍になっていくから。(4) は【9】(3) の準備です。

### 【2】
(1) $391=323\times1+68$、$323=68\times4+51$、$68=51\times1+17$、$51=17\times3$ → **17**
(2) $1147=899\times1+248$、$899=248\times3+155$、$248=155\times1+93$、$155=93\times1+62$、$93=62\times1+31$、$62=31\times2$ → **31**
(3) $2023=1547\times1+476$、$1547=476\times3+119$、$476=119\times4$ → **119**
(4) (2) より最大公約数 $31$。$899\div31=29$、$1147\div31=37$ → **$\dfrac{29}{37}$**

**ワンポイント**：最後に「わる数」を答えること。(1) で余りの $0$ や商の $3$ を答えてしまうミスに注意。たしかめは、答えで両方をわってみればすぐできます（$391=17\times23$、$323=17\times19$）。

### 【3】
(1) $ab=GL$ より $18\times b=6\times72=432$、$b=$ **24**（たしかめ：$G(18,\ 24)=6$、$L=72$ ✓）
(2) $120=84\times1+36$、$84=36\times2+12$、$36=12\times3$ → $G=12$。$L=\dfrac{84\times120}{12}=$ **840**

### 【4】
(1) タイルの1辺は $36$ と $84$ の最大公約数 **12 cm**。枚数は $(36\div12)\times(84\div12)=3\times7=$ **21枚**
(2) **1辺36 cmの正方形が2個、1辺12 cmの正方形が3個**

**ワンポイント**：(1) と (2) の答えの「12」が一致するのが、互除法と「しきつめ」の関係です。

### 【5】
$a=14a'$、$b=14b'$（$a',\ b'$ は互いに素、$a'<b'$）とおくと、$14a'b'=420$ より $a'b'=30$。
互いに素な組は $(1,\ 30),\ (2,\ 15),\ (3,\ 10),\ (5,\ 6)$。
**答え　$(a,\ b)=(14,\ 420),\ (28,\ 210),\ (42,\ 140),\ (70,\ 84)$**

**ワンポイント**：$30=2\times3\times5$ のように、$L\div G$ が **ちがう素数の積** なら、どの分け方でも互いに素になります。もし $a'b'=12$ なら $(2,\ 6)$ は互いに素でないので除く、という確認が必要です。

### 【6】
(1) 指数の形は「$(11)$」「$(5,\ 1)$」「$(3,\ 2)$」「$(2,\ 1,\ 1)$」（$12=12=6\times2=4\times3=3\times2\times2$）。それぞれ最小は $2^{11}=2048$、$2^5\times3=96$、$2^3\times3^2=72$、$2^2\times3\times5=60$。→ **60**
(2) 約数が3個 ⇔ $(a+1)=3$ ⇔ 素数の2乗。→ **4、9、25、49**
(3) 約数の個数が奇数 ⇔ 平方数。$14^2=196\le200<225=15^2$ → **14個**
(4) $a=12a'$、$b=12b'$ とおくと $a'+b'=7$、互いに素で $a'<b'$ → $(1,\ 6),\ (2,\ 5),\ (3,\ 4)$。**$(12,\ 72),\ (24,\ 60),\ (36,\ 48)$**

**ワンポイント**：(1) は大きい指数を小さい素数にわりあてるのがコツ。(4) の $a'+b'=7$ は、$7$ が素数なので、どの組も自動的に互いに素になります。

### 【7】
**答え　3**
$1739=1517\times1+222$、$1517=222\times6+185$、$222=185\times1+37$、$185=37\times5$ → $37$
（$1517=37\times41$、$1739=37\times47$）

**ワンポイント**：選択肢の $41$ は $1517$ だけの素因数。「一方をわり切る」だけで飛びつかず、両方をわり切るか確かめましょう。

### 【8】
(1) **証明**　$3n+2=(2n+1)\times1+(n+1)$、$2n+1=(n+1)\times1+n$、$n+1=n\times1+1$。
互除法の原理より、$3n+2$ と $2n+1$ の最大公約数は、$2n+1$ と $n+1$、$n+1$ と $n$、$n$ と $1$ の最大公約数に順に等しく、$n$ と $1$ の最大公約数は $1$ である。
したがって $3n+2$ と $2n+1$ の最大公約数は $1$ で、互いに素である。

(2) **証明**　$21n+4=(14n+3)\times1+(7n+1)$、$14n+3=(7n+1)\times2+1$。
互除法の原理より、$21n+4$ と $14n+3$ の最大公約数は、$14n+3$ と $7n+1$ の最大公約数、さらに $7n+1$ と $1$ の最大公約数に等しく、これは $1$ である。
よって分子と分母は互いに素なので、$\dfrac{21n+4}{14n+3}$ はこれ以上約分できない。

(3) 例題4より、最大公約数が $7$ ⇔ $n+5$ が $7$ の倍数（このとき $2n+3=2(n+5)-7$ も $7$ の倍数）。$n+5=7,\ 14,\ 21$ → **$n=2,\ 9,\ 16$**

**ワンポイント**：(2) が第1回国際数学オリンピック（1959年）と同じタイプの問題です。答案は「わり算の式 → 互除法の原理 → 最大公約数が1 → 結論」の順で書けば満点です。

### 【9】
(1) $89=55\times1+34$、$55=34\times1+21$、$34=21\times1+13$、$21=13\times1+8$、$13=8\times1+5$、$8=5\times1+3$、$5=3\times1+2$、$3=2\times1+1$、$2=1\times2$。商の合計 $1\times8+2=$ **10個**
(2) （解答例）となりあう3つの数を $a,\ b,\ c$（$c=a+b$）とすると、$c=b\times1+a$ なので、互除法の原理より「$b$ と $c$ の最大公約数」＝「$a$ と $b$ の最大公約数」。これをくり返すと、列の最初の「$1$ と $1$」の最大公約数 $1$ に等しくなる。よって、となりあう2数の最大公約数はいつでも $1$ で、互いに素である。
(3) $496=2^4\times31$ より、約数の総和は $(1+2+4+8+16)(1+31)=31\times32=992$。自分自身をのぞく約数の和は $992-496=496$ で、自分自身と等しい。よって $496$ は完全数である。

**ワンポイント**：(1) のようにフィボナッチ数列では商がほとんど $1$ になり、互除法の回数がいちばん多くなります（「互除法がいちばん時間のかかる数の組」として知られています）。完全数は $6,\ 28,\ 496,\ 8128$ と続き、どれも $2^{k-1}(2^k-1)$（$2^k-1$ は素数）の形です。

### 【10】
（解答例）「最大公約数が $10$、最小公倍数が $420$ である2つの自然数 $a,\ b$（$a<b$）の組をすべて求めよ。」
$a=10a'$、$b=10b'$ とおくと $a'b'=42=2\times3\times7$。互いに素な組 $(1,\ 42),\ (2,\ 21),\ (3,\ 14),\ (6,\ 7)$ → $(10,\ 420),\ (20,\ 210),\ (30,\ 140),\ (60,\ 70)$ の **4組**。

**ワンポイント**：$L\div G$ が異なる素数 $k$ 個の積なら、組は $2^{k-1}$ 組できます。$L$ が $G$ の倍数でないと答えが0組になるので、まず「$L$ は $G$ の倍数」を確かめるのが問題作りのコツです。
