# 📚 中3-09　相似な図形①　相似条件と証明

**対象：中学3年（相似な図形の前半）｜目安：100分｜つながる先：中3「平行線と線分の比」「面積比・体積比」「円周角」「三平方の定理」→ 神奈川入試 問3（図形の証明・長さ）**

---

## 👨‍🏫 導入・その単元についての歴史や詳細など

<div class="history" markdown="1">

紀元前6世紀ごろの古代ギリシャの学者 **タレス** は、エジプトを旅したとき、**ピラミッドの高さを、棒1本と影だけで測った**と伝えられています。

やり方はこうです。地面に棒を立て、「棒の影の長さが、棒の長さと同じになる瞬間」を待ちます。その瞬間なら、ピラミッドの影の長さ（中心から測った長さ）も、ピラミッドの高さと同じはず。太陽の光は平行に届くので、**棒と影がつくる三角形と、ピラミッドと影がつくる三角形は「同じ形」**になるからです。
登らなくても、巨大なものの長さがわかる。これが今日学ぶ「**相似**」の力です。

</div>

小6で「拡大図・縮図」を学びましたね。形は同じで、大きさだけがちがう図形です。中3では、これを「**相似**」と呼び、さらに一歩進んで「**2つの三角形が相似であることを、証明する**」ことに挑戦します。
中2の「合同の証明」ができた人なら大丈夫。書き方の型はほとんど同じです。ちがうのは、使う「条件」だけ！

<div class="mokuhyo" markdown="1">

この単元でできるようになることを、目標としてまとめました。

1. 相似の意味と記号（∽）を理解し、対応する辺・角、相似比を正しく答えられる。
2. 三角形の相似条件を3つ言え、それぞれがなぜ「形を決める条件」なのか説明できる。
3. 相似の証明を、答案の形（仮定・根拠・条件・結論）で書ける。
4. 直角三角形の中にできる相似（入試頻出）を見つけ、長さを求められる。

</div>

> 💬 **先生のひとこと**
> 神奈川の入試の問3では、毎年のように「**三角形が相似であることの証明**」が出ます（空らんをうめる形や、選択肢から選ぶ形が多い）。そして相似は、このあと学ぶ「平行線と比」「面積比」「円」「三平方」**全部の土台**です。今日の答案の型は、何度も書いて手に覚えさせましょう。

### 三角形の相似条件 ― 3つだけ

2つの三角形は、次のどれか1つが成り立てば相似です。

<div class="koushiki" data-title="三角形の相似条件" markdown="1">

**① 3組の辺の比がすべて等しい**
　$a:a'=b:b'=c:c'$
**② 2組の辺の比とその間の角がそれぞれ等しい**
　$a:a'=c:c'$、∠B＝∠B′
**③ 2組の角がそれぞれ等しい**
　∠B＝∠B′、∠C＝∠C′

</div>

中2で学んだ合同条件とならべると、そっくりなことがわかります。

| 合同条件 | 相似条件 |
|---|---|
| 3組の**辺**がそれぞれ等しい | 3組の**辺の比**がすべて等しい |
| 2組の**辺**とその間の角がそれぞれ等しい | 2組の**辺の比**とその間の角がそれぞれ等しい |
| 1組の辺とその両端の角がそれぞれ等しい | **2組の角**がそれぞれ等しい |

<div class="memo" markdown="1">

**本質**
なぜこの3つなのでしょう？ 合同条件は「**三角形の形と大きさ**が1つに決まる条件」でした。相似は「**大きさは自由で、形だけ**が決まればよい」ので、合同条件の「長さ」を「長さの**比**」に変えればよいのです。
特に③は、合同条件の「1組の辺とその両端の角」から「辺」を取ったもの。辺の長さは自由（大きさは自由）でよいので、**角が2つ決まれば形が決まる**のです。（角が2つ決まれば、3つ目の角も 180° から自動的に決まります）
入試の証明で使われるのは、圧倒的に **③ 2組の角**です。迷ったら、まず「等しい角を2組さがす」から始めましょう。

</div>

> ⚠️ **よくあるミス**
> 「2組の辺の比と **1つの角**」が等しくても、その角が「**2辺の間の角**」でなければ相似とはいえません。合同条件と同じ注意です。

### 相似の証明の書き方 ― 答案の型

<div class="koushiki" data-title="相似の証明の答案の型" markdown="1">

**① どの三角形とどの三角形か**：「△ABC と △DEF において」
**② 等しい角（等しい比）を、根拠つきで書く**：「仮定から　∠B＝∠E　…①」「共通な角だから　∠A＝∠A　…②」
**③ 相似条件を書く**：「①、②より、**2組の角がそれぞれ等しい**から」
**④ 結論**：「△ABC∽△DEF」（対応する順に！）

</div>

等しい角の「根拠」として、よく使うものはこの5つです。

| 根拠 | どんなときに使う？ |
|---|---|
| **共通な角** | 2つの三角形が、1つの角を共有している |
| **対頂角は等しい** | 2本の直線が交わっている（砂時計の形） |
| **平行線の錯角・同位角は等しい** | 図に平行線（平行四辺形・台形）がある |
| **仮定から** | 問題文に「∠○＝∠△」「直角」などと書いてある |
| **三角形の内角・外角** | 「180° から引く」「外角＝となりにない2つの内角の和」 |

> 🔍 **探偵で例えると**
> 証明は、犯人（結論）を当てるだけでは不合格。「**なぜそう言えるのか**」という証拠（根拠）を1つずつ示して、はじめて有罪にできます。「∠A＝∠D」だけ書いて理由がないのは、証拠のない推理と同じです。

<div class="koushiki" data-title="直角三角形と垂線" markdown="1">

**△ABC∽△HBA∽△HAC**
理由：どれも直角をもち、△ABC と △HBA は ∠B が共通、△ABC と △HAC は ∠C が共通。
ここから、次の関係が出てくる（発展）
**$\text{AB}^2=\text{BH}\times\text{BC}$　　$\text{AC}^2=\text{CH}\times\text{CB}$　　$\text{AH}^2=\text{BH}\times\text{HC}$**

</div>

<div class="memo" markdown="1">

**発展**
たとえば △ABC∽△HBA から AB：HB＝BC：BA、これを「外側どうし・内側どうし」でかけると $\text{AB}^2=\text{BH}\times\text{BC}$ になります。丸暗記ではなく、**毎回、相似から比例式を立てて**出せるようにしておきましょう。この形は、のちに学ぶ「**三平方の定理**」の証明にも使われます。

</div>

### 相似を使って長さを求める ― 比例式

相似がわかったら、**対応する辺の比**で比例式をつくります。

<div class="koushiki" data-title="比例式の性質" markdown="1">

**$a:b=c:d$ ならば $ad=bc$**（外側どうしの積＝内側どうしの積）

</div>

> 💡 **コツ**：対応する辺を見つけるときは、∽ の記号の**順番**を見ます。△ABC∽△DEF なら、AB と DE（1・2文字目どうし）、BC と EF（2・3文字目どうし）、CA と FD（3・1文字目どうし）が対応です。図の向きにまどわされないように！
