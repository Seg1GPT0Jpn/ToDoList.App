# 📚 中3-16　神奈川入試 数学 総合演習

**対象：中学3年（中学数学の全範囲）｜目安：120〜150分（演習50分＋解説）｜つながる先：神奈川県公立高校入試（共通選抜）本番**

---

## 👨‍🏫 導入・その単元についての歴史や詳細など

<div class="history" markdown="1">

神奈川県の公立高校入試（共通選抜）の数学は、**50分・100点満点**。解答は **マークシート方式** で、選択肢の番号をマークする問題と、「あ」「い」…のわくに **答えの数字を1けたずつマークする** 問題があります。
マークシートなので、途中式は採点されません。そのかわり、**最後の答えが合っていなければ0点**。「考え方は合っていたのに計算ミス」が、そのまま失点になります。

ここ数年の問題は、おおむね次のような構成です（年度によって入れかわることがあります）。

| 大問 | 主な内容 | 特徴 |
|---|---|---|
| 問1 | 計算（5問前後） | 正負の数・式の計算・平方根。**全問正解が前提** |
| 問2 | 小問集合（6問前後） | 因数分解・二次方程式・変化の割合・文章題・平方根の性質・標本調査など |
| 問3 | 図形と資料 | **円と相似の証明（穴うめ選択）**、角度・長さ・面積比、箱ひげ図などの資料の読み取り |
| 問4 | 関数 | 放物線と直線、直線の式、面積が等しくなる点 |
| 問5 | 確率 | さいころ・カードで「操作」をする問題が多い |
| 問6 | 空間図形 | 体積、線分の長さ、表面上の最短距離 |

</div>

いよいよ、中学数学の総まとめです。
入試は「全部の問題を解く試験」ではありません。**50分で、取れる問題を確実に取りきる試験** です。神奈川の数学は、各大問の後半がとても難しく作られています。満点をねらうより、**「取るべき問題」を落とさない** ことが合格への近道です。

<div class="mokuhyo" markdown="1">

この単元でできるようになることを、目標としてまとめました。

1. 神奈川入試の大問構成と、それぞれで出やすい「型」を知る。
2. 50分の時間配分と、解く順番の作戦を立てられる。
3. 分野ごとの「この型が出たらこう解く」を使って、すばやく方針を立てられる。
4. 本番と同じ形の総合問題を50分で解き、自分の弱点を見つけられる。

</div>

### 時間配分と解く順番の作戦

| 時間 | やること | ポイント |
|---|---|---|
| 0〜12分 | **問1・問2** | 1問1分が目安。ここで 35点前後を確実に |
| 12〜27分 | **問3** | (ア) の証明の穴うめ、資料の読み取りを先に。重い小問は後回し |
| 27〜35分 | **問4・問5** の前半 | 関数の (ア)(イ)、確率の (ア) は基本。必ず取る |
| 35〜42分 | **問6** の前半 | 体積や長さの (ア)(イ) は三平方の定理で解ける |
| 42〜47分 | 後回しにした問題 | 「あと1つ取れそう」な問題を選んで挑戦 |
| 47〜50分 | **マークの見直し** | 番号のずれ・マークもれを確認 |

> 💬 **先生のひとこと**
> 作戦は「**各大問の前半を全部取ってから、後半に戻る**」です。問3の最後の小問に15分使って、問6の (ア) を解く時間がなくなる……これが毎年いちばん多い失敗パターン。**2分考えて方針が立たなければ、印をつけて次へ！**

## 📖 ポイント（解説）

### 問1・問2（計算・小問）の型

| 出たら | こう解く |
|---|---|
| 分数をふくむ式の計算 | **通分** して1つの分数に。分母をはらうのは方程式のときだけ |
| 単項式の乗除 | 全部をかけ算に直し、**符号 → 係数 → 文字** の順に決める |
| 平方根の計算 | 分母の有理化、$\sqrt{a^2b}=a\sqrt{b}$ で簡単にしてから計算 |
| 因数分解 | ①共通因数 → ②公式。式が長ければ **展開して整理してから** |
| 二次方程式 | 因数分解できなければ **解の公式** $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$ |
| $y=ax^2$ の変化の割合 | $x$ が $p$ から $q$ まで → **$a(p+q)$** |
| $\sqrt{\ }$ が自然数になる $n$ | 根号の中を **素因数分解** し、指数をすべて偶数にする |
| 割合の文章題 | 「去年」を $x,\ y$ とおき、増減は **$0.1x$、$-0.05y$** と表す |

### 問3（図形・資料）の型

<div class="koushiki" data-title="円と相似の証明（穴うめ）" markdown="1">

① 図に **同じ角の印** を書きこむ（円周角・対頂角・共通な角・平行線の錯角や同位角）。
② 証明の流れの中で「すでに出た式」と「まだ出ていない式」を区別し、**①②…の番号のつながり** から空らんに入るものを決める。
③ 相似条件は、円の問題ならほとんどが **「2組の角がそれぞれ等しい」**。

</div>

- **角度** → 「どの弧に対する円周角か」を確認。中心があれば半径をひいて二等辺三角形。
- **面積比** → 「相似な三角形（相似比の2乗）」と「高さが等しい三角形（底辺の比）」を組み合わせ、**面積を数で図に書きこむ**。
- **長さ** → 直角三角形があれば三平方の定理、平行線があれば相似。直角三角形の中の垂線は、**面積を2通りに表す** と速い。
- **箱ひげ図** → 範囲＝最大値−最小値、四分位範囲＝第3四分位数−第1四分位数。**平均値は箱ひげ図からは読み取れない** ことに注意。

### 問4（関数）の型

<div class="koushiki" data-title="放物線と直線の定番手順" markdown="1">

① グラフ上の点の座標を式に代入して **$a$ を求める**。
② 2点の座標から **直線の式**（傾き＝$y$ の増加量÷$x$ の増加量）。
③ 三角形の面積は **$y$ 軸で2つに分ける**：$\dfrac{1}{2}\times(\text{切片})\times(\text{2点の }x\text{ 座標の差})$
④ 面積が等しい点は **等積変形**：底辺に平行で、もとの頂点を通る直線の上をさがす。

</div>

### 問5（確率）の型

- 大小2つのさいころ → **6×6の表** をかいて、条件に合うマスを数える（全部で36通り）。
- 「操作」の問題 → 問題文の操作を **具体的な1つの目で1回ためして** から、表を作る。
- 「少なくとも1つ」→ **1−（1つもない確率）**。

### 問6（空間図形）の型

- 体積 → 底面と高さを決める。三角錐は **どの面を底面にしてもよい**。
- 線分の長さ → 立体の中から **直角三角形をぬき出す**（直方体の対角線 $\sqrt{a^2+b^2+c^2}$）。
- 表面上の最短距離 → **展開図で一直線**。どの辺でつなぐかを確認。
- 点と平面の距離 → **体積を2通りに表す**。

<span class="toi">問1</span> 関数 $y=-3x^2$ で、$x$ の値が $-2$ から $5$ まで増加するときの変化の割合を求めなさい。

<span class="toi">問2</span> $\sqrt{90n}$ が自然数となるような、最も小さい自然数 $n$ を求めなさい。

**STEP 1　直線ABの式**
傾き $\dfrac{4-1}{2-(-1)}=1$、$y=x+b$ に A を代入して $b=2$。直線AB：$y=x+2$

**確率：表で数える**
大小2つのさいころを同時に1回投げ、大きいさいころの出た目を $a$、小さいさいころの出た目を $b$ とします。$a+2b$ が 10 以上になる確率を求めなさい。

**STEP 1　$b$ で場合分けして数える**
$b=6$：$a+12\ge10$ → $a$ は何でもよい → 6通り
$b=5$：$a+10\ge10$ → 6通り
$b=4$：$a+8\ge10$ → $a\ge2$ → 5通り
$b=3$：$a+6\ge10$ → $a\ge4$ → 3通り
$b=2$：$a+4\ge10$ → $a\ge6$ → 1通り
$b=1$：$a+2\ge10$ → 0通り
**STEP 2　合計して36でわる**
$6+6+5+3+1=21$、$\dfrac{21}{36}=\dfrac{7}{12}$

**答え　$\dfrac{7}{12}$**

</div>

<div class="rei" data-label="例題" data-num="3" markdown="1">

**マークシートの数字の答え方**
答えが $\dfrac{7}{12}$ で、解答らんが「$\dfrac{\text{あ}}{\text{いう}}$」のとき、どうマークしますか。また、答えが $3\sqrt{2}$ で「え$\sqrt{\text{お}}$」のときは？

**STEP 1　1つのわくに数字1つ**
あ＝7、い＝1、う＝2
**STEP 2　わくの数をヒントにする**
え＝3、お＝2。もし「$\sqrt{\text{おか}}$」のように2けたのわくなら、$\sqrt{18}$ のような **簡単にしていない形** になるはずがないので、自分の答えを見直すサインです。

**答え　あ7・い1・う2、え3・お2**

</div>

> 💬 **先生のひとこと**
> わくの数は **最大のヒント** です。分母が1けたのはずなのに2けたのわくがあったら、約分や計算をもう一度確認。逆に、答えを出してからわくの数と合わないときは、ほぼ確実にどこかでミスしています。

## 💡 解答と解説（別冊）

### 問1・問2
問1　$-3\times(-2+5)=$ **$-9$**
問2　$90n=2\times3^2\times5\times n$ なので、$n=2\times5=$ **10**（$\sqrt{900}=30$）

### 【1】（問1：計算）
(ア) **3**　$-7+12=5$
(イ) **2**　$-\dfrac{9}{12}+\dfrac{10}{12}=\dfrac{1}{12}$
(ウ) **1**　$-\dfrac{18x^2y\times2y}{3x}=-12xy^2$
(エ) **1**　$\dfrac{4(2x+y)-3(x-2y)}{12}=\dfrac{8x+4y-3x+6y}{12}=\dfrac{5x+10y}{12}$
(オ) **2**　$(3-4)+\dfrac{6\sqrt{3}}{3}=-1+2\sqrt{3}$

**ワンポイント**：(エ) の 2 は $-3\times(-2y)$ を $-6y$ としたミス、4 は分母どうしをたしたミス。選択肢は「よくあるミス」の集まりです。

### 【2】（問2：小問集合）
(ア) **1**　展開すると $x^2-4x-12+3x=x^2-x-12=(x-4)(x+3)$
(イ) **2**　$x=\dfrac{-5\pm\sqrt{25-8}}{2}=\dfrac{-5\pm\sqrt{17}}{2}$
(ウ) **1**　$a(1+4)=-10$ → $a=-2$
(エ) **2**　昨年の男子を $x$ 人、女子を $y$ 人とすると $x+y=500$、$0.1x-0.05y=8$。
　2つ目を20倍して $2x-y=160$。たして $3x=660$、$x=220$。今年の男子は $220\times1.1=242$（人）
(オ) **3**　$60=2^2\times3\times5$ なので $n=3\times5=15$（$\sqrt{900}=30$）
(カ) **3**　$4000\times\dfrac{2}{80}=100$

**ワンポイント**：(エ) は **1 の 220人（昨年の男子）** を選ぶミスが多い問題。聞かれているのは「今年」です。

### 【3】（問3：図形・資料）
(ア)(i) (a) **1**　(b) **2**　(c) **3**
(ii) △CBE∽△CAB より CB：CA＝CE：CB → $6:9=CE:6$ → $CE=4$。AE＝$9-4=$ **5 cm**
(イ) **2**　A：範囲は1組 $38-12=26$、2組 $40-8=32$ → 正しい。B：四分位範囲は1組 $31-20=11$、2組 $34-22=12$ → 誤り。C：中央値は1組26点、2組25点 → 正しい。D：箱ひげ図から平均値は読み取れない → 誤り。
(ウ) **1：5**　AD∥BE より △AFD∽△EFB、相似比は AD：EB＝$2:1$。△BEF＝1 とすると △AFD＝4。AF：FE＝$2:1$ より △ABF＝2。△ABD＝$2+4=6$ なので △BCD＝6。四角形FECD＝$6-1=5$
(エ) **$\dfrac{24}{5}$ cm**　AB＝$\sqrt{8^2+6^2}=10$。△ABC の面積を2通りに表すと $\dfrac{1}{2}\times6\times8=\dfrac{1}{2}\times10\times CD$ → $CD=\dfrac{48}{10}=\dfrac{24}{5}$

**ワンポイント**：(ア)(i) は「**角のリレー**」。∠CBE（＝∠CBD）を、②で ∠CAD に、③で ∠BAC（＝∠CAB）にうつしています。(エ) の「面積を2通り」は、直角三角形の垂線の長さを求める最速の方法です。

### 【4】（問4：関数）
(ア) **2**　$8=a\times16$ → $a=\dfrac{1}{2}$
(イ) B$(2,\ 2)$。傾き $m=\dfrac{2-8}{2-(-4)}=-1$。$y=-x+n$ に B を代入して $n=4$。**$m=-1$、$n=4$**
(ウ) **$-1+\sqrt{17}$**　△OAB と △PAB は底辺ABが共通。Oと反対側で、直線ABからの距離がOと等しい直線は、切片が $4+4=8$ の $y=-x+8$（直線ABとの切片の差が、OとABの切片の差 4 と等しい）。
$\dfrac{1}{2}x^2=-x+8$ → $x^2+2x-16=0$ → $x=-1\pm\sqrt{17}$。正の方で $x=-1+\sqrt{17}$

**ワンポイント**：Oを通る平行線 $y=-x$ との交点 $x=-2$ もありますが、問題の条件「$x$ 座標が正」に合いません。**直線ABの反対側** にも平行線をひくのがこの問題の山場です。

### 【5】（問5：確率）
(ア) **$\dfrac{1}{3}$**　$N=10a+b$ が3の倍数 ⇔ $a+b$ が3の倍数。和が3：2通り、6：5通り、9：4通り、12：1通り、合計12通り。$\dfrac{12}{36}=\dfrac{1}{3}$
(イ) **$\dfrac{2}{9}$**　素数は 11、13、23、31、41、43、53、61 の8通り。$\dfrac{8}{36}=\dfrac{2}{9}$

**ワンポイント**：(イ) は 51（＝3×17）を素数とまちがえやすい。各位の和が3の倍数なら3でわれます。

### 【6】（問6：空間図形）
