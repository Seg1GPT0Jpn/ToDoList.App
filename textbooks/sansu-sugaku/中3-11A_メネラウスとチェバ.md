**対象：中学3年（相似な図形の発展・難関校対策）｜目安：120分｜つながる先：高校 数学A「図形の性質」→ 神奈川入試 問3（線分の比・面積比）・難関私立の図形問題**

---

## 👨‍🏫 導入・その単元についての歴史や詳細など

<div class="history" markdown="1">

**メネラウス**は、紀元100年ごろ、エジプトのアレクサンドリアで活やくしたギリシャの天文学者・数学者です。星の位置を計算するために「球面の上の三角形」を研究し、その本『球面論』の中で、今日学ぶ定理（を球面に広げたもの）を使いました。平面の定理は、それより前から知られていたと考えられています。
**チェバ**は17世紀のイタリアの数学者で、1678年に出した本で「三角形の3本の線が1点で交わる条件」を発表しました。（実は11世紀のスペインのイスラム王国の王で数学者でもあった人物が、同じ内容をすでに書き残していたことが、のちにわかっています。）
そして**てんびん法**のもとになっているのは、紀元前3世紀のアルキメデスが調べた「**てこの原理**」と「**重心**」です。「私に支点を与えよ。そうすれば地球を動かしてみせよう」と言ったと伝えられています。

</div>

これまでの相似の単元で、「**平行線を引けば比が写る**」「**高さが同じ三角形の面積比は底辺の比**」という2つの武器を手に入れました。今日はこの2つを組み合わせてできた、**線分の比を一発で出す"必殺技"**を学びます。

ここで1つ大事なことを先に言っておきます。メネラウスの定理とチェバの定理は、**高校の数学A（図形の性質）で正式に学ぶ内容**で、中学の教科書にはのっていません。でも、難関校の入試問題では「知っていると30秒、知らないと5分」という差がつく場面がよくあります。だから今日は、

- 中学で習ったこと（平行線と比・面積比）だけで**証明できる**ことを確かめてから使う
- 記述や証明の問題では、**中学の範囲の方法（平行線を引く・相似）で書く**

という2つのルールで進めます。てんびん法は、中学受験の算数でよく使われる考え方で、図に数を書きこむだけで答えが出る、とても速い方法です。

<div class="mokuhyo" markdown="1">

この単元でできるようになることを、目標としてまとめました。

1. 角の二等分線の定理（内角・外角）を、平行線を引いて証明し、使える。
2. メネラウスの定理を「一筆書き」で正しく立式し、どの三角形とどの直線に使うかを選べる。
3. チェバの定理を面積比で説明し、メネラウスの定理と使い分けられる。
4. てんびん法で、三角形の中の線分の比をすばやく求められ、それが正しい理由を説明できる。
5. 求めた線分の比から、三角形や四角形の面積比を求められる。

</div>

**証明**（平行線を引いて、二等辺三角形をつくる）
① C を通り DA に平行な直線を引き、BA の延長との交点を E とする。
② AD∥EC だから、**錯角**で ∠DAC＝∠ACE、**同位角**で ∠BAD＝∠AEC。
③ ∠BAD＝∠DAC（二等分線）だから、∠ACE＝∠AEC。
④ 2つの角が等しいので、△ACE は**二等辺三角形**。よって **AE＝AC**。
⑤ △BCE で AD∥EC だから、三角形と比の定理より BD：DC＝BA：AE＝**AB：AC**。

上の図では BD：DC＝6：4＝3：2 なので、BD＝$5\times\dfrac{3}{5}=3$、DC＝2 です。

<div class="memo" markdown="1">

**本質**
面積を使った、もう1つの見方もあります。角の二等分線の上の点 D から辺 AB、AC までの距離は等しい（中1の作図で学んだ性質）。だから、△ABD と △ACD は、AB、AC を底辺とみると**高さが同じ**で、面積比は AB：AC。
一方、BD、DC を底辺とみると頂点 A が共通なので、面積比は BD：DC。同じ2つの三角形の面積比だから、**AB：AC＝BD：DC**。
「1つの面積比を、2通りの底辺で見る」――これは、あとでチェバの定理の証明でも使う大事な発想です。

### メネラウスの定理

三角形の「外から」1本の直線がつきささって、2辺を横切り、残り1辺の延長と交わる図を考えます。

<div class="koushiki" data-title="メネラウスの定理" markdown="1">

直線 ℓ が、△ABC の辺 AB、BC、CA（またはその延長）と、それぞれ点 P、Q、R で交わるとき
$$\dfrac{\mathrm{AP}}{\mathrm{PB}}\times\dfrac{\mathrm{BQ}}{\mathrm{QC}}\times\dfrac{\mathrm{CR}}{\mathrm{RA}}=1$$

**覚え方は「一筆書き」**です。
1. 三角形の頂点（A）からスタートする。
2. **頂点 → 分点 → 頂点 → 分点 → …** と、直線 ℓ との交点（分点）と三角形の頂点を交互に通って、ぐるっと1周して A にもどる。
3. 通った6本の線分を、**分子・分母・分子・分母…と交互に**並べて、かけると 1。

ポイントは、③BQ のように、**延長上の分点 Q へ行くときは三角形の外にはみ出していい**こと。B から Q まで行き（③）、Q から C へもどってくる（④）。この「行って、もどる」で迷う人が多いので、上の図の矢印をよく見てください。

C を通り ℓ に平行な直線を引き、辺 AB との交点を D とします。
・△BPQ で DC∥PQ だから　BQ：QC＝BP：PD
・△ADC で PR∥DC だから　CR：RA＝DP：PA
分数で書くと $\dfrac{\mathrm{BQ}}{\mathrm{QC}}=\dfrac{\mathrm{BP}}{\mathrm{PD}}$、$\dfrac{\mathrm{CR}}{\mathrm{RA}}=\dfrac{\mathrm{DP}}{\mathrm{PA}}$。これを左辺に入れると
$$\dfrac{\mathrm{AP}}{\mathrm{PB}}\times\dfrac{\mathrm{BP}}{\mathrm{PD}}\times\dfrac{\mathrm{DP}}{\mathrm{PA}}=1$$
と、きれいに約分されて 1 になります。**辺 AB の上の比に、ぜんぶ"写して"しまう**のがアイデアです。

**使い方の手順**（ここがいちばん大事）

| 手順 | やること |
|---|---|
| ① | 求めたい比（たとえば AO：OD）が乗っている**線分 AD を1辺にもつ三角形**を探す |
| ② | その三角形を**横切る直線**（点 O を通る直線）を見つける。それが ℓ |
| ③ | 三角形の頂点から一筆書きで式を立て、わかっている比を入れる |

入試でよく出るのは、2本の線 AD、BE が O で交わり、**AO：OD を求める**形です。このときは
**△ADC と、それを横切る直線 B-O-E** を使います（B は辺 DC の延長上の分点）。

$$\dfrac{\mathrm{AO}}{\mathrm{OD}}\times\dfrac{\mathrm{DB}}{\mathrm{BC}}\times\dfrac{\mathrm{CE}}{\mathrm{EA}}=1$$

（A →O→ D →B→ C →E→ A の一筆書き。DB は「D から延長上の B へ行く」、BC は「B から C へもどる」）

> ⚠️ **よくあるミス**
> ・②の「BC」を「DC」にしてしまう。分点 B から**次の頂点 C まで**なので BC です。

### チェバの定理

今度は、三角形の3つの頂点から向かいの辺へ引いた3本の線が、**1点で交わる**図です。

<div class="koushiki" data-title="チェバの定理" markdown="1">

△ABC の内部の点 O について、AO、BO、CO の延長が辺 BC、CA、AB と交わる点を D、E、F とすると
$$\dfrac{\mathrm{AF}}{\mathrm{FB}}\times\dfrac{\mathrm{BD}}{\mathrm{DC}}\times\dfrac{\mathrm{CE}}{\mathrm{EA}}=1$$
（頂点 → 分点 → 頂点 …と三角形の周を1周する。メネラウスと同じ一筆書き）

**証明**（面積比を使う）
△AFC と △BFC は、底辺 AF、FB が一直線上で頂点 C が共通だから、面積比は AF：FB。△AFO と △BFO も同じく AF：FB。
大きいほうから小さいほうをひくと、**△AOC：△BOC＝AF：FB** です（同じ比の三角形どうしをひいても、比は変わらない）。同じように
$$\dfrac{\mathrm{AF}}{\mathrm{FB}}=\dfrac{\triangle\mathrm{AOC}}{\triangle\mathrm{BOC}},\quad \dfrac{\mathrm{BD}}{\mathrm{DC}}=\dfrac{\triangle\mathrm{AOB}}{\triangle\mathrm{AOC}},\quad \dfrac{\mathrm{CE}}{\mathrm{EA}}=\dfrac{\triangle\mathrm{BOC}}{\triangle\mathrm{AOB}}$$
3つをかけると、分子と分母がすべて約分されて **1** になります。

<div class="memo" markdown="1">

**本質**
チェバの定理の正体は、「**O を頂点とする3つの三角形 △OBC、△OCA、△OAB の面積の比**」です。辺の上の比は、すべてこの3つの面積の比で表せます。だから、3つをかけると1周して元にもどり、1 になるのです。この見方は、あとのてんびん法の「本質」でもう一度出てきます。

</div>

**メネラウスとチェバの使い分け**

| | メネラウスの定理 | チェバの定理 |
|---|---|---|
| 図の形 | 1本の直線が三角形を**横切る** | 3本の線が三角形の中の**1点で交わる** |
| 出てくる比 | **交点 O で線分がどう分かれるか**（AO：OD など）が求まる | **辺の上の比**（AF：FB など）だけ |
| よくある使い方 | 2本の線の交点で、線分の比を求める | 2つの辺の比から、3つ目の辺の比を求める |

つまり、チェバは**辺の比どうし**の関係、メネラウスは**交点 O の位置**まで分かる定理です。入試では「チェバで3つ目の辺の比を出す → メネラウスで AO：OD を出す」と**組み合わせる**ことも多いです。

**③ 2本の線の交点（メネラウス型）**

「AD と BE の交点 O で、AO：OD と BO：OE を求めよ」という形は、メネラウスの定理を2回使う問題でした。てんびん法なら、**辺の比が2つわかれば、おもりが3つ全部決まる**ので、一気に両方出ます（例題4）。
しかも、CO を延ばして AB と交わる点 F の比（AF：FB）まで、ついでに出てしまいます。チェバ型とメネラウス型は、てんびんでは**同じ図**なのです。

<span class="toi">問6</span> △ABC で、BD：DC＝1：3、AE：EC＝1：1 です。AD と BE の交点を O とするとき、AO：OD と BO：OE を、てんびん法で求めなさい。

<div class="memo" markdown="1">

**本質**　なぜ、てんびん法はメネラウス・チェバと同じ答えになるのか
**(1) チェバの定理が自動的に成り立つから**
A、B、C のおもりを $a$、$b$、$c$ とすると、AF：FB＝$b:a$、BD：DC＝$c:b$、CE：EA＝$a:c$。かけると
$\dfrac{b}{a}\times\dfrac{c}{b}\times\dfrac{a}{c}=1$。どんな重さを置いても、チェバの定理の式がちゃんと成り立つのです。
**(2) おもりの正体は「面積」だから**
チェバの証明で見たように、BD：DC＝△OAB：△OCA です。おもりは「逆の比」なので、
**A のおもり：B のおもり：C のおもり＝△OBC：△OCA：△OAB**
つまり、おもりは「**その頂点の向かいにある、O を頂点とする三角形の面積**」になっています。
すると AO：OD は、△OAB：△ODB＝△OCA：△ODC で、この2組をたすと（同じ比をたしても比は変わらない）
AO：OD＝（△OAB＋△OCA）：△OBC＝（$b+c$）：$a$
これは、てんびん法の「D のおもり：A のおもり」そのものです。
**(3) 物理の言葉で言うと**
3つのおもり全体の重心は、「B と C を先にまとめて D に置き、A とつり合わせる」と考えても、「A と C を先にまとめて E に置き、B とつり合わせる」と考えても、**同じ1つの点**です。その点が O です。
メネラウスもチェバもてんびんも、「**O で分けられた三角形の面積の比**」という1つの事実を、ちがう形で書いたものなのです。

</div>

| 記述・証明の問題 | **平行線を引く・相似** | 中学の範囲の方法で書く |
| 答えの確かめ | 別の方法でもう1回 | 2つの方法で同じなら安心 |

### 入試での使いどころ ― 線分の比から面積比へ

線分の比が出たら、入試ではたいてい**面積**を聞かれます。使うのは前の単元の道具です。

1. **高さが同じ三角形の面積比＝底辺の比**（いちばんよく使う）
2. 全体の面積 → 大きい三角形 → 小さい三角形へと、**比を順番にかけて**しぼりこむ
3. 四角形は「三角形−三角形」で出す

たとえば例題5のように、△ABC → △ABD（BD：BC で）→ △OBD（OD：AD で）と、**2段階で比をかける**のが定番の流れです。「どの頂点が共通で、どの底辺が一直線上か」を図で確かめながら進めましょう。

### 問1〜問6
問1　BD：DC＝10：6＝5：3 → BD＝$8\times\frac{5}{8}=$ **5 cm**
問2　BE：EC＝9：6＝3：2。BE−EC＝BC＝5 で、比の差 1 が 5 cm → CE＝$5\times2=$ **10 cm**

問4　$\frac{2}{1}\times\frac{1}{1}\times\frac{\mathrm{CE}}{\mathrm{EA}}=1$ → CE：EA＝1：2 → **AE：EC＝2：1**
問5　AP：PB＝6：4＝3：2 → AP＝$20\times\frac{3}{5}=$ **12 cm**（たしかめ：4×12＝48、6×8＝48 ✓）

### 【1】
(1) BD：DC＝9：6＝3：2 → BD＝$10\times\frac{3}{5}=$ **6 cm**
(2) AB：AC＝BD：DC → 8：AC＝4：3 → **AC＝6 cm**
(3) BD：DC＝12：8＝3：2 → DC＝$15\times\frac{2}{5}=$ **6 cm**
(4) BE：EC＝6：4＝3：2。BE−EC＝BC＝4 で、比の差 1 が 4 cm → CE＝$4\times2=$ **8 cm**

**ワンポイント**：(3) は BD ではなく **DC** を聞いています。AB に近いほうが BD、AC に近いほうが DC。(4) の外角は「差が BC」。内角の「和が BC」と区別しましょう。

### 【2】
(1) $\frac{2}{3}\times\frac{\mathrm{BQ}}{\mathrm{QC}}\times\frac{1}{2}=1$ → BQ：QC＝3：1 → BC＝3−1＝2 なので **BC：CQ＝2：1**
(2) BC：CQ＝2：1 → BQ：QC＝3：1。$\frac{1}{1}\times\frac{3}{1}\times\frac{\mathrm{CR}}{\mathrm{RA}}=1$ → CR：RA＝1：3 → **AR：RC＝3：1**

**ワンポイント**：メネラウスの式に出てくるのは **BQ と QC**（分点 Q からの長さ）です。問題が BC：CQ を聞いているときは、BQ＝BC＋CQ と**直してから**答えます。ここでのミスがいちばん多いです。

### 【3】

(2) $\frac{3}{2}\times\frac{\mathrm{BD}}{\mathrm{DC}}\times\frac{1}{2}=1$ → **BD：DC＝4：3**
(3) $\frac{2}{5}\times\frac{5}{4}\times\frac{\mathrm{CE}}{\mathrm{EA}}=1$ → CE：EA＝2：1 → **AE：EC＝1：2**

**ワンポイント**：チェバの式は CE：EA の順（C から A へ回る向き）です。答えが AE：EC を聞いていたら**ひっくり返す**のを忘れずに。てんびんで確かめると、(1) は A：B＝1：1、B：C＝3：2 → A＝3、B＝3、C＝2 → AE：EC＝C：A＝2：3 ✓
