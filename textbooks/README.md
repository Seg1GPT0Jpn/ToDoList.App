# 小5〜中3　5教科オリジナルテキスト

小学5年生2人（週1回・60〜90分）に教えるためのテキスト集です。
ゴールは**神奈川県の公立高校入試**。小5のうちから中学の内容にも挑戦できるように作っています。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `sansu-sugaku/` | 算数・数学（高校数学の教科書風デザイン。カラー版とモノクロ版） |
| `eigo/` | 英語（中1〜中3の文法） |
| `rika/` | 理科（物理・化学・生物・地学） |
| `shakai/` | 社会（地理・歴史・公民） |
| `kokugo/` | 国語（小5〜中3） |
| `pdf/` | 印刷用 PDF（上のテキストから自動で作る） |
| `tools/` | PDF を作るためのプログラムとデザイン（CSS） |

## 教科ごとの形式

| 教科 | タイトル | 中身 | 解答 |
|---|---|---|---|
| 算数・数学 | 📚 単元名 | 導入（history・目標）→ ポイント（公式の箱）→ 例題 → 演習（基礎・標準・挑戦）→ 先生用メモ。**高校数学の教科書風デザイン**（カラー版とモノクロ版） | 別冊（改ページ） |
| 英語 | 中1英語 Unit 1-1「単元名」 | □の枠（POINT）で文法の要点を例文と確認 → **文法の演習問題をたくさん**（基本・標準・入試にチャレンジ）。大きな単元が終わったら「**Unit ○ まとめの問題**」 | 冊子の最後 |
| 国語 | 中1国語 文法1「単元名」 | 英語と同じ（文法のまとめを重視：POINT の枠 → 演習） | 冊子の最後 |
| 理科 | 中1理科 第○単元「単元名」 | **要点まとめ 約4ページ → 練習問題 約4ページ** | 冊子の最後 |
| 社会 | 中1地理 第○単元「単元名」 | 理科と同じ（要点まとめ 約4ページ → 練習問題 約4ページ） | 冊子の最後 |

英語・国語・理科・社会は、塾テキスト風（ゴシック体・モノクロ）のデザインです（\`tools/juku.css\`）。
どの教科にも、神奈川入試の形式（「1〜4の中から1つ選び」「使わない語が1つまじった並べかえ」など）の問題を入れています。

## PDF の作り方

初回だけ準備します。

```bash
pip install markdown
```

```bash
cd textbooks/tools && npm install
```

全テキストを PDF にします（`textbooks/pdf/` に出力）。

```bash
python3 textbooks/tools/build_pdf.py
```
