# 小5〜中3　五教科テキスト（神奈川県公立高校入試対策）

小学5年生から中学3年生まで使い続けて、神奈川県の公立高校入試に挑める五教科の教材です。
教科ごとに1冊の本（PDF）になっています。

## 本（`books/`）

| ファイル | 中身 |
|---|---|
| `英語.pdf` | 中1〜中3の全文法（全55単元）。Unit ごとに「まとめの問題」。巻末に全解答 |
| `算数数学.pdf` / `算数数学_モノクロ.pdf` | 小5〜中3（全76単元）。高校数学の教科書風デザイン |
| `算数数学_解答解説_別冊.pdf` | 算数・数学の解答・解説と先生用メモ（別冊） |
| `理科.pdf` | 物理・化学・生物・地学（全36単元）。要点まとめ約4ページ＋練習問題約4ページ。巻末に全解答 |
| `社会.pdf` | 地理・歴史・公民（全46単元）。理科と同じ形式。巻末に全解答 |
| `国語.pdf` | 小5〜中3（全39単元）。文法のまとめを重視。巻末に全解答 |

本の作り：表紙 → 目次（ページ番号つき）→ 分野・学年ごとのタイトルページ → 本文（単元ごとに改ページ）→ 巻末解答（算数・数学は別冊）。

## フォルダ

| フォルダ | 中身 |
|---|---|
| `eigo/` `sansu-sugaku/` `rika/` `shakai/` `kokugo/` | 単元ごとの原稿（Markdown）。1ファイル＝1単元 |
| `books/` | 教科ごとの本（PDF） |
| `tools/` | 本を作るプログラム・デザイン・執筆ルール |

## 本の作り方

準備（初回のみ）：Python の markdown・pypdf・reportlab、Node.js と Playwright（Chromium）、ghostscript、日本語フォント（IPAex 明朝・ゴシック）。

```bash
python3 textbooks/tools/build_book.py            # 5教科すべて
```

```bash
python3 textbooks/tools/build_book.py 英語 理科   # 教科を指定
```

単元を1本だけ確認用の PDF にする（出力は `textbooks/pdf/`、リポジトリには入れない）：

```bash
python3 textbooks/tools/build_pdf.py textbooks/eigo/U01-1_be動詞の文.md
```

形式の検査：

```bash
python3 textbooks/tools/check_units.py
```

- 単元の並び・タイトル：`tools/book_manifest.py`
- 執筆ルール（教科ごとの形式・部品・品質基準）：`tools/STYLE_GUIDE.md`
- デザイン：`tools/math.css`（算数・数学）、`tools/juku.css`（英・理・社・国）、`tools/book.css`（本の組み方）
