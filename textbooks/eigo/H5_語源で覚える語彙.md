# 発展英語 Unit H5「語源（接頭辞・接尾辞）で語彙を増やす」

<p class="lead">ねらい：長い単語を「接頭辞＋語根＋接尾辞」のパーツに分けて、意味と品詞を自分で組み立てられるようになる。1つの語根から何十語も覚え、初めて見る単語の意味を文脈と語源から推測する力をつける。　LEVEL 3〜4（高校・大学入試の語彙力への橋渡し。中学の Unit 6-1「品詞と文型」を使う）</p>

## 文法のポイント

<div class="memo" markdown="1">

**本質**　**長い単語は「パーツの組み立て」でできている**
英語の、学問やニュースで使う「かたい単語」の多くは、ラテン語やギリシャ語のパーツを組み合わせて作られています。レゴブロックと同じで、パーツを知っていれば、**初めて見る単語でも組み立て図が読める**のです。
　　un（〜でない）＋ believ（信じる）＋ able（〜できる）＝ unbelievable（信じられない）
単語を1語ずつ丸暗記すると、高校卒業までに必要な数千語はとても覚えきれません。でも、パーツを100個知っていれば、その組み合わせで何千語もの見当がつきます。暗記を「推理」に変えるのが、この単元の目標です。

</div>

<div class="point" markdown="1">

**POINT 1　単語の3つのパーツ ― 前は「意味を変える」、真ん中は「中心」、後ろは「品詞を決める」**

| パーツ | 役割 | 例：international |
|---|---|---|
| **接頭辞**（せっとうじ） | 単語の前について、**意味を変える**（否定・方向・時・数など） | **inter**（〜の間） |
| **語根**（ごこん） | 単語の**中心の意味** | **nation**（国） |
| **接尾辞**（せつびじ） | 単語の後ろについて、**品詞を決める** | **-al**（形容詞を作る） |

→ international ＝「国と国の間の」＝国際的な（形容詞）

<div class="ex" markdown="1">

**trans**（越えて）＋ **port**（運ぶ）＋ **-ation**（名詞）＝ transportation（輸送・交通機関）
**dis**（反対）＋ **agree**（賛成する）＋ **-ment**（名詞）＝ disagreement（意見の不一致）
**re**（再び）＋ **use**（使う）＋ **-able**（〜できる）＝ reusable（再利用できる）

</div>

**大事**：接尾辞を見れば、意味がわからなくても**品詞がわかる**。品詞がわかれば、文の中で S・V・O・C のどこに入る語か（＝文の骨組み）がわかる。

</div>

<div class="point" markdown="1">

**POINT 2　接頭辞の一覧** <span class="deru">入試</span>

| 接頭辞 | 意味 | 例 |
|---|---|---|
| **un-** | 〜でない・反対の動作 | unhappy（不幸な）／ unlock（カギを開ける）／ unknown |
| **in- / im- / il- / ir-** | 〜でない | incorrect ／ impossible ／ illegal（違法の）／ irregular（不規則な） |
| **dis-** | 〜でない・反対・はなれて | dislike ／ disappear（消える）／ discover（おおいを取る→発見する） |
| **mis-** | まちがって | mistake ／ misunderstand（誤解する） |
| **re-** | 再び・もとへ | rebuild ／ recycle ／ return（もとへ回る→帰る） |
| **pre-** | 前に・先に | preview（下見）／ prepare（前もって整える→準備する）／ predict |
| **inter-** | 〜の間 | international ／ interview（間で見る→面接）／ internet |
| **trans-** | 越えて・向こうへ | transport ／ translate（言葉を越えて移す→翻訳する） |
| **sub-** | 下 | subway（地下鉄）／ submarine（潜水艦） |
| **super-** | 上・こえて | supermarket ／ superstar |
| **ex- / e-** | 外へ | export（輸出する）／ exit（出口）／ eject（外へ投げる→放り出す） |
| **in- / im-**（入る） | 中へ | import（輸入する）／ input（入力） |
| **co- / com- / con-** | 共に | cooperate（協力する）／ connect ／ combine（組み合わせる） |
| **contra- / anti-** | 反対・対抗 | contradict（反論する）／ antivirus |
| **over- / under-** | こえすぎ／足りない・下 | overeat（食べすぎる）／ underground（地下の） |
| **uni- / bi- / tri- / multi-** | 1つ／2つ／3つ／たくさん | uniform ／ bicycle ／ triangle ／ multicultural |

</div>

<div class="point" markdown="1">

**POINT 3　否定の接頭辞の使い分け ― 次の文字で決まるもの** <span class="deru">入試</span>

| 接頭辞 | どんなとき | 例 |
|---|---|---|
| **im-** | p・b・m の前 | **im**possible ／ **im**patient（短気な）／ **im**balance ／ **im**mature（未熟な） |
| **il-** | l の前 | **il**legal ／ **il**logical（非論理的な） |
| **ir-** | r の前 | **ir**regular ／ **ir**responsible（無責任な） |
| **in-** | 上以外（主にラテン語系の語） | **in**correct ／ **in**complete ／ **in**dependent（独立した） |
| **un-** | 上以外（英語にもとからある語や -able など） | **un**happy ／ **un**comfortable ／ **un**kind |
| **dis-** | 動詞・名詞にもつきやすい | **dis**like ／ **dis**agree ／ **dis**honest |

**本質**：im- / il- / ir- は、もとは全部 in-。「インポッシブル」は言いにくいので、**次の音に合わせて口の形が変わった**（p・b・m は唇を閉じる音なので n → m）。「ルール」というより「発音のしやすさ」から生まれた変化なのです。

</div>

<div class="point" markdown="1">

| 語根 | 意味 | 例 |
|---|---|---|
| **port** | 運ぶ | import ／ export ／ transport ／ report（運び戻す→報告する）／ support ／ portable（持ち運べる） |
| **spect** | 見る | inspect（中を見る→検査する）／ respect（ふり返って見る→尊敬する）／ spectator（観客）／ expect |
| **vis / vid** | 見る | visit ／ vision（視力・未来像）／ visible（見える）／ video |
| **dict** | 言う | dictionary ／ predict（前もって言う→予言する）／ contradict（反対を言う→反論する） |
| **ject** | 投げる | project（前へ投げる→計画・映写する）／ reject（投げ返す→断る）／ object ／ inject |
| **duce / duct** | 導く | produce（前へ導く→生産する）／ reduce（減らす）／ introduce ／ conduct |
| **struct** | 積み上げる・建てる | structure（構造）／ construct（建設する）／ instruct（教える） |
| **mit / mis** | 送る | transmit（送信する）／ permit ／ submit（提出する）／ mission（使命） |
| **press** | 押す | express（外へ押し出す→表現する）／ impress（心に押しつける→感動させる） |
| **form** | 形 | inform（形を与える→知らせる）／ uniform（1つの形→制服）／ transform（変形させる） |
| **scrib / script** | 書く | describe（描写する）／ script（台本）／ subscribe |
| **tract** | 引く | attract（引きつける）／ tractor ／ subtract（引き算する） |
| **cept / ceive** | 取る | accept（受け入れる）／ receive ／ concept（概念）／ except |
| **vent / ven** | 来る | event ／ prevent（先に来る→防ぐ）／ invent（出会う→発明する）／ adventure |
| **fer** | 運ぶ | transfer（乗りかえる）／ prefer（〜のほうを好む）／ offer |
| **pose / pos** | 置く | position ／ propose（前に置く→提案する）／ expose（さらす） |
| **rupt** | 破る | interrupt（間を破る→さえぎる）／ erupt（外へ破れ出る→噴火する） |
| **aud** | 聞く | audience（聴衆）／ audio ／ audible（聞こえる） |
| **graph** | 書く・記す | photograph ／ autograph（自分で書く→サイン）／ biography（伝記） |
| **bio / geo / tele** | 生命／地球・土地／遠い | biology（生物学）／ geography ／ telephone ／ telescope（望遠鏡） |

</div>

<div class="point" markdown="1">

**POINT 5　接尾辞と品詞の一覧 ― 語尾を見れば品詞がわかる** <span class="deru">入試</span>

| 品詞 | 接尾辞 | 例 |
|---|---|---|
| **名詞**（こと・状態） | -tion / -sion | decide → decision ／ invent → invention ／ inform → information |
| | -ment | develop → development ／ agree → agreement ／ move → movement |
| | -ness | kind → kindness ／ happy → happiness ／ dark → darkness |
| | -ity / -ty | able → ability ／ possible → possibility ／ safe → safety |
| | -ance / -ence | important → importance ／ different → difference |
| **名詞**（人） | -er / -or / -ist / -ian | teacher ／ inventor ／ scientist ／ musician |
| **形容詞** | -ful（〜でいっぱい）／ -less（〜がない） | careful ⇔ careless ／ useful ⇔ useless ／ hopeful ⇔ hopeless |
| | -able / -ible（〜できる） | comfortable ／ reusable ／ visible |
| | -ous | danger → dangerous ／ fame → famous |
| | -al / -ic / -ive / -y | nature → natural ／ science → scientific ／ act → active ／ rain → rainy |
| **動詞** | -ize（〜化する） | real → realize ／ memory → memorize ／ global → globalize |
| | -en（〜にする） | short → shorten ／ wide → widen ／ strong → strengthen |
| | -fy（〜にする） | simple → simplify ／ class → classify |
| **副詞** | -ly | quick → quickly ／ careful → carefully ／ easy → easily |

- 品詞が変わるとき、**つづりが少し変わる**ものに注意：decide → deci**s**ion、happy → happ**i**ness、easy → eas**i**ly、science → scient**if**ic、strong → stren**gth**en。
- -ly がついても形容詞のものがある：friendly（親しみやすい）／ lovely ／ lonely。名詞＋-ly は形容詞になりやすい。

</div>

<div class="point" markdown="1">

**POINT 6　品詞変換は「文の骨組みの穴」を埋める作業** <span class="deru">入試</span>

同じ語根でも、**文のどの位置（S・V・O・C・修飾語）に入るか**で形が決まる。

<div class="ex" markdown="1">

They **decided** quickly.　　S＋**V**（動詞が必要）
Their **decision** surprised us.　　**S**＋V＋O（主語の位置 → 名詞）
They made a quick **decision**.　　S＋V＋**O**（a quick の後ろ → 名詞）
The goal was **decisive**.　　S＋V＋**C**（be動詞の後ろ、a/the なし → 形容詞）（そのゴールは決定的だった）

</div>

| 穴の位置 | 入る品詞 | 見分けるヒント |
|---|---|---|
| a / the / my / 形容詞 の後ろ、前置詞の後ろ | **名詞** | a quick **decision** ／ for your **kindness** |
| be動詞・become・look の後ろ（C）、名詞の前 | **形容詞** | It is **dangerous**. ／ a **dangerous** river |
| 主語の後ろ、to の後ろ、助動詞の後ろ | **動詞** | We should **protect** it. ／ to **simplify** it |
| 動詞を修飾、文の最後、形容詞の前 | **副詞** | She spoke **quickly**. ／ **really** big |

</div>

<div class="point" markdown="1">

**POINT 7　初めて見る単語を推測する4つの手順** <span class="deru">入試</span>

① **位置から品詞を決める**（POINT 6）。② **パーツに分ける**（接頭辞・語根・接尾辞）。③ **パーツの意味をつなぐ**。④ **文脈に入れて確かめる**（前後の文と矛盾しないか）。

<div class="ex" markdown="1">

The students left the room quietly so that they would not **interrupt** the speaker.
① would not の後ろ → **動詞**　② inter（間）＋ rupt（破る）　③「間に割りこんで破る」　④ 話し手の話を…→「**話をさえぎる・じゃまをする**」
（生徒たちは、話し手の話をじゃましないように静かに部屋を出た。）

</div>

④の確認がいちばん大事。パーツの意味は「方向」を教えてくれるだけで、**最後に意味を決めるのは文脈**です。

</div>

<div class="memo" markdown="1">

**注意**　語源が「わな」になる単語もある。
・**invaluable**：in（〜でない）＋ value（評価する）＋ able。「評価できないほど」→ **とても貴重な**（× 価値がない）。
・**understand** は under＋stand だが、「下に立つ」から今の意味は推測しにくい。
・**discover** の dis は「おおいを取る」の意味（cover を取る → 発見する）。「反対」だけではない。
だから手順④（文脈で確認）を飛ばしてはいけない。語源は**推測の出発点**であって、答えそのものではないのです。

</div>

<div class="memo" markdown="1">

**発展**　大学入試の長文では、知らない単語がいくつも出てくるのがふつうです。難関私立高校や国立大学の入試では、「下線部の語の意味に最も近いものを選べ」という**文脈からの語彙推測問題**がよく出ます。語源＋文脈の4つの手順は、そのまま使える武器になります。また、1つの語根を見たら、**仲間の語を3つ言う**クセをつけましょう（spect → inspect / respect / spectator）。これが語彙を何倍にも増やすいちばんの近道です。

</div>

## 解答・解説

<div class="kaito" markdown="1">

#### <span class="no">1</span>
(1) un＋happi＋ness「不幸」　(2) inter＋nation＋al「国際的な」
(3) trans＋port＋ation「輸送・交通機関」　(4) dis＋agree＋ment「意見の不一致」

#### <span class="no">12</span>
（解答例）語根 **spect**（見る）
① inspect ＝ in＋spect（中を見る→検査する）／ respect ＝ re＋spect（ふり返って見る→尊敬する）／ spectacular ＝ spect＋acul＋ar（見ものの→壮観な）
② Many people **respect** the doctor because she helps poor people.
③ 問題：The doctor is ( respect ) by many people.　→　答え：respected（受け身なので過去分詞）
　　別解の問題：She is a ( respect ) doctor.（形容詞にかえなさい）→ respected（尊敬されている）
**解説**　問題を作るときは、空所が「S・V・O・C のどこか」を自分で決めてから作ると、答えが1つに決まる問題になる。動詞の位置なら時制や受け身、名詞の前なら形容詞、と品詞と文型を組み合わせよう。
