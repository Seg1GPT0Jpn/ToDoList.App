# 発展英語 Unit H1「関係副詞・関係代名詞 what・非制限用法」

<p class="lead">ねらい：関係副詞 where / when / why / how を「前置詞＋which」から自分で導き、関係代名詞 what・前置詞＋関係代名詞・非制限用法（カンマ）を使いこなす。後ろが「完全な文」か「穴のある文」かで、関係詞を論理的に見分けられるようになる。</p>

<div class="memo" markdown="1">

**発展**　**LEVEL 4（高校内容への橋渡し）**　この単元は、高校の「英語コミュニケーションⅠ」「論理・表現Ⅰ」で学ぶ内容です。使う道具は、中学で習った**関係代名詞の主格・目的格（Unit 15-2・15-3）**、**5文型（Unit 11）**、**間接疑問文（Unit 16-1）**の3つだけ。新しい暗記はほとんどありません。「2つの文を1つにする」という関係代名詞の本質を、もう一歩先まで使いこなす単元です。難関私立・国立高校の入試では、which と where の選択、what の文の構造、カンマのある関係詞の訳し分けがよくねらわれます。

</div>

## 文法のポイント

<div class="point" markdown="1">

**POINT 1　復習：関係代名詞の後ろには「穴」がある**

関係代名詞は、2つ目の文の**名詞（主語や目的語）の代わり**になって前に出ます。だから、関係代名詞の後ろの文は、その名詞が**1つぬけた「穴のある文（不完全な文）」**になります。

<div class="ex" markdown="1">

a friend **who** ＿ lives in Canada　　← lives の**主語（S）**が穴（主格）
the book **which** I read ＿ yesterday　　← read の**目的語（O）**が穴（目的格）

</div>

- 「穴」があるかどうかは、**文型で確かめる**。read は「〜を読む」で O が必要（SVO）なのに O がない → 穴がある。
- この「穴チェック」が、この単元すべての見分けの道具になる。

</div>

<div class="point" markdown="1">

**POINT 2　前置詞＋関係代名詞　　the house in which I live**

2つ目の文で、同じものが**前置詞の目的語**になっているときは、次の2通りに作れる。

<div class="ex" markdown="1">

This is the house. ＋ I live **in it**.
→ ① This is the house **which** I live **in**.　　（前置詞を後ろに残す：話し言葉）
→ ② This is the house **in which** I live.　　（前置詞ごと前へ：書き言葉）
→ ③ This is the house I live **in**.　　（目的格なので省略もできる）
（これは私が住んでいる家です。）

The girl **with whom** I talked was Emi.　＝ The girl (who / that) I talked **with** was Emi.
（私が話した女の子はエミでした。）

</div>

- 前置詞の直後には **that は置けない**（× in that）。人なら **whom**（× with who）。
- ②の形では関係代名詞を**省略できない**（× the house in I live）。
- live は「住む」（SV）。live in the house で「その家に住む」なので、in を落とすと意味が通らない（× the house which I live）。

</div>

<div class="point" markdown="1">

| 先行詞 | 前置詞＋which | 関係副詞 | 例 |
|---|---|---|---|
| **場所**（the town, the park, the room など） | in / at / to which | **where** | the park **where** we played |
| **時**（the day, the year, the time など） | on / in / at which | **when** | the day **when** we met |
| **理由**（the reason だけ） | for which | **why** | the reason **why** he was late |
| **方法**（the way） | in which | **how** | **how** I solved it ／ **the way** I solved it |

- 関係副詞の後ろは、**穴のない完全な文**（I was born は受け身の SV で、もう何も足りない）。前置詞＋名詞（副詞のかたまり）が抜けても、文型はこわれないから。
- **the way how は×**。the way か how の**どちらか一方だけ**を使う。
- when / why / where は、先行詞を**省略**できることがある：That is **why** I was late.（そういうわけで遅れた）／ This is **where** I was born.（ここが私の生まれた所だ）<span class="deru">入試</span>

<div class="point" markdown="1">

**POINT 4　which か where か ― 先行詞ではなく「後ろの穴」で決める**　<span class="deru">入試</span>

先行詞が場所でも、**後ろに穴があれば関係代名詞**、**穴がなければ関係副詞**。

<div class="ex" markdown="1">

This is the town **which** I visited ＿ last year.　　← visit は「〜を訪れる」（SVO）。O が穴 → which
This is the town **where** I lived last year.　　← live は SV で完結。穴なし → where
Kyoto is a city **which** ＿ has many old temples.　　← has の S が穴 → which
Kyoto is a city **where** you can see many old temples.　　← you can see temples（SVO）で完結 → where

</div>

| チェック | 後ろの文 | 使う関係詞 |
|---|---|---|
| S か O（前置詞の後ろの名詞もふくむ）が足りない | **不完全な文**（穴あり） | 関係代名詞 who / which / that（前置詞＋which もここ） |
| 文型がそろっていて、何も足りない | **完全な文**（穴なし） | 関係副詞 where / when / why / how |

- 時も同じ：the day **when** we met（we met「私たちが出会った」で完結）／ the day **which** I will never forget ＿（forget の O が穴）。
- 注意：**前置詞＋which ＝ 関係副詞**なので、in which の後ろも**完全な文**になる。

</div>

<div class="point" markdown="1">

**POINT 5　関係代名詞 what ＝ the thing(s) which 「〜すること・もの」**

what は、**先行詞をふくんだ関係代名詞**。先行詞 the thing と which が1語に合体したもの、と考えます。

<div class="ex" markdown="1">

**What** I want ＿ is a new bike.　　＝ **The thing which** I want is a new bike.
［S：What I want］［V：is］［C：a new bike］ → **SVC**（私がほしいものは新しい自転車です。）
I believe **what** he said ＿.　　［S：I］［V：believe］［O：what he said］ → **SVO**（私は彼が言ったことを信じる。）
This is **what** I was looking for ＿.　　［S］［V］［C：what I was looking for］ → **SVC**（これが私がさがしていたものです。）

</div>

- what のかたまりは、文の中で**名詞**として働く（S・O・C になれる）。who / which のかたまりが名詞を説明する**形容詞**の働きなのとちがう。
- what の前に先行詞を置かない（× the thing what）。先行詞はもう中に入っているから。
- what の後ろも**穴のある文**（want の O が穴）。
- 疑問詞の what（間接疑問 Unit 16-1）とつづりは同じ。I don't know what he said. は「彼が何を言ったか」とも「彼が言ったこと」とも読める。**文の意味が自然になるほうで訳せばよい**。

</div>

<div class="point" markdown="1">

**POINT 6　非制限用法（カンマつき）＝「ちなみに」の追加説明**　<span class="deru">入試</span>

関係詞の前に**カンマ（,）**を置くと、先行詞を「しぼりこむ」のではなく、**ちなみに〜**と情報を**付け足す**意味になる。

<div class="ex" markdown="1">

My brother **who** lives in Osaka is a doctor.　　（制限用法）
→ 大阪に住んでいる兄は医者だ。　※兄が**2人以上**いて、「大阪の兄」をしぼりこんでいる。
My brother**, who** lives in Osaka**,** is a doctor.　　（非制限用法）
→ 兄は医者で、（ちなみに）大阪に住んでいる。　※兄は**1人**。

</div>

| | 制限用法（カンマなし） | 非制限用法（カンマあり） |
|---|---|---|
| 働き | 先行詞を**しぼりこむ** | 先行詞に**情報を付け足す** |
| 訳し方 | 後ろから「〜する…」 | 前から「…で、それは〜」「…だが、〜」 |
| that | 使える | **使えない**（× , that） |
| 省略 | 目的格は省略できる | **省略できない** |
| 先行詞 | 名詞 | 名詞、固有名詞、**前の文全体**（, which） |

<div class="ex" markdown="1">

I visited Nara**, where** I saw many deer.　（奈良を訪れて、そこでたくさんのシカを見た。）
We arrived on Monday**, when** it was raining.　（月曜日に着いたが、そのとき雨が降っていた。）
He said nothing**, which** made me angry.　（彼は何も言わず、**そのことが**私を怒らせた。）← which ＝ 前の文全体

</div>

- 固有名詞（Nara, Mt. Fuji など）は1つしかないので、しぼりこむ必要がない → **カンマつき**で説明する。
- why と how には非制限用法がない。

</div>

<div class="point" markdown="1">

**POINT 7　関係詞の見分け方 ― 3ステップ**

| ステップ | 見るところ | 判断 |
|---|---|---|
| ① 前に先行詞はある？ | 空所の直前 | **ない** → what（先行詞をふくむ）。ある → ②へ |
| ② 後ろは完全な文？ | 空所の後ろの文型 | **穴あり** → who / which / that。**穴なし** → where / when / why / how（または前置詞＋which） |
| ③ カンマはある？ | 空所の直前 | ある → that は使えない。訳は「…で、〜」 |

</div>

<div class="memo" markdown="1">

**本質**　**関係「代名詞」と関係「副詞」のちがいは、名前そのもの。**
代名詞は**名詞**の代わり → 名詞（S・O）が抜けるから**穴ができる**。
副詞は文型の要素（S・V・O・C）に**入らない**おまけ → 抜けても**文型はこわれない**。
だから「後ろが完全か不完全か」を見れば、品詞（名詞か副詞か）がわかり、正しい関係詞が選べるのです。暗記ではなく、**5文型と品詞から論理的に決まる**ことを覚えておこう。

</div>

<div class="memo" markdown="1">

**先生のひとこと**　関係詞の問題は「先行詞を見て選ぶ」と必ずひっかかります。場所の名詞が見えても、すぐに where に飛びつかない！ **空所の後ろに指をおいて、動詞が求めるもの（O や前置詞の後ろの名詞）がそろっているか**を確かめよう。それだけで、難関校の関係詞問題の8割は解けます。

</div>

(1) 私が知りたいのは、彼の電話番号です。（what）

#### <span class="no">13</span> 自分で問題を作ってみよう

次の(1)〜(3)にしたがって、「which か where かを選ぶ問題」を自分で作り、自分で解きなさい。
(1) 先行詞が**同じ場所の名詞**（例：the museum）で、which が正解になる文と、where が正解になる文を1つずつ作る。
(2) それぞれの答えの理由を、「後ろの文に穴があるか」という言葉を使って説明する。
(3) さらに、where の文を「前置詞＋which」の形に書きかえる。

#### <span class="no">1</span>
(1) This is the room in which my father works.
(2) Do you know the boy with whom Mika is talking?
(3) This is the pen which (that) I wrote the letter with.
(4) The hotel where we stayed was very nice.
**解説**　(2) 前置詞の直後なので who ではなく **whom**。(4) 主語の the hotel の直後に where 〜 を入れ、文の動詞 was はその後ろ。主語が長くなる型（Unit 15-2 POINT 4）。

#### <span class="no">2</span>

**解説**　(4) the way how は×。(8) 後ろの my sister was born は完全な文（受け身 SV）なので which ではなく when。

#### <span class="no">3</span>
(1) where　(2) which　(3) which　(4) where　(5) which　(6) when　(7) in which　(8) which

#### <span class="no">11</span>

(2) 私の祖母は、私が小さいころよく私をそこへ連れて行ってくれたのだが、私に本の楽しみ方を教えてくれた。

#### <span class="no">13</span>
(解答例)
(1) which の文：This is the museum (　) I visited last Sunday.　→ which
　where の文：This is the museum (　) I saw a famous painting.　→ where
(2) visit は「〜を訪れる」で O が必要なのに、後ろの文には O がない（穴がある）ので関係代名詞 which。I saw a famous painting は S・V・O がそろった完全な文で穴がないので、関係副詞 where。
(3) This is the museum **in which** I saw a famous painting.
**解説**　問題を作るときは、**同じ先行詞で後ろだけを変える**のがコツ。そうすると「先行詞では決まらない」ことがはっきりして、よい問題になる。
