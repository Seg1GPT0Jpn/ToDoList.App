# つづりクエスト3D

2D 版「つづりクエスト」（`../rpg_game_app`）とは**別のゲーム**です。2D 版のコード・保存データには一切触れません。

- タイトルの「冒険をはじめる」：400m 四方の **はじまりの大地**（村・森・草原・川と古橋・星見の山と遺跡・岩場の洞窟・石碑群）
- タイトルの「試作の草原（40m・確認用）」：最初の試作（平らな 40m の草原）。比べるために残している

- 3D 描画：flutter_scene 0.24.3（Android は Impeller＋Flutter GPU、Web は WebGL2）
- 物理・当たり判定：flutter_scene_rapier 0.5.2（Rapier）
- 問題データ・バトルの計算・経験値とレベル：共通のコア `../rpg_game`（2D 版と同じもの）
- セーブ：この端末だけ（`tq3d_progress_v1`・`tq3d_field_v2`（地域ごと）・`tq3d_learning_v1`・`tq3d_quality_v1`・`tq3d_bench_v1`）。クラウドには送らない
  - 古い `tq3d_field_v1`（試作の草原だけだったころ）は消さずに読み、試作の草原の続きとして引き継ぐ

## 操作
- PC：WASD／矢印で移動、Shift で走る、マウスのドラッグ・Q/E でカメラ、ホイールで距離、Space で話す・たたかう・しらべる、M で地図、Esc で戻る
- スマホ：左下のスティックで移動（端まで倒すと走る）、画面の右側をドラッグでカメラ、「はなす」「たたかう」「しらべる」ボタン、右上の小さな地図をタップで大きな地図

## はじまりの大地の流れ（第 1 章）
1. 村長ことのは（村の家の前）に話しかける → クエストが始まる。左上に「目的」と方角・距離、右上の地図に ★
2. 村の東の草原でスライムをたおす（歩き回り、近づくと追いかけてくる。ぶつかるとバトル。歩いて離れれば逃げられる）
3. メイン街道を北東へ。川辺の野営テント（S2）でしらべると記録（負けたときはここに戻る）
4. 古橋の手前で **古橋の番人**（ボス）。近づくと必ずバトル。勝つと橋をわたれる
5. 南東の石碑群で石碑をしらべる → 1 問に正解すると岩場の洞窟の封印がとける
6. 星見の登山道（坂 13.5 度・19.7 度）を登り、山頂の **遺跡の守護者**（ボス）をたおすと遺跡に入れる
7. 遺跡の祭壇をしらべると第 1 章クリア。東のゲートが開く（次の地域はまだない）
- 寄り道：森の古の大樹の宝箱、中腹の宝箱（1 問に正解で経験値）、森・草原・岩場の敵
- クエストは目的を達成したその場で達成になる（広い地図で村まで戻らなくてよい）
- 通れない場所：川（橋だけ）・森の奥（道と広場だけ）・山のふもとの崖（登山道だけ）・岩壁・山頂のふち
- 地図の設計：`docs/map_v2_1.md`

## 試作の草原の流れ
1. 案内人ノート（頭に「！」）に話しかける → クエストを受ける。画面左上に「目的」が出る
2. スライムとたたかう（下の「バトル」）。まちがえたら答えと解説を読んで「つぎへ」
3. 目的を達成すると「案内人ノートに報告しよう」になり、「！」が出る → 報告で経験値・称号
4. たおしたスライムは、復習の日が来ると（次の日以降）「復習スライム」として戻ってくる
5. メニュー（︙）の「冒険の記録」で、レベル・クエスト・称号・教科ごとの正答率・習得数・今日の復習を見られる

クエスト：冒険のはじまり → はじめてのバトル → 草原の見回り（称号）→ わすれたころの復習（称号）→ 知識の根っこ（10問習得・称号）。
「習得」は 2D 版と同じ基準（同じ問題に日をあけて正解を重ね、間隔反復の箱が 3 以上）。

## バトル（その場で戦う）
1. スライムに近づいて Space（スマホは「たたかう」ボタン）でバトル開始。画面は切りかわらない
2. 問題に答える（PC は 1〜4 キーかクリック）。制限時間あり
3. 正解すると 4 秒間「剣（えんぴつ）をふれる時間」。クリック／Space／J（スマホは右下の えんぴつボタン）でふる
   - 届く距離（2.4m）で当てると攻撃。答えてから当てるまでが速いとクリティカル
   - ふれずに時間切れ → ふり遅れ（ダメージ半分・反撃も半分）
   - 届かないときは近づいてもう一度ふれる
4. 不正解・時間切れは敵の体当たり（反撃）。あなたの答え・正解・解説が出て、「つぎへ」（Space）で進む
   - ヒントのある問題は「ヒント」（H）で見られる
   - 1問ごとに学習記録（tq3d_learning_v1）に残す。まちがえた問題・復習の日の問題ほど先に出る
5. 勝つと経験値・レベル（2D 版と同じ計算。保存は 3D 版だけ）。負けても正解したぶんの経験値は入る。
   Esc／「にげる」で離脱、遠くへ離れても離脱（にげたときは経験値なし）
6. 復習スライムは、復習の日が来た問題から出る。経験値は 2D 版の「練習」と同じ計算。その日のうちは二度は出ない

計算は rpg_game の BattleEngine。剣の流れは `lib/game/field_battle.dart`（単体テストあり）。

## 計測
右上に fps・平均と最大のフレーム時間・初回表示までの時間・メモリを常に表示する。
メニュー（︙）で画質を「高／標準／軽量」に切りかえられる（計測用）。
- メモリ：Android はアプリ全体の常駐メモリ（RSS）、Web は JS のヒープだけ（GPU のメモリは含まない）

### 自動計測（Android 実機の性能を測る）
メニュー（︙）→「自動計測（約54秒）」。さわらずに待つと、画質「高→標準→軽量」の順に
それぞれ 3 秒ならし＋15 秒計測（カメラが草原をひとまわり回る）して、結果を出す。
はじまりの大地では、画質ごとに見える距離も変わる（高 300m・標準 230m・軽量 150m。その先は霧）。

- 結果は画面のダイアログ（「コピー」でクリップボードへ）、ログの 1 行（`TQ3D_BENCH {...}`）、
  この端末の記録（メニュー「計測の記録」・最新 10 件・`tq3d_bench_v1`）に残る
- 計測中の画質は保存しない（終わるともとの画質にもどる）。「やめる」／Esc で中止
- 見方：
  - フレーム（画面の更新の間隔）：60Hz の端末なら平均 16.7ms・p95 が 20ms 以下ならなめらか。
    「カクつき(>33ms)」は 1% 未満がめやす
  - 描画（raster）・UI（build）：Flutter の FrameTiming。Android の profile／release で取れる。
    Web では WebGL の GPU 時間が入らないので参考にならない（フレームの間隔で見る）
  - メモリ：Android はアプリ全体（RSS）、Web は JS のヒープだけ
- debug ビルドの数値は参考値（結果に「debug（参考値）」と出る）。測るときは `--profile`

ログから結果だけ取り出す（PowerShell、実機をつないだまま）：
```
adb logcat -d | Select-String TQ3D_BENCH
```
