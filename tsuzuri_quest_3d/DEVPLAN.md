# つづりクエスト3D 開発計画（2026-10-17 更新）

次に作業する人（人・AI）が、ここから再開できるようにするメモ。

## 1. 構成

- Flutter（Dart 3.13 / Flutter 3.47）＋ flutter_scene 0.24.3（3D 描画）＋ flutter_scene_rapier 0.5.2（物理）
- 共通のコア `../rpg_game`（純 Dart）は読むだけ：問題データ・BattleEngine・Progression・LearningRecord／ReviewPlanner
- 画面：タイトル → フィールド（地域 2 つ：400m の「はじまりの大地」と、40m の「試作の草原」）
- 描画に依存しない部分は `lib/game/`（単体テストあり）、3D は `lib/field/`
- セーブは端末の中だけ（`tq3d_` で始まるキー）。ログイン・Firestore・課金は使わない
- 戦闘は「その場で戦う」方式（画面を切りかえない）。2D 版の戦闘画面は 2D 版のアプリの中にあり、3D 版からは使えない（2D 版を変えないため）

## 3. 確認したこと（2026-10-17）

- `flutter analyze`：問題なし
- `flutter test`：すべて成功（地形・道・通れる場所・敵の配置・敵の動き・クエスト・保存の引き継ぎ・バトル・計測・学習記録）
- `flutter build web --profile`：成功
- ヘッドレス Chrome（ソフトウェア描画・約 1fps。性能の数値は参考にならない）で確認：
  起動、地形の自己確認、村・橋・山道・山頂・森の宝箱・洞窟・石碑群の見た目、
  休憩地をしらべる、宝箱の 1 問（まちがい→解説）、追いかけてくる敵とのバトル開始、
  ボス（古橋の番人）が近づくと始まる、川岸で止まる、大きな地図、試作の草原がこれまでどおり動く
- **未確認**：Android（この環境に Android SDK がなく、ビルドも実機も試せていない）、実機と PC の fps、
  タッチ操作、いろいろな画面の大きさ、ボスに勝って橋をわたる・山頂まで登る通しプレイ
