第 2 版（400m×400m の SVG と配置表）を検算して見つかった矛盾を直し、実装した値。
**正しい値はコード** `lib/game/map_v2.dart`（地形・道・通れる場所）と
`lib/game/world_v2.dart`（人・敵・しらべる場所・出口）にあり、
`test/map_v2_test.dart` がこの文書の約束（道がつながる・坂がゆるい・敵が道をふさがない など）を確かめる。

座標：北西の角が (X=0, Z=0)、東が +X、南が +Z、Y が標高（m）。

## 決まっていなかったことの決め方

- **草原の起伏**：Y≈2.2m を中心に ±0.8m のゆるい波（傾き 3 度未満）。川の東は X=235→305 で 2.2m 上がる
- **森の通り道**：道（幅 4m）と隠し広場（半径 20m）だけ通れる。木は道から 2.5m 以上はなして植える
- **崖の上下の境目**：ふもとの崖は 4→12m（通れない）、踊り場 16m、山頂 28m。山頂のふち 2.5m は通れない
- **川岸**：中心から 10m までが水の下（川底 -2m）、10〜16m が岸のゆるい坂
- **T2・T4 の内部**：作らない（入口の演出まで）。洞窟は石碑のなぞを解くと封印がとける
- **G1〜G3**：次の地域は未実装。近づくと予告を出す（G1 は祭壇をしらべると「開いた」になる）
