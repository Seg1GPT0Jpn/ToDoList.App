## 動かし方

school_planner を開発している PC（Flutter が入っている PC）で次を実行します。

```
cd rpg_game_app
flutter pub get
flutter run -d chrome     # ブラウザで動かす（いちばん簡単）
flutter run               # Android の実機やエミュレーターをつないでいる場合
```

操作方法:
- **歩く**: 画面左下の十字ボタン（押している間歩き続ける）。PC では矢印キーか WASD キーでも歩けます
- **話しかける**: 敵や看板に向かって歩くと話しかけられます
- **バトル**: 4択をタップして回答します。制限時間を過ぎると時間切れです
- **最初からやり直す**: ワールドマップ右上の「︙」→「データをリセット」

## つづりクエスト 2.0 の追加機能

- **世界の物語**：6つの国の「知識の欠片」を集めると「世界の中心」がひらき、忘却の魔王（6教科の総合）と決戦（ホーム →「物語」）
- **マップ**：エリアの名前（「ばねの林」「助動詞の関所」など）から19種類の地形を決め、組み立て方も見た目もエリアごとに変える。隠し通路・知識の扉（問題で開く）・ワープ石・強敵・ボスの間
- **学力で世界が変わる**：熟練度の低い単元のエリアは暗く、上がると明るくなる。熟練度80以上で隠し通路がひとりでに開く
- **敵の能力とボスのルール**：防御型・妨害型・コンボ型・特化型など。強敵は3連続正解、ボスは5問中4問の試練、最後のボスは分野横断
- **カードとデッキ**：学習カード・コンボカードを追加。10枚のデッキを組む（おまかせ：バランス・攻撃・防御・苦手攻略）。ガチャはなし
- **学習ステータス**：実際の正答率から、分野ごとの熟練度・教科の学習Lv・総合力を表示（冒険Lvとは別）
- **復習の塔の階**：最近まちがえた／何度もまちがえた／苦手な分野／しばらく解いていない／忘れていそう／最上階の苦手克服ボス（10問中8問）
- **学習ナビ**：「今日のあなた」（教科の信号・気づいたこと・今日のおすすめ）。端末の中の記録から計算する（外部のAIは使っていない）
- **共通テスト遺跡**（5階層）：各階層は「ボスが重なる連戦」。前のボスが弱ると次のボスが乱入してきて、2体が重なって攻めてくる（HP は引き継ぎ）。上の階ほどボスが多い（2〜5体）。問題はすべてオリジナル
- **定期テストの海**：6教科を1つの試験ワールドにまとめ、航路のフィールドも作る。**船で大海原を進み、終盤は潜水艦で深海へ潜っていく**。敵は海の魔物（クラゲ・カニ・サメ・タコ・アンコウ・ダイオウイカ・海竜など8種）。試験日・あと○日・テスト対策ゲージ・今日のおすすめ
- **模擬試験の空**：定期テストの海と対になる、もっと難しい上級者向けモード。**飛行船で雲海を進み、終盤はロケットで宇宙へ**。敵は空の魔物（雨雲・カラス・雷・ワイバーン・隕石・UFO・天空の審判など7種）。2回まちがえると倒れる・制限時間は RPG の半分。範囲から作る「模試対策ワールド」と、制限時間つきで100点満点の「採点模試」もある
- **装備・職業・連続学習のごほうび**、**称号10個追加**、**図鑑から苦手な単元の練習へ**
- **Google ログイン**：手順は `docs/GOOGLE_LOGIN.md`

## Firebase につなぐ（友達に Web で遊んでもらう）

school_planner に組み込む前に友達に遊んでもらえるよう、このアプリだけで使う Firebase プロジェクトにつなげるようにしてあります。

- Firebase の設定がないとき（`lib/firebase_options.dart` が仮のまま）は、これまでどおり端末の中だけに保存します
- 設定すると、アカウント画面の「Google アカウントで登録」が本物の Google ログインになります
  - ログイン中は、冒険の記録（`users/{uid}/rpg_progress/main`）とプロフィール（`users/{uid}/rpg_profile/main`）が Firestore にも保存されます
  - 別の端末でも、同じ Google アカウントで登録すれば続きから遊べます（クラウドに記録があればそちらを使い、なければ端末の記録をクラウドに上げます）
- 個人用単語帳（LEAP）はクラウドに送りません。今までどおり端末の中だけです

### 手順（最初の1回だけ・PC で行う）

1. https://console.firebase.google.com で新しいプロジェクトを作る（例：`tsuzuri-quest`。Google アナリティクスは不要）
2. 「Authentication」→「始める」→「Sign-in method」で **Google** を有効にする（サポートメールに自分のアドレスを選ぶ）
3. 「Firestore Database」→「データベースを作成」。場所は `asia-northeast1`（東京）、モードは「本番環境モード」
4. PC にツールを入れてログインする
   ```
   npm install -g firebase-tools
   firebase login
   dart pub global activate flutterfire_cli
   ```
5. 設定ファイルを作る（`lib/firebase_options.dart` が本物に置きかわる）
   ```
   cd rpg_game_app
   flutterfire configure --project=tsuzuri-quest --platforms=web
   ```
   （プロジェクト ID `tsuzuri-quest` は `.firebaserc` に書いてあるので、`firebase use` は不要です）
6. セキュリティルールを反映する（本人だけが自分の記録を読み書きできるルール。`firestore.rules`）
   ```
   firebase deploy --only firestore:rules
   ```

### 公開する（更新するたびに行う）

```
cd rpg_game_app
flutter build web --release --pwa-strategy=none
firebase deploy --only hosting
```

（`--pwa-strategy=none` は、古い版がブラウザに残って更新が反映されない問題を防ぐための指定です）

表示される `https://tsuzuri-quest.web.app` を友達に送れば、スマホ（iPhone も可）や PC のブラウザで遊べます。

メモ:
- `lib/firebase_options.dart` の中身は秘密の情報ではありません（Web アプリの識別子です）。データはセキュリティルールで守っています。コミットしてかまいません
- 公開版（`flutter build web --release`）では購入ボタンが使えません。有料の5教科（理科・社会・国語・数学・情報）は、**プロモーションコード**を入力した人だけが受け取れます（下の「プロモーションコード」）
- Android アプリ（Pixel など）で Google ログインを使う手順は、`docs/GOOGLE_LOGIN.md` にまとめました（署名の SHA-1 の登録もふくみます）

## プロモーションコード

本物の決済（Google Play Billing）ができるまでは、有料の5教科をプロモーションコードで配ります。

- ワールドマップ右上の「︙」→「プロモーションコード」か、ロックされたワールドをタップ →「コードを入力」から入力します
- 正しいコードを入れると、理科・社会・国語・数学・情報をまとめて受け取れます（英語はもともと無料）
- 受け取った状態は進行状況に保存され、Google で登録していればほかの端末にも引きつがれます
- コードはソースにも README にも書いていません。ハッシュ値だけを `rpg_game/lib/src/purchase/promo_code.dart` に置いています
  - コードを変えるときは、`sha256("tsuzuri-promo:" + 新しいコード)` を計算して `_allSubjectsHash` を書きかえます
- 5回まちがえると30秒待たないと入力できません
- ただしブラウザの中で照合しているので、詳しい人が本気で調べれば破れます。友達に配る範囲の鍵だと考えてください（本格的に売るときは、サーバー側の検証と本物の決済にします）
- 開発中（`flutter run` のデバッグ版）だけは、これまでどおりダミー購入と「エリアを選んでバトル（確認用）」が使えます

## 定期テストの海（学習モード）

ワールドマップ上部の「定期テストの海」から入ります。**単元を選ぶと、海の魔物とのバトルになります**（「単語帳練習」タブだけは、バトルではなく単語帳の練習）。

難易度はとても高く設定しています（`SeaBattle`）。
- 敵の HP は、ふつうの正解（チェイン・クリティカルなし）で約15回ぶん
- 3回まちがえると、ほぼ倒れる
- 制限時間は RPG の約6割
- 強さはプレイヤーのレベルに合わせて決まるので、レベルを上げても楽にはならない
- RPG の進行や経験値は変わりません。単元ごとに正答率の自己ベストが記録されます

問題を増やした範囲（おおむね2〜2.5倍）:
- 英語：高1の全単元と、高2の「分詞構文」までの単元（1単元 6〜9問 → 16〜21問）
- 数学Ⅰ・数学A（各エリア 10問 → 20問）
- 生物基礎・化学基礎（各エリア 16問 → 32問）
- 地理、政治・経済の政治分野（各エリア 12問 → 24問）
- 古文・漢文（各エリア 12問 → 24問）

画面上部のチップで教科（英語・理科・社会・国語・数学・情報）を選びます。英語は下の表のタブ、ほかの教科はルート（物理・日本史・古文・数学Ⅱ など）ごとのタブに、エリアの一覧が並びます。英語以外の教科は、RPG でそのワールドを解放すると使えるようになります。

英語のタブ:

| タブ | 内容 |
| --- | --- |
| 高1 | 12単元（文型・時制・助動詞・不定詞・動名詞・分詞・受動態・比較・関係詞・仮定法・接続詞・代名詞など）各8〜9問 |
| 高2 | 12単元（完了・助動詞+完了・分詞構文・関係詞/仮定法/比較の発展・否定・倒置・名詞節・複雑な構文）各6問 |
| 高3 | 9単元（高度な関係詞・仮定法・倒置・省略・強調/挿入/同格・複雑な分詞構文/不定詞/時制・構文）各6問 |
| 単語・熟語 | 単語（基礎・標準・難関）と熟語、各40語。英→日／日→英、1回20問 |
| 単語帳練習 | 忘却曲線（FSRS）で出題日を決める単語帳。LEAP・EEVI（名前とパスワードで開く）と自作の単語帳。下の「単語帳練習」を参照 |

- 単元ごとの最高正答率が記録され、一覧に表示されます
- 結果画面から「間違えた問題だけもう一度」を選べます
- 問題はすべて自作です。LEAP・STEP（EEVI）の単語は、暗号化したもの（`assets/vocab/`）だけを同梱しています。平文の一覧もパスワードも GitHub には置いていません。ゲームの問題には使いません

#### 単語帳練習

- **単語帳**：LEAP・EEVI（名前とパスワードを入れると、取り込まずにすぐ使える）と、自分で作る単語帳（英検・学校のテスト範囲・模試で間違えた単語など）。
  - LEAP・EEVI は PBKDF2-HMAC-SHA256 で作った鍵で暗号化して同梱し、名前とパスワードが合ったときだけ開きます。作り直すときは `rpg_game/tool/vocab_seal.dart <名前> <パスワード> <一覧.txt> ../rpg_game_app/assets/vocab`（平文の一覧はコミットしない）。
- **取り込み**：LEAP の「番号・単語・意味」の一覧、STEP の「番号／単語／■品詞：意味」の一覧、Excel の表のコピー、CSV（見出し term, meaning, pron, example, translation）をそのまま貼り付けられます。同じ単語があれば、例文や発音記号の空いている所だけ埋めます。
- **AI で作る**：「たのみ方をコピー」で、プリント・PDF・写真から品詞・発音記号・例文・訳つきの CSV を作ってもらう文章をコピーできます（Claude や ChatGPT に資料と一緒に送り、返ってきた CSV を貼り付ける）。
- **FSRS（v4.5）**：単語 × 力ごとに「安定度」と「難しさ」を持ち、「忘れた／難しかった／まあまあ／簡単だった」で次の出題日を決めます。忘れた単語はその回の最後にもう一度出ます。
- **力ごとの熟練度**：意味（英→日）・想起（日→英）・スペル・発音（聞く）・例文（文脈）を別々に測ります。3回続けて思い出せて、安定度が7日以上になるまで「習得」にしません。
- **出題形式**：フラッシュカード、4択（英→日・日→英）、スペル入力、リスニング、例文穴埋め、似た単語の比較。覚えはじめは4択（認識）、覚えてきたらカード（想起）、そのあとスペル・例文（運用）へ進みます。
- **間違えた理由**：意味・スペル・似た単語との混同・発音・文中、から選ぶと、その力を重点的に出します。混同した単語は比較問題になります（affect / effect など、似たつづりも自動で見つけます）。
- **今日の最適学習**：忘れかけた順の復習 → 比較問題 → まだ練習していない力 → 新しい単語（1日の数は変えられます）。
- **分析**：弱点・あやふや・安定の数、今日の復習予定、連続日数、1週間の学習時間と正答率、今週最も間違えた単語、忘れやすい単語、混同した組。
- **コース**：100語ずつの Week に分け、「使える単語」の数で進み具合を表示します。
- **発音**：端末の読み上げで単語・例文を読みます（米音・英音、速さを変えられます）。
- **保存**：単語帳も学習記録も端末の中だけ（オフラインで使えます）。別の端末へはバックアップのコピー／読み込みで移します。LEAP・EEVI の単語はバックアップに入りません（移す先でも名前とパスワードで開けます）
- 取り込んだ単語帳の問題は、RPG のバトル・宿・課金ワールドでは使えないようにしています
- パスワード（仮）は `lib/study/personal_books.dart` の `leapPassword` です。アプリの中に書かれた合言葉なので、強い保護ではありません

## 物語

冒険の手帳の「物語」から、いつでも読み返せます（物語の回想）。

- 記憶をなくした「しおりの精」しおりと旅に出る。行く先々で、仮面の少年ノイズが「どうせ覚えても、すぐ忘れる」と立ちはだかる
- 国ごとに守り人がいる（言葉の女王リリカ・ことわりの博士ニュート・年代記の長老クロノ・歌よみのことは・設計士ユークリ・通信士ビット）
- 場面は全部で21：序章、6つの国それぞれの「導入・最後のボスの前・欠片を取りもどしたとき」、終章、エピローグ
- 国に入ったとき・国の最後のボスに挑む前・欠片を取りもどしたあとに、まだ読んでいない場面が自動で流れる（絵本のような画面。文字送り・スキップつき）

## バトルの新しい要素

- **必殺技ゲージ**：正解するとたまる（すばやい正解はもっとたまる）。満タンで「必殺技！」を構え、次の問題に正解するとダメージ2.5倍。まちがえると空振りでゲージがなくなる
- **今日の挑戦状**：クリアしたエリアから、毎日1体、強化された魔物が現れる（能力は日替わり）。たおすと経験値3倍（1日1回）。冒険の手帳から挑む
- **バトルの舞台**：地形ごとの背景（空・遠景・舞う粒）。ボス戦は赤い光。当たると火花、クリティカルは白く光る。勝つと紙吹雪

## 対戦モード（早押しクイズ）

冒険の手帳の「対戦モード」から入ります。先に正しく答えた人が相手にダメージを与えます。
- はやく答える（制限時間の3割以内）とボーナス、続けて正解するとさらにダメージアップ
- まちがえると「お手つき」：自分に少しダメージ。その問題は相手だけが答えられる
- どちらかの HP が 0 になるか、問題数（10・15・20）を使い切ったら決着

| 相手 | 遊び方 |
| --- | --- |
| CPU | かんたん・ふつう・つよい・達人の4段階。強いほど正確で速い |
| この端末で2人 | 画面を上下に分け、上の人の側はさかさまに表示。机に置いて向かい合って遊ぶ |
| オンライン | 4けたの部屋番号で、ほかの端末の人と対戦。**2人とも Google でログイン**が必要 |

オンライン対戦を使うには、Firestore のルールをもう一度公開してください（`versus_rooms` の部屋を読み書きできるようにしました）。
```
cd rpg_game_app
firebase deploy --only firestore:rules
```
しくみ：2人とも同じ問題・同じシードから対戦を組み立て、答え（出来事）を Firestore の部屋に順番に書きこみます。書きこむときはトランザクションで「その問題にまだ答えられるか」を確かめるので、同時に押しても先に届いた1人だけが通ります。

## 模擬試験の空（上級の学習モード）

ワールドマップの「模擬試験の空」（または冒険の手帳の「模擬試験の空」）から入ります。定期テストの海と同じつくりで、さらに難しくしています（`StudyRealm.sky`）。

| | 定期テストの海 | 模擬試験の空 |
| --- | --- | --- |
| 乗り物 | 船 → 終盤は潜水艦（深海） | 飛行船 → 終盤はロケット（宇宙） |
| 敵を倒すのに必要な正解 | 約15回 | 約16回 |
| 何回まちがえると倒れるか | 3回 | 2回 |
| 制限時間 | RPG の約6割 | RPG の半分 |

- 教科（6教科）を選ぶと、ルート（英語は地方）ごとに単元が並びます。単元を選ぶと空の魔物とのバトル
- 右上の「模試対策」で、範囲から航路のワールドを作れます（作り方は試験対策ワールドと同じ）
- 右上の ⏱ で「採点模試」：制限時間の中で教科を順に解き、100点満点で採点して弱点を出します
- 自己ベストは海とは別に記録します

## 試験対策ワールド（定期テストの海）

定期テストの海の右上「試験対策」から入ります。試験範囲を入力すると、その範囲のエリアを集めた1本道のワールドを自動で作ります。

1. 教科を選ぶ（有料の教科は、RPG でワールドを解放すると使える）
2. 試験の名前と、試験範囲を入力する（例：`2次関数、三角比、データの分析`）
3. 「範囲から探す」を押すと、単元名・場所・分野名に範囲の言葉が入っているエリアが選ばれる。一覧のチェックで足したり外したりできる（最大60エリア）
4. 「ワールドをつくる」で完成。選んだエリアが順に並び、最後に範囲全部から出題する「試験本番」のボスがいる

- フィールドは航路になります。船で大海原を進み（島・岩礁・うずしお・ブイ）、全体の4分の1ほどの終盤は潜水艦で深海へ潜っていきます（サンゴ・海藻・海溝・いかり）。深海に入ると「潜水艦に乗りかえた！」の演出が出ます
- 敵は海の魔物で、前半は大海原の魔物、終盤は深海の魔物、最後の「試験本番」は範囲の海竜リヴァイアサン

- 前のエリアをクリアすると次に進めます。敵の強さはワールドの中の順番で決まるので、どの範囲でも少しずつ強くなります
- 定期テストの海と同じく、とても難しい強さで戦います。RPG の進行・経験値には影響しません（練習用）。何度でも挑戦できます
- 問題は RPG と同じ自作問題です。作ったワールドは端末の中に保存されます
- 「二次関数」と「2次関数」、全角と半角のちがいは同じものとして探します

## 20エリアと地方

フィールドは下から草原（エリア1〜5）→ 海岸（6〜10）→ 洞窟（11〜15）→ 溶岩（16〜20、四天王とラスボス）と続きます。地方ごとに床・壁・木・水の見た目が変わり、画面上部に今いる地方が表示されます。

マップは各エリア 31×9 マスの広い部屋です（`field_map.dart`）。
- 木立・岩場・池は、ランダムに置いた障害物をならして自然な形にしている（シード固定なので毎回同じ形）
- ゲートの位置はエリアごとに左右にずれ、入口から出口まではくねくねした道がかならずつながる
- 入口の近くに宿、一番奥の行き止まりに宝箱、道の途中に泉がある
- 亡霊を置いても道がふさがらないマスをあらかじめ調べておき（`safeCells`）、テストで確認している

ワールドマップ右上の「︙」→「エリアを選んでバトル（確認用）」から、好きなエリアの敵とすぐに戦えます（結果は保存されません）。

## 理の国（理科）

ワールドマップで「理の国」をタップすると、ダミー購入のあと遊べます。

- スタート地点「はじまりの実験広場」には、上下左右に出入口があります。上＝物理、左＝化学、右＝地学、下＝生物です
- 出入口をくぐると、その系統のマップに移ります。マップの向きも道の向きに合わせてあり、化学は左へ、地学は右へ、生物は下へ進みます。帰り口からは広場に戻れます
- 各系統は16エリアです。エリア1〜8が基礎、9〜16が発展科目で、エリア8と16にボスがいます
- 選択肢が長い問題は、全文が読めるように縦に並べて表示します
- 確認用のバトルは「︙」→「エリアを選んでバトル」から、教科 →（理科なら系統）→ エリア の順に選びます

## 時と地の国・言の葉の国・数理の国・情報の国

理の国と同じく、広場（スタート地点）から門を通って各ルートのマップに入ります。広場の看板に、どの門がどのルートかが書いてあります。

| --- | --- | --- |

| 言の葉の国（国語） | 言の葉の広場 | 上＝現代文、左＝古文、右＝漢文 |

| 情報の国（情報） | （ルートが1本なので広場はなし） | — |

- 宿の授業は、英語と理科は手書きの授業、ほかの教科はそのエリアの問題から要点を3つ取り出して表示します
- 確認用のバトルは「︙」→「エリアを選んでバトル」から、教科 → ルート → エリア の順に選びます

## ユーザー名と Google アカウント

- 初めて起動したときに、ユーザー名（1〜12文字）を登録します。ワールドマップの上に表示されます
- ワールドマップ右上の「︙」→「アカウント」で、ユーザー名の変更と Google アカウントの連携・解除ができます
- Firebase を設定すると本物の Google ログインになります（`lib/cloud/`）。設定していないときはダミーです（メールアドレスを入力すると連携したことになります）

## 宿（RPG）

20のエリアすべてに宿（屋根の赤い家）があり、話しかけると次の敵の文法テーマの授業を受けられます。授業のあとに練習問題が5問あり、正解1問につき 2 EXP もらえます。何度でも受けられます。

## 学びの記録・復習の塔・図鑑・実績（進化計画 PHASE 1〜5）

設計の全体は [`docs/EVOLUTION.md`](../docs/EVOLUTION.md) にあります。

| 機能 | 内容 |
| --- | --- |
| 学習記録 | 問題ごとに正誤・連続正解・かかった時間を記録（ライトナー式の箱 0〜6）。3回続けて正解で「習得」 |
| 適応出題 | 苦手な問題・復習の日が来た問題ほど出やすく、習得した問題はたまにしか出ない（完全には消えない） |
| 復習の塔 | ホームの「復習の塔」。まちがえた・復習の日・時間がかかった・ひさしぶり の問題だけで戦う。10問正解ごとに1階上がり、5階ごとに番人 |
| 教科レベル | 教科ごとの習得数でレベルが上がる（ホームの冒険の手帳に表示） |
| 冒険の手帳（ホーム） | 称号・連続日数・次の目標（1つだけ）・今日のクエスト3つ（達成すると EXP を受け取れる） |
| 魔物図鑑 | 24種族。出会うと姿、倒すと性格・攻撃・説明が見える。レア度は色と★の数 |
| 実績・称号 | 22の実績。解除した実績は称号として名前の横に出せる |
| BGM・効果音 | すべてプログラムで合成したオリジナル（`tools/audio/`）。教科ごとのフィールド曲、ボス登場の演出 |
| 学ぶほど曲が完成する | バトル曲はピアノ・ベース・打楽器・ストリングスの4パート。正解を続けるとパートが増え、まちがえると1つ減る |
| 設定 | BGM・効果音のオン/オフと音量、文字の大きさ（3段階）、動きをへらす |

- 学習記録には問題 ID と数値だけが入ります。個人用単語帳（LEAP など）の問題は記録しません。
- Google でログインしていると、学習記録（`rpg_learning`）と冒険の記録（`rpg_journal`）もクラウドに保存されます。
  **`firestore.rules` を更新したので、`firebase deploy --only firestore:rules` をもう一度実行してください。**
- ブラウザは画面に一度さわるまで音を出させてくれないので、最初のタップで BGM が始まります。

## 敵のデザイン（文房具モンスター）

敵は「ノートの世界」に合わせた文房具のモンスターです。すべてコード（`lib/art/enemy_painter.dart` と `stationery_painter.dart`）で描いていて、待機中はそれぞれ動きます。

- 消しゴム：消しカスを飛ばす
- 鉛筆：削られて短くなった「老兵」もいる
- シャーペンロボ：ノックすると芯がのびる
- 定規、三角定規、分度器、コンパス（2本の脚で歩く）
- ページャー（紙）、教科書（ページを翼にして飛ぶ）、バインダーゴーレム
- ボールペン、蛍光ペン（ペン先が光る）
- 付箋（「！」を出す）、ホッチキス（口をぱくぱく）、はさみ、クレヨン
- これまでのスライム・ゴブリン・コウモリ・ゴーレム・騎士・ドラゴンも、名前に合う敵にだけ残しています

となりのエリアに同じ形の敵が来ないことと、1本の道に同じ形が3体までであることは、テストで確認しています。

## アプリのアイコンとスマホで動かす方法

アイコンは `assets/icon/app_icon.png` です。そこから次のアイコンを作ってあります。
- Android のランチャーアイコン（`mipmap-*`、Android 8 以降のアダプティブアイコン）
- Web（PWA）のアイコンとファビコン

アプリ名は「つづりクエスト」です。

Android スマホで動かす手順：
1. スマホの「開発者向けオプション」で「USB デバッグ」をオンにして、PC と USB でつなぐ
2. `flutter devices` でスマホが表示されることを確認する
3. `flutter run --release` で、スマホにインストールして起動する

APK ファイルを作ってスマホに送る方法もあります。
1. `flutter build apk --release` を実行する
2. `build/app/outputs/flutter-apk/app-release.apk` をスマホにコピーして開く

iPhone 用のビルドには Mac が必要です。

## school_planner に組み込むときの注意

- UI はこの試作では `package:flutter/material.dart` を使っています。school_planner では `material_ui` パッケージと既存の `lib/app/theme.dart` に合わせて書き換えます
- 保存先（`PrefsProgressRepository`）は、Firestore の `users/{uid}/rpg_progress/main` を読み書きする実装に差し替えます
- 単体版の同期（`lib/cloud/cloud_sync.dart`）は school_planner と同じパス（`users/{uid}/rpg_progress/main`、`users/{uid}/rpg_profile/main`）を使っています。組み込むときは、school_planner の Firebase プロジェクトと Firestore の仕組みに合わせます
- 準備中ワールドの購入ダイアログは、デバッグ版でだけ「購入する」ボタンが出ます（ダミー購入）
- マップの形は `lib/field/field_map.dart` の文字の並びで決まります。敵の配置と進行順がおかしくないかは、テスト（`test/field_map_test.dart`）で自動チェックしています
